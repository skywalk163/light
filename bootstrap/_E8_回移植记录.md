## 2. 批次 1：⑨列表弹栈 + ④转字符串（最小批，单元探针已依赖）

### 改了什么
在 `bootstrap_level6.light` 的 `段落 建 接收 t, v` 之后，按 **level6 无冒号纯缩进方言**新增两个 helper（**非 Python 字节回填**，逐字用 level6 语法重写）：

```
段落 列表弹栈 接收 lst
    如果 列表长度(lst) 大于 0
        lst.pop()

段落 转字符串 接收 v
    返回 str(v)
```

语义对齐 `level7_generated.py`：
- `列表弹栈`：长度守卫下的 `lst.pop()`（与 level7 `def 列表弹栈` 等价）。
- `转字符串`：`str(v)` 封装（level7 同名函数即 `return str(v)`）。

**本批未接线到 codegen**——仅作为自包含 helper 定义落地。接线属后续 gap 批：
- `列表弹栈` → 接 `扫` 的缩进栈（gap ②，与 E.7 同域）；
- `转字符串` → 接拼接/类型检查发射 codegen（gap ③/④）。

## 4. 下一批建议

剩余代差（按 `_P_27KB外壳溯源.md` §3.3 优先级）：

1. **【最急】gap ② 缩进/DEDENT 机制 + ⑤ 编译错误异常**（与 E.7 块边界同域）。
   - 本批已就位的 `列表弹栈` 可**立即接线进 `扫` 的缩进栈**（替换宿主注入依赖），是 ② 的最小切入点；⑤ 需新增 `class 编译错误(Exception)` 并接 `扫`/`解析` 的越界报错路径。
2. **gap ③ 类型检查发射**：接线 `转字符串` + `生成类型检查代码` 进赋值 codegen（当前类型检查开启=假，已有 `开启/关闭类型检查` 关键字桩，缺发射体）。
3. **gap ⑥ 反引号转义**：接线 `字符串` 扫描（`` `关键字` `` 强制作标识符）。
4. **gap ⑦ 最长匹配**：接线 `扫` 的关键字分词（贪心字符位匹配）。
5. **gap ⑧ 编译单行块**：接线 parser（`段 foo 接收 a: 返回 a` 式单行块）。

**风险提示**：②⑤③⑥⑦⑧ 均须**改 codegen / 扫描逻辑**（非纯 helper 定义），风险显著高于批次1。每批仍须保留「三阶段阶梯 + 自包含性 + 4 护栏」一证，且建议每批改**单一机制点**后先做该机制的小范围单测，再入阶梯。
