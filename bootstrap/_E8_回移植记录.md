### 6.1 改了什么（全部按 level6 无冒号纯缩进方言重写，非 Python 字节回填）

**⑥ 反引号转义标识符**（接 `扫` 的行内字符循环）
- 在 `"` 字符串分支之后新增 `` ` `` 分支：遇反引号则跳过首符、逐字符收集到下一个 `` ` ``，发射 `建("ID", name)`。
- 未闭合分支因 gap ⑤ `编译错误` 尚未并入，做优雅兜底（收集到 EOF 即发射，不抛错）——level6 源自身 0 反引号，该路径永不触发。
- 功能实证：out2 词法 `设 `如果` 为 1` → `['ID','如果']`（关键字被强制作标识符，不再切 KW）。

**⑦ 最长匹配（贪心字符位关键字分词）**
- 新增 `段落 最长匹配 接收 src, p, n` helper（对齐 level7 `def 最长匹配`：遍历 `关键字列表()`，取最长可匹配关键字，返回 `列表创建(是否命中, KW, 长度)`）。
- 接入 `扫` 的 CJK 分发（`c 大于等于 "一"` 分支）：先 `最长匹配`，命中后做**保守词界保护**——若命中点后一字符仍是 `_`/a-z/A-Z/中文，则放弃贪心、退回整词 `词()` 读。这保证了 `列表获取(x,0)` 仍整体作 ID（不会被切成 KW`列表`+ID`获取`），而独立关键字 `如果`/`大于` 照常切 KW。
- 功能实证：`如果 a 大于 0` → KW如果/IDa/KW大于/NUM0；`列表获取(x,0)` → ID 列表获取（整词）。

**⑧ 编译单行块**
- 新增 `段落 编译单行块 接收 toks, p, indent` helper（对齐 level7：向后扫到下一个 NEWLINE/DEDENT，对区间跑 `compile_block`，空则补 `indent+"pass\n"`，返回 `(body, end_p+1)`）。
- 在 `comp_if` / `comp_while` / `comp_for` 条件表达式之后各加一个单行分支：条件后紧邻 token 不是 NEWLINE 则走 `编译单行块` 并提前返回；否则走原有多行（NEWLINE+INDENT+find_matching_end）路径。
- 功能实证：out2 编译 `如果 x 大于 0 返回 x` → `if x > 0:\n    return x`（AST OK）。

**本批踩到的坑（留档）**：首个版本把保护标志变量命名为 `词界通过`，其中 `过` 是关键字列表里的单字关键字，被宿主编译器的词内关键字边界切分拆成 `词界通`+KW`过`，导致发射码 `if after_c == '_':` 函数体为空、IndentationError。改名为不含任何关键字子串的 `词界放行` 后通过。**教训：新增中文标识符不得包含任何关键字（尤其单字关键字 段/过/返/接/承/出/导/自/类/在 等），否则会被 level7 宿主切词误伤。**
