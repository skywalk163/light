# 光明自举编译器 bootstrap_level5.light 缺失功能分析报告

> 分析日期：2026-08-11
> 分析对象：bootstrap_level5.light（Level 4，1623行，47个段落/函数）
> 目标：Level 6 → Level 8 完全自举

---

## 一、总体概述

`bootstrap_level5.light` 当前标记为 Level 4，实际功能覆盖了：
- Level 4 基础：词法分析、表达式解析、控制流（if/while/for）、异常（try/catch/finally）、类定义与继承、函数定义
- 部分 Level 5：导入/导出关键字识别（但只是跳过，无实际模块解析）

**bootstrap_level6.light** 已存在（由 `convert_to_level6.py` 从 Level 5 自动转换生成），但仅做了语法转换（移除`结束`/`：`/`。`，调整缩进），**并未增加新功能**。

**level7_generated.py** 已存在，是 Level 7 的 Python 生成版本，包含了类型注解等完整功能。

---

## 二、词法分析器缺失功能

### 2.1 无空格分词（Level 6 核心）

| 当前状态 | 目标状态 |
|---------|---------|
| 需要空格分隔：`设 x 为 10` | 无空格：`设x为10` |
| 简单字符级扫描 | 最长匹配（Longest-match）多字符关键字 |

**具体缺失：**
- `最长匹配` 函数（level7_generated.py 第1944行有实现，但 Level 5 中没有）
- 多字符关键字的优先级匹配算法
- 关键字列表需要扩展（包含 `开启类型检查`、`关闭类型检查` 等长关键字）

### 2.2 NEWLINE / INDENT / DEDENT 令牌（Level 6 核心）

| 当前状态 | 目标状态 |
|---------|---------|
| 无 NEWLINE 令牌 | 生成 `NEWLINE` 令牌 |
| 无 INDENT/DEDENT | 生成 `INDENT` / `DEDENT` 令牌 |
| 用 `结束` 关键字标记块结束 | 用缩进级别标记块结构 |

**具体缺失：**
- `扫` 函数中未处理 `\n` → 需要生成 `NEWLINE` 令牌
- 缺少缩进栈管理（跟踪缩进级别变化）
- 缺少 `find_block_end` 函数（level7_generated.py 第626行）
- 缺少 `编译单行块` 函数（level7_generated.py 第1988行）

### 2.3 运算符符号支持（Level 6 / P3 特性）

**当前**：仅支持中文运算符关键字 `加` `减` `乘` `除` `取模`
**目标**：同时支持符号运算符 `+` `-` `*` `/` `%` `==` `!=` `<` `>` `<=` `>=`

**具体缺失**（在 `扫` 函数中需要新增）：
- `+` → `加` 的符号形式
- `-` → `减` 的符号形式
- `*` → `乘` 的符号形式
- `/` → `除` 的符号形式
- `%` → `取模` 的符号形式
- `==` → `等于` 的符号形式
- `!=` → `不等于` 的符号形式
- `<` → `小于` 的符号形式
- `>` → `大于` 的符号形式
- `<=` → `小于等于` 的符号形式
- `>=` → `大于等于` 的符号形式

### 2.4 反引号转义标识符（Level 6 / P3 特性）

**缺失**：\`关键字\` 语法，允许将关键字作为标识符使用
- 需要新增 `反引号标识符` 令牌类型
- 需要反引号闭合检测
- 如 `` `真` ``、`` `类` ``、`` `如果` ``

### 2.5 制表符检测（Level 6）

**缺失**：检测代码中的制表符（Tab）并报错
- `缩进中不能使用制表符(Tab)`
- `代码中不能包含制表符(Tab)`

### 2.6 字面量增强

**缺失**：
- `真` → `True` 映射（当前作为普通标识符处理）
- `假` → `False` 映射（当前作为普通标识符处理）
- `空` → `None` 映射（可选）

## 三、语法/解析器缺失功能

### 3.1 纯缩进语法（Level 6 核心）

| 当前状态 | 目标状态 |
|---------|---------|
| `如果 条件：... 结束` | `如果条件↵    代码块` |
| 块结束标记 `结束` | 基于缩进的块结构 |
| 语句结束标记 `。` | 换行符结束语句 |

**具体缺失**：
- 所有 `comp_*` 函数（`comp_if`、`comp_while`、`comp_for`、`comp_try`）需要改写为基于 INDENT/DEDENT 的块检测
- 需要移除 `find_matching_end` 函数或其逻辑需重写
- 需要新增 `find_block_end` 函数（基于缩进级别）
- 需要新增 `编译单行块` 函数

### 3.2 关键字别名（Level 6 / P3 特性）

**缺失的关键字别名**：

| 别名 | 等价于 | 用途 |
|------|--------|------|
| `若` | `如果` | 条件判断 |
| `否` | `否则` | 否则分支 |
| `遍` | `遍历` | 迭代 |
| `于` | `在` | for...in... |
| `不是` | `非` | 逻辑非 |
| `跳` | `跳出` | 中断循环 |
| `过` | `跳过` | 跳过本次循环 |
| `返` | `返回` | 函数返回 |
| `试` | `尝试` | try |
| `捕` | `捕获` | catch |
| `抛` | `抛出` | throw |
| `终` | `最终` | finally |
| `接` | `接收` | 参数声明 |
| `承` | `继承` | 类继承 |
| `自` | `己` | self |
| `配` | — | 匹配（未来扩展） |
| `之` | — | 连接词（未来扩展） |
| `从` | — | 导入来源（未来扩展） |
| `是` | — | 类型判断（未来扩展） |
| `出` | `导出` | 导出声明 |
| `导` | `导入` | 导入声明 |

### 3.3 跳出/跳过（break/continue）（Level 6）

**缺失**：
- `跳出` → `break` 编译
- `跳过` → `continue` 编译
- 在 `compile_block` 和 `compile_stmts` 中缺少对 `跳出`/`跳过` 的处理分支

### 3.4 单行块（P3 特性，Level 6）

**缺失**（level7_generated.py 第1988行有实现）：
- `如果cond 输出("ok")` 形式的单行块
- 需要 `编译单行块` 函数
- 需要 `comp_if`、`comp_while`、`comp_for` 支持单行块模式

## 四、类型注解系统缺失（Level 7 核心）

### 4.1 基础类型定义

**完全缺失**，需要新增：

| 光明类型 | Python 类型 | 说明 |
|---------|------------|------|
| `整数` | `int` | 整型 |
| `文本` | `str` | 字符串 |
| `小数` | `float` | 浮点数 |
| `布尔` | `bool` | 布尔值 |
| `空` | `None` | 空类型 |
| `列表` | `list` | 列表类型 |
| `字典` | `dict` | 字典类型 |

**需要新增的函数**：
- `is_type_name(name)` → 判断是否为类型名
- `type_to_py(tname)` → 光明类型 → Python 类型字符串

### 4.2 变量类型注解

**缺失**：`设x为整数=10` 语法

- 当前 `comp_set` 只处理 `设x为10`
- 需要解析 `设x为<类型>=<值>` 模式
- 需要支持 `设x为整数`（无初始值）
- 需要区分 `设己.x为10`（属性赋值，不应注解类型）

### 4.3 函数参数/返回类型注解

**缺失**：`段add接收a 整数,b 整数返回整数` 语法

- 当前 `解析参数` 只收集参数名
- 需要解析参数名后的类型注解
- 需要解析 `返回<类型>` 返回类型注解
- 需要修改 `compile_single_func` 和 `compile_class_method`

### 4.4 复合类型

**缺失**：`列表[整数]`、`字典[文本,整数]` 语法

- 需要新增 `parse_type` 函数
- 需要支持 `LBRACKET` / `RBRACKET` 令牌
- 需要支持嵌套复合类型
- 需要映射 `列表[整数]` → `list[int]`

### 4.5 运行时类型检查

**缺失**：

- `开启类型检查` / `关闭类型检查` 关键字处理
- `类型检查开启` 全局变量
- `gen_type_check(var_name, py_type, indent)` 函数
- 在变量赋值和函数调用时生成 `isinstance` 检查代码

**当前状态**：`compile_block` 中遇到 `导入` 和 `导出` 关键字只是跳过，不做任何处理

**缺失**：
- 模块解析器（ModulePreprocessor）→ 已在 `module_preprocessor.py` 中实现
- 导出变量收集机制
- 模块依赖拓扑排序
- 跨文件模块解析（`bootstrap_level5.light` 是单文件自举，暂时不需要，但 Level 5 应支持）

**缺失**：

### 7.2 操作符

**缺失**：符号操作符（见 2.3 节）

## 八、自举收敛性要求

### 8.1 编译器自编译能力

**当前状态**：Level 4 编译器无法编译自身（语法不兼容）
**目标**：Level 8 编译器能编译自身源码

**必要条件**：
1. 编译器源码必须用自身支持的语法编写
2. 编译器生成的代码必须能再次编译同样的源码
3. 两次编译的结果必须一致（确定性编译）

### 8.2 语法兼容性鸿沟

Level 4 语法（当前）→ Level 6/7 语法（目标）存在根本性差异：

| 特性 | Level 4（当前） | Level 6/7（目标） |
|------|----------------|-------------------|
| 分词 | 空格分隔 | 无空格（最长匹配） |
| 块结构 | `结束` 关键字 | 缩进（INDENT/DEDENT） |
| 语句分隔 | `。` | 换行符 |
| 操作符 | 中文关键字 | 符号 + 中文关键字 |
| 类型注解 | 不支持 | 完整支持 |
| 关键字集 | 约37个 | 约60+个 |
