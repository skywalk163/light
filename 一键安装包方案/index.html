    光明（Light）一键安装包方案设计¶

    版本：1.1 | 更新日期：2026-08-07 | 对应光明版本：v6.2.0

    1. 概述¶

    光明（Light）是一套中文自然语言编程语言。为了让用户（尤其是中文初学者）能够零门槛安装和体验光明，需要为三大主流操作系统分别提供一键安装包。

    核心目标：

    • 用户只需下载安装包、双击运行，即可获得完整的光明开发环境（CLI + REPL + 标准库）
    • 安装过程无需手动安装 Python、pip、或配置环境变量
    • 支持卸载、文件关联、桌面快捷方式等桌面级体验

    项目元信息：

    项目 值
    包名 light
    版本 6.0.0
    最低 Python 3.10+
    CLI 入口 light（REPL/运行/编译）
    编译入口 lightc（编译）
    核心依赖 无（零依赖）
    可选依赖 prompt-toolkit（REPL 增强）、antlr4-python3-runtime（ANTLR 后端）

    2. Windows 安装方案（Inno Setup）¶

    2.1 技术选型¶

    选择 Inno Setup（免费、轻量、功能完善）作为 Windows 安装包制作工具。

    2.2 打包结构¶

    光明-6.0.0-Setup.exe
├── python-3.10.xx-embed-amd64.zip    # Python 嵌入式发行版
│   ├── python.exe
│   ├── python3.dll
│   ├── python310.dll
│   └── Lib/
├── light-6.0.0-py3-none-any.whl       # 预构建的光明 wheel 包
├── scripts/
│   ├── light.bat                       # 启动脚本（调用嵌入 Python）
│   └── lightc.bat                      # 编译脚本
├── unins000.exe                       # 卸载程序（Inno 自动生成）
└── assets/
    ├── light.ico                       # 桌面快捷方式图标
    └── light_installer.bmp             # 安装界面背景

    2.3 Inno Setup 脚本关键逻辑¶

    ; 安装 Python 嵌入式发行版
Source: "python-3.10.xx-embed-amd64.zip"; DestDir: "{app}\python"; Flags: ignoreversion

; 解压 Python（通过 7zip 或 Python 自身解压）
; 安装光明
Run: "{app}\python\python.exe -m pip install {app}\light-6.0.0-py3-none-any.whl"; Flags: runhidden

; 创建启动脚本
; 脚本内容：@{app}\python\python.exe -m cli.light_unified %*
; 脚本内容：@{app}\python\python.exe -m cli.lightc %*

; 添加到 PATH
Root: HKLM; Subkey: "SYSTEM\CurrentControlSet\Control\Session Manager\Environment"; \
    ValueType: expandsz; ValueName: "Path"; ValueData: "{olddata};{app}"; \
    Check: NeedsAddPath('{app}')

; 桌面快捷方式
Name: "{commondesktop}\光明 REPL"; Filename: "{app}\light.bat"; \
    Parameters: "repl"; IconFilename: "{app}\assets\light.ico"

; .light 文件关联
Root: HKCR; Subkey: ".light"; ValueType: string; ValueName: ""; ValueData: "LightFile"; \
    Flags: uninsdeletevalue
Root: HKCR; Subkey: "LightFile"; ValueType: string; ValueName: ""; ValueData: "光明源文件"
Root: HKCR; Subkey: "LightFile\shell\open\command"; ValueType: string; ValueName: ""; \
    ValueData: """{app}\light.bat"" run ""%1"""

; 卸载
UninstallDisplayIcon: "{app}\assets\light.ico"
UninstallDisplayName: "光明编程语言 v6.0.0"

    2.4 启动脚本示例¶

    light.bat：

    @echo off
"%~dp0python\python.exe" -m cli.light_unified %*

    lightc.bat：

    @echo off
"%~dp0python\python.exe" -m cli.lightc %*

    2.5 关键考量¶

    问题 方案
    Python 嵌入版缺少 pip 使用 get-pip.py 或手动将 pip 嵌入版打包
    PATH 冲突 启动脚本中使用绝对路径，避免干扰系统 Python
    架构选择 优先提供 x64 版本，可选 x86
    管理员权限 安装时请求管理员权限（写入 HKLM / PATH）
    静默安装 /VERYSILENT /SUPPRESSMSGBOXES 支持企业批量部署

    3. macOS 安装方案（.dmg + .pkg）¶

    3.1 技术选型¶

    • .dmg：提供拖拽式安装体验，适合分发包
    • .pkg：提供更完整的安装/卸载脚本，适合需要写入系统路径的场景

    3.2 .dmg 方案¶

    打包结构：

    光明-6.0.0.dmg
├── 光明.app
│   └── Contents/
│       ├── MacOS/
│       │   └── light                # 启动脚本（shell）
│       ├── Resources/
│       │   ├── light.icns           # 图标
│       │   └── light-document.icns  # 文件类型图标
│       └── Frameworks/
│           └── Python.framework/   # 完整 Python 框架（3.10+）
│       └── lib/
│           └── light/               # 光明安装包
│               ├── site-packages/  # pip install 后的 site-packages
│               └── bin/
│                   ├── light
│                   └── lightc
├── Applications/                   # 拖拽提示
└── .DS_Store

    启动脚本 light：

    #!/bin/bash
DIR="$(cd "$(dirname "$0")/.." && pwd)"
export PYTHONHOME="$DIR/Frameworks/Python.framework/Versions/3.10"
export PATH="$PYTHONHOME/bin:$PATH"
exec "$PYTHONHOME/bin/python3" -m cli.light_unified "$@"

    3.3 .pkg 方案（推荐用于生产）¶

    使用 pkgbuild + productbuild 制作正式的安装包。

    安装脚本 postinstall：

    #!/bin/bash
# 创建符号链接到 /usr/local/bin
ln -sf /Applications/光明.app/Contents/MacOS/light /usr/local/bin/light
ln -sf /Applications/光明.app/Contents/MacOS/lightc /usr/local/bin/lightc

# 注册 .light 文件类型
/System/Library/Filesystems/AppleFileServer.app/Contents/Resources/...

    卸载脚本：

    #!/bin/bash
rm -f /usr/local/bin/light
rm -f /usr/local/bin/lightc
rm -rf "/Applications/光明.app"

    3.4 注意事项¶

    问题 方案
    Python Framework 体积 约 30-50MB，可裁剪不必要的库（tkinter、test 等）
    代码签名 需要 Apple Developer 账号签名，避免 Gatekeeper 拦截
    公证（Notarization） 提交到 Apple 公证服务，确保在 macOS 10.15+ 可运行
    自定 Python 框架 使用 pyinstaller 打包为单文件也是可选方案，但体积更大

    4.5 Python 依赖处理策略¶

    Linux 发行版通常已预装系统 Python，但版本可能不满足（< 3.10）。有三种策略：

    策略 描述 优点 缺点
    A：系统 Python 依赖系统 Python 3.10+ 包体积小 需用户安装 Python，可能版本不满足
    B：捆绑 Python 在包内嵌入 Python 3.10+ 开箱即用 包体积增大 ~30MB
    C：pip 安装 仅提供 pip 安装脚本，不打包 维护简单 需网络和 pip

    推荐：策略 B（捆绑 Python），降级为 A（当系统 Python 3.10+ 可用时）。

    5. 示例工具打包¶

    5.1 概述¶

    安装包在提供光明开发环境的同时，也附带预构建的示例工具，方便用户开箱即用地体验光明的实际应用能力。示例工具通过 tools/packager/build_example.py 打包脚本自动构建。

    5.2 安装包内示例工具¶

    工具名称 源文件 功能说明
    data_cleaner examples/data_cleaner/主程序.light 数据清洗工具 — CSV/JSON 数据处理，包括去重、字段标准化、格式清洗
    data_pipeline examples/data_pipeline/pipeline.light 数据处理管道 — CSV 读取→清洗→聚合→SQLite 存储→JSON 导出 ETL 流程
    web_crawler examples/web_crawler/crawler.light Web 爬虫 — 递归抓取网页链接，生成站点地图
    cli_tool examples/cli_tool/file_organizer.light 文件整理器 — 按文件类型自动分类整理

    5.3 打包工具使用说明¶

    打包脚本路径： tools/packager/build_example.py

    # 打包所有示例工具（默认 SRC 后端）
python tools/packager/build_example.py

# 打包指定示例工具
python tools/packager/build_example.py data_pipeline

# 使用 LLVM 后端编译
python tools/packager/build_example.py --backend llvm

# 指定输出目录
python tools/packager/build_example.py --output dist

# 列出所有可打包的示例
python tools/packager/build_example.py --list

    data_pipeline.bat（或 data_pipeline）

    7.2 GitHub Actions CI/CD 配置¶

    name: 构建安装包

on:
  push:
    tags:
      - 'v*'

jobs:
  build-windows:
    runs-on: windows-latest
    steps:
      - uses: actions/checkout@v4
      - uses: actions/setup-python@v5
        with:
          python-version: '3.10'
      - run: pip install build
      - run: python -m build --wheel
      - run: choco install innosetup
      - run: iscc tools/installer/windows/setup.iss
      - uses: actions/upload-artifact@v4
        with:
          name: light-windows-setup
          path: output/光明-*.exe

  build-macos:
    runs-on: macos-latest
    steps:
      - uses: actions/checkout@v4
      - uses: actions/setup-python@v5
        with:
          python-version: '3.10'
      - run: pip install build
      - run: python -m build --wheel
      - run: bash tools/installer/macos/build_pkg.sh
      - run: |
          # 签名（需要配置 Apple 证书）
          # codesign --deep --force --verify --verbose \
          #   --sign "Developer ID Application: ..." \
          #   output/光明-6.0.0.pkg
      - uses: actions/upload-artifact@v4
        with:
          name: light-macos-pkg
          path: output/光明-*.pkg

  build-linux:
    runs-on: ubuntu-latest
    steps:
      - uses: actions/checkout@v4
      - uses: actions/setup-python@v5
        with:
          python-version: '3.10'
      - run: pip install build fpm
      - run: python -m build --wheel
      - run: bash tools/installer/linux/build_deb.sh
      - uses: actions/upload-artifact@v4
        with:
          name: light-linux-deb
          path: output/light_*.deb

    9. 技术细节¶

    9.1 最低 Python 版本要求¶

    配置 要求
    最低 Python 版本 3.10
    推荐的 Python 版本 3.10、3.11、3.12
    未来兼容性 3.13 兼容（需测试）

    9.2 磁盘空间¶

    组件 大小（约）
    Python 嵌入式发行版（win） 25-35 MB
    Python Framework（macOS） 30-50 MB
    光明核心包 2-5 MB
    标准库 + 贡献库 5-10 MB
    合计（约） 40-100 MB

    9.3 依赖管理¶

    光明核心零依赖，但可选功能需要额外包：

    功能 依赖 打包策略
    核心功能（编译/运行） 无 始终包含
    REPL 增强（历史补全） prompt-toolkit 可选安装
    ANTLR 后端 antlr4-python3-runtime>=4.13.0 可选安装
    LLVM 代码生成 LLVM 系统库 需手动安装
    开发工具 pytest, flake8, black, mypy 仅开发环境

    9.4 更新机制¶

    7.4.1 方案 A：内置更新检查¶

    light update check    # 检查新版本
light update          # 自动下载并安装更新

    实现方式：调用 GitHub Releases API 检查最新版本，下载新安装包自动替换。

    9.4.2 方案 B：pip 更新（仅限 pip 安装用户）¶

    pip install --upgrade light

    7.4.3 方案 C：手动下载¶

    在官网提供各平台最新安装包，用户手动下载覆盖安装。

    推荐： 方案 A（内置更新） + 方案 C（手动下载）并行。

    7.5 安全考量¶

    • 安装包必须签名（Authenticode / Apple Developer ID / GPG）
    • 嵌入式 Python 发行版从 python.org 官方下载，校验 SHA256 哈希
    • 光明 wheel 包从 PyPI 或 GitHub Releases 获取，校验签名
    • 安装脚本不执行任何网络请求（离线安装）
