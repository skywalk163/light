    光明统一语法规范 v3.2¶

    版本：v3.2 日期：2026-07-04 状态：正式版

    1. 核心设计原则¶

    1.1 中文优先，空格可选¶

    • 所有语句中关键字、变量名、运算符之间都不需要空格
    • 词法分析器实现三层分词机制，自动识别无空格的中文代码
    • 例如以下写法完全合法： 
      如果甲大于十：打印甲
遍历甲于[1,2,3]：打印甲
设乙等于甲加三
段落阶乘接收甲：
    如果甲小于等于一：
        返回一
    否则：
        返回甲乘以阶乘甲减一
    • 也支持有空格的写法，两种风格可混用： 
      设 甲 为 10
如果甲大于5：
    打印 "大"

    1.2 纯缩进式语法¶

    • 用缩进表示代码块，不使用花括号或 begin/end
    • 移除「结束」关键字（可选向后兼容，默认关闭）

    1.3 句号可选¶

    • 语句末尾的句号是可选的
    • 例外：无——所有语句句号均可选

    1.4 冒号规则¶

    • 块级语句必须以冒号结尾：条件、循环、段落、类等
    • 冒号后换行并缩进表示代码块开始

    1.5 语法简洁性¶

    • 只保留一种标准语法形式，降低用户记忆负担
    • 不支持过多的旧语法变体

    9.5 推迟（defer）¶

    延迟执行：推迟体在作用域退出时执行（FILO 栈序），包括提前 返回 和异常路径。

    语法： 

    推迟 语句。
推迟：
    语句1
    语句2

    等价 Python： 

    _light_defers = []
try:
    def _light_defer_0():
        # 推迟体
    _light_defers.append(_light_defer_0)
    # 段落体
finally:
    for _d in reversed(_light_defers):
        _d()

    说明： - 多个推迟按后进先出（FILO）执行：后注册的先执行。 - 提前 返回 时推迟体仍执行（finally 语义）。 - 异常传播时推迟体仍执行（finally 语义），异常之后继续传播。 - 仅作用于当前段落（段落）作用域。

    9.7 位运算¶

    六个中文中缀位运算符 + 一个一元前缀，优先级遵循 Python 口径：

    语法 Python 等价 优先级（高→低）
    位非 表达式 ~表达式 一元前缀（最高）
    甲 左移 乙 甲 << 乙 位移
    甲 右移 乙 甲 >> 乙 位移
    甲 位与 乙 甲 & 乙 位与
    甲 位异或 乙 甲 ^ 乙 位异或
    甲 位或 乙 甲 \| 乙 位或（最低）

    说明： - 位运算符均为中文词形式，不支持符号形式（| 已是管道操作符） - 优先级链：算术 > 位移 > 位与 > 位异或 > 位或 > 比较 > 逻辑 - 位非 是一元前缀运算符，等价 Python ~

    10. 与 v3.1 的主要差异¶

    项目 v3.1 v3.2 说明
    跳出/跳过 句号 未明确 不需要句号 参考 Python 语法
    条件语句冒号 可选 强制 统一块级语句规则
    段落定义形式 多种旧形式 仅标准形式 降低语法负担
    段落关键字 段落/函数/段 仅「段落」 简化
    参数关键字 参数/接收/输入 仅「接收」 简化
    参数形式 中文+括号 仅中文形式 简化
    遍历「于」支持 规范有 补上 完善
    全局无空格 未明确 明确支持 所有关键字/变量间无需空格
    设语句赋值关键字 仅「为」 「为」和「等于」 统一赋值语义
