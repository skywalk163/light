    快速开始¶

    安装¶

    从 PyPI 安装（推荐）¶

    pip install light

    安装后即可使用 light 命令： 

    light --version
light --help

    从源码安装¶

    git clone https://github.com/skywalk163/light.git
cd light
pip install -e .

    第一个程序¶

    创建 hello.light 文件：

    打印 "你好，世界！"

    运行：

    light run hello.light

    输出： 

    你好，世界！

    编译为 Python 文件¶

    light compile hello.light -o hello.py

    编译为 Windows EXE¶

    # 需要先安装 PyInstaller
pip install pyinstaller

# 编译为 exe
light compile hello.light -o hello.exe

    原理： 先将光明代码编译为 Python 代码，再使用 PyInstaller 打包为独立的 .exe 可执行文件。

    注意： 仅适用于 Windows 平台，生成的 exe 文件无需 Python 环境即可运行。

    基础语法¶

    注释¶

    光明支持以下注释语法：

    # 这是单行注释（推荐使用）
// 这也是单行注释
注 这也是注释（以"注"开头，不加冒号）

    光明支持三种注释风格，可以灵活使用。

    语句结束¶

    每个语句以句号 。 结束（句号是可选的，不强制要求）。

    令 甲 = 123
打印 甲

    标点符号¶

    中文符号 英文符号 用途
    。 . 语句结束
    ， , 参数分隔、管道操作
    ： : 块开始、类型注解
    （ ） ( ) 括号
    【 】 [ ] 列表
    「 」 " " 字符串

令 乙 = 3

    打印 "相等"

    控制流程¶

    条件语句¶

    基础语法： 

    如果 条件:
    执行语句

    示例： 

    令 分数 = 85

如果 分数 >= 90:
    打印 "优秀"
否则如果 分数 >= 80:
    打印 "良好"
否则如果 分数 >= 70:
    打印 "中等"
否则:
    打印 "及格"

    循环语句¶

    遍历循环： 

    令 列表 = [1, 2, 3, 4, 5]

遍历 元素 于 列表:
    打印 元素

    当循环（while）： 

    令 计数 = 1

当 计数 <= 5:
    打印 计数
    令 计数 = 计数 + 1

    循环控制： 

    遍历 元素 于 列表:
    如果 元素 == 3:
        跳出
    打印 元素

    函数 阶乘(数):

      返回 1

令 结果 = 阶乘(5)

    斐波那契： 

    函数 斐波那契(数):
  如果 数 <= 2:
      返回 1
  返回 斐波那契(数 - 1) + 斐波那契(数 - 2)

令 结果 = 斐波那契(10)
打印 结果  # 55

    访问修饰符¶

    光明支持三种访问级别：

    修饰符 说明 生成代码
    公有 (默认) 任何地方可访问 无前缀
    私有 仅在类内部可访问 加 _ 前缀
    保护 类及子类可访问 加 _ 前缀（Python约定） 
    类 账户：
    公有 属性 用户名
    私有 属性 密码
    保护 属性 余额

    构造 接收 用户名, 密码：
        己.用户名 = 用户名
        己.密码 = 密码
        己.余额 = 0

    公有 函数 获取用户名():
        返回 己.用户名

    私有 函数 验证密码(输入密码):
        返回 己.密码 == 输入密码

    静态属性和方法¶

    使用 静态 修饰符定义类级别的属性和方法：

    静态 属性 总数

设 计数器.总数 为 0

    编译器使用¶

    CLI 工具¶

    基本用法： 

    # 解释执行
light run file.light

# 编译为 Python 文件
light compile file.light

# 指定输出文件
light compile file.light -o output.py

# 编译为 Windows EXE（需安装 PyInstaller）
light compile file.light -o output.exe

# 显示 Token 流
light tokens file.light

# 显示 AST
light ast file.light

# 选择后端（antlr / src / llvm）
light run file.light --backend antlr
light compile file.light --backend src

# 详细输出
light run file.light -v

# 启动 REPL
light repl

# 查看版本
light --version

# 查看帮助
light --help

    编译目标说明¶

    命令 输出格式 说明
    light compile file.light file.py 编译为 Python 源代码
    light compile file.light -o file.exe file.exe 编译为 Windows 可执行文件（需 PyInstaller）
    light compile file.light --backend native 原生可执行文件 走原生腿（--backend llvm-typed 等价），需安装 clang

    Python API¶

    import sys
sys.path.insert(0, 'src')

from compiler import LightCompiler
from code_generator_unified import UnifiedCodeGenerator

# 编译流程
compiler = LightCompiler()
result = compiler.compile(source)

if result['success']:
    code_gen = UnifiedCodeGenerator()
    py_code = code_gen.generate(result['ast'])
    print(py_code)
else:
    print("编译错误:", result['errors'])

    1. 计算器¶

    函数 计算器(操作, 甲, 乙):
  如果 操作 == "加":
      返回 甲 + 乙
  如果 操作 == "减":
      返回 甲 - 乙

令 结果 = 计算器("加", 10, 5)

    2. 学生成绩管理¶

    类 学生：
  属性 姓名
  属性 成绩列表

  构造(姓名):
    己.姓名 = 姓名
    己.成绩列表 = []

  函数 添加成绩(成绩):
    己.成绩列表.添加(成绩)

  函数 计算平均分():
    如果 长(己.成绩列表) == 0:
        返回 0
    令 总和 = 求和(己.成绩列表)
    返回 总和 / 长(己.成绩列表)

  函数 显示信息():
    打印 "学生：" + 己.姓名
    打印 "平均分：" + 转字符串(己.计算平均分())

令 学生 = 学生("张三")
学生.添加成绩(85)
学生.添加成绩(92)
学生.添加成绩(78)
学生.显示信息()

    3. 银行账户¶

    类 银行账户：
  属性 账户号
  属性 余额

  构造(账户号, 初始余额):
    己.账户号 = 账户号
    己.余额 = 初始余额

  函数 存款(金额):
    如果 金额 <= 0:
      抛出 ValueError("存款金额必须大于零")
    己.余额 = 己.余额 + 金额
    打印 "存款成功，当前余额：" + 转字符串(己.余额)

  函数 取款(金额):
    如果 金额 <= 0:
      抛出 ValueError("取款金额必须大于零")
    如果 金额 > 己.余额:
      抛出 ValueError("余额不足")
    己.余额 = 己.余额 - 金额
    打印 "取款成功，当前余额：" + 转字符串(己.余额)

  函数 查询余额():
    返回 己.余额

令 账户 = 银行账户("12345", 1000)
账户.存款(500)
账户.取款(200)
打印 账户.查询余额()  # 1300

    常见问题¶

    1. 为什么我的代码编译失败？¶

    常见原因： - 缺少句号 。 - 关键字拼写错误 - 括号不匹配 - 字符串引号不匹配

    解决方法： 使用 light tokens 查看词法分析结果： 

    light tokens file.light

    2. 如何调试代码？¶

    方法1： 使用 light ast 查看语法树 

    light ast file.light

    方法2： 使用 -v 详细输出 

    light run file.light -v

    3. 光明支持哪些关键字？¶

    核心关键字： - 定义：令、设、常量、类型 - 条件：如果、那么、否则 - 循环：遍历、当、跳出、跳过 - 函数：函数、段落、返回 - 类：类、继承、属性*、构造 - 模块：导入、导出、从 - 异常：尝试、捕获、抛出、最终

    4. 如何参与开发？¶

    步骤： 1. Fork 项目仓库 2. 创建功能分支 3. 编写代码和测试 4. 提交 Pull Request

    开发指南： - 代码风格：遵循 PEP 8 - 测试要求：新增功能必须有测试 - 文档要求：新增功能必须更新文档
