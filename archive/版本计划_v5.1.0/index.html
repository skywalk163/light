    段言（Duan）v5.1.0 开发计划¶

    版本: v5.1.0 基础版本: v5.0.0（2026-08-06） 计划周期: 2026-08-07 ~ 2026-08-20（2 周，AI 辅助加速预估） 当前状态: 1,944 tests / 0 failures / 53 duanpub 模块 / 109 包索引

    一、版本定位¶

    v5.0.0 已完成了原三个月计划中「夯实底座」「扩展生态」「正式发布」的全部核心功能： trait/协议系统、模式匹配增强、迭代器协议、上下文管理器、duanpub 53 桥接模块、 框架库（单元测试/日志/配置/HTTP）、LSP/调试器/Playground、文档站。

    v5.1.0 的目标是从「功能完整」走向「工程成熟」—— 补齐 LLVM 后端能力、 完善社区基础设施、升级 AI 工具链、深化 duanpub 生态质量。

    二、方向 A：LLVM 后端深化¶

    目标: 补齐 LLVM 后端的三个关键缺口，使段言成为真正的原生编译语言 预估: 2-3 天 优先级: P1（性能突破）

    2.1 ARM64 交叉编译支持¶

    任务 优先级 预估 验收标准
    检测目标架构：根据 --target 参数或 -arch 自动选择 x64/ARM64 目标三元组 P1 0.5 天 duan build --target aarch64-linux-gnu 生成 ARM64 汇编
    交叉编译工具链检测：自动检测 aarch64-linux-gnu-gcc 等交叉编译器 P1 0.5 天 缺少工具链时给出清晰安装提示
    运行时库交叉编译：stdlib 的 LLVM IR 需为 ARM64 重新编译 P1 0.5 天 ARM64 目标可正确链接 stdlib
    CI 交叉编译验证：GitHub Actions 中添加 ARM64 交叉编译测试 P2 0.5 天 CI 中 duan build --target aarch64 通过

    关键文件: src/llvm/compiler.py, src/llvm/core.py, .github/workflows/ci.yml

    2.2 优化 Pass 增强¶

    任务 优先级 预估 验收标准

    优化级别映射：-O0/-O1/-O2/-O3 对应不同 Pass 组合 P1 0.5 天 各优化级别生成不同质量的 IR
    基准测试验证：benchmark.py 对比优化前后性能 P1 0.5 天 -O2 相对 -O0 性能提升 ≥20%
    调试信息保留：优化不影响断点/变量查看 P2 0.5 天 优化后仍可调试

    关键文件: src/llvm/compiler.py, tools/benchmark.py

    10.2 质量保障红线¶

    1. 每次变更必须跑全量测试 — 0 failures 是硬性门槛
    2. 新增功能必须附带测试 — 无测试的代码不合并
    3. 不允许改测试期望值来「修 bug」 — 必须修复底层逻辑
    4. 不允许用 SkipTest 跳过失败 — 必须修复或标注为环境依赖
    5. 每次提交前 git status 检查 — 不引入新的未跟踪临时文件
    6. CHANGELOG 必须同步更新 — 每个功能变更都有记录
