    光明学习路径地图¶

    版本： v6.2 本文档为不同背景的学习者提供个性化的学习路径，帮助你高效掌握光明编程语言。

    📚 教程总览¶

    教程 预计时间 适合人群 前置要求
    入门教程 2-3 小时 编程初学者 无
    30分钟入门光明 30 分钟 所有用户 无
    进阶教程 3-4 小时 有编程经验者 入门教程 或 30分钟入门
    应用案例（examples/ 目录） 2-3 小时/案例 有基础者 进阶教程
    交互式教程 20-30 分钟 所有用户 无
    视频教程（video_scripts/ 目录） 各 5-35 分钟 视觉学习者 视教程而定

    🧭 学习路径¶

    路径一：零基础编程学习者¶

    如果你从未写过代码，从零开始学习编程：

    ┌─────────────────────────────────────────────────────────────────┐
│  ① 入门教程 (2-3小时)                                           │
│  └─ 变量、数据类型、条件判断、循环、函数、类、模块               │
├─────────────────────────────────────────────────────────────────┤
│  ② 30分钟入门 (30分钟)                                          │
│  └─ 快速复习 + REPL 练习 + 调试入门                             │
├─────────────────────────────────────────────────────────────────┤
│  ③ 进阶教程 (3-4小时)                                           │
│  └─ FFI、Web开发、并发编程、测试调试                             │
├─────────────────────────────────────────────────────────────────┤
│  ④ 应用案例 (每个2-3小时)                                       │
│  └─ 选择感兴趣的项目动手实践                                     │
│     ├─ Web 爬虫 → 抓取网页数据                                  │
│     ├─ 数据处理管道 → 分析 CSV 数据                             │
│     ├─ CLI 文件整理器 → 自动化文件管理                          │
│     └─ 博客系统 → 构建 Web 应用                                 │
├─────────────────────────────────────────────────────────────────┤
│  ⑤ 少儿趣味示例 (可选)                                          │
│  └─ examples/kids/ → 图形绘制、猜数字、故事生成器               │
└─────────────────────────────────────────────────────────────────┘

    推荐学习时长： 每天 1-2 小时，约 1-2 周完成基础，2-4 周完成应用案例。

    🎯 学习建议¶

    1. 动手为主：编程是实践技能，每个知识点学完后立即动手写代码
    2. 善用 REPL：light repl 让你可以快速验证想法，无需创建文件
    3. 从错误中学习：遇到错误提示，耐心阅读并理解原因
    4. 循序渐进：不要跳步，基础知识不牢固会影响后续学习
    5. 多读示例：examples/ 目录中有大量可运行的代码，阅读并修改它们
    6. 使用调试器：light debug 帮助你理解代码的执行流程
    7. 加入社区：遇到问题可以查阅文档或寻求帮助

    开始学习： 选择适合你的路径，从 入门教程 或 30分钟入门光明 开始吧！
