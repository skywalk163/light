    进阶教程¶

    版本： v6.0 适合已有编程基础的光明用户，深入掌握 FFI 外部函数接口、Web 应用开发、并发编程等高级主题。

    1. FFI 与 C 交互¶

    光明支持通过 FFI（外部函数接口）直接调用 C 语言函数，实现高性能计算和系统级编程。

    1.1 加载动态库¶

    # 加载系统数学库
加载库 "libc.so.6" 为 数学库
# 在 Windows 上使用 "msvcrt.dll"
# 加载库 "msvcrt.dll" 为 数学库

外部 段落 正弦 接收 甲: 小数 返回 小数 在 数学库
外部 段落 余弦 接收 甲: 小数 返回 小数 在 数学库
外部 段落 平方根 接收 甲: 小数 返回 小数 在 数学库

设 结果 为 正弦(3.14159 / 2)
打印 "sin(π/2) = " + 转字符串(结果)

设 结果2 为 平方根(144.0)
打印 "sqrt(144) = " + 转字符串(结果2)

    1.2 结构体与指针¶

    # 定义 C 结构体（结构体字面量目前只作说明用，parser 还不接受这一形式）
@C 结构体 时间结构 {
    年: 整数,
    月: 整数,
    日: 整数,
    时: 整数,
    分: 整数,
    秒: 整数
}

    # 内存操作
外部 段落 内存分配 接收 大小: 整数 返回 指针 在 数学库
外部 段落 内存释放 接收 指针 返回 空 在 数学库

# 指针操作
设 缓冲区 为 内存分配(1024)
打印 "分配了 1024 字节内存"

# 使用完后释放
内存释放(缓冲区)
打印 "内存已释放"

    2. Web 应用开发¶

    2.1 创建 HTTP 服务器¶

    从 贡献.HTTP服务端 导入 创建服务器, 路由, 请求, 响应

段落 首页 接收 请求：
    返回 响应(200, {"内容类型": "text/html"}, "<h1>欢迎使用光明！</h1>")

段落 用户信息 接收 请求：
    设 用户ID 为 请求.参数["id"]
    返回 响应(200, {"内容类型": "application/json"}, "{\"id\": " + 用户ID + ", \"name\": \"张三\"}")

段落 提交数据 接收 请求：
    设 数据 为 请求.主体
    打印 "收到数据：" + 数据
    返回 响应(201, {"内容类型": "text/plain"}, "数据已接收")

# 配置路由
设 路由表 为 路由()
路由表.添加("GET", "/", 首页)
路由表.添加("GET", "/用户", 用户信息)
路由表.添加("POST", "/数据", 提交数据)

# 启动服务器
设 服务器 为 创建服务器("0.0.0.0", 8080, 路由表)
打印 "服务器已启动：http://localhost:8080"
服务器.启动()

    2.2 HTTP 客户端请求¶

    从 贡献.HTTP客户端 导入 获取, 提交, 请求

# GET 请求
设 响应 为 获取("https://api.example.com/users")
打印 "状态码：" + 转字符串(响应.状态码)
打印 "响应体：" + 响应.主体

# POST 请求
设 数据 为 "{\"name\": \"张三\", \"email\": \"zhangsan@example.com\"}"
设 响应2 为 提交("https://api.example.com/users", 数据, 头信息={"内容类型": "application/json"})
打印 "创建成功：" + 响应2.主体

    2.3 JSON 数据处理¶

    从 JSON 导入 解析JSON, 序列化JSON

# 解析 JSON
设 json文本 为 "{\"name\": \"张三\", \"age\": 30, \"hobbies\": [\"读书\", \"编程\"]}"
设 数据 为 解析JSON(json文本)
打印 "姓名：" + 数据["name"]
打印 "年龄：" + 转字符串(数据["age"])

# 构建并序列化 JSON
设 用户 为 {"id": 1, "姓名": "李四", "邮箱": "lisi@example.com", "活跃": 真}
设 输出 为 序列化JSON(用户, 缩进=2)
打印 输出

    2.4 完整的 Web API 应用¶

    从 贡献.HTTP服务端 导入 创建服务器, 路由, 请求, 响应
从 JSON 导入 解析JSON, 序列化JSON
从 日期时间 导入 当前时间

# 内存数据库
设 用户列表 为 []
设 下一个ID 为 1

段落 获取所有用户 接收 请求：
    返回 响应(200, {"内容类型": "application/json"}, 序列化JSON(用户列表))

段落 创建用户 接收 请求：
    设 数据 为 解析JSON(请求.主体)
    设 新用户 为 {"id": 下一个ID, "姓名": 数据["姓名"], "邮箱": 数据["邮箱"]}
    设 下一个ID 为 下一个ID + 1
    用户列表.追加(新用户)
    返回 响应(201, {"内容类型": "application/json"}, 序列化JSON(新用户))

段落 获取用户详情 接收 请求：
    设 用户ID 为 转整数(请求.参数["id"])
    遍历 用户列表 为 用户：
        如果 用户["id"] == 用户ID：
            返回 响应(200, {"内容类型": "application/json"}, 序列化JSON(用户))
    返回 响应(404, {"内容类型": "application/json"}, "{\"error\": \"用户未找到\"}")

段落 健康检查 接收 请求：
    返回 响应(200, {"内容类型": "application/json"}, "{\"status\": \"ok\", \"time\": " + 转字符串(当前时间()) + "}")

# 路由配置
设 路由表 为 路由()
路由表.添加("GET", "/api/users", 获取所有用户)
路由表.添加("POST", "/api/users", 创建用户)
路由表.添加("GET", "/api/users/:id", 获取用户详情)
路由表.添加("GET", "/health", 健康检查)

# 启动
设 服务器 为 创建服务器("0.0.0.0", 3000, 路由表)
打印 "RESTful API 服务已启动：http://localhost:3000"
服务器.启动()

    3. 并发编程¶

    3.1 异步函数¶

    异步 段落 获取数据 接收 url：
    打印 "正在获取：" + url
    等待 异步睡眠(1)  # 模拟网络延迟
    返回 "数据来自：" + url

异步 段落 主程序 接收：
    设 结果1 为 等待 获取数据("https://api.example.com/data1")
    设 结果2 为 等待 获取数据("https://api.example.com/data2")
    打印 结果1
    打印 结果2

# 运行异步主程序（顶层不能直接写 `等待`，要用启动语句）
异步 运行 主程序()

    3.2 并行执行¶

    段落 耗时任务 接收 名称, 时间：
    打印 名称 + " 开始执行"
    休眠(时间)  # 模拟耗时操作
    打印 名称 + " 执行完成"
    返回 名称 + " 的结果"

# 并行执行多个任务
并行 {
    设 结果1 为 耗时任务("任务A", 2)
    设 结果2 为 耗时任务("任务B", 3)
    设 结果3 为 耗时任务("任务C", 1)
}

打印 "所有任务已完成！"
打印 结果1
打印 结果2
打印 结果3

    4. 测试与调试¶

    4.1 单元测试¶

    从 贡献.单元测试框架 导入 测试, 断言相等, 断言真, 运行测试

段落 加法 接收 甲, 乙：
    返回 甲 + 乙

段落 除法 接收 甲, 乙：
    如果 乙 == 0：
        抛出 "除数不能为零"
    返回 甲 / 乙

# 测试用例
段落 测试加法 接收：
    断言相等(加法(2, 3), 5)
    断言相等(加法(-1, 1), 0)
    断言相等(加法(0, 0), 0)
    打印 "测试加法通过 ✓"

段落 测试除法 接收：
    断言相等(除法(10, 2), 5)
    断言相等(除法(7, 2), 3.5)
    打印 "测试除法通过 ✓"

# 运行所有测试
测试加法()
测试除法()

    4.2 使用调试器¶

    # 打印调试信息
打印 "[调试] 甲 = " + 转字符串(甲)
打印 "[调试] 乙 = " + 转字符串(乙)
打印 "[调试] 结果 = " + 转字符串(结果)

# 条件断点：条件成立时用断言把执行停在这里
如果 结果 > 30：
    断言 假, "结果超过预期"
