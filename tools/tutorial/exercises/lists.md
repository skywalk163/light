# 练习 6：列表操作

## 题目描述
编写程序完成以下列表操作：
1. 创建一个列表 `[3, 1, 4, 1, 5, 9, 2, 6]`
2. 向列表追加一个元素 5
3. 删除列表中的第一个元素 1
4. 对列表进行排序
5. 打印每次操作后的列表

## 提示
- 使用 `列表追加(列表, 元素)` 追加元素
- 使用 `列表删除(列表, 元素)` 删除指定元素
- 使用 `列表排序(列表)` 排序
- 使用 `列表弹出(列表, 索引)` 按索引删除

## 预期输出
```
初始列表：[3, 1, 4, 1, 5, 9, 2, 6]
追加 5 后：[3, 1, 4, 1, 5, 9, 2, 6, 5]
删除第一个 1 后：[3, 4, 1, 5, 9, 2, 6, 5]
排序后：[1, 2, 3, 4, 5, 5, 6, 9]
```
