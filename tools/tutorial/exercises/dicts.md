# 练习 8：字典操作

## 题目描述
编写程序完成以下字典操作：
1. 创建一个字典表示学生信息：`{"姓名": "张三", "年龄": 18, "成绩": 92}`
2. 打印字典中的姓名和成绩
3. 将成绩修改为 95
4. 添加一个新键 `"等级"`，值为 `"优秀"`
5. 打印修改后的字典

## 提示
- 使用 `{"键": 值}` 创建字典
- 使用 `字典["键"]` 访问和修改值
- 使用 `字典["新键"] 为 值` 添加新键值对
- 使用 `字典包含键(字典, "键")` 检查键是否存在

## 预期输出
```
姓名：张三
成绩：92
修改后字典：{'姓名': '张三', '年龄': 18, '成绩': 95, '等级': '优秀'}
```
