# 练习 2：变量与运算

## 题目描述
声明变量并完成基本运算。要求：
1. 声明两个整数变量 `甲` 和 `乙`，分别赋值为 10 和 3
2. 计算并打印它们的和、差、积、商
3. 计算 `甲` 的平方并打印

## 提示
- 使用 `设 变量名 为 值` 声明变量
- 使用 `加`、`减`、`乘`、`除` 进行算术运算
- 使用 `打印` 输出结果

## 预期输出
```
和: 13
差: 7
积: 30
商: 3.3333333333333335
甲 的平方: 100
```
