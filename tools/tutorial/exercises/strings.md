# 练习 7：字符串处理

## 题目描述
编写程序完成以下字符串操作：
1. 声明字符串 `"Hello, 段言!"` 并打印
2. 将字符串 `"Hello, 段言!"` 中的 "Hello" 替换为 "你好"
3. 将字符串 `"apple,banana,orange"` 按逗号分割成列表
4. 将列表 `["段言", "编程", "语言"]` 用连字符 `-` 拼接成字符串

## 提示
- 使用 `字符串替换(原字符串, 旧子串, 新子串)` 替换
- 使用 `字符串分割(字符串, 分隔符)` 分割
- 使用 `字符串拼接(分隔符, 列表)` 拼接
- 字符串可以用 `加` 运算符拼接

## 预期输出
```
原始字符串：Hello, 段言!
替换后：你好, 段言!
分割后：['apple', 'banana', 'orange']
拼接后：段言-编程-语言
```
