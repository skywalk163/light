# 练习 3：条件判断

## 题目描述
编写程序完成两个任务：
1. 判断一个整数是奇数还是偶数
2. 根据分数（0-100）输出成绩等级：90 及以上为"优秀"，80-89 为"良好"，70-79 为"中等"，60-69 为"及格"，60 以下为"不及格"

## 提示
- 使用 `如果`、`否则若`、`否则` 进行条件判断
- 判断奇偶可用 `数 模 2 等于 0` 来判断
- 模运算使用 `模` 关键字

## 预期输出
```
7 是 奇数
12 是 偶数
分数 85 的等级是：良好
分数 42 的等级是：不及格
```
