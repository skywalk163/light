# 练习 10：综合练习——简易学生成绩管理系统

## 题目描述
编写一个简易的学生成绩管理系统，要求：
1. 定义一个 `学生` 类，包含姓名、语文成绩、数学成绩属性
2. 定义一个 `计算平均分` 函数，接收学生对象，返回平均分
3. 定义一个 `评级` 函数，根据平均分返回等级（>=90 优秀，>=80 良好，>=60 及格，<60 不及格）
4. 创建 3 个学生对象，放入列表
5. 遍历列表，打印每个学生的姓名、成绩、平均分和等级

## 提示
- 使用 `类 类名：` 定义类
- 使用 `构造 接收 参数：` 定义构造函数
- 使用 `己属性名` 访问实例属性
- 使用 `遍历 学生 于 学生列表：` 遍历

## 预期输出
```
===== 学生成绩单 =====
姓名：张三，语文：85，数学：92，平均分：88.5，等级：良好
姓名：李四，语文：78，数学：65，平均分：71.5，等级：及格
姓名：王五，语文：95，数学：98，平均分：96.5，等级：优秀
====================
```
