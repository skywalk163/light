  属性 年龄

  构造(姓名, 年龄)：
    设 己.姓名 为 姓名。
    设 己.年龄 为 年龄。

  段落 介绍：
    打印("我叫" + 己.姓名)。

    class 学生:
    姓名: str
    年龄: int

    def __init__(self, 姓名, 年龄):
        self.姓名 = 姓名
        self.年龄 = 年龄

    def 介绍(self):
        print(f"我叫{self.姓名}")
