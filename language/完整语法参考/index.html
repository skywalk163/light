    L3：领域嵌入¶

    L3 层允许在光明代码中直接嵌入领域特定语言。

    SQL 嵌入¶

    # 直接编写 SQL 查询
设 结果 = 查询 用户 中 筛选 年龄 > 18 排序 年龄 升序

# 更复杂的 SQL 操作
设 数据 = 查询 订单 中
  筛选 金额 > 100
  且 状态 = "已完成"
  排序 时间 降序
  限制 10

    正则表达式嵌入¶

    # 使用 / / 定义正则表达式
设 模式 = /^\d{3}-\d{8}$/
设 是否匹配 = 模式.测试("010-12345678")

# 正则匹配提取
设 文本 = "联系电话：010-12345678"
设 匹配结果 = 文本.匹配(/(\d{3})-(\d{8})/)
如果 匹配结果：
  打印(匹配结果[0])  # 完整匹配
  打印(匹配结果[1])  # 区号：010
  打印(匹配结果[2])  # 号码：12345678

    L4：外语引用¶

    L4 层通过 引 语言: 块安全地嵌入其他语言代码。

    引用 Python¶

    引 Python:
    import math
    def calculate_area(radius):
        return math.pi * radius ** 2
出 calculate_area

设 面积 = calculate_area(5)
印(面积)

    引用 C¶

    引 C:
    #include <math.h>
    double power(double base, double exp) {
        return pow(base, exp);
    }
出 power

印(power(2, 10))

    引用 Go¶

    引 Go:
    func hello(name string) string {
        return "Hello, " + name
    }
出 hello

印(hello("光明"))

    引用 MoonBit¶

    引 MoonBit:
    fn add(a: Int, b: Int) -> Int {
        a + b
    }
出 add

印(add(1, 2))

    运算符优先级¶

    从高到低：

    1. **（幂运算）
    2. 非（逻辑非）
    3. * / % // 乘 除 模
    4. + - 加 减
    5. > < >= <= == !=（比较）
    6. 且（逻辑与）
    7. 或（逻辑或）
    8. = += -= *= /= %=（赋值）
