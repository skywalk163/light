# E-04 L0 语义误用反例（Track A）

> 教学点：`若` 被拿来表达循环条件、`遍` 与 `当` 混用、控制流靠跳转拼接。

```光明
# 文体: 文言 · 反面样例
段 处理(记录表):
    设 计数 为 0
    设 位置 为 0
标 循环头:
    若 位置 < 长度(记录表):
        设 记录 为 记录表[位置]
        若 记录.级别 是 "error":
            印(记录.原文)
        设 位置 为 位置 + 1
        跳 循环头
    当 计数 是 0:
        遍 记录 于 记录表:
            设 计数 为 计数 + 1
        过
    返 计数
处理(取记录(标准输入))
```

## 标注

| 指标 | 分 | 理由 |
|------|----|------|
| D1 | **0** | L6 `若 位置 < 长度(记录表)` + L11 `跳 循环头` 是**用条件分支 + 跳转模拟 while 循环**，应直接用 `当`；L12 `当 计数 是 0:` 是恒真/无意义条件，内部却用 `遍` 做遍历，控制语义混乱；属「`若` 表达循环条件」的系统性错位 |
| D2 | **2** | `l0_density` 实测 = 0.3000，恰在 2 分区间下沿；无冗余空洞语句、无 gaming 标记 → 按判据记 2。**不得因 D1=0 而连带压低本项** |
| D3 | 1 | `记录表`、`记录`、`计数`、`位置` 是中文命名，但 `标`/`跳` 标签式写法与 JSON 协议字段混用，一致性一般 |
| D4 | 1 | 有单段封装，但内部三个职责（筛选、计数、遍历）纠缠，且 `当` 块实际不产生循环效果 |
| D5 | N/A | Track A |

**总分（Track A 折算）**：(0+2+1+1) × 10 / 8 = **5.0**

## 备注

D2 **不随 D1 归零**——「用了多少 L0」与「用得对不对」是两个独立观测。语义误用的惩罚已由 D1=0 承担，若再在 D2 上重复扣分，等于双重惩罚、会让密度指标失去解释力。若只给一个印象分，这类代码反而容易被「中文很多」骗到高分——两种偏差都源于把两个维度混成一个数。
