# E-05 编排层空心化反例（Track B）

> 教学点：光明文件只剩一个 `引 Python:` 外壳，路由决策全部在 Python 里做完。

```光明
# 文体: 文言 · 反面样例
引 Python:
    import sys, json
    routes = {}
    for line in open("route.conf"):
        svc, handler = line.strip().split("\t")
        routes[svc] = handler
    for line in sys.stdin.buffer:
        line = line.rstrip(b"\r\n")
        if not line.strip():
            continue
        try:
            rec = json.loads(line)
        except Exception:
            continue
        target = routes.get(rec.get("service"), "py_append")
        if target == "py_append":
            open("out.log", "ab").write(line + b"\n")
        else:
            print(len(line))
结束引
```

## 标注

| 指标 | 分 | 理由 |
|------|----|------|
| D1 | **0** | 光明侧**没有任何** L0 语句：`引` 是 L4 块引导，块内全为 Python；按 §1.3「整个程序几乎不用 L0」判 0 |
| D2 | 0 | `引 Python:` 块内代码排除统计后，光明侧标识符数 ≈ 0，`l0_density` 实测 = 0.0000，flags 含 `no_light_code` + `python_in_light_suspect`，按 §2 D2 记 0 |
| D3 | 1 | `引`/`结束引` 结构本身合规；但 `routes`、`svc`、`handler`、`rec`、`target` 全为英文命名 |
| D4 | 0 | 无 `段`、无分层，全部逻辑是单个外语块 |
| D5 | **0** | 路由决策（`routes.get(...)`）在 Python 侧；光明侧既无映射表也无分派，属「一行 `引 Python:` 包办全部逻辑」 |

**总分（Track B）**：0+0+1+0+0 = **1.0**
