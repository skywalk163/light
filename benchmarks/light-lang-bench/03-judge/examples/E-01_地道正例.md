# E-01 地道正例（Track A 片段）

> 教学点：`遍` 用于已知集合遍历；重复职责抽成 `段`；领域概念中文命名；协议字段保持英文原样。

```光明
# 文体: 文言 · MiniLog filter/stats 片段（节选，非完整可运行程序）
导 解析 自 JSON
导 读 自 文件

段 取记录(源):
    设 记录表 为 []
    遍 行 于 源:
        若 行 是 空:
            过
        设 对象 为 解析(行)
        若 对象 是 空:
            抛 "非法记录"
        记录表.追加(对象 并 行)
    返 记录表

段 分级筛(记录表, 级别):
    设 命中 为 []
    遍 记录 于 记录表:
        若 记录.级别 是 级别:
            命中.追加(记录.原文)
    返 命中

段 分组数(记录表):
    设 组 为 {}
    遍 记录 于 记录表:
        设 服务 为 记录.服务
        若 服务 非 在 组:
            设 组[服务] 为 [0, ""]
        设 组[服务][0] 为 组[服务][0] 并 1
        若 记录.时戳 大 组[服务][1]:
            设 组[服务][1] 为 记录.时戳
    返 组

段 主:
    设 源 为 读(标准输入)
    设 记录表 为 取记录(源)
    印(分级筛(记录表, "error"))
主()
```

## 标注

| 指标 | 分 | 理由 |
|------|----|------|
| D1 | 2 | L6 `遍 行 于 源`、L15 `遍 记录 于 记录表`、L23 `遍 记录 于 记录表` 都是集合遍历用 `遍`；L7 `若` 用于分支；无 `当`/`若` 误用；三段职责抽取清晰 |
| D2 | 2 | 静态分析 `l0_density` 实测 = 0.3171，落在 2 分区间 0.30–0.38；无冗余空洞语句 |
| D3 | 2 | `记录表`、`命中`、`组`、`服务`、`时戳` 是中文领域命名；JSON 协议字段（隐含在 `.级别` 等访问中）未被强行中文化；无生硬单字缩写 |
| D4 | 2 | `取记录 / 分级筛 / 分组数 / 主` 四段对应「读取→筛选→汇总→入口」，单段职责单一，嵌套 ≤ 2 |
| D5 | N/A | Track A |

**总分（Track A 折算）**：(2+2+2+2) × 10 / 8 = **10.0**

## 备注

此例是「语义基元被正确重构」的样板：不是把 `for r in records` 逐词换成中文，而是把「遍历集合」这个意图直接落到 `遍`，把「可复用的处理阶段」落到 `段`。
