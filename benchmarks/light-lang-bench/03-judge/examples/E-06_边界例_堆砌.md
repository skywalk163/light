# E-06 边界例：关键字正确但为凑密度堆砌（Track A）

> 教学点：D1 高不等于 D2 高；Judge 有权在明显堆砌时降 D2，但必须指出具体冗余行。

```光明
# 文体: 文言 · 边界样例
段 筛(记录表, 级别):
    设 命中 为 []
    遍 记录 于 记录表:
        若 记录 是 空:
            过
        若 记录.级别 是 级别:
            设 临时 为 记录.原文
            设 临时二 为 临时
            设 临时三 为 临时二
            若 临时三 非 空:
                设 命中 为 命中 并 临时三
            否:
                过
        否:
            过
    返 命中
```

## 标注

| 指标 | 分 | 理由 |
|------|----|------|
| D1 | 2 | `遍` 遍历、`若` 分支、`过` 跳过，语义全部正确，无误用 |
| D2 | **1** | `l0_density` 实测 = 0.4400（> 0.38，落入 1 分区间）。**冗余证据**：L9–11 `临时 → 临时二 → 临时三` 三次纯中转绑定；L5–6 与 L14–15 两个 `否: 过` 空分支无任何作用。判为「明显为凑数插入的空洞语句」 |
| D3 | 2 | `记录表`、`命中` 命名自洽；但 `临时/临时二/临时三` 属无信息量命名，不额外扣分（归入 D2） |
| D4 | 1 | 单段封装尚可，但内层 `若...否:过` 使嵌套达 3 层且职责表达冗余，不是清晰分层 |
| D5 | N/A | Track A |

**总分（Track A 折算）**：(2+1+2+1) × 10 / 8 = **7.5**

## 备注

此例专门校准「密度越高越地道」的错误直觉。Judge 降 D2 时**必须**在 `evidence` 中列出冗余行号，否则按 §5.4 视为无效输出。
