# E-03 翻译腔反例（Track A）

> 教学点：英文实现逐句对译 —— 英文变量名照搬、`for` 用手写索引 + `当` 模拟、单一大块、临时变量堆叠。

```光明
# 文体: 文言 · 反面样例
段 main():
    设 records 为 []
    设 lines 为 split(读(标准输入), "\n")
    设 i 为 0
    当 i < length(lines):
        设 line 为 lines[i]
        设 obj 为 解析(line)
        设 tmp 为 obj
        设 tmp2 为 tmp
        设 records 为 append(records, tmp2)
        设 i 为 i + 1
    设 result 为 []
    设 j 为 0
    当 j < length(records):
        设 r 为 records[j]
        若 r.level 是 "error":
            设 result 为 append(result, r.raw)
        设 j 为 j + 1
    印(result)
main()
```

## 标注

| 指标 | 分 | 理由 |
|------|----|------|
| D1 | 1 | L7 `当 i < length(lines)` 与 L15 `当 j < length(records)` 用手写索引遍历**已知集合**，本应 `遍 ... 于 ...`；分支用 `若` 正确，未见 `若`/`当` 语义错位，故不是 0 |
| D2 | 1 | `l0_density` 实测 = 0.2405，落在 1 分区间；大量 `设` 但多为无意义中转（L10–12 `obj`→`tmp`→`tmp2`） |
| D3 | 0 | `records`、`lines`、`line`、`obj`、`tmp`、`tmp2`、`result`、`main`、`i`、`j`、`r` 全部照搬英文命名；零中文领域概念 |
| D4 | 0 | 单个 `main` 段承担读取、解析、筛选、输出 4 个职责；`设 obj → tmp → tmp2` 是典型英文逐句镜像，无 `段` 抽象 |
| D5 | N/A | Track A |

**总分（Track A 折算）**：(1+1+0+0) × 10 / 8 = **2.5**
