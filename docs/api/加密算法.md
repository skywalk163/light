# 加密算法 API

> 模块路径：`stdlib/加密算法.py`
> 导入方式：`从 加密算法 导入 函数名` 或 `导入 加密算法`

---

## 函数列表

| 函数 | 说明 |
|------|------|
| `获取算法名称()` | 获取支持的加密算法名称列表 |
| `生成密钥(算法)` | 根据算法生成密钥字节 |
| `生成IV(算法)` | 根据算法生成初始向量（IV） |
| `_derive_key(密钥, 盐值, 长度)` | 使用 PBKDF2 派生密钥 |
| `_xor_encrypt(数据, 密钥)` | XOR 加密（流模式） |
| `加密(明文, 密钥, 算法, iv)` | 加密数据 |
| `解密(密文, 密钥, 算法)` | 解密数据 |

---

## 函数详情

### `获取算法名称()`

获取支持的加密算法名称列表

**参数：**

无参数。

---

### `生成密钥(算法 = 'aes-256-cbc')`

根据算法生成密钥字节

**参数：**

| 参数名 | 类型 | 说明 |
|--------|------|------|
| `算法` | `None` | （默认：'aes-256-cbc'） |

---

### `生成IV(算法 = 'aes-256-cbc')`

根据算法生成初始向量（IV）

**参数：**

| 参数名 | 类型 | 说明 |
|--------|------|------|
| `算法` | `None` | （默认：'aes-256-cbc'） |

---

### `_derive_key(密钥, 盐值, 长度 = 32)`

使用 PBKDF2 派生密钥

**参数：**

| 参数名 | 类型 | 说明 |
|--------|------|------|
| `密钥` | `None` |  |
| `盐值` | `None` |  |
| `长度` | `None` | （默认：32） |

---

### `_xor_encrypt(数据, 密钥)`

XOR 加密（流模式）

**参数：**

| 参数名 | 类型 | 说明 |
|--------|------|------|
| `数据` | `None` |  |
| `密钥` | `None` |  |

---

### `加密(明文, 密钥, 算法 = 'aes-256-cbc', iv = None)`

加密数据

使用派生密钥 + XOR 流加密实现。
返回 base64 编码的密文（包含盐值和 IV）。

**参数：**

| 参数名 | 类型 | 说明 |
|--------|------|------|
| `明文` | `None` |  |
| `密钥` | `None` |  |
| `算法` | `None` | （默认：'aes-256-cbc'） |
| `iv` | `None` | （默认：None） |

---

### `解密(密文, 密钥, 算法 = 'aes-256-cbc')`

解密数据

**参数：**

| 参数名 | 类型 | 说明 |
|--------|------|------|
| `密文` | `None` |  |
| `密钥` | `None` |  |
| `算法` | `None` | （默认：'aes-256-cbc'） |

---

## 常量

| 常量名 | 值 |
|--------|-----|
| `result` | `bytearray()` |
| `key_len` | `len(密钥)` |
| `key_sizes` | `{'aes-128-cbc': 16, 'aes-256-cbc': 32, 'aes-128-gcm': 16, 'aes-256-gcm': 32, 'des3': 24, 'rc4': 16, 'sm4': 16}` |
| `size` | `key_sizes.get(算法, 32)` |
| `iv_sizes` | `{'aes-128-cbc': 16, 'aes-256-cbc': 16, 'aes-128-gcm': 12, 'aes-256-gcm': 12, 'des3': 8, 'rc4': 0, 'sm4': 16}` |
| `size` | `iv_sizes.get(算法, 16)` |
| `盐值` | `_os.urandom(16)` |
| `key_size` | `32 if '256' in 算法 else 16` |
| `derived_key` | `_derive_key(密钥, 盐值, key_size)` |
| `ciphertext` | `_xor_encrypt(明文, derived_key + iv)` |
| `result` | `盐值 + iv + ciphertext` |
| `raw` | `_b64.b64decode(密文)` |
| `盐值` | `raw[:16]` |
| `iv_size` | `16` |
| `iv` | `raw[16:16 + iv_size]` |
| `ciphertext` | `raw[16 + iv_size:]` |
| `key_size` | `32 if '256' in 算法 else 16` |
| `derived_key` | `_derive_key(密钥, 盐值, key_size)` |
| `plaintext` | `_xor_encrypt(ciphertext, derived_key + iv)` |
| `明文` | `明文.encode('utf-8')` |
| `密钥` | `密钥.encode('utf-8')` |
| `iv` | `生成IV(算法)` |
| `密文` | `密文.encode('ascii')` |
| `密钥` | `密钥.encode('utf-8')` |
| `iv_size` | `12` |
