# 集合扩展 API

> 模块路径：`stdlib/集合扩展.py`
> 导入方式：`从 集合扩展 导入 函数名` 或 `导入 集合扩展`

---

## 函数列表

| 函数 | 说明 |
|------|------|
| `列表_排序(列表, 反转, 键)` | 排序列表，返回新列表 |
| `列表_过滤(列表, 条件函数)` | 过滤列表，返回满足条件的元素新列表 |
| `列表_映射(列表, 转换函数)` | 对列表每个元素应用转换函数，返回新列表 |
| `列表_去重(列表, 键)` | 列表去重，保持顺序，返回新列表 |
| `列表_分组(列表, 键函数)` | 按指定键函数对列表分组，返回{键: [元素列表]} |
| `列表_分块(列表, 块大小)` | 将列表分块为指定大小的子列表 |
| `列表_扁平化(嵌套列表)` | 将嵌套列表扁平化为一层 |
| `列表_复制(列表)` | 复制列表（浅拷贝） |
| `字典_合并()` | 合并多个字典，返回新字典（后面的覆盖前面的） |
| `字典_获取键组(字典, 键列表)` | 从字典中获取指定键的键值对，返回新字典 |
| `字典_获取值组(字典, 键列表, 默认值)` | 从字典中获取指定键的值列表 |
| `字典_过滤(字典, 条件函数)` | 过滤字典中满足条件的键值对，返回新字典 |
| `集合_交集(集合1, 集合2)` | 返回两个集合的交集 |
| `集合_并集(集合1, 集合2)` | 返回两个集合的并集 |
| `集合_差集(集合1, 集合2)` | 返回两个集合的差集（在集合1中但不在集合2中） |
