# CSV API

> 模块路径：`stdlib/CSV.py`
> 导入方式：`从 CSV 导入 函数名` 或 `导入 CSV`

---

## 函数列表

| 函数 | 说明 |
|------|------|
| `inferCellType(值)` | 推断单元格值类型，返回 'int'/'float'/'bool'/'string' |
| `convertCellValue(值)` | 将单元格字符串转换为推断后的类型值 |
| `parseCSV(文本, 分隔符, 有表头)` | 解析 CSV 文本，返回二维列表（含表头） |
| `parseCSVFile(文件路径, 分隔符, 有表头)` | 解析 CSV 文件，返回二维列表 |
| `parseCSVStream(文件对象, 分隔符)` | 从文件流解析 CSV，返回二维列表 |
| `autoDetectDelimiter(文本)` | 自动检测 CSV 分隔符，返回分隔符字符 |
| `toDictList(数据, 有表头)` | 将二维列表转为字典列表（第一行作为表头） |
| `to2DArray(字典列表, 表头)` | 将字典列表转为二维列表（含表头行） |
| `getColumn(数据, 列名或索引)` | 获取指定列的所有值（支持列名或索引） |
| `serializeCSV(数据, 分隔符, 有表头)` | 将二维列表序列化为 CSV 文本 |
| `serializeCSVFile(文件路径, 数据, 分隔符, 有表头)` | 将二维列表序列化并写入 CSV 文件 |
| `解析CSV(文本, 分隔符)` | 解析 CSV 文本，返回二维列表 |
| `解析CSV文件(文件路径, 分隔符)` | 解析 CSV 文件，返回二维列表 |
| `序列化CSV(数据, 分隔符)` | 将二维列表序列化为 CSV 文本 |
| `序列化CSV文件(文件路径, 数据, 分隔符)` | 将二维列表序列化并写入 CSV 文件 |
| `自动检测分隔符(文本)` | 自动检测 CSV 分隔符 |
| `转字典列表(数据, 有表头)` | 将二维列表转为字典列表 |
| `转二维数组(字典列表, 表头)` | 将字典列表转为二维列表 |
| `获取列(数据, 列名或索引)` | 获取指定列的所有值 |
| `推断单元格类型(值)` | 推断单元格值类型 |
| `转换单元格值(值)` | 将单元格字符串转换为推断后的类型值 |

## 常量

| 常量名 | 值 |
|--------|-----|
| `s` | `str(值).strip()` |
| `类型` | `inferCellType(值)` |
| `s` | `str(值).strip() if 值 is not None else ''` |
| `reader` | `_csv.reader(_io.StringIO(文本), delimiter=分隔符)` |
| `reader` | `_csv.reader(文件对象, delimiter=分隔符)` |
| `候选` | `[',', '\t', ';', '|']` |
| `最佳` | `','` |
| `最佳得分` | `-1` |
| `第一行` | `文本.split('\n')[0] if '\n' in 文本 else 文本` |
| `结果` | `[]` |
| `结果` | `[表头[:]]` |
| `output` | `_io.StringIO()` |
| `writer` | `_csv.writer(output, delimiter=分隔符, lineterminator='\n')` |
| `得分` | `第一行.count(d)` |
| `表头` | `数据[0]` |
| `行` | `数据[1:]` |
| `表头` | `['列' + str(i) for i in range(len(数据[0]))]` |
| `行` | `数据` |
| `项` | `{}` |
| `表头` | `list(字典列表[0].keys())` |
| `行` | `[str(项.get(col, '')) for col in 表头]` |
| `reader` | `_csv.reader(f, delimiter=分隔符)` |
| `最佳得分` | `得分` |
| `最佳` | `d` |
| `writer` | `_csv.writer(f, delimiter=分隔符, lineterminator='\n')` |
