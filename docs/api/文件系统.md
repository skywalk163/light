# 文件系统 API

> 模块路径：`stdlib/文件系统.py`
> 导入方式：`从 文件系统 导入 函数名` 或 `导入 文件系统`

---

## 函数列表

| 函数 | 说明 |
|------|------|
| `读取文件(文件路径, 编码)` | 读取文件全部内容，返回字符串 |
| `写入文件(文件路径, 内容, 编码)` | 写入文件（覆盖），返回 True/False |
| `追加写入(文件路径, 内容, 编码)` | 追加写入文件，返回 True/False |
| `按行读取(文件路径, 编码)` | 按行读取文件，返回字符串列表 |
| `按字节读取(文件路径, 最大长度)` | 按字节读取文件，返回 bytes |
| `文件是否存在(路径)` | 检查文件/目录是否存在 |
| `文件大小(文件路径)` | 获取文件大小（字节） |
| `获取修改时间(文件路径)` | 获取文件最后修改时间（时间戳） |
| `获取文件信息(文件路径)` | 获取文件信息，返回 文件信息 对象 |
| `删除文件(文件路径)` | 删除文件 |
| `重命名文件(旧路径, 新路径)` | 重命名/移动文件 |
| `复制文件(源路径, 目标路径)` | 复制文件 |
| `列出目录(目录路径)` | 列出目录下的文件和子目录名，返回列表 |
| `递归遍历(目录路径)` | 递归遍历目录，返回所有文件的完整路径列表 |
| `创建目录(目录路径)` | 创建目录（含父目录） |
| `删除目录(目录路径)` | 删除目录及其所有内容 |
| `检查可读(文件路径)` | 检查文件是否可读 |
| `检查可写(文件路径)` | 检查文件是否可写 |
| `检查可执行(文件路径)` | 检查文件是否可执行 |
| `获取权限(文件路径)` | 获取文件权限码 |
| `设置权限(文件路径, 权限码)` | 设置文件权限 |
| `创建临时文件(后缀, 前缀)` | 创建临时文件，返回文件路径 |
| `创建临时目录(前缀)` | 创建临时目录，返回目录路径 |
| `检查文件变更(文件路径, 上次修改时间)` | 检查文件是否在上次修改时间之后被修改 |
| `等待文件变更(文件路径, 超时秒, 轮询间隔)` | 等待文件变更，返回 True/False（超时返回 False） |
| `__init__(self, 路径, 大小, 是否目录, 是否文件, 修改时间, 创建时间, 访问时间)` |  |
