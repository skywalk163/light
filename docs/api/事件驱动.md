# 事件驱动 API

> 模块路径：`stdlib/事件驱动.py`
> 导入方式：`从 事件驱动 导入 函数名` 或 `导入 事件驱动`

---

## 函数列表

| 函数 | 说明 |
|------|------|
| `创建事件循环()` | 创建新的事件循环，返回事件循环对象 |
| `事件循环添加事件(loop, event_name, callback)` | 向事件循环添加事件监听器 |
| `事件循环运行(loop)` | 运行事件循环 |
| `事件循环停止(loop)` | 停止事件循环 |
| `创建事件(event_name, data)` | 创建事件对象 |
| `触发事件(loop, event_name, data)` | 触发事件，调用所有注册的监听器 |

---

**参数：**

无参数。

## 常量

| 常量名 | 值 |
|--------|-----|
| `loop` | `_asyncio.new_event_loop()` |
| `event` | `创建事件(event_name, data)` |
| `events` | `getattr(loop, '_events', {})` |
| `callbacks` | `events.get(event_name, [])` |
