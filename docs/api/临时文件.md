## 函数详情

### `创建临时文件(后缀: str = '', 前缀: str = 'tmp', 目录: str = None, 文本模式: bool = True) -> Tuple[int, str]`

创建临时文件，返回(文件描述符, 文件路径)

参数:
    后缀: 文件名后缀
    前缀: 文件名前缀
    目录: 临时文件所在目录
    文本模式: 是否文本模式

返回:
    (文件描述符, 文件路径)

**参数：**

| 参数名 | 类型 | 说明 |
|--------|------|------|
| `后缀` | `str` | （默认：''） |
| `前缀` | `str` | （默认：'tmp'） |
| `目录` | `str` | （默认：None） |
| `文本模式` | `bool` | （默认：True） |

**返回：** `Tuple[int, str]`

---
