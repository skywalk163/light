# JSON 解析与序列化 API

> 模块路径：`stdlib/JSON.py`
> 导入方式：`从 JSON 导入 函数名` 或 `导入 JSON`

---

## 函数列表

| 函数 | 说明 |
|------|------|
| `解析JSON(文本)` | 解析 JSON 字符串，返回 dict/list/str/number/bool/None |
| `安全解析JSON(文本)` | 安全解析 JSON 字符串，失败返回 None |
| `解析JSON文件(文件路径)` | 从文件读取并解析 JSON，返回解析后的值 |
| `序列化JSON(值, 缩进, 确保ASCII)` | 将值序列化为 JSON 字符串 |
| `序列化JSON文件(文件路径, 值, 缩进, 确保ASCII)` | 将值序列化为 JSON 并写入文件 |
| `JSON美化(值, 缩进)` | 美化 JSON 输出（带缩进） |
| `JSON压缩(文本)` | 压缩 JSON 字符串（去除空白） |
| `JSON合并(基础)` | 合并多个 JSON 对象（浅合并），返回新 dict |
| `深合并(基础)` | 深度合并多个 JSON 对象，返回新 dict |
| `JSON深度相等(值1, 值2)` | 比较两个 JSON 值是否深度相等 |
| `JSON类型(值)` | 获取 JSON 值的类型名称（对象/数组/字符串/数字/布尔/空） |
| `取值形态(值)` | 取值形态（同 JSON类型，返回类型名称） |
| `是JSON对象(值)` | 判断是否为 JSON 对象（dict） |
| `是JSON数组(值)` | 判断是否为 JSON 数组（list） |
| `是JSON字符串(值)` | 判断是否为 JSON 字符串 |
| `是JSON数字(值)` | 判断是否为 JSON 数字 |
| `是JSON布尔(值)` | 判断是否为 JSON 布尔值 |
| `JSON指针获取(数据, 指针)` | 按 JSON Pointer 路径获取值，路径如 /a/b/0 |
| `JSON指针设置(数据, 指针, 值)` | 按 JSON Pointer 路径设置值，返回修改后的数据 |
| `_set_pointer(当前, tokens, 值)` | 内部：递归设置指针值 |
| `JSON指针删除(数据, 指针)` | 按 JSON Pointer 路径删除值，返回修改后的数据 |
| `_del_pointer(当前, tokens)` | 内部：递归删除指针值 |
