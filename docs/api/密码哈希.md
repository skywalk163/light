# 密码哈希 API

> 模块路径：`stdlib/密码哈希.py`
> 导入方式：`从 密码哈希 导入 函数名` 或 `导入 密码哈希`

---

## 函数列表

| 函数 | 说明 |
|------|------|
| `获取算法名称()` | 获取密码哈希算法名称 |
| `哈希密码(密码, 盐值, 算法)` | 哈希密码，返回包含盐值的哈希字符串 |
| `验证密码(密码, 哈希字符串)` | 验证密码与哈希字符串是否匹配 |
| `生成盐值(长度)` | 生成密码盐值 |

---

## 函数详情

### `获取算法名称()`

获取密码哈希算法名称

**参数：**

无参数。

---

### `哈希密码(密码, 盐值 = None, 算法 = 'scrypt')`

哈希密码，返回包含盐值的哈希字符串

格式: $algorithm$salt$hash（base64 编码）

**参数：**

| 参数名 | 类型 | 说明 |
|--------|------|------|
| `密码` | `None` |  |
| `盐值` | `None` | （默认：None） |
| `算法` | `None` | （默认：'scrypt'） |

---

### `验证密码(密码, 哈希字符串)`

验证密码与哈希字符串是否匹配

**参数：**

| 参数名 | 类型 | 说明 |
|--------|------|------|
| `密码` | `None` |  |
| `哈希字符串` | `None` |  |

---

### `生成盐值(长度 = 16)`

生成密码盐值

**参数：**

| 参数名 | 类型 | 说明 |
|--------|------|------|
| `长度` | `None` | （默认：16） |

---

## 常量

| 常量名 | 值 |
|--------|-----|
| `salt_b64` | `_b64.b64encode(盐值).decode('ascii')` |
| `hash_b64` | `_b64.b64encode(哈希值).decode('ascii')` |
| `parts` | `哈希字符串.split('$')` |
| `算法` | `parts[1]` |
| `salt_b64` | `parts[2]` |
| `original_hash_b64` | `parts[3]` |
| `盐值` | `_b64.b64decode(salt_b64)` |
| `new_hash_b64` | `_b64.b64encode(新哈希值).decode('ascii')` |
| `密码` | `密码.encode('utf-8')` |
| `盐值` | `_os.urandom(16)` |
| `密码` | `密码.encode('utf-8')` |
| `盐值` | `盐值.encode('utf-8')` |
| `哈希值` | `_hashlib.scrypt(密码, salt=盐值, n=16384, r=8, p=1, dklen=32)` |
| `哈希值` | `_hashlib.pbkdf2_hmac('sha256', 密码, 盐值, 100000, dklen=32)` |
| `新哈希值` | `_hashlib.scrypt(密码, salt=盐值, n=16384, r=8, p=1, dklen=32)` |
| `新哈希值` | `_hashlib.pbkdf2_hmac('sha256', 密码, 盐值, 100000, dklen=32)` |
| `哈希值` | `_hashlib.pbkdf2_hmac('sha256', 密码, 盐值, 100000, dklen=32)` |
| `新哈希值` | `_hashlib.pbkdf2_hmac('sha256', 密码, 盐值, 100000, dklen=32)` |
