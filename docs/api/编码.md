# 编码工具 API

> 模块路径：`stdlib/编码.py`
> 导入方式：`从 编码 导入 函数名` 或 `导入 编码`

---

## 函数列表

| 函数 | 说明 |
|------|------|
| `Base64编码(数据)` | Base64 编码 |
| `Base64解码(数据)` | Base64 解码 |
| `Hex编码(数据)` | Hex（十六进制）编码 |
| `Hex解码(数据)` | Hex（十六进制）解码 |
| `MD5哈希(数据)` | 计算 MD5 哈希值 |
| `SHA1哈希(数据)` | 计算 SHA-1 哈希值 |
| `SHA256哈希(数据)` | 计算 SHA-256 哈希值 |
| `SHA512哈希(数据)` | 计算 SHA-512 哈希值 |
| `字符串转字节(文本, 编码)` | 字符串转字节数组 |
| `字节转字符串(字节, 编码)` | 字节数组转字符串 |
| `字节长度(数据)` | 获取字节数组长度 |
