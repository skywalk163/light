## 函数详情

### `执行命令(命令: Union[str, List[str]], 捕获输出: bool = True, 工作目录: str = None, 环境变量: Dict[str, str] = None, 超时: float = None, 编码: str = 'utf-8') -> 命令结果`

执行外部命令

参数:
    命令: 命令字符串或命令列表
    捕获输出: 是否捕获标准输出和标准错误
    工作目录: 工作目录
    环境变量: 环境变量字典（会合并到当前环境）
    超时: 超时时间（秒）
    编码: 输出编码

返回:
    命令结果对象

**参数：**

| 参数名 | 类型 | 说明 |
|--------|------|------|
| `命令` | `Union[str, List[str]]` |  |
| `捕获输出` | `bool` | （默认：True） |
| `工作目录` | `str` | （默认：None） |
| `环境变量` | `Dict[str, str]` | （默认：None） |
| `超时` | `float` | （默认：None） |
| `编码` | `str` | （默认：'utf-8'） |

**返回：** `命令结果`
