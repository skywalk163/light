# 环境变量 API

> 模块路径：`stdlib/环境变量.py`
> 导入方式：`从 环境变量 导入 函数名` 或 `导入 环境变量`

---

## 函数列表

| 函数 | 说明 |
|------|------|
| `获取环境变量(键, 默认值)` | 获取环境变量值，不存在返回默认值 |
| `设置环境变量(键, 值)` | 设置环境变量 |
| `删除环境变量(键)` | 删除环境变量 |
| `环境变量是否存在(键)` | 检查环境变量是否存在 |
| `列出全部环境变量()` | 列出所有环境变量的键值对列表，返回[(键, 值), ...] |
| `获取环境变量或抛出(键)` | 获取环境变量值，不存在则抛出异常 |
| `展开环境变量(文本)` | 展开文本中的环境变量引用，如 $VAR 或 %VAR% |
| `解析env文本(文本)` | 解析环境变量文本，返回{键: 值}字典 |
| `解析env文件(文件路径)` | 从文件解析环境变量，返回{键: 值}字典 |
| `加载env文件(文件路径)` | 加载env文件到当前环境变量 |
| `获取环境变量整数(键, 默认值)` | 获取环境变量值并转为整数 |
| `获取环境变量布尔(键, 默认值)` | 获取环境变量值并转为布尔 |
| `获取环境变量列表(键, 分隔符, 默认值)` | 获取环境变量值并分割为列表 |
| `环境变量到字符串()` | 将所有环境变量转为字符串 |
| `范围(开始, 结束)` | 返回指定范围的整数列表 |
