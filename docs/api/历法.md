# 历法工具 API

> 模块路径：`stdlib/历法.py`
> 导入方式：`从 历法 导入 函数名` 或 `导入 历法`

---

## 函数详情

### `公历转农历(年, 月, 日)`

公历日期转农历日期。

返回: 字典 {年, 月, 日, 闰月}

**参数：**

| 参数名 | 类型 | 说明 |
|--------|------|------|
| `年` | `None` |  |
| `月` | `None` |  |
| `日` | `None` |  |

---

### `农历转公历(年, 月, 日, 闰月 = False)`

农历日期转公历日期。

参数:
    闰月: 该月是否为闰月

返回: 字典 {年, 月, 日}

**参数：**

| 参数名 | 类型 | 说明 |
|--------|------|------|
| `年` | `None` |  |
| `月` | `None` |  |
| `日` | `None` |  |
| `闰月` | `None` | （默认：False） |

---

### `_estimate_solar_term(year, term_index)`

估算指定年份第 n 个节气的公历日期。

基于《天文算法》中的近似公式。

返回: (月, 日)

**参数：**

| 参数名 | 类型 | 说明 |
|--------|------|------|
| `year` | `None` |  |
| `term_index` | `None` |  |

---

### `节气(年, 序号)`

获取指定年份第 n 个节气的日期。

参数:
    年: 公历年份
    序号: 节气序号 0-23（0=小寒, 1=大寒, 2=立春, ...）

返回: 字典 {名称, 月, 日}

**参数：**

| 参数名 | 类型 | 说明 |
|--------|------|------|
| `年` | `None` |  |
| `序号` | `None` |  |

---

### `节气列表(年)`

获取指定年份全部 24 个节气。

返回: 列表，每个元素是 {名称, 月, 日}

**参数：**

| 参数名 | 类型 | 说明 |
|--------|------|------|
| `年` | `None` |  |

---

### `查找节气(年, 名称)`

按名称查找指定年份的节气。

返回: 字典 {名称, 月, 日}，找不到返回 None

**参数：**

| 参数名 | 类型 | 说明 |
|--------|------|------|
| `年` | `None` |  |
| `名称` | `None` |  |

---

### `天干(序号)`

获取天干。

参数:
    序号: 0-9（0=甲, 1=乙, ...）

返回: 天干字符

**参数：**

| 参数名 | 类型 | 说明 |
|--------|------|------|
| `序号` | `None` |  |

---

### `地支(序号)`

获取地支。

参数:
    序号: 0-11（0=子, 1=丑, ...）

返回: 地支字符

**参数：**

| 参数名 | 类型 | 说明 |
|--------|------|------|
| `序号` | `None` |  |

---

### `干支(序号)`

获取干支（六十甲子）。

参数:
    序号: 0-59

返回: 干支字符串（如"甲子"）

**参数：**

| 参数名 | 类型 | 说明 |
|--------|------|------|
| `序号` | `None` |  |

---

### `干支纪年(年)`

获取公历年份的干支纪年。

参数:
    年: 公历年份

返回: 干支字符串（如"丙午"）

注意: 以立春为分界，这里简化为以公历年计算。
      已知 1984 年为甲子年。

**参数：**

| 参数名 | 类型 | 说明 |
|--------|------|------|
| `年` | `None` |  |

---

### `干支纪月(年, 月)`

获取公历年月的干支纪月。

返回: 干支字符串

**参数：**

| 参数名 | 类型 | 说明 |
|--------|------|------|
| `年` | `None` |  |
| `月` | `None` |  |

---

### `干支纪日(年, 月, 日)`

获取公历日期的干支纪日。

基于已知基准日推算。
已知: 1900年1月1日为甲戌日（干支序号 10）。

返回: 干支字符串

**参数：**

| 参数名 | 类型 | 说明 |
|--------|------|------|
| `年` | `None` |  |
| `月` | `None` |  |
| `日` | `None` |  |

---

### `生肖(年)`

获取公历年份对应的生肖。

参数:
    年: 公历年份

返回: 生肖字符（如"马"）

注意: 以立春为分界，这里简化为以公历年计算。
      已知 2020 年为鼠年。

**参数：**

| 参数名 | 类型 | 说明 |
|--------|------|------|
| `年` | `None` |  |

---

### `农历月名(月, 闰月 = False)`

获取农历月份名称。

参数:
    月: 农历月份 1-12
    闰月: 是否为闰月

返回: 月份名（如"正月"、"闰四月"）

**参数：**

| 参数名 | 类型 | 说明 |
|--------|------|------|
| `月` | `None` |  |
| `闰月` | `None` | （默认：False） |

---

### `农历日名(日)`

获取农历日名称。

参数:
    日: 农历日 1-30

返回: 日名（如"初一"、"十五"、"廿三"）

**参数：**

| 参数名 | 类型 | 说明 |
|--------|------|------|
| `日` | `None` |  |

---

### `农历完整日期(年, 月, 日, 闰月 = False)`

获取农历日期的完整中文名称。

返回: 如"丙午年六月二十"

**参数：**

| 参数名 | 类型 | 说明 |
|--------|------|------|
| `年` | `None` |  |
| `月` | `None` |  |
| `日` | `None` |  |
| `闰月` | `None` | （默认：False） |
