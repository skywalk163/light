## 常量

| 常量名 | 值 |
|--------|-----|
| `圆周率` | `_math.pi` |
| `自然常数` | `_math.e` |
| `无穷大` | `_math.inf` |
| `负无穷` | `-_math.inf` |
| `非数字` | `_math.nan` |
| `n` | `len(列表)` |
| `平均` | `sum(列表) / n` |
| `方差和` | `sum(((x - 平均) ** 2 for x in 列表))` |
| `除数` | `n if 总体 else n - 1` |
