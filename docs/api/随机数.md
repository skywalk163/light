# 随机数生成 API

> 模块路径：`stdlib/随机数.py`
> 导入方式：`从 随机数 导入 函数名` 或 `导入 随机数`

---

## 函数列表

| 函数 | 说明 |
|------|------|
| `设置种子(种子)` | 设置随机数生成器的种子 |
| `随机整数(最小值, 最大值)` | 生成指定范围内的随机整数，包含两端 |
| `随机浮点数(最小值, 最大值)` | 生成指定范围内的随机浮点数 |
| `随机选择(序列)` | 从序列中随机选择一个元素 |
| `随机打乱(序列)` | 随机打乱序列（原地操作） |
| `均匀采样(总体, 样本数)` | 从总体中均匀随机采样（无放回） |
| `正态采样(均值, 标准差)` | 从正态分布中采样一个随机数 |

---
