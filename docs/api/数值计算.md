# 数值计算 API

> 模块路径：`stdlib/数值计算.py`
> 导入方式：`从 数值计算 导入 函数名` 或 `导入 数值计算`

---

## 函数列表

| 函数 | 说明 |
|------|------|
| `内部平方根(x)` | 计算平方根（内部函数，直接返回 math.sqrt） |
| `向量点积(向量A, 向量B)` | 计算两个向量的点积 |
| `向量加法(向量A, 向量B)` | 向量加法 |
| `向量减法(向量A, 向量B)` | 向量减法 |
| `向量模值(向量)` | 计算向量的模（长度） |
| `向量归一化(向量)` | 向量归一化（单位向量） |
| `矩阵乘法(矩阵A, 矩阵B)` | 矩阵乘法 |
| `矩阵转置(矩阵)` | 矩阵转置 |
| `行列式(矩阵)` | 计算方阵的行列式 |
| `矩阵求逆(矩阵)` | 矩阵求逆（高斯消元法） |
| `线性插值(x0, y0, x1, y1, x)` | 线性插值：在点 (x0,y0) 和 (x1,y1) 之间对 x 进行插值 |
| `梯形积分(函数, a, b, n)` | 梯形法数值积分 |
| `辛普森积分(函数, a, b, n)` | 辛普森法数值积分（n 必须为偶数） |
