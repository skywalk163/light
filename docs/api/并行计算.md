# 并行计算 API

> 模块路径：`stdlib/并行计算.py`
> 导入方式：`从 并行计算 导入 函数名` 或 `导入 并行计算`

---

## 函数列表

| 函数 | 说明 |
|------|------|
| `创建线程池(max_workers)` | 创建线程池，返回线程池对象 |
| `线程池提交任务(pool, fn)` | 向线程池提交任务，返回 Future 对象 |
| `创建进程池(max_workers)` | 创建进程池，返回进程池对象 |
| `进程池提交任务(pool, fn)` | 向进程池提交任务，返回 Future 对象 |
| `并行映射(fn)` | 并行映射，对可迭代对象并行执行函数 |
| `等待完成(futures, timeout, return_when)` | 等待 futures 完成 |
| `获取结果(future, timeout)` | 获取 Future 执行结果 |
| `异步执行(fn)` | 异步执行函数，返回 Future 对象 |
