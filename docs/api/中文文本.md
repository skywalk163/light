# 中文文本处理 API

> 模块路径：`stdlib/中文文本.py`
> 导入方式：`从 中文文本 导入 函数名` 或 `导入 中文文本`

---

## 函数列表

| 函数 | 说明 |
|------|------|
| `_is_cjk(char)` | 判断字符是否为 CJK 汉字 |
| `中文分词(文本)` | 简易中文分词：按非中文字符（空格、标点、英文）切分中文文本。 |
| `中文逐字(文本)` | 将中文文本拆分为单个汉字列表 |
| `汉字数量(文本)` | 统计文本中的汉字数量 |
| `转拼音(文本, 首字母模式)` | 将中文文本转为拼音。 |
| `转拼音列表(文本)` | 将中文文本转为拼音列表（每个字一个拼音）。 |
| `转带声调拼音(文本)` | 将中文文本转为带声调的拼音。 |
| `简转繁(文本)` | 简体中文转繁体中文 |
| `繁转简(文本)` | 繁体中文转简体中文 |
| `中文标点转英文(文本)` | 将文本中的中文标点替换为英文标点 |
| `英文标点转中文(文本)` | 将文本中的英文标点替换为中文标点 |
| `笔画数(字符)` | 获取单个汉字的笔画数。 |
| `部首(字符)` | 获取单个汉字的部首。 |
| `数字转中文(数值, 大写)` | 将数字转为中文表示。 |
| `中文转数字(文本)` | 将中文数字转为阿拉伯数字。 |

### `中文分词(文本)`

简易中文分词：按非中文字符（空格、标点、英文）切分中文文本。

返回: 列表，每个元素是一个词或字符块

### `转拼音(文本, 首字母模式 = False)`

将中文文本转为拼音。

参数:
    文本: 中文文本
    首字母模式: True 时只返回首字母

返回: 拼音字符串（多字之间用空格分隔）

**参数：**

| 参数名 | 类型 | 说明 |
|--------|------|------|
| `文本` | `None` |  |
| `首字母模式` | `None` | （默认：False） |

---

### `转拼音列表(文本)`

**参数：**

| 参数名 | 类型 | 说明 |
|--------|------|------|
| `数值` | `None` |  |
