## 常量

| 常量名 | 值 |
|--------|-----|
| `子进程列表` | `[]` |
| `参数` | `[]` |
| `cmd` | `[命令] + 参数` |
| `进程` | `_subprocess.Popen(cmd, cwd=工作目录 or None, env=环境变量, stdout=_subprocess.PIPE, stderr=_subprocess.PIPE, stdin=_subprocess.PIPE, text=True)` |
| `参数` | `[]` |
| `cmd` | `[命令] + 参数` |
| `结果` | `_subprocess.run(cmd, cwd=工作目录 or None, capture_output=True, text=True)` |
| `参数` | `[]` |
| `cmd` | `[命令] + 参数` |
| `结果` | `_subprocess.run(cmd, cwd=工作目录 or None, capture_output=True, text=True, check=True)` |
| `参数` | `[]` |
| `cmd` | `[命令] + 参数` |
| `current_pid` | `_os.getpid()` |
| `current` | `_psutil.Process(current_pid)` |
| `子进程列表` | `[p.info['pid'] for p in current.children(recursive=True)]` |
