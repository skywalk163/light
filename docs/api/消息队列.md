# 消息队列 API

> 模块路径：`stdlib/消息队列.py`
> 导入方式：`从 消息队列 导入 函数名` 或 `导入 消息队列`

---

## 函数列表

| 函数 | 说明 |
|------|------|
| `创建消息队列()` | 创建消息队列 |
| `消息队列发布(mq, topic, message)` | 发布消息到指定主题 |
| `消息队列订阅(mq, topic, callback)` | 订阅指定主题的消息 |
| `消息队列取消订阅(mq, topic, callback)` | 取消订阅指定主题 |
| `消息队列接收消息(mq, timeout)` | 接收消息，返回 (topic, message) 元组 |
| `消息队列确认消息(mq, topic, message)` | 确认消息处理完成 |
| `消息队列获取长度(mq)` | 获取消息队列长度 |
| `消息队列清空(mq)` | 清空消息队列 |
| `消息队列关闭(mq)` | 关闭消息队列 |
| `__init__(self)` |  |
| `publish(self, topic, message)` |  |
