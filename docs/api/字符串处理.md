# 字符串处理 API

> 模块路径：`stdlib/字符串处理.py`
> 导入方式：`从 字符串处理 导入 函数名` 或 `导入 字符串处理`

---

## 函数列表

| 函数 | 说明 |
|------|------|
| `normalizeNFC(文本)` | 将字符串规范化为 NFC 格式 |
| `normalizeNFD(文本)` | 将字符串规范化为 NFD 格式 |
| `isCombiningChar(字符)` | 判断字符是否为组合字符 |
| `toUTF8(文本)` | 将字符串转为 UTF-8 字节 |
| `fromUTF8(数据)` | 将 UTF-8 字节转为字符串 |
| `templateInterpolate(模板, 变量)` | 模板插值，将 {key} 替换为变量中的值 |
| `editDistance(s1, s2)` | 计算两个字符串的编辑距离（Levenshtein） |
| `fuzzyMatch(查询, 文本)` | 模糊匹配：检查文本是否包含查询（不区分大小写） |
| `fuzzyMatchSimilarity(查询, 文本)` | 模糊匹配相似度，返回 0.0-1.0 的值 |
| `strReverse(文本)` | 反转字符串 |
| `strRepeat(文本, 次数)` | 重复字符串 |
| `strTruncate(文本, 最大长度, 后缀)` | 截断字符串到指定长度，超出部分加后缀 |
| `toCamelCase(文本)` | 转为驼峰命名（小驼峰） |
| `toSnakeCase(文本)` | 转为蛇形命名 |
| `toKebabCase(文本)` | 转为短横线命名 |
| `capitalizeFirst(文本)` | 首字母大写 |
| `capitalizeWords(文本)` | 每个单词首字母大写 |
| `trimWhitespace(文本)` | 去除首尾空白 |
| `trimPrefix(文本, 前缀)` | 去除前缀 |
| `trimSuffix(文本, 后缀)` | 去除后缀 |
| `countChars(文本)` | 统计字符数 |
| `countLines(文本)` | 统计行数 |
| `getSubstring(文本, 起始, 结束)` | 获取子字符串 |

## 常量

| 常量名 | 值 |
|--------|-----|
| `dp` | `[[0] * (n + 1) for _ in range(m + 1)]` |
| `result` | `模板` |
| `words` | `_re.split('[-_\\s]+', 文本)` |
| `result` | `words[0].lower()` |
| `s1` | `_re.sub('([A-Z]+)([A-Z][a-z])', '\\1_\\2', 文本)` |
| `s2` | `_re.sub('([a-z0-9])([A-Z])', '\\1_\\2', s1)` |
| `s` | `toSnakeCase(文本)` |
| `result` | `result.replace('{' + key + '}', str(value))` |
