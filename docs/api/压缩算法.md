# 压缩算法 API

> 模块路径：`stdlib/压缩算法.py`
> 导入方式：`从 压缩算法 导入 函数名` 或 `导入 压缩算法`

## 函数列表

| 函数 | 说明 |
|------|------|
| `gzip压缩(数据, 压缩级别)` | gzip 压缩数据，返回字节 |
| `gzip解压(数据)` | gzip 解压数据，返回字节 |
| `zlib压缩(数据, 压缩级别)` | zlib 压缩数据，返回字节 |
| `zlib解压(数据)` | zlib 解压数据，返回字节 |
| `lz4压缩(数据)` | lz4 压缩数据 |
| `lz4解压(数据)` | lz4 解压数据 |
| `zstd压缩(数据, 压缩级别)` | zstd 压缩数据 |
| `zstd解压(数据)` | zstd 解压数据 |
