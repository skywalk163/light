# 迭代器工具 API

> 模块路径：`stdlib/迭代器工具.py`
> 导入方式：`从 迭代器工具 导入 函数名` 或 `导入 迭代器工具`

---

## 函数列表

| 函数 | 说明 |
|------|------|
| `迭代器_映射(func, iterable)` | 对可迭代对象每个元素应用函数，返回迭代器 |
| `迭代器_过滤(predicate, iterable)` | 过滤可迭代对象，返回迭代器 |
| `迭代器_链式()` | 链式连接多个可迭代对象 |
| `迭代器_压缩()` | 压缩多个可迭代对象，返回对应位置元组的迭代器 |
| `迭代器_计数(start, step)` | 无限递增计数器 |
| `迭代器_循环(iterable)` | 无限循环可迭代对象 |
| `迭代器_重复(value, times)` | 重复返回同一个值 |
| `迭代器_分块(iterable, size)` | 将可迭代对象分块为指定大小的子序列 |
| `迭代器_窗口(iterable, n)` | 滑动窗口迭代器 |
| `迭代器_扁平化(iterable)` | 扁平化嵌套可迭代对象 |
| `迭代器_枚举(iterable, start)` | 枚举可迭代对象，返回 (索引, 值) 对 |
| `迭代器_累计(iterable, func)` | 累积迭代 |
| `迭代器_分组(iterable, key)` | 按 key 函数分组可迭代对象 |
| `迭代器_切片(iterable, start, stop, step)` | 对可迭代对象进行切片 |
| `迭代器_排列(iterable, r)` | 生成排列 |
| `迭代器_组合(iterable, r)` | 生成组合 |
