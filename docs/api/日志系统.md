# 日志系统 API

> 模块路径：`stdlib/日志系统.py`
> 导入方式：`从 日志系统 导入 函数名` 或 `导入 日志系统`

---

## 函数列表

| 函数 | 说明 |
|------|------|
| `创建日志器(名称, 级别, 格式, 输出文件)` | 创建或获取指定名称的日志器 |
| `日志器记录(logger, 级别, 消息)` | 日志器记录指定级别的日志 |
| `日志器调试(logger, 消息)` | 日志器记录 DEBUG 级别日志 |
| `日志器信息(logger, 消息)` | 日志器记录 INFO 级别日志 |
| `日志器警告(logger, 消息)` | 日志器记录 WARNING 级别日志 |
| `日志器错误(logger, 消息)` | 日志器记录 ERROR 级别日志 |
| `日志器设置级别(logger, 级别)` | 设置日志器级别 |
| `日志器关闭(logger)` | 关闭日志器并释放资源 |

## 常量

| 常量名 | 值 |
|--------|-----|
| `DEBUG` | `_logging.DEBUG` |
| `INFO` | `_logging.INFO` |
| `WARNING` | `_logging.WARNING` |
| `ERROR` | `_logging.ERROR` |
| `CRITICAL` | `_logging.CRITICAL` |
| `logger` | `_logging.getLogger(名称)` |
| `fmt` | `_logging.Formatter(格式 or '%(asctime)s [%(levelname)s] %(message)s', datefmt='%Y-%m-%d %H:%M:%S')` |
| `handler` | `_logging.FileHandler(输出文件, encoding='utf-8')` |
| `handler` | `_logging.StreamHandler()` |
