# 集合操作 API

> 模块路径：`stdlib/集合操作.py`
> 导入方式：`从 集合操作 导入 函数名` 或 `导入 集合操作`

---

## 函数列表

| 函数 | 说明 |
|------|------|
| `去重(items)` | 去除重复元素（保持顺序） |
| `合并()` | 合并多个列表 |
| `交集(甲, 乙)` | 两个列表的交集（保持顺序） |
| `差集(甲, 乙)` | 甲有而乙没有的元素（保持顺序） |
| `补集(甲, 乙)` | 对称差集：出现于甲或乙但不同时出现 |
| `分组(items, key_func)` | 按指定函数分组 |
| `排序(items, 反转)` | 排序列表 |
| `反转顺序(items)` | 反转列表顺序 |
| `打乱(items)` | 随机打乱列表 |
| `扁平(items)` | 扁平化嵌套列表（一层） |
| `取部分(items, 开始, 结束)` | 取列表部分元素（切片） |
| `条件过滤(items, predicate)` | 按条件过滤 |
| `条件映射(items, mapper)` | 按函数映射 |
