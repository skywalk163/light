## 函数详情

### `缓存(最大缓存数: int = 128, 过期秒数: int = None, 忽略关键字参数: bool = False)`

缓存装饰器

参数:
    最大缓存数: 最大缓存条目数，超出时使用LRU策略
    过期秒数: 缓存过期时间，None表示永不过期
    忽略关键字参数: 是否忽略关键字参数

**参数：**

| 参数名 | 类型 | 说明 |
|--------|------|------|
| `最大缓存数` | `int` | （默认：128） |
| `过期秒数` | `int` | （默认：None） |
| `忽略关键字参数` | `bool` | （默认：False） |

---

**返回：** `str`

### `重试(最大次数: int = 3, 间隔秒数: float = 1.0, 退避因子: float = 2.0, 捕获异常: tuple = (Exception,), 日志函数: Callable = None)`

重试装饰器

参数:
    最大次数: 最大重试次数
    间隔秒数: 初始重试间隔
    退避因子: 指数退避因子，每次重试间隔乘以该因子
    捕获异常: 需要捕获的异常类型
    日志函数: 日志记录函数

**参数：**

| 参数名 | 类型 | 说明 |
|--------|------|------|
| `最大次数` | `int` | （默认：3） |
| `间隔秒数` | `float` | （默认：1.0） |
| `退避因子` | `float` | （默认：2.0） |
| `捕获异常` | `tuple` | （默认：(Exception,)） |
| `日志函数` | `Callable` | （默认：None） |
