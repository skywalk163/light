## 函数详情

### `插入中英文空格(文本)`

在中文字符和英文/数字之间插入空格。

示例: "你好world" -> "你好 world"

参数:
    文本: 待处理的文本

返回: 处理后的文本

**参数：**

| 参数名 | 类型 | 说明 |
|--------|------|------|
| `文本` | `None` |  |

---

### `转全角(文本)`

将文本中的半角字符转为全角字符。

参数:
    文本: 待转换的文本

返回: 全角文本

**参数：**

| 参数名 | 类型 | 说明 |
|--------|------|------|
| `文本` | `None` |  |

---

### `转半角(文本)`

将文本中的全角字符转为半角字符。

参数:
    文本: 待转换的文本

返回: 半角文本

**参数：**

| 参数名 | 类型 | 说明 |
|--------|------|------|
| `文本` | `None` |  |

---

### `_is_cjk_context(文本, 位置, 方向 = 'both')`

判断某个位置附近是否有中文字符

**参数：**

| 参数名 | 类型 | 说明 |
|--------|------|------|
| `文本` | `None` |  |
| `位置` | `None` |  |
| `方向` | `None` | （默认：'both'） |

---

### `规范化标点(文本)`

在中文上下文中，将英文标点替换为中文标点。

仅在标点前后有中文字符时替换，避免误改英文句子中的标点。

参数:
    文本: 待处理的文本

返回: 处理后的文本

**参数：**

| 参数名 | 类型 | 说明 |
|--------|------|------|
| `文本` | `None` |  |

---

### `规范化引号(文本)`

将英文直引号转为中文弯引号。

"..." -> "..."
'...' -> '...'

参数:
    文本: 待处理的文本

返回: 处理后的文本

**参数：**

| 参数名 | 类型 | 说明 |
|--------|------|------|
| `文本` | `None` |  |

---

### `检查排版(文本)`

检查文本中的排版问题。

返回: 问题列表，每个元素是 {类型, 位置, 描述, 建议}

**参数：**

| 参数名 | 类型 | 说明 |
|--------|------|------|
| `文本` | `None` |  |

---

### `自动排版(文本)`

一键执行全部排版优化：
1. 插入中英文空格
2. 全角英数字转半角
3. 规范化标点
4. 规范化引号

参数:
    文本: 待处理的文本

返回: 排版后的文本

**参数：**

| 参数名 | 类型 | 说明 |
|--------|------|------|
| `文本` | `None` |  |
