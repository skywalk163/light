# 文件匹配 API

> 模块路径：`stdlib/文件匹配.py`
> 导入方式：`从 文件匹配 导入 函数名` 或 `导入 文件匹配`

---

## 函数列表

| 函数 | 说明 |
|------|------|
| `匹配文件(模式, 递归, 目录)` | 按模式匹配文件 |
| `迭代匹配(模式, 递归, 目录)` | 迭代器方式匹配文件（适合大量文件） |
| `名称匹配(文件名, 模式)` | 检查文件名是否匹配模式（fnmatch） |
| `名称匹配忽略大小写(文件名, 模式)` | 忽略大小写的文件名匹配 |
| `过滤列表(文件列表, 模式)` | 从文件列表中过滤出匹配模式的文件 |
| `转义元字符(字符串)` | 转义特殊字符（* ? [），使其作为普通字符匹配 |
| `查找所有Python文件(目录, 递归)` | 查找所有Python文件（便捷函数） |
| `查找所有文本文件(目录, 递归)` | 查找所有文本文件（便捷函数） |
| `查找所有JSON文件(目录, 递归)` | 查找所有JSON文件（便捷函数） |

## 函数详情

### `匹配文件(模式: str, 递归: bool = True, 目录: str = None) -> List[str]`

按模式匹配文件

参数:
    模式: 匹配模式（支持 * ? [abc] 等）
    递归: 是否递归搜索子目录
    目录: 搜索根目录，None为当前目录

返回:
    匹配的文件路径列表

**参数：**

| 参数名 | 类型 | 说明 |
|--------|------|------|
| `模式` | `str` |  |
| `递归` | `bool` | （默认：True） |
| `目录` | `str` | （默认：None） |

**返回：** `List[str]`

---
