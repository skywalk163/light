# 二进制编码 API

> 模块路径：`stdlib/二进制编码.py`
> 导入方式：`从 二进制编码 导入 函数名` 或 `导入 二进制编码`

## 函数列表

| 函数 | 说明 |
|------|------|

| `字节转十六进制大写(数据)` | 将字节转为十六进制大写字符串 |
| `Base64编码(数据)` | Base64 编码，返回字节 |
| `Base64编码字符串(数据)` | Base64 编码，返回字符串 |
