# 命令行参数 API

> 模块路径：`stdlib/命令行参数.py`
> 导入方式：`从 命令行参数 导入 函数名` 或 `导入 命令行参数`

---

## 函数列表

| 函数 | 说明 |
|------|------|
| `新建参数定义(name)` | 新建一个参数定义 |
| `设置短名称(arg, short_name)` | 设置参数的短名称 |
| `设置默认值(arg, default)` | 设置参数的默认值 |
| `设置必需(arg, required)` | 设置参数为必需 |
| `新建子命令(name, help_text)` | 新建一个子命令 |
| `子命令添加参数(subcmd, arg)` | 为子命令添加参数 |
| `解析参数(程序名, 参数列表, 子命令列表, 描述)` | 解析命令行参数，返回参数字典。 |
| `获取参数值(参数字典, key, 默认值)` | 从参数字典获取指定参数的值 |
| `生成帮助文本(程序名, 参数列表, 子命令列表, 描述)` | 生成帮助文本（不退出程序） |
| `__init__(self, name)` |  |
| `__init__(self, name, help_text)` |  |
