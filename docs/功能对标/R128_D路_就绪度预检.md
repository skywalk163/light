### 1.3 关键实测证据（详见 §4）

**① `issubclass` / `hasattr` 在原生腿的真实能力**（探针 `p1_判型.light`，真编译真跑，rc=0）：

```
== issubclass ==
  issubclass(子类, 父类) = 真      ← 正确
  issubclass(父类, 父类) = 真      ← 正确
  issubclass(父类, 子类) = 假      ← 正确（方向未反）
== hasattr ==
  hasattr(乙, "标记")        = 假  ← ❌ 方法存在却为假
  hasattr(乙,"不存在的方法") = 假
  ✅ 分支命中：issubclass 在原生腿返回 真
  ❌ 分支未命中：hasattr 在原生腿非 真
```

**② `hasattr` 覆盖面定位**（探针 `p3_hasattr形态.light`，rc=0）：

```
hasattr(字典, "名称")      = 假   ← 字典字面量不为真
hasattr(字典, "没有的键")  = 假
hasattr(实例, "名称")      = 真   ← ✅ 仅「实例字段」（己.x 赋过值）为真
hasattr(实例, "构造")      = 假   ← ❌ 方法名不为真
hasattr(列表, "追加")      = 假
getattr(实例,"名称",空)    = 甲    ← getattr 与 hasattr 同口径，同样只覆盖字段
```

**根因**（`src/llvm/runtime_typed.c:8245` + `:8154`）：
`dv_has_attr → dv_r117_obj_has_member` 只接受 `obj->type == 3` 且带 `OBJ_PREFIX` 的**字段 blob**，在 blob 里搜 `"名\x1F"`；
**方法不存在于字段 blob（在类方法表）⇒ 恒假**。这是真实的跨腿不等价（Python 腿 `hasattr(obj, "方法名")` 为真）。

**③ 嵌套段落定义（真闭包）**（探针 `p2_嵌套段落.light`）：

```
❌ 编译失败：NotImplementedError: 原生后端暂不支持语句类型「SegmentDefinition」
   （src/llvm/codegen_typed.py:5420 → :5298 _reject_unsupported_stmt）
```
R122-A2 结论**本轮复验成立**：目前是**明确拒绝**，不是静默错误。

**④ `dv_make_function_value` 补 env 的改动面评估**（只读静态盘点）：

| 层 | 文件 | 触点 | 说明 |
|---|---|---|---|
| 运行时 | `src/llvm/runtime_typed.c` | `dv_make_function_value` 2 处、`LV_TYPE_FUNCTION` 6 处、`DvSegFunc` typedef（`:89`，现为 `void(*)(LightValue*,LightValue*,int)`） | 加 env 必须改段函数统一签名 |

**⑤ L-076 护栏复评**：

**⑥ 对象池缓存 翻面必红的直接证据**（`tests/test_stdlib_phase10.py:302-314`）：

```python
def test_缓存装饰器(self):
    from 对象池缓存 import 缓存装饰器
    调用次数 = [0]
    @缓存装饰器(最大容量=10)
    def 计算(n):
        调用次数[0] += 1
        return n * n
    self.assertEqual(计算(5), 25)
    self.assertEqual(计算(5), 25)
    self.assertEqual(调用次数[0], 1)     # ← 要求「真记忆化」
```
`stdlib/对象池缓存.light:260` 现为 `段落 缓存装饰器(最大容量=128): 返回 直通装饰`（R127 直通退化），
第二次调用**仍会执行被装饰函数** ⇒ `调用次数[0] == 2 ≠ 1` ⇒ **翻面必然新增红**。
R127 的「直通退化」解决的是「装饰器必须是一等函数值」，**没有**解决「真记忆化」——两者不可混为一谈。

**三模块里性价比最高 = `对象池缓存`**：
