## 1. 候选 1：三门面落地与前置必测

### 1.1 前置必测：两条腿解析优先级实测（任务书红线）

任务书警告：`_light_import_hook.py:238-252` 显示新增 `socket.light` 可能顶掉 Python 腿真
CPython socket（Windows 大小写不敏感下 `lightpub/Socket.py` 可能被判「有 .py 兄弟」）。

**实测（`_r128f_tmp/probe_resolve.py --with-facade`，rc=0）**：

```
== Python 腿（_light_import_hook 已装，search_paths=[stdlib]） ==
socket     __file__=...\Lib\socket.py      __light_source__=False  → ✅ 真 CPython
selectors  __file__=...\Lib\selectors.py   __light_source__=False  → ✅ 真 CPython
errno      __file__=<?>(内置)              __light_source__=False  → ✅ 真 CPython
== 原生腿（ModuleResolver().find_module，默认 search_paths） ==
socket     → G:\...\stdlib\socket.light        ✅ 门面
selectors  → G:\...\stdlib\selectors.light     ✅ 门面
errno      → G:\...\stdlib\errno.light         ✅ 门面
== 静态核对 _light_import_hook 保护分支 ==
socket/selectors/errno in _STDLIB_MODULES=True ; _exists_exact(stdlib, '<名>.py')=False
```

**三层保护闭合（比任务书预想的单层更稳）**：

1. **裸 Python import**（tests/宿主代码）：`socket/selectors/errno ∈ _STDLIB_MODULES` 且
   stdlib 平层无同名 `.py`（`_exists_exact` 精确匹配，`lightpub/Socket.py` 在子目录不算）→
   `find_spec` 保护分支直接 `return None` → 真 CPython 接管。**实测 rc=0**。
2. **Python 腿光明用户代码 `导入 socket`**：codegen 别名化条件是
   `module_name ∈ _PYTHON_LEG_PURE_LIGHT_ALIAS AND _stdlib_light_is_pure AND from-import`
   （`src/code_generator.py:5110-5120`）——白名单 `_PYTHON_LEG_PURE_LIGHT_ALIAS = frozenset({'re'})`
   （`code_generator.py:52`），**socket/selectors/errno 均不在列** → 不别名化 → 生成
   `import socket` → 走第 1 层保护 → 真 CPython。**行为零变化**。
3. **别名可达性**：`_light_socket` 只被烟测工具的诊断口径构造（用户代码无此路径）；
   门面在 Python 腿**完全不可达**，只在原生腿可达（目标达成）。

### 1.2 门面能力边界（只封 codegen 已暴露的内建，不做假绿空壳）

| 门面 | 封了（codegen_typed.py 已暴露） | 留白登记（运行时有但 codegen 未暴露） |
|---|---|---|
| `socket.light`（90 行） | socket_create/connect/send/recv/close/last_error/last_error_code（中文别名 创建/连接/发送/recv/关闭/取错误/取错误码）+ AF_INET 等 6 个零参取值段 | bind/listen/accept/setsockopt/shutdown/getpeername——**HTTP服务端 仍不可编的原因** |
| `selectors.light`（65 行） | 创建poller/注册poller/poller_wait/销毁poller/poller错误/poller后端/poller计数 | unregister；SelectorKey/事件数组模型（`poller_wait` 只返就绪个数，不伪造 select() 元组语义） |
| `errno.light`（106 行） | 19 个 errno 常量做零参取值段 + `取错误码(位置值,窗口值)` 运行期平台判档 + `是视窗()` | errorcode 反向映射表（原生腿无模块级字典属性形态，如实留白） |

**命名纪律（实测踩坑后固化进文件头注释）**：
- 段名不取 `接收`/`关闭`/`等待`——`接收`/`等待` 是光明关键字，实测 `从 socket 导入 接收` 后
  `接收(fd,64)` 编译期报 LambdaExpression、`等待(选择器,50)` 被 await 语句截胡**静默返空**
  （f_plat/f_plat2 原生腿实测复证，rc=0：直调 `poller_wait` 得 0，经 `等待` 段得 `[]`）。
- 段内委托内建一律用 ASCII 名（`socket_recv`/`poller_wait`）——中文别名 `接收socket`/`关闭socket`
  会被词法器切成「关键字+socket(...)」。
- `errno.light` 平台判别**不用** `连接_path`（实测原生腿 Windows 上也返回 `甲/乙`，是已在线
  跨腿分叉，沿用会把 Windows 误判 posix）——改用 `poller后端()`：Windows 返 `WSAPoll`
  （runtime_typed.c:5846），实测可用。

## 3. 候选 4：`节点网络` 两腿对拍与翻面/终局裁定

### 3.1 对拍方法与范围

D 线预检（R128-D 路）已留结论：`节点网络.light` 原生腿**可编**（IR 745,989）、Python 腿
15/15 行为对齐——但「原生腿语义等价性尚未对拍，仍不主张翻面」。F 路补的就是这份证据。

对拍脚本 `_r128f_tmp/dup.light`：同一份源码两腿各跑一次逐行 diff（8 组 API：JSON 解析/序列化、
ID 谓词、常量比较、取头值、类型转换、时钟、ID 生成形态、环境/文件读写）。

- Python 腿：`_r128f_tmp/run_py_leg.py`（钩子 install([stdlib, stdlib/分布式])，tests/
  `test_distributed_eval_light.py` 同款口径；HAS-PY+非魔数 → 钩子让位 → 承载 = `节点网络.py`）
- 原生腿：`light run _r128f_tmp/dup.light --backend native`（承载 = `节点网络.light`）

### 3.2 对拍结果：8 组中 3 处真实差异

布尔形态差异（Python `True/False` vs 原生 `真/假`）为已知设计，不计。逐条定性：

| # | 差异 | Python 腿（.py） | 原生腿（.light） | 定性 |
|---|---|---|---|---|
| 1 | `写JSON(路径,{"键":"值"})` 段内 `序列化缩进(字典,2)` 写出的内容 | `{"键": "值"}` ✅ | **写出了全局 `字典`（A 组解析结果）** | **语言缺陷 L-182**（见 §3.3） |
| 2 | `取环境(不存在, 缺省)` | 返回缺省 ✅ | 返回空串 ❌ | 原生腿内建 `环境变量` 缺失返**空串**（非空值）→ `.light:242` `值 == 空` 判假 → 返值不返缺省；.py 腿 `os.environ.get` 返 None → `== 空` 判真 → 缺省。u_env_int.light 实测 rc=0 |
| 3 | `转整数("abc", 9)` | 返回缺省 9 ✅ | 返回 0 ❌ | 原生腿内建 `整数` 对非数字**容错返 0 不抛** → `.light:274` `尝试/捕获` 捕不到 → 返 0；.py 腿 `int()` 抛 ValueError → 捕获 → 缺省。同上实测 |

最小复现三件套（全部 rc=0 留档 `_r128f_tmp/`）：
`u_shadow_min.light`（差异 1 三形态：A 撞名参数直返 / B 撞名经导入函数 / C 不撞名对照——
原生腿 A/B 错、C 对；Python 腿 A/B/C 全对）、`u_env_int.light`（差异 2/3）、
`u_dup3_min.light`（组合）。

### 3.3 新发现 L-182：原生腿段落参数遮蔽失效

差异 1 的最小化三形态证明这不是 `节点网络` 实现缺陷，而是**原生腿 codegen 的通用作用域
缺陷**：段落参数与模块级全局变量同名时，段内引用解析到全局变量——参数被静默穿透。
Python 腿语义正确（参数优先）。已登记 `docs/功能对标/语言缺陷账.md` **L-182**（状态待修复，
真修在 `src/llvm/`，受「一轮只一条线动 src/」约束）。

### 3.4 裁定：暂缓翻面（终局暂缓，非永久拒绝）

| 翻面前置（R122 两档风险口径 · HAS-PY 档） | 现状 |
|---|---|
| Python 腿语义等价（.light vs .py） | ✅ 8 组对拍全对齐（dup_py.out） |
| **原生腿语义等价**（D 线预检明示的前置） | ❌ **3 处真实差异**（§3.2） |
| 082 全量门（翻后必跑） | 未跑（前置已不达标，不进入） |

**裁定**：**暂缓翻面**。理由：
1. 任务书候选 4 的前置是「原生腿语义等价性尚未对拍 → 需先补证据」——证据补齐后显示
   **不**等价，前置不成立；
2. 翻面对 Python 腿本身安全（对拍已证），但翻面**计数收益**只有 +1（68/78 = 87.1795%，
   +0.167pp 纯簿记），而 L-182 是真实咬人的语言缺陷（写JSON 静默写错文件）——**先修缺陷
   再谈计数**符合 R123「主题换挡：正确性优先于数字」；
3. 差异 2/3 是内建语义层（`环境变量`/`整数`）——修法都在 src/，与 L-182 同批修复最省
   （同一批原生腿语义回归窗口）。

**重审路径（R129+）**：L-182 修复（`src/llvm/`）+ 差异 2/3 处置（补内建语义或登记设计边界）
→ u_shadow_min / u_env_int / dup 三探针回归全绿 → 再过 082 门 → 翻面 +1。
