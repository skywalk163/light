# 搜索配置

光明文档站使用 MkDocs Material 主题内置的搜索插件，支持中文分词和全文搜索。

## 搜索插件配置

搜索配置位于 `mkdocs.yml` 文件的 `plugins` 部分：

```yaml
plugins:
  - search:
      lang: zh
```

### 配置项说明

| 配置项 | 类型 | 默认值 | 说明 |
|--------|------|--------|------|
| `lang` | 字符串/列表 | `"en"` | 搜索语言，设为 `zh` 启用中文分词 |
| `separator` | 字符串 | 无 | 自定义分词分隔符（正则表达式） |
| `min_search_length` | 整数 | `3` | 最小搜索词长度 |
| `prebuild_index` | 布尔 | `false` | 是否预构建搜索索引（加快首次搜索速度） |

## 中文搜索优化

### 分词支持

MkDocs Material 的搜索插件内置了 [lunr.js](https://lunrjs.com/) 的中文分词支持。设置 `lang: zh` 后，搜索插件会自动使用中文分词算法，支持：

- 单字搜索（如搜索「段」）
- 双字词搜索（如搜索「编译」）
- 多字词组搜索（如搜索「类型检查」）
- 混合中英文搜索（如搜索「L4 沙箱」）

### 搜索精度提升建议

1. **使用完整术语**：在文档中使用完整的中文术语，避免缩写和歧义
2. **添加关键词**：在页面开头或显眼位置使用目标关键词
3. **合理使用标题**：使用 `##`、`###` 等层级标题，搜索索引会优先匹配标题内容
4. **避免过于简短的页面**：页面内容过少可能导致搜索匹配度降低

## 自定义搜索行为

如需更精细的搜索控制，可以扩展搜索插件：

```yaml
plugins:
  - search:
      lang: zh
      separator: '[\s\-\.]+'
      min_search_length: 2
      prebuild_index: true
```

### 多语言搜索

如果文档包含多种语言内容，可以将 `lang` 设为列表：

```yaml
plugins:
  - search:
      lang:
        - zh
        - en
```

## 搜索快捷键

- `Ctrl+K`（Windows/Linux）或 `Cmd+K`（macOS）：打开搜索面板
- `↑`/`↓`：在搜索结果间导航
- `Enter`：打开选中的搜索结果
- `Esc`：关闭搜索面板

## 常见问题

### Q: 搜索不到中文内容

确保 `mkdocs.yml` 中 `search.lang` 设置为 `zh`，并重新构建文档站点。

### Q: 搜索速度慢

可以开启 `prebuild_index: true` 在构建时预生成搜索索引，但会延长构建时间。

### Q: 搜索结果不准确

检查文档内容是否使用了统一的术语，避免同义词混用。例如统一使用「编译」而非「编译/编译过程/代码编译」等多种表达。
