# 光明 (LightLang) v6.0

光明（LightLang）是一门中文编程语言，核心设计理念是**像中文一样分层**。

v6.0 是光明发展历程中的里程碑版本，实现了**完全自举**、**类型系统完善**、**生态工具链建设**和**性能优化**四大目标。

## 快速开始

```bash
# 安装
pip install light

# 运行
light hello.light
```

## v6.0 新特性

### 完全自举（Level 8）
- 编译器全部功能用光明自身编写，4 轮编译输出完全收敛
- 支持类型注解、泛型、联合类型等全部新特性

### 类型系统完善
- **泛型支持**：`列表[T]`、`字典[K,V]` 运行时泛型
- **联合类型**：`整数|文本|空` 语法
- **模式匹配**：`配 值: 若 模式1: ...`
- **类型别名**：`类型 别名 = 原始类型`

### 生态工具链
- **VSCode 扩展**：完整语法高亮、调试适配器、LSP 语言服务
- **文档站点**：mkdocs 搭建，完整 API 参考与教程
- **在线 Playground**：交互式编译/运行，20+ 示例库
- **包注册表**：包搜索、发布、安装、版本管理

### 性能优化
- **LLVM 优化 Pass 管线**：常量折叠、死代码消除、循环优化
- **增量编译**：基于源码哈希的段缓存，编译速度提升 50%+
- **代码体积优化**：可执行文件体积减少 30%+

## 五层架构

光明 v6.0 借鉴中文"字→文体→领域→外语"的分层智慧：

| 层级 | 名称 | 说明 |
|------|------|------|
| **L0** | 核心字集 | 30 个单字关键字，永远不变 |
| **L1** | 白话体 | 19 字子集，中文标点，适合教学 |
| **L2** | 文言体 | 30 字全集，英文标点，适合商业 |
| **L3** | 领域嵌入 | SQL/正则/数学公式直接嵌入 |
| **L4** | 外语引用 | 用 `引` 块引用 Python/C/Go/MoonBit |

## 核心特性

- **分层设计**：五层架构，从教学到商业全场景覆盖
- **30 个核心字**：极简关键字设计，降低学习成本
- **L1/L2 文体**：白话体适合教学，文言体适合商业项目
- **L3 领域嵌入**：SQL、正则、数学公式直接使用
- **L4 外语引用**：沙箱隔离的 Python/C/Go/MoonBit 代码嵌入
- **类型系统**：泛型、联合类型、模式匹配、类型别名
- **完全自举**：编译器用自身语言编写，4 轮编译收敛
- **双后端**：Python 解释执行 + LLVM 原生编译

## 示例

```python
# 你好，光明！
印("你好，光明！")

# 变量与类型注解
设 甲 为 整数 = 10
设 乙 为 文本 = "hello"

# 泛型函数
段 首元素[T](列表: 列表[T]) -> T：
  返回 列表[0]

# 模式匹配
配 值：
  若 1:
    印("一")
  若 2:
    印("二")
  若 _:
    印("其他")

# L4 外语引用
引 Python:
    import math
    def l4_sqrt(x):
        return math.sqrt(x)
出 l4_sqrt

印(l4_sqrt(16))
```
