# 完整语法参考

本文档按语言层次（L0-L4）组织，完整覆盖光明的所有语法结构、关键字和运算符。

---

## L0：核心字集

L0 是光明的基石，包含 30 个单字关键字，覆盖所有编程语义。这 30 个字**永远不会改变**。

### 变量声明

```python
设 变量名 = 值
设 变量名 为 值
```

| 关键字 | 语义 | 示例 |
|--------|------|------|
| `设` | 声明变量 | `设 甲 为 10` |
| `为` | 赋值标记 | `设 甲 为 10` |

### 条件判断

```python
若 条件：
  代码块
则：
  代码块
否：
  代码块
```

| 关键字 | 语义 | 示例 |
|--------|------|------|
| `若` | if 条件判断 | `若 甲 > 乙：` |
| `则` | then 分支 | `则：` |
| `否` | else 分支 | `否：` |

### 循环

```python
# 当循环（while）
当 条件：
  代码块

# 遍循环（for-in）
遍 变量 于 可迭代对象：
  代码块
```

| 关键字 | 语义 | 示例 |
|--------|------|------|
| `当` | while 循环 | `当 计数 > 0：` |
| `遍` | for-in 遍历 | `遍 i 于 范围(10)：` |
| `断` | break 跳出循环 | `断` |
| `跃` | continue 跳过本轮 | `跃` |

### 函数

```python
段 函数名(参数1, 参数2)：
  代码块
  返 返回值
```

| 关键字 | 语义 | 示例 |
|--------|------|------|
| `段` | 函数定义 | `段 加法(甲, 乙)：` |
| `返` | 返回值 | `返 甲 + 乙` |

### 类与面向对象

```python
类 类名：
  性 属性名
  构(参数)：
    己.属性名 = 参数
  段 方法名()：
    返 己.属性名

类 子类 承 父类：
  构(参数)：
    父.构(参数)

设 实例 = 新 类名(参数)
```

| 关键字 | 语义 | 示例 |
|--------|------|------|
| `类` | 类定义 | `类 人：` |
| `承` | 继承 | `类 学生 承 人：` |
| `性` | 属性声明 | `性 姓名` |
| `构` | 构造函数 | `构(姓名)：` |
| `己` | self 自引用 | `己.姓名` |
| `父` | super 父类引用 | `父.构(姓名)` |
| `新` | 创建实例 | `新 人("张三")` |

### 接口

```python
约 接口名：
  段 方法名(参数)

类 实现类 现 接口名：
  段 方法名(参数)：
    实现代码
```

| 关键字 | 语义 | 示例 |
|--------|------|------|
| `约` | 接口定义（契约） | `约 可比较：` |
| `现` | 实现接口 | `类 整数 现 可比较：` |

### 模块

```python
# 导入
引 "模块名"
从 模块名 引 名称1, 名称2

# 导出
出 名称1, 名称2
```

| 关键字 | 语义 | 示例 |
|--------|------|------|
| `引` | 导入模块 | `引 "数学"` |
| `出` | 导出符号 | `出 加法, 减法` |
| `自` | 自引用模块 | `自.版本` |

### 逻辑运算符

```python
若 甲 > 0 且 乙 > 0：
  打印("都为正数")

若 甲 > 0 或 乙 > 0：
  打印("至少一个为正数")

若 非 条件：
  打印("条件不成立")
```

| 关键字 | 语义 | 示例 |
|--------|------|------|
| `且` | 逻辑与 (and) | `甲 > 0 且 乙 > 0` |
| `或` | 逻辑或 (or) | `甲 > 0 或 乙 > 0` |
| `非` | 逻辑非 (not) | `非 条件` |

### 常量

| 关键字 | 语义 | 示例 |

### 输出

|--------|------|------|

| 关键字 | 语义 | 示例 |

### 模式匹配

```python
匹 值：
  例 模式1：
    代码块
  例 模式2：
    代码块

    默认代码块
```

| 关键字 | 语义 | 示例 |

### 异步


| 关键字 | 语义 | 示例 |
|--------|------|------|

### 修饰符

```python
常 设 PI = 3.14159    # 常量
```

## L3：领域嵌入

L3 层允许在光明代码中直接嵌入领域特定语言。

### SQL 嵌入

```python
# 直接编写 SQL 查询
设 结果 = 查询 用户 中 筛选 年龄 > 18 排序 年龄 升序

# 更复杂的 SQL 操作
设 数据 = 查询 订单 中
  筛选 金额 > 100
  且 状态 = "已完成"
  排序 时间 降序
  限制 10
```

### 正则表达式嵌入

```python
# 使用 / / 定义正则表达式
设 模式 = /^\d{3}-\d{8}$/
设 是否匹配 = 模式.测试("010-12345678")

# 正则匹配提取
设 文本 = "联系电话：010-12345678"
设 匹配结果 = 文本.匹配(/(\d{3})-(\d{8})/)
如果 匹配结果：
  打印(匹配结果[0])  # 完整匹配
  打印(匹配结果[1])  # 区号：010
  打印(匹配结果[2])  # 号码：12345678
```

### 数学公式嵌入

```python
# 数学公式直接计算
设 结果 = ∫(0, 1, x**2)  # 定积分

# 矩阵运算
设 矩阵A = [[1, 2], [3, 4]]
设 矩阵B = [[5, 6], [7, 8]]
设 乘积 = 矩阵A × 矩阵B
```

## L4：外语引用

L4 层通过 `引 语言:` 块安全地嵌入其他语言代码。

### 引用 Python

```python
引 Python:
    import math
    def calculate_area(radius):
        return math.pi * radius ** 2
出 calculate_area

设 面积 = calculate_area(5)
印(面积)
```

### 引用 C

```python
引 C:
    #include <math.h>
    double power(double base, double exp) {
        return pow(base, exp);
    }
出 power

印(power(2, 10))
```

### 引用 Go

```python
引 Go:
    func hello(name string) string {
        return "Hello, " + name
    }
出 hello

印(hello("光明"))
```

### 引用 MoonBit

```python
引 MoonBit:
    fn add(a: Int, b: Int) -> Int {
        a + b
    }
出 add

印(add(1, 2))
```

4. `+` `-` `加` `减`
5. `>` `<` `>=` `<=` `==` `!=`（比较）
6. `且`（逻辑与）
7. `或`（逻辑或）
8. `=` `+=` `-=` `*=` `/=` `%=`（赋值）

```python
设 变量名: 类型 = 值
```
