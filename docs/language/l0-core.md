L0 是光明的基石，包含 30 个单字关键字，覆盖所有编程语义。

## 模块（3字）

| 关键字 | 语义 |
|--------|------|
| `引` | 导入/引用 |
| `出` | 导出 |
| `自` | 从（来源连接词） |

`自` 只作来源连接词，不作 self —— self/this 是 `己`（见「自引用」一节）。
两种导入形式语义不同，不可互换：

- `导 X 自 Y` ≡ `import Y as X`（模块绑定；`X` 与 `Y` 同名时不加 `as`）
- `导入 X 从 Y` ≡ `from Y import X`（符号导入）
