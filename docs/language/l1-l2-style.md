# L1/L2 文体

光明 v4.0 支持两种文体风格，完全兼容。

## L1 白话体

L1 使用 L0 的 19 字子集，配合中文标点（，。），关键字采用双字别名。

**特点：**
- 关键字：双字形式（`如果` `打印` `遍历` `段落` `返回`）
- 标点：中文标点（，。：）
- 目标：教学、青少年、入门
- 类型标注：可选

**示例：**
```python
如果 甲 > 乙：
  打印("甲更大")
否则：
  打印("乙更大")
```

## L2 文言体

L2 使用 L0 全部 30 字，配合英文标点（,.）。

**特点：**
- 关键字：L0 单字（`若` `印` `遍` `段` `返`）
- 标点：英文标点（,.:）
- 目标：商业项目、熟练开发者
- 类型标注：推荐显式

**示例：**
```python
若 甲 > 乙:
  印("甲更大")
否则:
  印("乙更大")
```

## 混用规则

L1 和 L2 关键字可以自由混用：

```python
设 分数 为 85
如果 分数 >= 60 那么：
  印("及格")
否则：
  印("不及格")
```
