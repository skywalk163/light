# 五层架构详解

光明 v4.0 借鉴中文"字→文体→领域→外语"的分层智慧，设计了五层架构。

## 架构总览

```
L4 外语引用 ── 引 Python/C/Go/MoonBit
L3 领域嵌入 ── SQL / 正则 / 数学公式
L2 文言体   ── 30字全集，英文标点
L1 白话体   ── 19字子集，中文标点
L0 核心字集 ── 30个单字，永远不变
```

## L0：核心字集（30字）

L0 是光明的基石，永远不变。包含变量、控制流、函数、类、模块、异常等所有编程语义。

## L1：白话体（19字子集）

L1 使用 L0 的 19 字子集，配合中文标点（，。），关键字采用双字别名（如 `如果` `打印` `遍历`）。适合教学场景和初学者。

## L2：文言体（30字全集）

L2 使用 L0 全部 30 字，配合英文标点（,.），代码更简洁精炼。适合商业项目和熟练开发者。

## L3：领域嵌入

L3 层直接在光明代码中嵌入 SQL、正则表达式、数学公式，无需特殊标记。

## L4：外语引用

L4 层通过 `引 语言:` 块嵌入 Python、C、Go、MoonBit 代码，运行在隔离沙箱中。
