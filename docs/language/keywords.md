# 关键字参考

## v4.0 L0 核心关键字（44字）

| 类别 | 关键字 | 语义 |
|------|--------|------|
| 变量 | `设` `为` | 声明/赋值 |
| 条件 | `若` `则` `否` | if/else |
| 循环 | `当` `遍` `断` `跃` | while/for/break/continue |
| 函数 | `段` `返` | 定义/返回 |
| 类 | `类` `承` `性` `构` `己` `父` `新` | OOP |
| 接口 | `约` `现` | 接口/实现 |
| 模块 | `引` `出` `自` | 导入/导出（`自` 是来源连接词，非 self；self 用 `己`） |
| 逻辑 | `且` `或` `非` | and/or/not |
| 常量 | `真` `假` `空` | true/false/null |
| 输出 | `印` `写` | print/write |
| 异常 | `试` `捕` `掷` | try/catch/throw |
| 匹配 | `匹` `例` | match/case |
| 异步 | `异` `等` | async/await |
| 修饰 | `常` `护` `私` `公` `静` | 修饰符（`常` 是 `设` 的前缀，如 `常 设 圆周率 为 3.14159。`；双字 `常量` 等义） |
| 类型 | `是` | instanceof |

| `导入` `导出` | `引` `出` |
| `打印` | `印` |
| `尝试` `捕获` `抛出` | `试` `捕` `掷` |
