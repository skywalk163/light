# 类型系统

光明 v4.3 引入了泛型、联合类型和模式匹配。

## 基本类型

| 类型 | 说明 | 示例 |
|------|------|------|
| `数` | 数字（整数/浮点） | `42` `3.14` |
| `串` | 字符串 | `"你好"` |
| `布尔` | 布尔值 | `真` `假` |
| `空` | 空值 | `空` |
| `列` | 列表 | `[1, 2, 3]` |
| `典` | 字典 | `{"a": 1}` |

## 类型标注

```python
段 加法(a: 数, b: 数) -> 数：
  返回 a + b
```

## 泛型

```python
段 首元素[T](列表: 列[T]) -> T:
  返回 列表[0]

设 结果 = 首元素([1, 2, 3])  # 类型推断为 数
```

## 联合类型

```python
段 处理(值: 数 | 串):
  若 值 是 数：
    印("数字: " + 值)
  否则：
    印("字符串: " + 值)
```

## 可选类型

```python
段 查找(列表: 列[数], 目标: 数) -> 数 | 空:
  遍 项 于 列表：
    若 项 == 目标：
      返回 项
  返回 空
```

## 类型别名

```python
类型 可选数 = 数 | 空
类型 字符串列表 = 列[串]
```
