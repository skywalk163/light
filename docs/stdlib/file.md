# 文件系统模块

## 函数列表

| 函数 | 说明 |
|------|------|
| `读取(path)` | 读取文件内容 |
| `写入(path, content)` | 写入文件 |
| `追加(path, content)` | 追加到文件 |
| `存在(path)` | 检查文件是否存在 |
| `删除(path)` | 删除文件 |
| `复制(src, dst)` | 复制文件 |
| `移动(src, dst)` | 移动文件 |
| `列表(dir)` | 列出目录内容 |
| `创建目录(path)` | 创建目录 |
| `删除目录(path)` | 删除目录 |
| `大小(path)` | 获取文件大小 |
| `修改时间(path)` | 获取修改时间 |

## 示例

```python
# 写入文件
写入("hello.txt", "你好，光明！")

# 读取文件
设 内容 = 读取("hello.txt")
印(内容)

# 检查文件
若 存在("hello.txt"):
  印("文件存在，大小: " + 大小("hello.txt"))
```
