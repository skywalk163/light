## 使用方式

### 内置函数
内置函数直接可用，无需导入：
```light
打印("你好，世界")
随机整数(1, 100)
```

### 模块导入
使用 `从《模块名》导入《函数名》` 语法：
```light
从《JSON》导入《解析JSON》《生成JSON》
从《数学》导入《正弦》《余弦》《平方根》
```

### 统一导入
通过 `stdlib` 包统一导入所有模块：
```python
from stdlib import *
```

## 模块结构

每个标准库模块通常包含两个文件：
- `.light` 文件：定义光明接口，声明导出函数
- `.py` 文件：Python 实现，提供实际功能

部分模块（如 `列表工具`）是纯光明实现，无需 Python 文件。

## 注意事项

1. **平台兼容性**：`信号` 模块中的 `SIGALRM` 仅 Unix 系统支持，`进程` 模块中的信号发送在 Windows 上有限制
2. **外部依赖**：`分词` 模块的 jieba 分词需要安装 jieba 库，`网络` 模块的端口扫描需要安装 python-nmap
3. **线程安全**：`日志` 和 `线程` 模块是线程安全的，但自定义回调函数需注意线程安全性
4. **编码**：所有文件操作默认使用 UTF-8 编码，支持 utf-8-sig BOM 头
