# 正则表达式模块

## 函数列表

| 函数 | 说明 |
|------|------|
| `匹配(pattern, text)` | 匹配第一个结果 |
| `查找全部(pattern, text)` | 查找所有匹配 |
| `分割(pattern, text)` | 按模式分割 |
| `替换(pattern, repl, text)` | 替换匹配内容 |
| `是否匹配(pattern, text)` | 检查是否匹配 |

## 示例

```python
# 匹配邮箱
设 邮箱模式 = "[a-zA-Z]+@[a-zA-Z]+\\.[a-zA-Z]+"
设 结果 = 匹配(邮箱模式, "test@light-lang.org")
若 结果：
  印("匹配成功: " + 结果)

# 查找所有数字
设 数字 = 查找全部("\\d+", "abc123def456")
印(数字)  # ["123", "456"]

# 替换
设 替换后 = 替换("\\d+", "X", "abc123def456")
印(替换后)  # "abcXdefX"
```
