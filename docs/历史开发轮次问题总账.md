# 历史开发轮次问题总账（开发前必读）

> **这份账的目的：让同一个坑不要踩第三次。**
>
> 背景：截至 R153，项目跑了 **150+ 个轮次**，问题记录散落在**七个互不相通的地方**
> （缺陷账、known_issues、各轮 `_Rxxx_报告`、编程注意事项、`.workbuddy/memory` 日志、
> 能力清单、API 文档）。结果是：**R152/R153 连续两轮在同一个 `是空` 上炸红**，
> 而它的完整答案早在 R55（L-059）就出现过一次，只是没人知道。
>
> 本文是**索引，不是第三份拷贝**。每条只给「一句话根因 + 去哪看」，
> 权威细节仍在原载体——那样才不会再制造新的漂移。

### C 族 · 新增原生内置的注册点（结构性，最易漏）

### E 族 · 自举链与横切定义点

- **铁律**：改任何横切语义（判型、内置、`追加` 类）必须 `git grep` **全仓 tracked 文件**，
  不能按目录猜。R153 第一轮只扫 `bootstrap/` 与 `src/`，**漏了 5 处**
  （`bootstrap/release/bootstrap_compiler.py`、`run_compiler.py`、`test_parser_debug.py`、
  `tests/test_self_host.py`、`tools/archive/verify_bootstrap.py`）。
- 自举链定义点：`bootstrap/bootstrap_v3.light`、`codegen.light`、`release/bootstrap_v3.light`、
  `bootstrap_v3_gen{,2,3}.py`。
- 改 LM 真身必须同步 `lightharness/stdlib/`，否则 `test_builtins_drift.py::test_lh_public_body_hash_equals_main` 红。
