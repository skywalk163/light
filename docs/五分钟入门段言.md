# 五分钟入门段言 —— 交互式 REPL 快速上手

> **版本：** v6.2
> **更新日期：** 2026-08-07
> **前置条件：** 已安装段言（`pip install duan`）
>
> 本教程带你用 **5 分钟**，通过 REPL 交互式环境亲手敲出段言代码。不需要创建文件，不需要切换目录——打开终端就能开始。

---

## ✅ 开始前的准备

请先确认以下环境已经就绪。打开终端（Windows 按 `Win+R`，输入 `cmd` 回车），逐一检查：

| 检查项 | 命令 | 预期结果 |
|-------|------|---------|
| Python 已安装 | `python --version` | 显示 `Python 3.10` 或更高版本 |
| 段言已安装 | `duan --version` | 显示 `段言编译器 v6.x.x` |
| 段言 REPL 可启动 | `duan repl` | 出现 `段言 REPL v6.x` 和 `>>>` 提示符 |

**如果卡住了：**
- 看不到 Python 版本 → 去 [python.org](https://www.python.org/downloads/) 下载安装，记得勾选「Add Python to PATH」
- 看不到段言版本 → 在终端执行 `pip install duan`
- REPL 启动后先输入 `退出()` 或按 `Ctrl+Z` 回车（Windows）退出，然后继续往下看

## 练习 1：Hello World（30 秒）

**预计时间：** 0.5 分钟

**学习目标：** 启动 REPL 并输出第一行文字

**步骤：**

我们来打开 REPL 环境，敲下你在段言中的第一行代码。

1. 在终端中启动 REPL：

```bash
duan repl
```

你会看到：

```
段言 REPL v6.2
>>>
```

`>>>` 就是 REPL 的提示符——它正在等你输入代码。

2. 在 `>>>` 后面输入：

```段言
>>> 打印 "你好，世界！"
```

3. 按回车，观察输出：

```
你好，世界！
```

**🎯 知识点：**
- `打印` 是段言的内置函数，用来输出内容到屏幕
- REPL 是「敲一行，执行一行」的交互式环境
- 不需要写文件，不需要 `duan run`，直接就能看到结果

**💡 小提示：** `打印` 后面可以加括号，也可以不加——`打印("你好，世界！")` 效果完全一样。本教程统一不加括号，更简洁。

---

## 练习 2：变量与计算（1 分钟）

**预计时间：** 1 分钟

**学习目标：** 学会用 `设` 创建变量，做简单的算术运算

**步骤：**

REPL 中定义的变量会一直保留——我们来试试。

1. 在 REPL 中依次输入：

```段言
>>> 设 x 为 10
>>> 设 y 为 20
>>> x + y
```

2. 你会看到：

```
30
```

3. 试试更多运算：

```段言
>>> x * y
200
>>> y - x
10
>>> y / x
2.0
```

**🎯 知识点：**
- `设 变量名 为 值` 是段言创建变量的方式
- REPL 中输入一个表达式会自动计算并显示结果（不需要 `打印`）
- 变量在 REPL 中会一直存在，直到你退出

**💡 小提示：** 如果不小心退出了 REPL，变量就丢了。重新启动 REPL 后需要重新定义。这是正常的——每次 REPL 都是全新的环境。

---

## 练习 3：条件判断（1 分钟）

**预计时间：** 1 分钟

**学习目标：** 学会用 `如果` 和 `否则` 让程序做决策

**步骤：**

我们让段言帮我们判断一个分数是否及格。

1. 在 REPL 中输入：

```段言
>>> 设 分数 为 85
>>> 如果 分数 >= 60：
...     打印 "及格"
... 否则：
...     打印 "不及格"
...
```

注意：输入 `如果 分数 >= 60：` 后按回车，提示符会变成 `...`——这表示 REPL 知道你的代码还没写完，在等你继续输入。输入完 `否则：` 后的内容后，再按一次回车结束。

2. 输出结果：

```
及格
```

3. 试试换个分数：

```段言
>>> 设 分数 为 45
>>> 如果 分数 >= 60：
...     打印 "及格"
... 否则：
...     打印 "不及格"
...
```

```
不及格
```

**🎯 知识点：**
- `如果 条件：` 后面缩进的代码，在条件成立时执行
- `否则：` 后面缩进的代码，在条件不成立时执行
- 冒号 `：` 告诉段言「接下来是条件成立时要执行的代码」
- 缩进（前面空 4 个空格）标示哪些代码属于这个条件

**💡 小提示：** 常见错误——忘记冒号、缩进不统一。如果 REPL 报错了，检查一下 `：` 是否漏了，或者 `...` 后面的空格是否一致。

## 练习 4：循环（1 分钟）

**预计时间：** 1 分钟

**学习目标：** 学会用 `遍历` 循环让计算机重复做事

**步骤：**

计算机最擅长的事情就是——不厌其烦地重复。我们来试试。

1. 在 REPL 中输入：

```段言
>>> 遍历 i 从 1 到 5：
...     打印 i
...
```

2. 输出：

```
1
2
3
4
5
```

3. 试试更复杂的循环——打印每个数的平方：

```段言
>>> 遍历 i 从 1 到 5：
...     打印 i * i
...
```

```
1
4
9
16
25
```

**🎯 知识点：**
- `遍历 变量 从 开始 到 结束：` 是最常用的循环形式
- `开始` 和 `结束` 都包含在范围内（即 1 到 5 包含 1 和 5）
- 循环体中的代码会为每个值执行一次

**💡 小提示：** 如果循环体有多行代码，每行都需要缩进。REPL 中按退格键可以取消缩进并结束循环体。

## 练习 5：函数定义（1.5 分钟）

**预计时间：** 1.5 分钟

**学习目标：** 学会用 `段落` 定义函数，并调用它

**步骤：**

把一段代码「打包」成一个名字，以后随时调用——这就是函数。

1. 在 REPL 中定义一个打招呼的函数：

```段言
>>> 段落 打招呼 接收 姓名：
...     打印 "你好，" + 姓名
...
```

2. 调用它：

```段言
>>> 打招呼("张三")
你好，张三

>>> 打招呼("李四")
你好，李四
```

3. 试试带返回值的函数：

```段言
>>> 段落 加法 接收 a, b：
...     返回 a + b
...
>>> 加法(3, 5)
8

>>> 加法(10, 20)
30
```

**🎯 知识点：**
- `段落 函数名 接收 参数：` 定义一个新函数
- `返回 值` 把结果「抛」回给调用者
- 函数可以接收多个参数，用逗号分隔
- `"你好，" + 姓名` 是字符串拼接——把两段文字连起来

**💡 小提示：** 定义函数时，`接收` 后面即使没有参数也要写（`段落 函数名 接收：`）。REPL 中定义完函数后，记得多按一次回车回到 `>>>` 提示符。

## ❓ 常见问题

### 怎么退出 REPL？

| 操作系统 | 退出方式 |
|---------|---------|
| Windows | 按 `Ctrl+Z` 然后回车，或输入 `退出()` |
| Mac / Linux | 按 `Ctrl+D`，或输入 `退出()` |

### 输入代码时 REPL 报错了怎么办？

别慌！报错信息会告诉你哪里出了问题。常见的情况：

- **语法错误：** 检查是否漏了冒号 `：`、引号是否成对
- **变量未定义：** 确认是否先用 `设` 创建了变量
- **缩进错误：** 检查 `...` 后面的空格是否一致

如果实在搞不清楚，输入 `退出()` 重新启动 REPL，再试一次。

### REPL 中的变量能保存下来吗？

不能。REPL 是临时环境，退出后所有变量都会消失。如果你想保存代码，创建一个 `.duan` 文件，用 `duan run 文件名.duan` 运行。

### 在 REPL 中不小心按了方向键，出现了乱码？

方向键（上下左右）在 REPL 中用于浏览历史命令和移动光标，不会产生乱码。如果出现了奇怪字符，按 `Ctrl+C` 取消当前输入，重新开始。

### 我想清空 REPL 屏幕？

输入 `清屏()` 或按 `Ctrl+L`（Windows 和 Mac/Linux 都支持）。
