## 一、待办事项列表

### P0 — 严重（影响核心功能）

- [ ] **[P0] 自举验证：用 level6_generated.py 编译 bootstrap_level5.light 并验证一致性**
  - **描述**：Level 6 编译器当前是 Python 手动实现，尚未完成光明自举编译。需要：
    1. 用 `level6_generated.py` 编译 `bootstrap/bootstrap_level5.light`，生成 `level6_self_compiled.py`
    2. 用 `level6_self_compiled.py` 再次编译自身，生成 `level6_self_compiled2.py`
    3. 验证两次输出一致（自举收敛）
  - **关联**：`docs/BOOTSTRAP_STRATEGY.md` §十一、Level 6 自举验证
  - **优先级**：P0

### P1 — 高（影响使用体验）

- [ ] **[P1] 异常捕获语法增强：支持 `捕获 类型 as 变量`**
  - **描述**：当前异常处理仅支持 `捕获` 块，不支持 `捕获 类型错误 as e` 的语法形式。需要：
    1. 在 `comp_try` 中解析捕获类型和变量名
    2. 生成 `except TypeError as e:` 的 Python 代码
    3. 支持中文异常类型别名映射（如 `值错误` → `ValueError`）
  - **参考**：`docs/level5_spec.md` §2.1 异常处理语法
  - **优先级**：P1

- [ ] **[P1] 词法分析器边界修复：`-` 作为减法运算符的歧义处理**
  - **描述**：当前 `-` 在数字前被识别为负号前缀，但在 `a-1` 这样的表达式中，`-` 应被识别为减法运算符而非负号。需要：
    1. 在词法分析器中根据上下文判断 `-` 的角色
    2. 如果前一个 token 是标识符、数字或右括号，`-` 为减法运算符
    3. 如果前一个 token 是运算符、左括号或行首，`-` 为负号前缀
  - **优先级**：P1

### P2 — 中（影响健壮性）

- [ ] **[P2] 缩进规范增强：制表符检测与错误提示**
  - **描述**：纯缩进语法要求严格的缩进对齐，混合制表符和空格可能导致解析错误。需要：
    1. 在词法分析器中检测制表符，给出明确的错误提示
    2. 支持可配置的缩进宽度（当前隐含为 4 空格）
    3. 提供 `--fix-indent` 自动修复工具
  - **优先级**：P2

- [ ] **[P2] 编译错误信息增强：提供更友好的错误定位**
  - **描述**：当前编译错误信息较简单，缺少行号、列号和上下文提示。需要：
    1. 在 token 中保存行号/列号信息
    2. 编译错误时输出错误位置和附近代码
    3. 提供中文错误提示
  - **优先级**：P2

### P3 — 低（增强功能）

- [x] **[P3] 单行块支持：`如果x大于0：返回x`**
  - **描述**：当前纯缩进语法要求块必须有缩进内容，不支持 `：` 后直接跟语句的单行块形式。需要：
    1. 在 `compile_block` 中检测 `：` 后的非换行内容
    2. 将单行内容作为块内唯一语句处理
  - **参考**：`docs/superpowers/specs/2026-07-01-level6-type-annotation-design.md` §4.3
  - **优先级**：P3
  - **完成**：2026-08-06，在 level6_generated.py 中添加 `编译单行块` 辅助函数，修改 comp_if/comp_while/comp_for 支持单行块

- [x] **[P3] 运算符符号别名支持：`+`、`-`、`*`、`/`、`==` 等**
  - **描述**：当前仅支持中文运算符关键字（`加`、`减`、`乘`、`除`、`等于`），不支持符号形式。需要：
    1. 在词法分析器中添加 `+`、`-`、`*`、`/`、`%`、`==`、`!=`、`<`、`>`、`<=`、`>=` 的映射
    2. 所有符号统一映射到内部标记
  - **参考**：`docs/superpowers/specs/2026-07-01-level6-type-annotation-design.md` §5.1
  - **优先级**：P3
  - **完成**：2026-08-06，在词法分析器中添加符号映射（+→加, *→乘, /→除, %→取模, ==→等于, !=→不等于, <→小于, >→大于, <=→小于等于, >=→大于等于），- 使用 SUB 特殊 token 处理歧义

- [x] **[P3] 反引号转义标识符支持**
  - **描述**：不支持反引号 `` ` `` 包裹的内容强制作为标识符（用于关键字做变量名的场景）。需要：
    1. 在词法分析器中添加反引号处理
    2. 反引号内的内容无论是否为关键字，都作为标识符返回
  - **参考**：`docs/superpowers/specs/2026-07-01-level6-type-annotation-design.md` §2.3
  - **优先级**：P3
  - **完成**：2026-08-06，在词法分析器中添加反引号处理，修复 compile_block 中关键字检查(token 类型判断)

- [x] **[P3] 调试日志输出到文件支持**
  - **描述**：当前 `调试模式` 将日志输出到 stdout，与程序输出混杂。需要：
    1. 支持将调试日志输出到指定文件
    2. 支持 `调试模式=文件("debug.log")` 的形式
  - **优先级**：P3
  - **完成**：2026-08-06，添加 `调试模式设为文件(路径)` 函数和 `调试日志文件` 全局变量
