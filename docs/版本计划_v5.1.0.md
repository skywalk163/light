**版本**: v5.1.0

## 一、版本定位

v5.0.0 已完成了原三个月计划中「夯实底座」「扩展生态」「正式发布」的全部核心功能：
trait/协议系统、模式匹配增强、迭代器协议、上下文管理器、duanpub 53 桥接模块、
框架库（单元测试/日志/配置/HTTP）、LSP/调试器/Playground、文档站。

v5.1.0 的目标是从「功能完整」走向「工程成熟」—— 补齐 LLVM 后端能力、
完善社区基础设施、升级 AI 工具链、深化 duanpub 生态质量。

  └───────────────┘ └────────────┘ └───────────────┘

### 10.2 质量保障红线

1. **每次变更必须跑全量测试** — 0 failures 是硬性门槛
2. **新增功能必须附带测试** — 无测试的代码不合并
3. **不允许改测试期望值来「修 bug」** — 必须修复底层逻辑
4. **不允许用 SkipTest 跳过失败** — 必须修复或标注为环境依赖
5. **每次提交前 `git status` 检查** — 不引入新的未跟踪临时文件
6. **CHANGELOG 必须同步更新** — 每个功能变更都有记录
