## 全局内置（无需导入，直接用）

### 通用工具
| 函数 | 签名 | 说明 | 示例 |
|------|------|------|------|
| `长(x)` | `(列表/字符串/字典) -> 整数` | 取长度 | `长([1,2,3])` → `3` |
| `打印(x)` | `(任意) -> 空` | 输出到控制台 | `打印("你好")` |
| `字符串(x)` | `(任意) -> 字符串` | 转字符串 | `字符串(123)` → `"123"` |
| `数字(x)` | `(字符串) -> 数字` | 字符串转数字 | `数字("3.14")` → `3.14` |

### 判型函数
| 函数 | 签名 | 说明 | 示例 |
|------|------|------|------|
| `是数值(x)` | `(任意) -> 布尔` | **判值类型**：int/float 是真，bool 排除 | `是数值(7)` → `真`；`是数值("7")` → `假` |
| `是整数(x)` | `(任意) -> 布尔` | 判是否为 int（排除 bool） | `是整数(5)` → `真` |
| `是浮点(x)` | `(任意) -> 布尔` | 判是否为 float | `是浮点(3.14)` → `真` |
| `是字符串(x)` | `(任意) -> 布尔` | 判是否为 str | `是字符串("甲")` → `真` |
| `是列表(x)` | `(任意) -> 布尔` | 判是否为 list | `是列表([1])` → `真` |
| `是字典(x)` | `(任意) -> 布尔` | 判是否为 dict | `是字典({})` → `真` |
| `是空(x)` | `(任意) -> 布尔` | 判是否为 None | `是空(空)` → `真` |
| `是布尔(x)` | `(任意) -> 布尔` | 判是否为 bool | `是布尔(真)` → `真` |
| `是函数(x)` | `(任意) -> 布尔` | 判是否可调用 | `是函数(打印)` → `真` |
| `字符串全数字(串)` | `(字符串) -> 布尔` | **判字符串内容**：整个串是否全数字字符 | `字符串全数字("123")` → `真`；`字符串全数字("12a")` → `假` |

> ⚠️ **LP-D-016 名实辨析（勿混）**：
> - `是数字`（用户关键字）= `是数值` → 判**值类型**是不是 int/float
> - `是数字符`（用户关键字）= `是数字`（底层） → 判**单个字符**是不是数字字符
> - `字符串全数字`（R99-C 新增） → 判**整个字符串**是不是全数字字符
>
> 三者用途完全不同，写守卫时选对：
> - 收到一个值，想知道它能不能当数用 → `是数值(x)`
> - 收到一个字符，想知道它是不是 `'0'~'9'` → `是数字符(字符)`
> - 收到一个字符串，想知道它能不能直接转成数字 → `字符串全数字(串)`

## 字典方法面（从 `内置核心字典` 导入）

> 调用方式：`字典.方法(参数)` 或 `字典方法(字典, 参数)`

### 查询类（不修改原字典）
| 函数 | 签名 | 说明 | 示例 |
|------|------|------|------|
| `字典长度(映射)` | `(字典) -> 整数` | 键值对个数 | `字典长度({"a":1})` → `1` |
| `字典键列表(映射)` | `(字典) -> 列表` | 所有键的列表 | `字典键列表({"a":1,"b":2})` → `["a","b"]` |
| `字典值列表(映射)` | `(字典) -> 列表` | 所有值的列表 | `字典值列表({"a":1})` → `[1]` |
| `字典项列表(映射)` | `(字典) -> 列表` | 所有 (键,值) 元组列表 | `字典项列表({"a":1})` → `[("a",1)]` |
| `字典包含键(映射, 键)` | `(字典, 任意) -> 布尔` | 键是否存在 | `字典包含键({"a":1}, "a")` → `真` |
| `字典获取(映射, 键, 默认)` | `(字典, 键, 默认值) -> 值` | 安全取值，不存在返默认 | `字典获取({"a":1}, "b", 0)` → `0` |

### 修改类
| 函数 | 签名 | 说明 | 示例 |
|------|------|------|------|
| `字典设置(映射, 键, 值)` | `(字典, 键, 值) -> 空` | 设置键值对 | `字典设置(甲, "新键", 100)` |
| `字典删除(映射, 键)` | `(字典, 键) -> 空` | 删除键（键不存在静默） | `字典删除(甲, "旧键")` |
| `字典合并(目标, 来源)` | `(字典, 字典) -> 字典` | **R99-C 新增**：浅合并，来源覆盖目标 | `字典合并(默认, 用户)` → 新字典 |
| `字典弹出(映射, 键)` | `(字典, 键) -> 值` | 弹出键值（不存在抛 KeyError） | `字典弹出(甲, "a")` → `1` |
| `字典弹出默认(映射, 键, 默认)` | `(字典, 键, 默认值) -> 值` | **R99-C 新增**：存在则弹，否则返默认不报错 | `字典弹出默认(甲, "b", 0)` → `0` |

> ❌ **字典没有的方法（别凭直觉用）**：
> - `字典.删除(键)` / `字典.移除(键)` —— 仅列表有按值删，对字典报错；删键用 `字典弹出(键)` 或 `字典删除(映射, 键)`
> - ⚠️ **置空软删除陷阱**：`设 字典[键] 为 空` **不删键**，之后 `字典包含键(键)` 仍为真！取值处必须补判空。
