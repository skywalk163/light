## 1. 零基础入门路径

> 适合：完全没有编程经验，想从段言开始学习编程的新手

### 第一阶段：编程启蒙（预计 1-2 周）

**目标**：理解编程的基本概念，能运行第一个段言程序

**学习内容**：

| 主题 | 说明 | 学习时间 |
|------|------|----------|
| 安装段言 | 安装 Python 和段言编译器 | 30 分钟 |
| 运行第一个程序 | 运行 `hello.duan`，理解"打印"输出 | 30 分钟 |
| 变量与赋值 | 理解 `设 变量 为 值` 的概念 | 1 小时 |
| 基本数据类型 | 数字、字符串、布尔值 | 1 小时 |
| 输入输出 | 使用 `打印()` 和 `input()` | 1 小时 |

**推荐资源**：
- [5 分钟入门段言](../video_scripts/5分钟入门段言.md) — 快速上手视频脚本
- [入门教程](../tutorials/入门教程.md) — 详细图文教程
- [基础示例](../../examples/basic.duan) — 基础语法示例

**实践任务**：
- 编写一个程序，输出自己的名字和年龄
- 编写一个简单的加减法计算器

### 第二阶段：基础语法（预计 2-3 周）

**目标**：掌握段言的核心语法，能编写简单的交互程序

**学习内容**：

| 主题 | 说明 | 学习时间 |
|------|------|----------|
| 条件判断 | `如果` / `否则若` / `否则` | 2 小时 |
| 循环语句 | `遍历` 和 `当` 循环 | 2 小时 |
| 列表操作 | 创建、访问、修改列表 | 2 小时 |
| 字典操作 | 键值对存储和访问 | 2 小时 |
| 段落（函数） | 定义和调用函数 | 2 小时 |

**推荐资源**：
- [语法规范](../syntax.md) — 完整语法参考

- 编写猜数字游戏
- 编写待办事项列表程序

### 第三阶段：实用编程（预计 3-4 周）

**目标**：能编写实用的命令行工具，理解模块化编程

**学习内容**：

| 字符串操作 | 拼接、分割、查找、替换 | 2 小时 |
| 文件读写 | 读取和写入文件 | 2 小时 |

## 2. 有 Python 基础路径

> 适合：熟悉 Python，想快速掌握段言语法的开发者

### 快速迁移（预计 1-3 天）

**段言 vs Python 语法对照**：

| 概念 | Python | 段言 |
|------|--------|------|
| 变量赋值 | `x = 1` | `设 x 为 1` |
| 函数定义 | `def add(a, b):` | `段落 加法 接收 甲, 乙:` |
| 条件判断 | `if x > 0:` | `如果 x 大于 0:` |
| for 循环 | `for i in items:` | `遍历 i 于 items:` |
| while 循环 | `while x > 0:` | `当 x 大于 0:` |
| 类定义 | `class MyClass:` | `类 我的类:` |
| 构造方法 | `def __init__(self):` | `构造:` |
| 打印输出 | `print(x)` | `打印(x)` |
| 列表推导 | `[x*2 for x in list]` | 暂不支持 |
| 异常处理 | `try/except` | `尝试/捕获` |
| 导入模块 | `import os` | `导入 文件系统` |
| 注释 | `# comment` | `# 注释` |

**学习重点**：

1. **中文关键字**：段言使用中文关键字，如 `如果`、`遍历`、`当`、`段落`、`类`
2. **语句结尾**：段言建议使用 `。`（中文句号）结束语句
3. **代码块**：使用 `：`（中文冒号）+ 缩进表示代码块
4. **内置函数**：段言有独立的内置函数体系，如 `打印()`、`列表长度()`、`转字符串()`
5. **标准库**：段言有独立的标准库，如 `文件系统`、`JSON`、`数学` 等

**推荐资源**：
- [段言与 Python 对比案例](../段言与Python对比案例.md) — 详细对比
- [从段言到 Python](../从段言到Python.md) — 迁移指南
- [语法规范](../syntax.md) — 快速查阅语法

**实践任务**：
- 将你熟悉的 Python 小工具用段言重写
- 对比两种语言的实现差异

### 深入掌握（预计 1-2 周）

**推荐资源**：

## 3. 有英文编程语言基础路径

> 适合：熟悉 Java、C++、JavaScript 等英文编程语言，但不熟悉中文编程的开发者

### 段言特色功能速览（预计 1-2 天）

**段言的核心特色**：

1. **全中文关键字**：`如果`、`遍历`、`当`、`段落`、`类`、`返回` 等
2. **中文标识符**：变量名、函数名、类名均可使用中文
3. **中英文混编**：支持中英文关键字混用，如 `打印()` 等价于 `print()`
4. **自然语义语法**：`设 姓名 为 "张三"` 读起来像自然语言
5. **LLVM 编译后端**：支持编译为原生可执行文件，性能接近 C
6. **自举编译器**：段言的编译器本身可以用段言编写

**与主流语言的差异**：

| 方面 | 主流语言 | 段言 |
|------|----------|------|
| 关键字 | 英文 | 中文 |
| 变量声明 | `var x = 1` / `let x = 1` | `设 x 为 1` |
| 函数定义 | `function f() {}` / `def f()` | `段落 函数名:` |
| 代码块 | `{}` 或缩进 | 缩进（类似 Python） |
| 语句结束 | `;` 或换行 | `。` 或换行 |
| 泛型/模板 | `<T>` | 暂不支持泛型 |
| 静态类型 | 可选类型注解 | 可选类型注解 |

**推荐资源**：
- [语法规范](../syntax.md) — 完整语法参考
- [设计哲学与定位](../设计哲学与定位.md) — 了解段言的设计理念
- [统一语法规范](../统一语法规范_v3.2.md) — 语言规范文档
