# 调试器

光明提供内置调试器，支持断点调试和单步执行。

## 启动调试

```bash
light --debug hello.light
```

## 调试命令

| 命令 | 说明 |
|------|------|
| `b <行号>` | 设置断点 |
| `c` | 继续执行 |
| `n` | 单步跳过 |
| `s` | 单步进入 |
| `r` | 单步跳出 |
| `p <变量>` | 打印变量值 |
| `l` | 列出源代码 |
| `q` | 退出调试器 |

## Playground 调试器

Playground 内置图形化调试器，支持：
- 点击设置/取消断点
- 单步跳过/进入/跳出
- 变量查看
- 调用栈显示
- 实时输出
