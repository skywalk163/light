## 性能分析

- 平均总编译耗时: 748.58 ms
- 测试文件数: 10

### 瓶颈分析

1. **语法解析** 通常是编译管道的瓶颈，尤其在处理大量嵌套结构时
2. **代码生成** 的耗时与 AST 节点数成正比，大型 AST 可导致显著延迟
3. **词法分析** 相对轻量，但随着源码增大仍可能成为瓶颈

### 优化建议

1. **三态缓存**：编译器缓存系统（CompilerCache）可缓存各阶段结果，避免重复编译
2. **增量编译**：增量构建系统（IncrementalBuilder）只编译变更部分
3. **并行编译**：多文件项目可并行执行词法分析阶段
4. **AST 优化**：减少 AST 节点数量可降低代码生成耗时

> 注：以上数据基于 SRC 后端的 Python 解释执行环境。
> LLVM 后端将使用不同的编译管道，性能特征可能有所不同。
