# v3.3 → v4.0 迁移指南

## 概述

v4.0 **完全兼容** v3.3 代码。所有 v3.3 双字关键字作为别名永久保留。

## 主要变化

### 1. 关键字简化

| v3.3 | v4.0 | 说明 |
|------|------|------|
| `如果` `那么` `否则` | `若` `则` `否` | 单字条件 |
| `打印` | `印` | 单字输出 |
| `遍历` | `遍` | 单字遍历 |
| `段落` `返回` | `段` `返` | 单字函数 |
| `导入` `导出` | `引` `出` | 单字模块 |

### 2. 运算符变化

| v3.3 | v4.0 | 说明 |
|------|------|------|
| `加` `减` `乘` `除` | `+` `-` `*` `/` | 符号运算符 |
| `大于` `小于` `等于` | `>` `<` `==` | 符号比较 |

### 3. 标点变化

| v3.3 | v4.0 (L2) | 说明 |
|------|-----------|------|
| 中文标点 | 英文标点 | L2 推荐 |
| 句号结尾 | 无句号 | L2 风格 |

## 自动迁移

```bash
light --migrate-v3-to-v4 old.light -o new.light
```

## 兼容性保证

- v4.0 可以运行所有 v3.3 代码
- 新旧关键字可以混用
- 中文运算符别名仍然支持
- 无需修改现有代码
