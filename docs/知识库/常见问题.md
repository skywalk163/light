# 光明常见问题（FAQ）

## 安装与配置

### Q: 如何安装光明？
```bash
pip install light
```

### Q: 安装后如何验证？
```bash
light --version
light --help
```

### Q: 光明支持哪些平台？
光明支持 Windows、Linux 和 macOS 三大主流平台。

## 语法问题

### Q: L1 白话体和 L2 文言体有什么区别？
L1 使用 19 个核心字的双字别名（如 `如果` `打印` `遍历`），配合中文标点，适合教学。
L2 使用全部 30 个核心字（如 `若` `印` `遍`），配合英文标点，适合商业项目。

### Q: 如何在文件中声明文体？
在文件首行添加注释：
```light
# 文体: 白话  → L1 白话体
# 文体: 文言  → L2 文言体
```

### Q: 光明的变量名可以用中文吗？
可以。光明支持中文标识符，推荐使用中文命名以提高代码可读性。

## 类型系统

### Q: 光明是强类型还是弱类型？
光明支持可选类型注解。不标注类型时动态执行，标注类型时进行静态类型检查。

### Q: 如何使用泛型？
```light
段 首元素[T](列表: 列表[T]) -> T:
    返回 列表[0]
```

### Q: 联合类型怎么用？
```light
设 值: 整数|文本 = 42
设 值 = "hello"  # 同一变量可以赋不同类型的值
```

## 标准库

### Q: 如何导入标准库模块？
```light
从 JSON 导入 解析JSON, 生成JSON
从 数学 导入 正弦, 余弦, 平方根
```

### Q: 光明有哪些内置函数？
内置函数直接可用，无需导入：
- `打印` - 输出
- `读取` - 输入
- `整数` - 转为整数
- `串` - 转为字符串
- `随机` - 随机数
- `类型` - 获取类型

## 工具链

### Q: 如何运行光明程序？
```bash
light run 程序.light
```

### Q: 如何编译光明程序？
```bash
# 编译为 Python 代码
light compile 程序.light

# 编译为原生可执行文件
light compile --native 程序.light
```

### Q: 如何使用 Playground？
访问在线 Playground 地址，或本地运行：
```bash
python playground/server.py
```

## 项目开发

### Q: 如何创建多模块项目？
1. 创建项目目录
2. 编写 `package.toml` 配置文件
3. 创建入口文件（如 `主.light`）
4. 创建模块文件，使用 `导`/`从` 导入

### Q: 光明支持包管理吗？
支持。光明内置包管理器，支持：
- 包搜索：`light search 关键词`
- 包安装：`light install 包名`
- 包发布：`light publish`

## 错误与调试

### Q: 光明报错信息看不懂怎么办？
光明提供中文错误提示，包含：
- 错误位置（文件名、行号、列号）
- 错误类型
- 错误描述
- 修复建议

### Q: 如何使用调试器？
```bash
light debug 程序.light
```
支持断点、单步执行、变量查看等调试功能。

## 与其他语言的关系

### Q: 光明和 Python 有什么关系？
光明底层使用 Python 实现，支持通过 L4 层 `引 Python:` 语法直接调用 Python 代码。

### Q: 光明能调用 C 语言库吗？
可以。光明通过 FFI 模块支持调用 C 语言库，也支持通过 L4 层调用 C、Go、MoonBit 代码。

### Q: 光明代码能迁移到 Python 吗？
光明提供了 `tools/ai_copilot/py2duan_transpiler.py` 工具，支持 Python 到光明的代码转换。光明语法与 Python 有相似性，迁移成本较低。
