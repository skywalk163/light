# 光明语言规范

## 1. 语法规范

### 1.1 文件编码
- 所有 `.light` 文件使用 UTF-8 编码（支持 BOM 头）
- 推荐使用 `utf-8-sig` 编码以兼容 Windows 平台

### 1.2 文体声明
文件首行可通过注释声明文体：
```light
# 文体: 白话  → L1 白话体，中文标点
# 文体: 文言  → L2 文言体，英文标点
```
未声明时，根据是否出现类型注解自动推断。

### 1.3 标识符规则
- 支持中文标识符（变量名、函数名等）
- 支持英文标识符
- 支持数字（不能开头）
- 支持下划线 `_`

### 1.4 注释
```light
# 这是单行注释
# 文体: 白话  → 特殊注释
```

## 2. 核心语法

### 2.1 变量声明
```light
# L1 白话体
设 变量名 = 值
设 变量名 为 值

# L2 文言体
设 变量名 为 值。
```

### 2.2 控制流
```light
# 条件判断
如果 条件：
    代码块
否则：
    代码块

# 当循环
当 条件：
    代码块

# 遍循环
遍历 变量 于 范围：
    代码块

# 模式匹配
配 值：
    若 模式1:
        代码块
    若 模式2:
        代码块
```

### 2.3 函数定义
```light
# L1 白话体
段 函数名(参数1, 参数2):
    返回 结果

# L2 文言体
段落 函数名 接收 参数1, 参数2：
    返回 结果。
```

### 2.4 异常处理
```light
试:
    可能出错的代码
捕 错误变量:
    错误处理代码
终:
    收尾代码（总是执行）
```

### 2.5 模块导入
```light
# L1 白话体
从 模块名 导入 函数1, 函数2

# L2 文言体
导入 函数1, 函数2 从 模块名
```

## 3. 类型系统

### 3.1 基本类型
| 类型 | 说明 | 示例 |
|------|------|------|
| `整数` | 整型数字 | `42`, `-10` |
| `浮点` | 浮点数 | `3.14`, `-0.5` |
| `文本` | 字符串 | `"你好"` |
| `布尔` | 布尔值 | `真`, `假` |
| `空` | 空值 | `空` |

### 3.2 复合类型
```light
# 列表
类型 编号清单 为 列表[整数]     # 整数列表
类型 名称清单 为 列表[文本]     # 字符串列表

# 字典
类型 名称编号表 为 字典[文本, 整数]  # 键为文本，值为整数的字典

# 联合类型
类型 可空取值 为 整数|文本|空     # 可以是整数、文本或空
```

### 3.3 类型注解
```light
# 变量注解
设 变量名: 整数 = 42

# 函数注解
段 函数名(参数: 整数) -> 文本:
    返回 "结果"
```

## 4. 模块系统

### 4.1 模块结构
每个标准库模块通常包含两个文件：
- `.light` 文件：定义光明接口，声明导出函数
- `.py` 文件：Python 实现，提供实际功能

### 4.2 包管理
使用 `package.toml` 配置文件：
```toml
[package]
name = "项目名"
version = "1.0.0"
entry = "主.light"
authors = []
description = "项目描述"
```

## 5. 五层架构

### 5.1 L0 核心字集（30字）
```
印 设 若 否 当 遍 为 段 返 类 接 承
试 捕 终 抛 导 出 引 配 出 型 真 假
空 和 或 不 新 生
```

### 5.2 L1 白话体（19字子集）
使用双字关键字：`打印` `设` `如果` `否则` `当` `遍历` `为` `段` `返回`
`试` `捕` `终` `抛` `从` `导` `出` `引` `结束引` `配` `若`

### 5.3 L2 文言体（30字全集）
使用单字关键字：`印` `设` `若` `否` `当` `遍` `为` `段` `返`
`类` `接` `承` `试` `捕` `终` `抛` `导` `出` `引` `配`

### 5.4 L3 领域嵌入
支持直接嵌入 SQL、正则表达式、数学公式。

### 5.5 L4 外语引用
通过 `引 语言:` 块嵌入外部语言代码：
```light
引 Python:
    def hello():
        return "Hello from Python"
出 hello
```
