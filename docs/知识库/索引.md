## 学习路径推荐

### 路径一：K12 学生入门
1. 课程1-5：认识光明、变量、条件、循环、函数
2. 课程6-7：列表、字典、字符串
3. 课程8-9：文件操作、小游戏
4. 课程10：综合项目

### 路径二：开发者快速上手
1. 快速开始 + 安装指南
2. L1 白话体语法
3. 标准库使用
4. CLI 工具链
5. 类型系统
6. L2 文言体 + L3/L4 高级特性

### 路径三：深入学习
1. 五层架构设计理念
2. 类型系统详解
3. 编译器 API
4. 模块系统
5. FFI 外部函数接口
6. 性能优化
