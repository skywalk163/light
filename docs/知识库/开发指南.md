# 光明开发指南

## 1. 开发环境搭建

### 1.1 安装
```bash
pip install light
```

### 1.2 验证安装
```bash
light --version
light --help
```

### 1.3 VS Code 扩展
安装光明 VSCode 扩展以获得语法高亮、代码补全、调试支持。

## 2. 项目结构规范

### 2.1 推荐项目结构
```
my_project/
├── package.toml          # 项目配置文件
├── 主.light               # 入口文件
├── 模块1.light            # 模块文件
├── 模块2.light            # 模块文件
├── data/                 # 数据目录
│   └── input.csv
└── docs/                 # 文档目录
    └── README.md
```

### 2.2 package.toml 配置
```toml
[package]
name = "my_project"
version = "0.1.0"
entry = "主.light"
authors = ["作者名"]
description = "项目描述"
```

## 3. 编码规范

### 3.1 命名规范
- **变量名**：使用有意义的名称，推荐中文
- **函数名**：动词开头，如 `计算面积`, `获取用户`
- **模块名**：名词短语，如 `数学工具`, `学生管理`
- **常量**：全大写或中文描述

### 3.2 代码风格
- 使用 4 空格缩进
- 函数之间空 1 行
- 注释使用 `#` 开头
- 关键字和操作符前后加空格

### 3.3 注释规范
```light
# 文件头注释
# 文体: 白话
# 功能：计算圆的面积

# 函数注释
段 计算面积(半径):
    # 根据半径计算圆的面积
    # 参数：半径 - 圆的半径
    # 返回：圆的面积
    返回 3.14159 * 半径 * 半径
```

## 4. 调试技巧

### 4.1 打印调试
```light
打印 "变量值：", 变量名
```

### 4.2 异常处理
```light
试:
    可能出错的代码

    打印 "出错：", 错误
```

### 4.3 使用调试器
```bash
light debug 程序.light
```

## 5. 测试指南

### 5.1 单元测试
```light
从 测试 导入 测试, 断言相等

段 测试加法():
    断言相等(加法(2, 3), 5)

测试(测试加法)
```

### 5.2 运行测试
```bash
light test 测试文件.light
```

## 6. 性能优化

### 6.1 编译优化
```bash

# 启用优化
light compile --optimize 程序.light
```

### 6.2 性能分析
```bash
light profile 程序.light
```

## 8. 常见模式

### 8.1 CRUD 模式
```light
# 创建
段 创建资源(数据):
    列表的 添加 数据

# 读取
段 获取资源(编号):
    遍 列表 为 项:
        如果 项["编号"] 等于 编号:
            返回 项

# 更新
段 更新资源(编号, 新数据):
    遍 列表 为 项:
        如果 项["编号"] 等于 编号:
            项["属性"] = 新数据

# 删除
段 删除资源(编号):
    新列表 = []
    遍 列表 为 项:
        如果 项["编号"] 不等于 编号:
            新列表的 添加 项
    列表 = 新列表
```

### 8.2 管线模式
```light
段 处理管线(数据):
    数据 = 步骤1(数据)
    数据 = 步骤2(数据)
    数据 = 步骤3(数据)
    返回 数据
```

### 8.3 状态机模式
```light
段 状态处理(状态, 输入):
    如果 状态 等于 "初始":
        返回 处理初始状态(输入)
    如果 状态 等于 "运行":
        返回 处理运行状态(输入)
    如果 状态 等于 "结束":
        返回 处理结束状态(输入)
```
