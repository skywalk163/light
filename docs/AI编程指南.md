# 光明语言 AI 编程指南

> **本文档专为 AI 设计**：看了就能直接写光明（Light）代码。
> 版本：v7.0+（2026-09-07）· 109 个标准库模块 · 711 项原生腿能力
> 文件后缀：`.light` · CLI：`light 运行 文件.light` 或 `lightc 编译 文件.light`

---

## 一、30 秒上手

```光明
# hello.light
从 时间 导入 当前时间

段落 问候 接收 名字 = "世界"：
    返回 "你好，" + 名字 + "！现在是 " + 当前时间()

段落 主：
    打印(问候("光明"))
    打印(问候())
```

运行：`light 运行 hello.light`

**AI 必须记住的 5 件事**：
1. 全中文关键字：`如果`/`遍历`/`段落`/`设`/`返回`/`类`/`从...导入`
2. 缩进 4 空格，冒号后换行缩进（`：` 或 `:` 均可）
3. 函数叫 `段落`，不是 `def`/`函数`
4. 字符串用双引号 `"..."`，注释用 `#`
5. 模块名和函数名都是中文：`从 数学 导入 平方根`

## 二、语法速查表（AI 写代码最常用）

### 2.1 变量与类型

```光明
# 基本类型
设 整数 为 42
设 浮点 为 3.14
设 字符串 为 "你好"
设 布尔 为 真          # 真/假，不是 True/False
设 空值 为 空          # 空，不是 None/null
# 值类型保留字：真/假/空 不可作变量名，但可作值使用，打印输出自身字面文本（空/真/假）

# 容器
设 列表 为 [1, 2, 3]
设 字典 为 {"a": 1, "b": 2}
设 集合 为 {1, 2, 3}
设 元组 为 (1, 2, 3)    # 部分版本支持

# 类型标注（可选，L2 文言体推荐）
设 计数: 整 为 0
设 名字: 串 为 ""
设 价格: 浮点 为 0.0

# 复合赋值
设 计数 为 计数 + 1    # 等价于 计数 += 1
计数 加上 1              # 中文复合赋值（等价）
```

### 2.3 控制流

```光明
# 条件
如果 分数 >= 90：
    打印("优秀")
否则如果 分数 >= 60：
    打印("及格")
否则：
    打印("不及格")

# 三元表达式（光明不支持 `? :`，写成「真值 如果 条件 否则 假值」）
设 结果 为 "及格" 如果 分数 >= 60 否则 "不及格"

# while 循环
当 计数 < 10：
    打印(计数)
    设 计数 为 计数 + 1

# for 循环（介词用 于/在/之/中的，推荐 于）
遍历 项 于 列表：
    打印(项)

遍历 i 在 1 到 10：
    打印(i)

遍历 i 在 0 到 长(列表)：
    打印(列表[i])

# 带步长
遍历 i 在 1 到 10 步 2：
    打印(i)    # 1, 3, 5, 7, 9

# 循环控制
遍历 i 在 1 到 10：
    如果 i % 2 == 0：
        跳过        # continue
    如果 i > 5：
        跳出        # break
    打印(i)
```

### 2.8 列表/字典操作

```光明
# 列表
设 列表 为 [3, 1, 4, 1, 5]
设 长度 为 长(列表)        # 5
设 首项 为 列表[0]          # 3
设 末项 为 列表[-1]         # 5
列表[0] 为 10               # 修改
列表.追加(6)                # 末尾添加（方法调用！不是 追加(列表, 6)）

设 字典 为 {"a": 1, "b": 2}
设 值 为 字典["a"]          # 1
字典["c"] 为 3              # 添加/修改
设 键列表 为 字典.键()      # 键列表
设 值列表 为 字典.值()      # 值列表
遍历 键, 值 在 字典：
    打印(键 + " = " + 转字符串(值))

# 字典推导式
设 平方字典 为 {k: v * v 遍历 k, v 在 字典}
```

### 容器创建
| 函数 | 说明 | 示例 |
|------|------|------|
| `列表创建()` | 创建空列表 | `设 l 为 列表创建()` |

### 5.4 带重试的网络请求
```光明
从 网络请求 导入 获取, 响应文本, 响应状态码
从 时间 导入 睡眠

段落 安全获取 接收 url, 最大重试 = 3：
    设 尝试 为 0
    当 尝试 < 最大重试：
        试：
            设 响应 为 获取(url)
            如果 响应状态码(响应) == 200：
                返回 响应文本(响应)
            打印("状态码 " + 转字符串(响应状态码(响应)) + "，重试")
        捕 错误：
            打印("请求失败：" + 转字符串(错误))
        设 尝试 为 尝试 + 1
        睡眠(1 * 尝试)    # 指数退避
    返回 空

段落 主：
    设 内容 为 安全获取("https://example.com/api/data")
    如果 内容 != 空：
        打印("获取成功，长度：" + 转字符串(长(内容)))

        打印("获取失败")
```

## 六、AI 避坑指南（最容易犯的 12 个错误）

### ❌ 错误 1：用 `def`/`function` 定义函数
```text
# 错误
def 加法(甲, 乙):
    return 甲 + 乙
```

```光明
# 正确
段落 加法 接收 甲, 乙：
    返回 甲 + 乙
```

### ❌ 错误 2：用 `if`/`for`/`while`
```text
# 错误
if x > 0:
    print(x)
```

```光明
# 正确
如果 x > 0：
    打印(x)
```

### ❌ 错误 3：布尔值用 `True`/`False`/`None`
```光明
# 错误
设 标志 为 True
设 值 为 None

# 正确
设 标志 为 真
设 值 为 空
```

> **保留字（值类型）**：`真`/`假`/`空` 是值类型保留字——禁止用作变量名/函数名（如 `设 空 为 123` 会编译报错），但可作值使用，打印时输出自身字面文本（`空`/`真`/`假`），等价于 Python 的 `None`/`True`/`False`。语义正确优先，测试预期跟随语义，绝不反过来让语义迁就测试。

### ❌ 错误 4：逻辑运算符用 `&&`/`||`/`!`
```text
# 错误
如果 a > 0 && b > 0 || !c：
```

```光明
# 正确
如果 a > 0 且 b > 0 或 非 c：
```

### ❌ 错误 5：创建空列表用 `新建列表()`
```光明
# 错误（新建列表 不存在）
设 列表 为 新建列表()

# 正确
设 列表 为 列表创建()
设 列表 为 []    # 更简单
```

### ❌ 错误 6：列表追加用函数调用
```光明
# 错误（追加(列表, 项) 会被误映射到文件模式常量）
追加(列表, 项)

# 正确（方法调用）
列表.追加(项)
```

### ❌ 错误 7：遍历介词用错
```光明
# 遍历语句用 于（推荐）
遍历 项 于 列表：

# 推导式用 之/在
设 平方 为 [x * x 遍历 x 之 列表]

# 不要混用：遍历语句里不要用 之，推导式里不要用 于
```

### ❌ 错误 8：字符串用单引号
```光明
# 错误（部分版本不支持单引号）
设 s 为 'hello'

# 正确
设 s 为 "hello"
```

### ❌ 错误 9：类的构造函数名
```光明
# 错误（不是 __init__）
类 动物：
    段落 __init__ 接收 名字：

# 正确
类 动物：
    段落 初始化 接收 名字：
        设 己.名字 为 名字
```

### ❌ 错误 10：实例属性不用 `己.`
```光明
# 错误
类 动物：
    段落 初始化 接收 名字：
        设 名字 为 名字    # 这是局部变量，不是属性

# 正确
类 动物：
    段落 初始化 接收 名字：
        设 己.名字 为 名字    # 己 = self
```

### ❌ 错误 11：导入用英文模块名
```光明
# 错误（没有 math 模块，叫 数学）
从 math 导入 sqrt

# 正确
从 数学 导入 平方根
```

### ❌ 错误 12：print 用英文
```光明
# 错误
print("hello")

# 正确
打印("hello")
```

## 九、AI 写代码检查清单（提交前自查）

- [ ] 所有关键字都是中文（如果/遍历/段落/设/返回/类/从...导入）
- [ ] 函数用 `段落 名 接收 参数：`，不是 `def`/`function`
- [ ] 布尔值用 `真`/`假`，空值用 `空`
- [ ] 逻辑运算用 `且`/`或`/`非`，不是 `&&`/`||`/`!`
- [ ] 字符串用双引号 `"..."`
- [ ] 列表追加用 `列表.追加(项)`（方法调用）
- [ ] 创建空容器用 `列表创建()`/`字典创建()`，不是 `新建列表()`
- [ ] 遍历语句介词用 `于`，推导式介词用 `之`/`在`
- [ ] 类的构造函数叫 `初始化`，实例属性用 `己.属性名`
- [ ] 模块名和函数名都是中文（`从 数学 导入 平方根`）
- [ ] 输出用 `打印(...)`，不是 `print`
- [ ] 缩进 4 空格，冒号后换行缩进
- [ ] 异常处理用 `试/捕/最终`，抛出用 `抛 新建 异常类型("消息")`
