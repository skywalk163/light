# 光明语言 AI 编程指南

> **本文档专为 AI 设计**：看了就能直接写光明（Light）代码。
> 版本：v0.4.0+（2026-10-03）· 109 个标准库模块 · 711 项原生腿能力
> 文件后缀：`.light` · CLI：`light 运行 文件.light` 或 `lightc 编译 文件.light`

---

## 一、30 秒上手

```光明
# hello.light
从 时间 导入 当前时间

段落 问候 接收 名字 = "世界"：
    返回 "你好，" + 名字 + "！现在是 " + 当前时间()

段落 主：
    打印(问候("光明"))
    打印(问候())
```

运行：`light 运行 hello.light`

**AI 必须记住的 5 件事**：
1. 全中文关键字：`如果`/`遍历`/`段落`/`设`/`返回`/`类`/`从...导入`
2. 缩进 4 空格，冒号后换行缩进（`：` 或 `:` 均可）
3. 函数叫 `段落`，不是 `def`/`函数`
4. 字符串用双引号 `"..."`，注释用 `#`
5. 模块名和函数名都是中文：`从 数学 导入 平方根`

## 二、语法速查表（AI 写代码最常用）

### 2.1 变量与类型

```光明
# 基本类型
设 整数 为 42
设 浮点 为 3.14
设 字符串 为 "你好"
设 布尔 为 真          # 真/假，不是 True/False
设 空值 为 空          # 空，不是 None/null
# 值类型保留字：真/假/空 不可作变量名，但可作值使用，打印输出自身字面文本（空/真/假）

# 容器
设 列表 为 [1, 2, 3]
设 字典 为 {"a": 1, "b": 2}
设 集合 为 {1, 2, 3}
设 元组 为 (1, 2, 3)    # 部分版本支持

# 类型标注（可选，L2 文言体推荐）
设 计数: 整 为 0
设 名字: 串 为 ""
设 价格: 浮点 为 0.0

# 复合赋值
设 计数 为 计数 + 1    # 等价于 计数 += 1
计数 加上 1              # 中文复合赋值（等价）
```

### 2.3 控制流

```光明
# 条件
如果 分数 >= 90：
    打印("优秀")
否则如果 分数 >= 60：
    打印("及格")
否则：
    打印("不及格")

# 三元表达式（光明不支持 `? :`，写成「真值 如果 条件 否则 假值」）
设 结果 为 "及格" 如果 分数 >= 60 否则 "不及格"

# while 循环
当 计数 < 10：
    打印(计数)
    设 计数 为 计数 + 1

# for 循环（介词用 于/在/之/中的，推荐 于）
遍历 项 于 列表：
    打印(项)

遍历 i 在 1 到 10：
    打印(i)

遍历 i 在 0 到 长(列表)：
    打印(列表[i])

# 带步长
遍历 i 在 1 到 10 步 2：
    打印(i)    # 1, 3, 5, 7, 9

# 循环控制
遍历 i 在 1 到 10：
    如果 i % 2 == 0：
        跳过        # continue
    如果 i > 5：
        跳出        # break
    打印(i)
```

### 2.8 列表/字典操作

```光明
# 列表
设 列表 为 [3, 1, 4, 1, 5]
设 长度 为 长(列表)        # 5
设 首项 为 列表[0]          # 3
设 末项 为 列表[-1]         # 5

字典["c"] 为 3              # 添加/修改
设 键列表 为 字典.键()      # 键列表
设 值列表 为 字典.值()      # 值列表

    打印(键 + " = " + 转字符串(值))
```

### 容器创建
| 函数 | 说明 | 示例 |

### 5.4 带重试的网络请求
```光明

段落 安全获取 接收 url, 最大重试 = 3：
    设 尝试 为 0
    当 尝试 < 最大重试：
        试：
            设 响应 为 获取(url)
            如果 响应状态码(响应) == 200：
                返回 响应文本(响应)
            打印("状态码 " + 转字符串(响应状态码(响应)) + "，重试")
        捕 错误：
            打印("请求失败：" + 转字符串(错误))

段落 主：
    设 内容 为 安全获取("https://example.com/api/data")
```

### ❌ 错误 1：用 `def`/`function` 定义函数


### ❌ 错误 3：布尔值用 `True`/`False`/`None`
```光明

# 正确

设 值 为 空
```

> **保留字（值类型）**：`真`/`假`/`空` 是值类型保留字——禁止用作变量名/函数名（如 `设 空 为 123` 会编译报错），但可作值使用，打印时输出自身字面文本（`空`/`真`/`假`），等价于 Python 的 `None`/`True`/`False`。语义正确优先，测试预期跟随语义，绝不反过来让语义迁就测试。


## 十一、语言层坑位现状（AI 必读，避免重复踩已修的坑）

> 本节区分两类：**（A）历史坑——已修复，不要再写 workaround**；**（B）当前真边界——必须绕开**。
> 证据日期：2026-10-08（v0.4.0-rc2，A9 / R110+ 轮次后实测）。

### A. 历史坑（已修复，直接写正规写法即可）

| 历史坑 | 旧 workaround（不要再用） | 现在的正规写法 |
|--------|--------------------------|----------------|
| 类体内不接受 `异步 段落` | 把 async 方法甩到模块级，再写桥接函数 | 直接在类里写 `异步 段落 拉数据(地址):` ✅ |
| `最终`(finally) 不可依赖 | 用哨兵文本预置槽位兜底 | 直接写 `试/捕获/最终`，finally 必定执行 ✅ |
| 切词歧义（含"到"的标识符被切断） | 改用不含"到"的名字 | `设 迟到时间 为 9` 合法 ✅ |
| 以已知名开头被切成属性链 | 避免用"数/时/日"等开头命名 | `设 数据 为 [1,2,3]` 合法 ✅ |
| 变量名以"异步"开头被拒 | 改名避开 | `设 异步任务 为 "A"` 合法 ✅ |
| 无空格分词 | 必须 `设 x 为 1` 加空格 | `设x为10` 也能解析 ✅ |
| `捕获 类型 as 变量`（中文变量名） | 只写 `捕获 e` | `捕获 错误 为 e` 完整支持 ✅ |

> 探针脚本：仓库根 `_r127_probe_*.light`（2026-10-08）可复验上表全部条目。

### B. 当前真边界（AI 必须绕开）

#### B1. lambda 不支持（G2，v6.1 排期）
```光明
# ❌ 以下三种写法都失败
# f = lambda x: x + 1
# f = 匿名(x): x + 1
# f = x => x + 1

# ✅ 用段落代替（即使只想传一个一次性函数）
段落 加一(x)：
    返回 x + 1
设 f 为 加一
打印(f(5))
```

#### B2. with 语句不支持（G3，v6.1 排期）
```光明
# ❌ 没有 with / 与 ... 为 ... 语法
# with open("f") as fh: ...

# ✅ 显式打开/关闭，或用 try/最终 兜底
试：
    设 f 为 打开("data.txt")
    设 内容 为 f.读取()
最终：
    f.关闭()
```

#### B3. 原生腿（--backend native / llvm-typed）的限制
- **列表/字典作为函数参数跨段变异不生效**：转译腿（默认 SRC）是 Python 引用语义；原生腿是值拷贝。不要写 `段落 压入(栈, 项): 栈.追加(项)` 这种跨段变异；要用类（`己.数据.追加(项)`）。
- **标准库覆盖率约 18%**：大量模块仍回退到 Python runtime。**开发调试一律用默认 SRC 后端**，跑通后再考虑原生编译分发。
- 单文件原生编译看不见 stdlib（`ImportStatement` no-op，B9 任务进行中）。

#### B4. 字符串字面量
- **只支持双引号** `"..."`，单引号 `'...'` 部分版本失败。
- **不支持 `\b` `\f` 转义**：退格用 `chr(8)`，换页用 `chr(12)`。
- 支持 `f"你好 {名}"` 插值（v0.4+）。

#### B5. 类与默认参数
- **默认参数只支持标量字面量和 `空`**：`段落 f(a, b = 0, s = "", flag = 假, x = 空)` ✅；`段落 f(列表 = [])` ❌（会被拒绝或行为异常）。需要可变默认值时在函数体内 `设 列表 为 空; 如果 列表 == 空: 设 列表 为 []`。
- **类体内裸调用自动改写为 `己.同名()`**：这是 feature 不是 bug。`段落 四倍(x): 返回 加倍(x)` 等价于 `返回 己.加倍(x)`。不要试图通过这个机制调模块级同名函数——改名避开。

#### B6. 其他高频小坑
- 创建空容器用 `列表创建()` / `字典创建()`，**不要写** `新建列表()`。
- 列表追加是方法调用 `列表.追加(项)`，**不是** `追加(列表, 项)`。
- 遍历语句介词用 `于`，推导式介词用 `之`/`在`，不要混。
- 从 0 开始写一个新文件，先 `light ai check 文件.light` 做后端兼容检测。

#### B7. 闭包不能重绑外层变量（L-098）
```光明

段落 计数器:
    设 计数 为 0
    段落 递增:
        设 计数 为 计数 + 1    # 这个 设 声明了局部新变量，外层 计数 不变！
    段落 取值:
        返回 计数
    返回 [递增, 取值]

# ✅ 正确：用字典原地 mutate（lightharness 标准模式）
```

```光明
段落 退避间隔(次数, 上限):
    设 秒 为 0.5 * (2 ** (次数 - 1))
    如果 秒 > 上限:
        设 秒 为 上限
    返回 秒

异步 段落 带重试(目标, 最大次数 = 3):
    设 次数 为 0
    当 真:
        设 次数 为 次数 + 1

            返回 结果
        如果 次数 >= 最大次数:
            返回 结果
        等待 asyncio.sleep(退避间隔(次数, 10.0))
```

### 12A.8 工程体里的"避坑"（从 lightharness 注释提炼）
- **模块级函数名避开关键字词根**：不写 `返回XXX`/`异步XXX` 结尾（`重试.light:24` 注释）。
- **默认参数用 ASCII `=`**：`超时值=5.0`，不要写 `超时值 = 5.0`（文言体模块里中文 `等于` 作方法名会撞车）。
- **字典下标赋值必须用 `设 … 为 …`**：`设 己.表[k] 为 v`，不能直接 `己.表[k] = v`（`事件.light:24` 注释）。
- **闭包不能重绑外层变量**：需要跨闭包共享状态时用模块级字典原地 mutate（`错误增强.light:15` 的 `异常状态 = {"最后": 空}` 模式）。
- **Windows 重命名不能覆盖**：原子写先 `删除文件` 再 `重命名`。
- **自定义异常继承 `Exception`**：`类 连接中断 继承 Exception:`。

### 12A.9 尝试/捕获与错误信封（来源：`lightharness/src/错误增强.light`）
```光明
段落 尝试执行详情(函数):
    设 成功 为 假
    设 结果 为 空
    尝试:
        设 结果 为 函数()
        设 成功 为 真
    捕获 异常:
        设 结果 为 空
    返回 {"成功": 成功, "结果": 结果}

段落 造除法(甲, 乙):
    段落 计算:
        返回 甲 / 乙
    返回 计算

打印(序列化JSON(尝试执行详情(造除法(1, 0))))
# 失败时返回 成功=假、结果=空，不向上抛
```
> `捕获 异常:` 不用声明类型，异常对象绑定到 `异常` 名；把成败装进信封字典返回，调用方按 `字典获取(果, "成功", 假)` 判定。闭包不能重绑外层变量（L-098），模块级共享状态用 `异常状态 = {"最后": 空}` 字典原地 mutate。

### 12A.10 深度键路径读写（来源：`lightharness/src/字典增强.light`）
```光明
段落 深度设置(字典, 键路径, 值):
    设 当前 为 字典
    设 i 为 0
    当 i < 列表长度(键路径) - 1:
        设 键 为 键路径[i]
        如果 字典包含键(当前, 键) == 假:
            设 当前[键] 为 {}
        设 当前 为 当前[键]
        设 i 为 i + 1
    设 当前[键路径[列表长度(键路径) - 1]] 为 值
    返回 字典

段落 深度获取(字典, 键路径, 默认值 = 空):
    设 当前 为 字典
    设 i 为 0
    当 i < 列表长度(键路径):
        如果 是字典(当前) == 假:
            返回 默认值
        设 键 为 键路径[i]
        如果 字典包含键(当前, 键) == 假:
            返回 默认值
        设 当前 为 当前[键]
        设 i 为 i + 1
    返回 当前

设 设置 为 {}
深度设置(设置, ["代理", "模型"], "小模型")
打印(序列化JSON(深度获取(设置, ["代理", "模型"], "缺省")))
```
> 双层下标赋值 `甲[键一][键二] = 值` 会静默失败（L-123），必须逐层 `设 当前[键] 为 {}` 中转；浅层缺失键用 `字典获取(甲, 键, 默认)` 一步兜底，深层路径用本惯用法。

### 12A.11 同步重试骨架（来源：`lightharness/src/重试.light`）
```光明
段落 退避间隔(次数, 基数, 上限):
    设 秒 为 基数 * (2 ** (次数 - 1))
    如果 秒 > 上限:
        设 秒 为 上限
    返回 秒

段落 重试耗尽即返回(目标, 最大次数):
    设 次数 为 0
    设 结果 为 空
    当 次数 < 最大次数:
        设 次数 为 次数 + 1
        设 结果 为 目标()
        如果 结果["种类"] == "完成":
            返回 结果
    返回 结果

段落 总是失败:
    返回 ["种类": "错误", "错误码": "限流"]

打印(序列化JSON(重试耗尽即返回(总是失败, 3)))
```
> 同步重试不需要 `异步/等待`；结果统一用信封字典 `["种类": ...]` 承载，按 `结果["种类"]` 判定成败，配合 `退避间隔(次数, 0.5, 8.0)` 指数退避封顶。异步版见 12A.6。
