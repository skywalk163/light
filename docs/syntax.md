### 运算符

```光明
# 算术运算符（符号与中文等价）
设 结果 为 10 + 5    # 加，等价于 10 加 5
设 结果 为 10 - 5    # 减，等价于 10 减 5
设 结果 为 10 * 5    # 乘，等价于 10 乘 5
设 结果 为 10 / 5    # 除，等价于 10 除 5
设 结果 为 10 % 3    # 取余，等价于 10 取余 3
设 结果 为 2 ** 3   # 幂，等价于 2 幂 3
设 结果 为 10 // 3   # 整除，等价于 10 整除 3

# 比较运算符
甲 > 乙             # 大于，等价于 甲 大于 乙
甲 < 乙             # 小于，等价于 甲 小于 乙
甲 == 乙            # 等于，等价于 甲 等于 乙
甲 != 乙            # 不等于，等价于 甲 不等于 乙
甲 >= 乙            # 大于等于，等价于 甲 大于等于 乙
甲 <= 乙            # 小于等于，等价于 甲 小于等于 乙

# 逻辑运算符
甲 且 乙            # 逻辑与
甲 或 乙            # 逻辑或
非 甲               # 逻辑非

# 复合赋值
设 计数 为 计数 + 1  # 计数 = 计数 + 1
计数 加上 1          # 中文复合赋值
```

## 控制流

### 条件语句

```光明
如果 条件：
    打印 "条件成立"
否则如果 条件2：
    打印 "条件2成立"
否则：
    打印 "条件不成立"
```

### 循环

```光明
# 当循环（while）
当 计数 < 10：
    打印 计数
    设 计数 为 计数 + 1

# 遍历循环（for-in）
遍历 项 在 列表：
    打印 项

# 范围循环
遍历 i 在 1 到 10：
    打印 i

# 范围循环带步长
遍历 i 在 1 到 10 步 2：
    打印 i  # 1, 3, 5, 7, 9

# 循环控制
遍历 i 在 1 到 10：
    如果 i % 2 == 0：
        跳过   # continue
    如果 i > 5：
        跳出   # break
    打印 i
```

光明使用 `段落` 关键字定义函数：


## 泛型

### 泛型函数

使用类型参数实现参数化类型：

```光明
# 单类型参数
段落 恒等[T] 接收 x：
    返回 x

设 结果1 为 恒等(42)      # x 被推断为 数字
设 结果2 为 恒等("你好")  # x 被推断为 字符串

# 多类型参数
段落 映射[T, U] 接收 列表, 函数：
    返回 列表
```

### 泛型类

```光明
# 泛型栈
类 栈[T]：
    属性 数据

    构造：
        己.数据 = []

    段落 入栈 接收 值：
        己.数据.追加(值)

    段落 出栈 接收：
        返回 己.数据.弹出()

# 使用泛型类
设 整数栈 为 栈()
设 字符串栈 为 栈()
```
