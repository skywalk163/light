**版本**：v3.2
**日期**：2026-07-04
**状态**：正式版

## 1. 核心设计原则

### 1.1 中文优先，空格可选
- **所有语句中关键字、变量名、运算符之间都不需要空格**
- 词法分析器实现三层分词机制，自动识别无空格的中文代码
- 例如以下写法完全合法：
  ```
  如果甲大于十：打印甲
  遍历甲于[1,2,3]：打印甲
  设乙等于甲加三
  段落阶乘接收甲：
      如果甲小于等于一：
          返回一
      否则：
          返回甲乘以阶乘甲减一
  ```
- 也支持有空格的写法，两种风格可混用：
  ```
  设 甲 为 10
  如果甲大于5：
      打印 "大"
  ```

### 1.2 纯缩进式语法
- 用缩进表示代码块，不使用花括号或 `begin/end`
- 移除「结束」关键字（可选向后兼容，默认关闭）

### 1.3 句号可选
- 语句末尾的句号是可选的
- 例外：无——所有语句句号均可选

### 1.4 冒号规则
- **块级语句必须以冒号结尾**：条件、循环、段落、类等
- 冒号后换行并缩进表示代码块开始

### 1.5 语法简洁性
- 只保留一种标准语法形式，降低用户记忆负担
- 不支持过多的旧语法变体

## 2. 基础语法

### 2.1 变量声明
```
设 甲 为 10
定义 乙 等于 "你好"
```

### 2.2 赋值语句
三种形式均支持，且支持无空格书写：
```
甲 = 20
甲 等于 30
甲 为 40
甲等于50      # 无空格也支持
甲为60        # 无空格也支持
```

### 2.3 变量声明
`设` 语句支持 `为` 和 `等于` 两种赋值关键字：
```
设甲为10        # 无空格
设 乙 等于 30   # 有空格
```

### 2.4 复合赋值

复合赋值必须使用 `设 X 为 X 运算符 Y` 的完整形式：
```
设 甲 为 甲 加上 1
设 乙 为 乙 减去 2
设 丙 为 丙 乘以 3
设 丁 为 丁 除以 4
设 戊 为 戊 取余 5
设 己 为 己 整除 3
设 庚 为 庚 幂 2
```

### 2.5 运算符

| 运算符 | 说明 | 示例 |
|--------|------|------|
| `加上` | 加法 | `甲 加上 乙` |
| `减去` | 减法 | `甲 减去 乙` |
| `乘以` | 乘法 | `甲 乘以 乙` |
| `除以` | 除法 | `甲 除以 乙` |
| `取余` | 取模 | `甲 取余 乙` |
| `幂` | 幂运算 | `甲 幂 乙` |
| `整除` | 整除 | `甲 整除 乙` |
| `异或` | 按位异或 | `甲 异或 乙` |
| `右移` | 右移位 | `甲 右移 乙` |
| `左移` | 左移位 | `甲 左移 乙` |

## 3. 条件语句

### 3.1 标准形式
```
如果 条件：
    语句1
    语句2
```

### 3.2 否则分支
```
如果 条件：
    语句
否则：
    语句
```

### 3.3 否则如果
```
如果 条件1：
    语句
否则如果 条件2：
    语句
否则：
    语句
```

### 3.4 单行形式
```
如果 条件： 语句
```

### 3.5 说明
- 冒号是**必须**的
- 「那么」、「则」是可选的
- 支持「若」作为「如果」的简写

---

## 4. 循环语句

### 4.1 当循环
```
当 条件：
    语句
```

说明：
- 冒号是**必须**的
- 「那么」是可选的

### 4.2 遍历循环
```
遍历 项 之 列表：
    语句
遍历 项 于 列表：
    语句
遍历 项 在 列表：
    语句
遍历 项 中的 列表：
    语句
```

说明：
- 冒号是**必须**的
- 支持「之」、「于」、「在」、「中的」四种连接词
- 支持「对」作为「遍历」的简写

### 4.3 跳出和跳过
```
跳出    # 跳出循环
跳过    # 跳过本次循环
```

说明：
- 句号是**可选**的（不需要句号）
- 参考 Python 的 `break` / `continue` 语法

### 4.4 推导式
```
[表达式 遍历 变量 之 列表]
[表达式 遍历 变量 于 列表 若 条件]
{表达式 遍历 变量 于 集合}
{键：值 遍历 变量 于 列表}
```

说明：
- 连接词与 4.2 遍历循环**同一张表**：「之」、「于」、「在」、「中的」四者等价
- 条件用「若」或「如果」引出，可省略
- 支持多重 `遍历`（嵌套推导）

## 5. 段落定义

### 5.1 标准形式
```
函数 段名(参数1, 参数2):
    语句
```

### 5.2 无参数
```
函数 段名():
    语句
```

### 5.3 带类型注解
```
函数 段名(甲: 数, 乙: 文本):
    语句
```

### 5.4 泛型参数
```
函数 映射[T, U](列表: 列, 函数: 函数):
    语句
```

### 5.5 说明
- **推荐使用「函数」关键字**（v3.3+），旧形式「段落」「段」仍兼容
- **只保留「接收」关键字**，移除「参数」、「输入」等旧形式
- **只保留中文参数形式**，移除括号 `(a, b)` 形式
- 冒号是**必须**的

### 5.6 参数默认值
```
函数 连接 接收 主机, 端口 等于 443, 超时 等于 30：
    语句
```

说明：
- 默认值用「等于」或「=」引出
- 调用侧可用具名实参：`连接("example.com", 超时 = 5)`

### 5.7 作用域声明
```
全局 计数。
外层 值。
全局 甲, 乙。
```

说明：
- 「全局」声明该名字指向模块级变量（等价 Python `global`）
- 「外层」声明该名字指向外层段落的变量（等价 Python `nonlocal`）
- 只能写在段落体内；不写声明时段落内的赋值一律新建局部变量
- 形态固定为「全局/外层 名字[, 名字…]。」；`全局 等于 1。` 这类把「全局」
  当变量名的旧写法不受影响

## 6. 类定义

### 6.1 标准形式
```
类 类名：
    变量
    函数 方法名():
        语句
```

### 6.2 继承
```
类 子类 继承 父类：
    语句
```

### 6.3 实现接口
```
类 类名 实现 接口：
    语句
```

### 6.4 属性声明
```
类 点：
    属性 横。
    属性 纵 为 0。
    属性 次数：整数 为 0。
```

说明：
- 「属性」声明实例属性，落在自动生成的 `__init__` 里；单字写法是「性」
- 默认值用「为」或「等于」引出，两者等价；不写默认值时为空值
- 可带类型标注 `属性 名：类型`，标注会随默认值一起发射
- 类级（静态）字段用「设」：`设 总数：整数 为 0`

## 8. 异步并发

### 8.1 异步函数
```
异步 函数 段名(参数):
    语句
```

### 8.2 等待
```
结果 = 等待 异步操作
```

### 8.3 异步作用域
```
异步作用域：
    任务1 = 异步 段落名()
    任务2 = 异步 段落名()
```

### 8.4 异步启动
```
异步 段落 主()：
    设 值 为 等待 取数()
    打印 值

异步 运行 主()。
```

说明：
- 「异步 运行 调用。」是把异步段落跑起来的入口，等价 `asyncio.run(...)`
- 「等待」与「异步 作用域」**只能写在异步段落体内**：写在模块顶层会报错，
  因为产物里那是模块级裸 `await`，Python 直接 `SyntaxError`

## 9. 其他语句

### 9.1 返回
```
返回
返回 值
```

### 9.2 打印
```
打印 "你好"
打印(甲, 乙)
```

### 9.3 异常处理
```
尝试：
    语句
捕获 异常类型：
    语句
最终：
    语句
```

### 9.4 抛出
```
抛出 异常
```

### 9.5 匹配
```
匹配 值：
    模式1：
        语句
    模式2：
        语句
```

### 9.6 生成
```
生成 值。
生成 全部 另一个生成器()。
```

说明：
- 「生成 值。」等价 Python `yield 值`
- 「生成 全部 可迭代对象。」等价 `yield from 可迭代对象`（生成器委托）
- 「全部」带括号时仍是内置函数 `all`：`生成 全部(列表)。` → `yield all(列表)`

## 10. 与 v3.1 的主要差异

| 项目 | v3.1 | v3.2 | 说明 |
|------|------|------|------|
| 跳出/跳过 句号 | 未明确 | 不需要句号 | 参考 Python 语法 |
| 条件语句冒号 | 可选 | 强制 | 统一块级语句规则 |
| 段落定义形式 | 多种旧形式 | 仅标准形式 | 降低语法负担 |
| 段落关键字 | 段落/函数/段 | 仅「段落」 | 简化 |
| 参数关键字 | 参数/接收/输入 | 仅「接收」 | 简化 |
| 参数形式 | 中文+括号 | 仅中文形式 | 简化 |
| 遍历「于」支持 | 规范有 | 补上 | 完善 |
| 全局无空格 | 未明确 | 明确支持 | 所有关键字/变量间无需空格 |
| 设语句赋值关键字 | 仅「为」 | 「为」和「等于」 | 统一赋值语义 |
