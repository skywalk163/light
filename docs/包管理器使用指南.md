# duanpub 包管理器使用指南

> **适用版本：** v6.0
> **最后更新：** 2026-08-07

---

## 概述

duanpub 是光明（Light）的官方包管理器，负责包的分发、安装、依赖管理和项目构建。通过 duanpub，你可以方便地分享和复用光明代码。

## 安装

duanpub 集成在光明 CLI 中，安装光明后即可使用：

```bash
pip install light
```

验证包管理器可用：

```bash
light pkg --help
```

## 项目初始化

### 创建新项目

```bash
light pkg init myproject
```

这会创建一个包含以下文件的项目目录：

```
myproject/
├── package.toml    # 项目配置文件
└── 主.light         # 入口文件
```

### 项目结构

一个典型的光明项目结构如下：

```
myproject/
├── package.toml      # 项目配置
├── 主.light           # 入口文件
├── 模块1.light        # 其他模块
├── 模块2.light
├── lib/              # 库目录（可选）
│   └── 工具.light
└── tests/            # 测试目录（可选）
    └── 测试_主.light
```

## light.json 配置

光明 v5.5.0 支持 `light.json` 作为项目配置文件（与 `package.toml` 等效）：

```json
{
    "name": "myproject",
    "version": "0.1.0",
    "entry": "主.light",
    "description": "我的光明项目",
    "authors": ["张三 <zhangsan@example.com>"],
    "dependencies": {
        "数学工具": "^1.0.0",
        "HTTP客户端": "~0.2.0"
    }
}
```

### 配置字段说明

| 字段 | 类型 | 必填 | 说明 |
|------|------|------|------|
| `name` | 字符串 | 是 | 包名称 |
| `version` | 字符串 | 是 | 语义化版本号 |
| `entry` | 字符串 | 否 | 入口文件（默认：`主.light`） |
| `description` | 字符串 | 否 | 项目描述 |
| `authors` | 字符串数组 | 否 | 作者列表 |
| `dependencies` | 对象 | 否 | 依赖包及版本约束 |

## 安装包

### 安装依赖

在项目目录下执行：

```bash
light pkg install
```

这会根据 `package.toml` 或 `light.json` 中的依赖声明，自动下载并安装所有依赖包。

### 安装特定包

```bash
light pkg install 数学工具
light pkg install HTTP客户端@^0.2.0
```

### 版本约束

| 约束 | 示例 | 说明 |
|------|------|------|
| 精确版本 | `1.0.0` | 只安装指定版本 |
| 兼容版本 | `^1.0.0` | 安装 >=1.0.0 且 <2.0.0 的最新版本 |
| 近似版本 | `~1.0.0` | 安装 >=1.0.0 且 <1.1.0 的最新版本 |
| 大于等于 | `>=1.0.0` | 安装 >=1.0.0 的最新版本 |
| 任意版本 | `*` | 安装最新版本 |

## 管理依赖

### 查看依赖树

```bash
light pkg list
```

显示当前项目的所有依赖及其版本。

### 更新依赖

```bash
# 更新所有依赖
light pkg update

# 更新特定依赖
light pkg update 数学工具
```

### 移除依赖

```bash
light pkg remove 数学工具
```

## 发布包

### 准备发布

1. 确保 `package.toml` 或 `light.json` 配置正确
2. 更新版本号（遵循语义化版本规范）
3. 确保所有测试通过

### 构建包

```bash
light pkg build
```

这会编译项目并生成可分发的包文件。

### 发布到注册中心

```bash
light pkg publish
```

> **注意：** duanpub 注册中心正在建设中，当前版本仅支持本地包管理。

## 构建与运行

### 编译项目

```bash
# 编译为 Python 代码
light pkg -p myproject build

# LLVM 原生编译
light pkg -p myproject native -o output.exe
```

### 运行项目

```bash
light pkg -p myproject run
```

### 运行测试

```bash
light pkg -p myproject test
```

## 高级用法

### 工作区模式

对于大型项目，可以使用工作区模式管理多个子包：

```json
{
    "name": "my-workspace",
    "version": "1.0.0",
    "workspaces": [
        "packages/*"
    ]
}
```

### 私有包索引

配置私有包索引地址：

```json
{
    "registries": {
        "private": "https://private-registry.example.com"
    }
}
```

### 包锁定

生成 `package-lock.json` 锁定依赖版本：

```bash
light pkg lock
```

## 常见问题

### 包安装失败

1. 检查网络连接
2. 确认包名和版本号正确
3. 查看详细错误信息：`light pkg install -v`

### 依赖冲突

如果两个包依赖了同一包的不同版本：

1. 使用 `light pkg list` 查看依赖树
2. 手动调整 `package.toml` 中的版本约束
3. 运行 `light pkg update` 重新解析依赖

### 如何创建可发布的包

1. 使用 `light pkg init` 创建项目
2. 编写代码并确保导出需要的符号
3. 在 `package.toml` 中配置 `name`、`version`、`entry`
4. 运行 `light pkg build` 验证构建成功
5. 运行 `light pkg publish` 发布

## 命令参考

| 命令 | 说明 |
|------|------|
| `light pkg init <name>` | 初始化新项目 |
| `light pkg install` | 安装所有依赖 |

| `light pkg update` | 更新所有依赖 |
| `light pkg update <pkg>` | 更新指定包 |
| `light pkg remove <pkg>` | 移除指定包 |
| `light pkg list` | 查看依赖列表 |
| `light pkg build` | 编译项目 |
| `light pkg run` | 运行项目 |
| `light pkg test` | 运行测试 |
| `light pkg publish` | 发布包 |
| `light pkg lock` | 锁定依赖版本 |
| `light pkg -p <path> <cmd>` | 在指定路径执行命令 |
