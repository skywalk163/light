# 段言端到端实战：从零构建一个天气查询程序

> **版本：** v6.0
> 本教程带你从零开始，用段言语言构建一个完整的天气查询程序。涵盖 duanpub 库导入、文件操作、异常处理和 Python 代码转译。

- 已阅读《30分钟入门段言》，掌握变量、条件、循环、函数的基本用法
- 安装段言运行时（`pip install duan` 或从源码构建）

## 第3步：天气项目结构

我们将在 `examples/weather_app/` 目录下创建天气查询程序，项目结构如下：

```
examples/weather_app/
├── main.duan      # 主程序
├── config.duan    # 配置文件
└── utils.duan     # 工具函数
```

## 第4步：编写配置模块

`config.duan` 包含 API 配置和城市列表：

```段言
# 天气应用配置
设 API_KEY 为 "your_api_key_here"
设 BASE_URL 为 "https://api.openweathermap.org/data/2.5"

# 支持的城市列表
设 城市列表 为 [
    {"name": "北京", "lat": 39.9, "lon": 116.4},
    {"name": "上海", "lat": 31.2, "lon": 121.5},
    {"name": "广州", "lat": 23.1, "lon": 113.3},
    {"name": "深圳", "lat": 22.5, "lon": 114.1},
    {"name": "杭州", "lat": 30.3, "lon": 120.2}
]

段落 获取城市名 接收 城市：
    返回 城市["name"]

导出 城市列表, 获取城市名, API_KEY, BASE_URL
```

## 第5步：编写工具模块

`utils.duan` 包含天气数据格式化函数：

```段言
段落 格式化温度 接收 开尔文温度：
    设 摄氏温度 为 开尔文温度 - 273.15
    返回 转字符串(取整(摄氏温度)) + "°C"

段落 格式化天气 接收 天气数据：
    设 城市 为 天气数据["name"]
    设 温度 为 格式化温度(天气数据["main"]["temp"])
    设 描述 为 天气数据["weather"][0]["description"]
    设 湿度 为 转字符串(天气数据["main"]["humidity"])

    返回 城市 + "：" + 温度 + "，" + 描述 + "，湿度：" + 湿度 + "%"

段落 显示帮助 接收：
    打印 "可用命令："
    打印 "  weather <城市名>  - 查询天气"
    打印 "  list              - 列出支持的城市"
    打印 "  help              - 显示帮助"
    打印 "  exit              - 退出"

导出 格式化温度, 格式化天气, 显示帮助
```

## 第6步：编写主程序

`main.duan` 是程序入口：

```段言
从 配置 导入 城市列表, 获取城市名, API_KEY, BASE_URL
从 工具 导入 格式化天气, 显示帮助
从 贡献.HTTP客户端 导入 获取
从 JSON 导入 解析JSON

段落 查询天气 接收 城市名：
    设 城市 为 空
    遍历 城市列表 为 城市项：
        如果 城市项["name"] == 城市名：
            设 城市 为 城市项

    如果 城市 == 空：
        打印 "不支持的城市：" + 城市名
        返回

    尝试：
        设 url 为 BASE_URL + "/weather?lat=" + 转字符串(城市["lat"]) + "&lon=" + 转字符串(城市["lon"]) + "&appid=" + API_KEY
        设 响应 为 获取(url)
        如果 响应.状态码 == 200：
            设 天气数据 为 解析JSON(响应.主体)
            打印 格式化天气(天气数据)
        否则：
            打印 "获取天气失败，状态码：" + 转字符串(响应.状态码)
    捕获 错误：
        打印 "网络错误：" + 转字符串(错误)

段落 主程序 接收：
    打印 "=== 段言天气查询系统 ==="
    显示帮助()

    当 真：
        设 输入 为 输入("> ")
        如果 输入 == "exit"：
            打印 "再见！"
            跳出
        否则如果 输入 == "help"：
            显示帮助()
        否则如果 输入 == "list"：
            遍历 城市列表 为 城市：
                打印 "  - " + 获取城市名(城市)
        否则：
            查询天气(输入)

# 启动主程序
主程序()
```

## 第7步：运行程序

```bash
# 运行天气查询程序
cd examples/weather_app
duan run main.duan
```

## 第8步：进阶扩展

### 添加文件缓存

```段言
从 文件系统 导入 存在, 写入, 读取
从 日期时间 导入 当前时间

# 缓存文件路径
设 缓存文件 为 "weather_cache.json"

段落 读取缓存 接收：
    如果 存在(缓存文件)：
        设 内容 为 读取(缓存文件)
        返回 解析JSON(内容)
    返回 {}

段落 写入缓存 接收 数据：
    设 缓存 为 读取缓存()
    缓存[城市名] = {"data": 数据, "time": 当前时间()}
    写入(缓存文件, 序列化JSON(缓存))

导出 读取缓存, 写入缓存
```

## 第9步：总结

通过本教程，你学会了：

1. 创建多文件段言项目
2. 使用 `导入` 和 `从...导入...` 管理模块依赖
3. 使用 `贡献.HTTP客户端` 发起网络请求
4. 使用 `JSON` 模块解析和序列化数据
5. 使用 `尝试`/`捕获` 处理异常
6. 使用 `文件系统` 模块进行文件操作
7. 构建完整的 CLI 交互式应用

这个示例展示了段言在真实项目中的应用能力。你可以基于此模板开发更复杂的应用，如：

- 博客系统
- 待办事项管理
- 数据采集工具
- 简单的 Web API 服务
