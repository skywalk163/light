# 编程注意事项（Pitfalls & Caveats）

> 本文件记录**光明 / Light 原生后端（LLVM 腿）与标准库开发中容易踩、且症状隐蔽的坑**。
> 目的：把每次「查了半天才定位」的根因固化下来，下次动同一处代码前先扫一眼，避免重蹈覆辙。
> 新增坑点时，按「症状 → 根因 → 隐蔽性 → 修复 → 规避守则」五段式追加，**不要覆盖已有条目**。

## 坑 01：POSIX 原生原语缺链接库 → 整条原生腿 `链接失败`

**影响范围**：`src/llvm/runtime_typed.c` 新增任何依赖系统库（pthread / dl / 其它）的原语时。
**首次暴露**：R151-D1 线程原语（`dv_thread_spawn` / `dv_fs_watch_start` / 目录监控）上 0.82 全量门。

### 症状
0.82 全量门出现**几百条**原生腿红，报错形如：

```
RuntimeError: 链接失败:
ld.lld: error: undefined symbol: pthread_create
>>> referenced by runtime_typed.c
>>>               .../产物_runtime.o:(dv_thread_spawn)
>>>               .../产物_runtime.o:(dv_fs_watch_start)
clang: error: linker command failed with exit code 1
```

### 根因
在 `runtime_typed.c` 里加了 POSIX 线程原语，走了 `pthread_create` / `pthread_join`，
但 `src/llvm/compiler.py` 的 `get_link_libs()` 的 POSIX 分支只返回 `['-lm']`，
**FreeBSD 的 `ld.lld` 不会自动链 libpthread**（Linux 多数发行版也需显式 `-pthread`）。
链接器在 `runtime_typed.c` 的目标文件里找到 `pthread_create` 的引用却找不到定义 → 整条原生腿链接失败。

### 隐蔽性（最坑的一点）
这条错误**极易被编译错误掩盖**。R151 同批还有一个 `static` 函数 `dv_mkdir_p`
「先调用后定义」导致的 `conflicting types` 编译错误，使得原生腿先报「运行时库编译失败」；
编译错误修掉之后，才轮到链接错误浮出水面——门红从「编译失败」变成「链接失败」，
乍看像修复引入新问题，其实是**同一个批次里藏着的第二个独立 bug**。

### 修复
1. `get_link_libs()` 的 POSIX 分支改为 `['-lm', '-pthread']`。
   `-pthread` 在 Linux / BSD / macOS 均安全（macOS/libc 已含 pthread，该标志为 no-op）。
2. `src/package_manager.py` 里**另抄的一份硬编码 `-lm` 链接命令**也改回调用 `get_link_libs()`。
   该文件原本自己 `link_args.append('-lm')`，绕过了唯一真相源——这正是
   `get_link_libs()` docstring 警告的「第二份拷贝会在另一个平台炸」陷阱。

### 规避守则（动原生后端前必读）
1. **加 `#include` ≠ 能链接**。头文件只解决「声明」，链接还需「库」。
   任何依赖系统库的原语（线程、动态加载、加密……）必须同步在 `get_link_libs()` 加对应链接标志。
2. **链接库参数的唯一真相源是 `get_link_libs()`**。全仓（生产 3 处链接点 +
   测试侧 `tests/llvm运行时.py` / `tests/unit/test_link_libs_guard.py`）都转调它，
   **绝不在别处硬编码 `-lm` / `-lpthread`**。改链接库只改这一处。
3. 改完 `runtime_typed.c` 后**先本机 `clang -c` 复编**确认 0 error，再上 0.82 门。
   若门红从「编译失败」转为「链接失败」，第一反应查 `ld.lld: error: undefined symbol: xxx`——
   缺的就是那个 `xxx` 对应的链接库。
4. 一次只动一条线（`src/` 是瓶颈）；`runtime_typed.c` 是 C 文件，编辑务必保留 CRLF
   （用 `open(p, encoding='utf-8', newline='')` 字节级改写，Edit 工具在 CRLF 上容易失手）。
