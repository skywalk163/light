## 概述

L1 白话体是光明的**入门级文体**,面向青少年、教学、个人脚本、快速原型场景。

**设计哲学**:
- **单行优先**:能用一行写的不用多行
- **无类型负担**:不要求类型注解,动态类型
- **容错性强**:句号、空格、冒号都可选
- **像说话一样写**:主谓宾语序、因果链语法

**文件头声明**:
```light
# 文体: 白话
```
无声明时默认 L1。

## 使用的 L0 核心字

L1 使用 L0 30 字中的 **19 字**(其余为 L2 专用):

| 类别 | L1 使用的字 |
|------|-----------|

## 一、词法

### 1.1 标识符命名

**规则**:中文字、英文字母、数字、下划线`_`,不以数字开头。

| 合法 | 不合法 |
|------|--------|
| `甲` | `123甲`(数字开头) |
| `成绩_列表` | `成绩-列表`(含破折号) |
| `userName` | `$name`(含特殊符号) |
| `学生_1` | 空标识符 |

**推荐**:
- 教学场景用中文单字(`甲`、`乙`、`和`、`数`)
- 脚本场景用中文词组(`成绩列表`、`学生姓名`)
- 英文字母仅限必要时使用

### 1.2 标点符号

**主用中文标点**,英文标点作为别名(不报错):

| 中文标点 | 英文别名 | 用途 |
|---------|---------|------|
| `，` | `,` | 分隔列表、参数 |
| `。` | `.` | 语句结束(可选) |
| `：` | `:` | 开块、三目 |
| `？` | `?` | 三目(可选) |
| `《》` | `<>` | 函数名修饰(见 3.3) |
| `""`、`''` | `""`、`''` | 字符串字面量 |

**容错性**:句号`。`/`.` 可选,即使漏掉也能解析。

### 1.3 字符串字面量

```light
设姓名="张三"
设消息='你好'
设多行="这是
多行
字符串"
```

**字符串插值**(用 `{}` 嵌入表达式):
```light
设年龄=15
打印"你{姓名},今年{年龄}岁了"
```

### 1.4 数字字面量

```light
设整数=123
设小数=3.14
设负数=-5
设科学=1.5e-3
```

### 1.5 列表字面量

```light
设空列表=[]
设数字=[1,2,3,4,5]
设混合=[1,"你好",真,[3,4]]
```

### 1.6 字典字面量

```light
设空字典={}
设配置={"端口":8080,"主机":"localhost","调试":真}
```

### 1.7 注释

```light
# 这是单行注释
打印"你好"  # 行尾注释
```

**多行注释**(三引号):
```light
"""
这是多行注释
可以写很多行
"""
打印"开始"
```

## 二、表达式与运算符

### 2.1 算术运算符

**符号形式为主,中文形式为别名**:

| 符号 | 中文别名 | 示例 |
|------|---------|------|
| `+` | 加 | `1+2`、`1加2` |
| `-` | 减 | `5-3`、`5减3` |
| `*` | 乘 | `2*3`、`2乘3` |
| `/` | 除 | `10/2`、`10除以2` |
| `%` | 取余 | `10%3`、`10取余3` |
| `**` | 幂 | `2**10`、`2的10次方` |
| `//` | 整除 | `7//2`、`7整除2` |

**优先级**:`**` > 一元`-` > `*`/`/`/`%`/`//` > `+`/`-`

### 2.2 比较运算符

| 符号 | 中文别名 | 示例 |
|------|---------|------|
| `==` | 等于、是 | `甲==10`、`甲等于10`、`甲是10` |
| `!=` | 不等于 | `甲!=5`、`甲不等于5` |
| `<` | 小于 | `甲<10`、`甲小于10` |
| `>` | 大于 | `甲>5`、`甲大于5` |
| `<=` | 小于等于 | `甲<=10`、`甲小于等于10` |
| `>=` | 大于等于 | `甲>=5`、`甲大于等于5` |

### 2.3 逻辑运算符

| 核心字 | 别名 | 示例 |
|-------|------|------|
| `且` | 并且 | `甲>0且乙>0` |
| `或` | 或者 | `甲>10或乙>10` |
| `非` | 不是 | `非甲`、`不是甲` |

### 2.4 成员与包含运算符

| 中文 | 别名 | 示例 |
|------|------|------|
| `是` | 属于 | `5是[1,2,3]`(False) |
| `之` | 的、`.` | `列表之长度`、`列表.长度` |

### 2.5 管道运算符

`并`(相当于 `|` 或 `.` 链式):
```light
设数据=[3,1,4,1,5]
设结果=数据 并 排序 并 反转 并 打印
# 等价于:打印(反转(排序(数据)))
```

### 2.6 三目表达式

```light
设等级=若分数>=60:"及格"否:"不及格"
```

## 三、语句

### 3.1 赋值语句

```light
# 基本赋值
设甲=10
设姓名="张三"
设列表=[1,2,3]

# 多赋值
设甲,乙,丙=1,2,3

# 复合赋值
设数=5
数+=1     # 加
数-=2     # 减
数*=3     # 乘
数/=2     # 除
数并=3    # 管道式赋值,等价于数=数并3
```

### 3.2 条件语句

#### 单行形式(推荐)

```light
# 简单 if
若甲>5:打印"大"

# if-else
若甲>5:打印"大"否:打印"小"

# if-elif-else
若甲>=90:打印"优"否若甲>=60:打印"及格"否:打印"不及格"
```

#### 多行形式(缩进块)

```light
若甲>5:
    打印"大"
    打印"大于5"
否:
    打印"小"
```

#### 因果链语法(白话体特色)

```light
温度大于30,开风扇
温度大于30且湿度大于60,开风扇、开空调
用户等级是"VIP"且余额大于100,打折、送积分
```

格式:`条件1,动作1`。多个条件写多行,从上到下依次判断。

### 3.3 函数定义与调用

#### 函数定义

```light
# 单行
段加法(甲,乙):返甲+乙

# 多行
段阶乘(n):
    若n<=1:返1
    返n*阶乘(n-1)
```

#### 函数调用

```light
# 常规
打印("你好")
加法(3,5)

# 无括号(白话特色,用于无参或简单参数)
打印"你好"
加法 3,5
```

**函数名修饰(《》)**:表达更复杂的函数名,无需绑定到标识符:
```light
段《快速排序》(列表):
    # ...排序逻辑...
    返列表

结果=快速排序([5,3,8,1])
```

#### 匿名函数(单行 lambda)

```light
设平方=段(x):返x*x
打印平方(5)   # 25
```

### 3.4 循环语句

#### 当循环(while/for 合一)

```light
# 条件循环(while)
设i=0
当i<5:
    打印i
    i+=1

# 无限循环
当真:
    设输入=用户输入()
    若输入=="退出":跳
```

#### 遍历循环

```light
# 遍历列表
遍[1,2,3]之为i:打印i

# 遍历字典
设配置={"端口":8080,"主机":"localhost"}
遍配置之为键值:打印键值之0并"="并键值之1

# 范围遍历
遍范围(1,10)之为i:打印i
```

#### 循环控制

```light
设i=0
当i<10:
    i+=1
    若i%2==0:过    # 跳过偶数,类似 continue
    若i>7:跳       # 提前跳出,类似 break
    打印i
# 输出:1 3 5 7
```

### 3.5 返回语句

```light
段求和(列表):
    设总=0
    遍列表之为x:总+=x
    返总     # 返 是 L0 核心字
```

`返` 无参数时,返回 `空`。

### 3.6 异常处理

```light
# 基本 try-catch
试:
    设结果=10/0
捕错误:
    打印"出错了"

# try-catch-finally
试:
    设结果=10/0
捕错误是e:
    打印"错误:"并e之消息
终:
    打印"清理完毕"

# 手动抛出
段除法(甲,乙):
    若乙==0:抛"除数不能为零"
    返甲/乙
```

### 3.7 输入输出

```light
# 输出
打印"你好"
打印(甲,乙,丙)
显示"完成!"

# 输入
设姓名=输入("请输入姓名:")
设年龄=输入数("请输入年龄:")
```

## 四、内置类型与操作

### 4.1 列表操作

```light
设列表=[3,1,4,1,5]

# 访问与切片
打印列表之0       # 3
打印列表之[1:3]   # [1,4]
打印列表之长度    # 5
打印列表之首      # 3
打印列表之尾      # 5

# 修改
列表.追加(2)     # [3,1,4,1,5,2]
列表.插入(0,9)   # [9,3,1,4,1,5,2]
列表.删除(1)     # [9,1,4,1,5,2]
列表.排序()      # [1,1,2,4,5,9]
列表.反转()      # [9,5,4,2,1,1]
列表.清空()      # []
```

### 4.2 字典操作

```light
设人={"姓名":"张三","年龄":15}

# 访问
打印人之"姓名"   # "张三"
打印人之键       # ["姓名","年龄"]
打印人之值       # ["张三",15]
打印人之长度     # 2

# 修改
人之"城市"="北京"     # 添加
人之"年龄"=16        # 修改
人.删除("年龄")       # 删除
人.清空()             # {}
```

### 4.3 字符串操作

```light
设消息="Hello World"

打印消息之长度           # 11
打印消息之大写()         # "HELLO WORLD"
打印消息之小写()         # "hello world"
打印消息之分割(" ")      # ["Hello","World"]
打印消息之替换("o","0")  # "Hell0 W0rld"
打印消息之包含("World")  # 真
打印消息之子串(0,5)      # "Hello"
```

### 4.4 特殊值

| 值 | 含义 |
|----|------|
| `真` | 布尔真 |
| `假` | 布尔假 |
| `空` | 空值/None |

真值判断:空字符串`""`、空列表`[]`、空字典`{}`、`0`、`0.0`、`空` 均为假,其余为真。

打印"我想了一个1到100的数,猜猜是多少?"

## 七、常见错误与友好提示

| 错误写法 | 正确写法 | 友好提示 |
|---------|---------|---------|
| `设甲=10` 写成 `设甲为10` | `设甲=10` | 提示:建议用 `设甲=10`(为 已简化为=) |
| `若甲>5则打印` | `若甲>5:打印` | 提示:建议用冒号开头 `:`(则 已简化) |
| `遍列表的每一项` | `遍列表之为x:` | 提示:用 `遍列表之为x:` 遍历 |
| `返回值` | `返值` | 提示:用 `返`(返回是双字别名) |
| `函数f()` | `段f():` | 提示:用 `段` 定义函数(函数是双字别名) |

L1 错误提示采用"解释+建议"的青少年友好风格,不抛异常栈,直接告诉用户错在哪、怎么改。

## 九、附注：规范未明确说明的实现细节

本附件记录规范正文中未明确说明、但在当前解析器实现中已确定的行为，供用户和第三方（如门户网站、在线 Playground、教学平台）参考。

### 9.1 `遍 X 之 Y` 遍历字典时的迭代语义

**规范原文**（3.4 遍历循环）：定义了 `遍 可迭代对象 之 变量` 的语法，但未明确说明遍历字典时迭代的是键、值还是键值对。

**实际实现**：当前解析器将 `遍 典 之 k` 翻译为 Python 的 `for k in 典:`，即**遍历字典时迭代的是键**。如需获取值，使用 `典[k]`。

**示例**：
```light
设配置={"端口":8080,"主机":"localhost"}
遍配置之为键:                   # 键 = "端口", "主机"
    打印键 并 "=" 并 配置[键]   # 通过键取值
```

**注意**：此行为与 Python 的 `for key in dict` 一致，而非 `.items()` 或 `.values()`。

### 9.2 `X的 属性` 与 `X的 方法()` 的解析规则

**背景**：由于词法分析器将 `的` 视为 `compound_safe` 关键字，`的` 前后的字符会被合并为单个标识符，而非解析为 `MemberAccess` 节点。例如 `成绩的长度` 在词法阶段被识别为一个整体标识符，而非 `成绩 . 长度`。

**实际实现**：当前在代码生成阶段通过白名单机制处理——将已知的常用属性名（如 `长度`、`首`、`尾`、`键`、`值`）从复合标识符中拆分出来，生成 Python 属性访问代码 `对象.属性`。对于其他 `X的Y` 形式，同样按 `X.Y` 的 Python 属性访问处理。

**示例**：
```light
设成绩=[85,92,78]
打印成绩之长度    # → 成绩.长度 → len(成绩)
打印成绩之首      # → 成绩.首 → 成绩[0]
```

**注意**：
- 在浏览器/Pyodide 环境下，`X的Y` 被翻译为 `X.Y` 的 Python 属性访问。
- 方法调用 `X的 方法(实参)` 在 L1 中应使用 `X.方法(实参)` 形式（英文句点），当前解析器对 `的` + 方法调用的支持有限，建议方法调用统一使用英文句点 `.`。
- 此行为属于当前实现的选择，未来版本可能随解析器升级而改进为更精确的 AST 节点拆分。

### 9.3 `为` 作为连接词的解析

**规范原文**：`为` 在 L0 中是赋值标记（`设 甲 为 10`），在 L1 中 `为` 被列为 `设` 的别名。

**实际实现**：当前解析器在 `遍 X 为 Y` 语法中，将 `为` 识别为连接词（等价于 `之`），即 `遍 列表 为 i` 等价于 `遍 列表 之 i`。此行为在规范中未明确列出，属于解析器兼容处理。
