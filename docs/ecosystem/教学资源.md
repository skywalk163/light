## 在线 Playground

光明 Playground 是一个基于浏览器的交互式编程环境，无需安装即可体验光明。

### 访问方式

- **在线版**：访问光明官网的 Playground 页面
- **本地版**：在项目目录下运行

```bash
python playground/server.py
```

然后访问 `http://localhost:8000` 即可使用。

### Playground 功能

- 代码编辑与实时运行
- 20+ 内置示例程序
- 语法高亮
- 错误提示
- 运行结果实时显示
- 支持 L1 白话体和 L2 文言体切换

### 内置示例

Playground 内置了以下示例程序：

| 示例 | 说明 |
|------|------|
| hello.light | 你好，光明！ |
| fibonacci.light | 斐波那契数列 |
| sorting.light | 排序算法演示 |
| class_demo.light | 面向对象示例 |

## 游戏化学习

光明提供了游戏化的学习方式，让编程学习更有趣。

### 编程游戏

在 Playground 的 `game.html` 页面中，可以通过游戏关卡学习编程概念：

- **关卡式学习**：从简单到复杂逐步解锁
- **即时反馈**：每完成一个关卡立即获得反馈
- **可视化效果**：代码执行过程可视化展示

### 游戏化特色

- 积分系统：完成挑战获得积分
- 成就徽章：达成特定目标解锁徽章
- 排行榜：与社区成员互动
- 挑战模式：限时完成编程任务

## K12 课程材料

光明提供了完整的 K12 编程教育课程，共 10 节课，从零基础到综合项目。

### 课程体系

| 课程 | 主题 | 适合年级 |
|------|------|---------|
| 课程 1 | 认识光明 | 小学高年级 |
| 课程 2 | 变量与计算 | 小学高年级 |
| 课程 3 | 条件判断 | 小学高年级 |
| 课程 4 | 循环 | 初中 |
| 课程 5 | 函数 | 初中 |
| 课程 6 | 列表与字典 | 初中 |
| 课程 7 | 字符串 | 初中 |
| 课程 8 | 文件操作 | 高中 |
| 课程 9 | 小游戏 | 高中 |
| 课程 10 | 综合项目 | 高中 |

### 课程结构

每节课包含三个部分：

1. **教案**（`教案.md`）：教师备课用的详细教案，包含教学目标、教学步骤、课堂活动设计
2. **习题**（`习题.md`）：学生练习用的习题集，包含基础题、进阶题和挑战题
3. **示例代码**（`示例.light`）：课堂演示用的示例程序

### 课程特色

- **全中文教学**：所有材料和代码示例均为中文
- **阶梯式难度**：从简单到复杂，循序渐进
- **项目驱动**：每节课都有动手实践环节
- **与学校课程结合**：融入数学、语文等学科知识

### 课程定位

课程材料位于项目 `edu/` 目录下，教师和学生可以直接使用。

## 学习路径推荐

### 路径一：K12 学生入门

适合中小学生，从零基础开始：

```
课程 1-2：认识光明 + 变量与计算  →  基础概念
课程 3-4：条件判断 + 循环        →  控制结构
课程 5-7：函数 + 列表 + 字符串   →  数据结构
课程 8-10：文件 + 游戏 + 项目   →  综合实践
```

### 路径二：开发者快速上手

适合有编程经验的开发者：

```
1. Playground 体验光明语法
2. 阅读示例代码库（L1/L2 示例）
3. 动手写第一个光明程序
4. 学习模块系统和标准库
5. 尝试 L3/L4 高级特性
6. 参考开源项目实践
```

### 路径三：教师教学

适合在课堂中使用光明的教师：

```
1. 熟悉 Playground 和 K12 课程材料
2. 按课程顺序备课（教案 + 示例 + 习题）
3. 课堂演示使用 Playground 在线运行
4. 布置课后练习（习题集）
5. 期末综合项目（课程 10）
```
