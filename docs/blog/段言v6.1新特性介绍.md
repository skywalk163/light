## 引言

在 v6.0 发布一个月后，段言迎来了 **v6.1.0** 版本。这次更新虽然没有 v6.0 那样的大版本变化，但在细节打磨和生态建设上做了大量工作。v6.1 聚焦于四个方向：**全面的中文错误信息**、**增强的标准库**、**LLVM 编译改进** 和 **AI Copilot 升级**。

让我们一起来看看 v6.1 带来了哪些新变化。

## 一、100% 中文错误信息

### 1.1 错误信息全面中文化

v6.1 最显著的变化是：**所有错误信息现在 100% 使用中文**。从词法错误到语法错误，从类型错误到运行时错误，用户看到的都是清晰的中文描述。

```bash
# 之前
$ duan run test.duan
SyntaxError: unexpected token '}'

# 现在
$ duan run test.duan
语法错误：第 3 行第 12 列，发现意外的符号 '}'
```

```bash
# 之前
$ duan run test.duan
TypeError: cannot add int and str

# 现在
$ duan run test.duan
类型错误：不能将「整数」类型和「字符串」类型相加
```

### 1.2 错误信息分级

v6.1 引入了错误信息分级系统，让调试更加高效：

| 级别 | 标签 | 说明 | 示例 |
|------|------|------|------|
| 🟢 提示 | `提示` | 优化建议或改进提示 | `提示：变量「甲」声明后未使用` |
| 🟡 警告 | `警告` | 潜在问题但不影响运行 | `警告：函数「加法」缺少返回类型注解` |
| 🔴 错误 | `错误` | 阻止编译或运行的问题 | `错误：未定义的变量「乙」` |
| ⚫ 严重 | `严重错误` | 编译器内部错误 | `严重错误：编译器内部异常，请联系开发者` |

### 1.3 错误信息上下文

每个错误信息现在都包含更多上下文：

```
错误：第 5 行，在函数「计算总分」中
  → 变量「成绩」未定义
  → 你是想用「分数」吗？（第 3 行定义）
  → 建议：检查变量名拼写，或确认变量已在使用前声明
```

### 1.4 错误信息国际化架构

虽然 v6.1 全部使用中文，但错误信息系统的架构已经支持多语言。开发者可以通过配置切换到其他语言，为未来的国际化做好了准备。

### 2.2 模块功能增强

#### 数据压缩模块

```段言
导入 数据压缩。

设 原始数据 为 "这是一段需要压缩的数据。" * 100
设 压缩后 为 数据压缩.压缩(原始数据)
打印("原始大小: ", 字符串长度(原始数据), " 字节")
打印("压缩后大小: ", 字符串长度(压缩后), " 字节")
打印("压缩率: ", 数据压缩.压缩率(原始数据, 压缩后))

设 解压后 为 数据压缩.解压(压缩后)
打印("解压后与原始数据一致: ", 解压后 等于 原始数据)
```

#### 日志系统模块

```段言
导入 日志系统。

设 日志器 为 日志系统.创建日志器("我的应用")
日志器.设置级别(日志系统.级别.调试)
日志器.添加文件输出("app.log")
日志器.添加控制台输出()

日志器.调试("这是调试信息")
日志器.信息("应用启动成功")
日志器.警告("磁盘空间不足：剩余 1.2GB")
日志器.错误("数据库连接失败：连接超时")

# 带结构化上下文的日志
日志器.信息("用户登录", {"用户": "张三", "IP": "192.168.1.1"})
```

#### 定时任务模块

```段言
导入 定时任务。
导入 时间。

段落 备份任务：
    打印("执行备份：", 时间.当前时间字符串())

段落 清理任务：
    打印("执行清理：", 时间.当前时间字符串())

设 调度器 为 定时任务.创建调度器()
调度器.添加任务("每日备份", "0 2 * * *", 备份任务)   # 每天凌晨 2 点
调度器.添加任务("每小时清理", "0 * * * *", 清理任务)  # 每小时
调度器.启动()

打印("定时任务已启动，按 Ctrl+C 停止")
# 调度器会在后台运行
```

## 三、LLVM 编译改进

### 3.1 编译性能提升

v6.1 在 LLVM 后端进行了多项优化：

| 指标 | v6.0.0 | v6.1.0 | 提升 |
|------|--------|--------|------|
| 编译速度（小型项目） | 基准 | +25% | +25% |
| 编译速度（中型项目） | 基准 | +18% | +18% |
| 生成代码执行速度 | 基准 | +8% | +8% |
| 生成代码体积 | 基准 | -12% | -12% |
| 内存占用 | 基准 | -15% | -15% |

### 3.2 新增优化 Pass

v6.1 新增了 3 个优化 Pass：

1. **常量传播优化**：在编译期计算常量表达式，减少运行时开销
2. **死代码消除增强**：更精确的活跃变量分析，移除更多无用代码
3. **内联优化增强**：基于调用频率和函数大小的智能内联决策

### 3.3 目标架构支持

v6.1 扩展了 LLVM 后端的编译目标支持：

- **x86_64**：完整支持（Windows/Linux/macOS）
- **ARM64/AArch64**：完整支持（Apple Silicon、ARM 服务器）
- **ARM32**：基础支持（树莓派、嵌入式设备）
- **RISC-V**：实验性支持（开发板、开源硬件）

### 3.4 链接时间优化（LTO）

v6.1 正式支持 LTO（Link Time Optimization），可以在链接阶段进行跨模块优化：

```bash
duan compile 主.duan --backend llvm-typed --lto
```

LTO 带来的好处：
- 跨函数内联优化
- 全局常量传播
- 死全局变量消除
- 生成代码体积减少 15-30%

## 四、AI Copilot 升级

### 4.1 段言→Python 翻译模型

v6.1 的 AI Copilot 新增了段言到 Python 的翻译功能，实现了双向翻译：

```bash
# Python → 段言
duan py2duan hello.py

# 段言 → Python
duan ai translate test.duan
```

### 4.2 上下文感知补全

AI Copilot 的代码补全现在支持上下文感知：

- 基于当前文件中已定义的函数和变量
- 自动推断期望的返回类型
- 考虑项目中的代码风格一致性

### 4.3 代码审查增强

AI 代码审查新增了以下检查项：

- **安全审查**：检测 SQL 注入、路径遍历等安全风险
- **性能审查**：识别潜在的性能瓶颈
- **风格审查**：检查代码风格一致性
- **最佳实践**：推荐段言惯用写法

### 4.4 智能修复建议

当编译错误发生时，AI Copilot 可以自动分析错误并提供修复建议：

```bash
duan ai fix 错误文件.duan --error "错误信息"
```

AI 会分析错误上下文，生成包含修复代码的 prompt，帮助开发者快速定位和解决问题。

## 五、新的示例项目

v6.1 新增了 **5 个** 示例项目，涵盖不同的应用场景：

### 5.1 Markdown 解析器

```段言
# examples/markdown_parser/
导入 文件系统。
导入 字符串。

段落 解析Markdown 接收 内容：
    # 支持标题、列表、代码块、链接等
    设 行列表 为 字符串.分割(内容, "\n")
    设 结果 为 []
    
    遍历 行 于 行列表：
        如果 行.以("## "开头)：
            结果.添加(解析标题(行, 2))
        否则 如果 行.以("# "开头)：
            结果.添加(解析标题(行, 1))
        否则 如果 行.以("- "开头) 或 行.以("* "开头)：
            结果.添加(解析列表项(行))
        否则：
            结果.添加(解析普通段落(行))
    
    返回 结果
```

### 5.2 简易数据库

```段言
# examples/simple_db/
导入 文件系统。
导入 JSON。
导入 数据校验。

类 简易数据库：
    构造 接收 路径：
        设 自身.路径 为 路径
        设 自身.数据 为 {}
        如果 文件系统.文件存在(路径)：
            设 自身.数据 为 JSON.解析文件(路径)
    
    段落 设置 接收 键, 值：
        设 自身.数据[键] 为 值
        自身.保存()
    
    段落 获取 接收 键, 默认值：
        返回 自身.数据.获取(键, 默认值)
    
    段落 保存：
        设 临时路径 为 自身.路径 + ".tmp"
        JSON.写入文件(临时路径, 自身.数据)
        文件系统.移动文件(临时路径, 自身.路径)
```

### 5.3 任务管理系统（Web）

一个基于 Web 框架的完整任务管理系统，支持任务的增删改查、分类和状态管理。

### 5.4 数据可视化工具

使用段言绘制基本的图表和统计图，支持柱状图、折线图和饼图。

### 5.5 简易聊天服务器

基于 WebSocket 的多房间聊天服务器，支持用户认证和消息广播。

## 八、升级指南

### 从 v6.0 升级

```bash
pip install --upgrade duan
```

### 验证升级

```bash
duan --version
# 输出：Duan v6.1.0
```

### 迁移注意事项

1. **错误信息变化**：所有错误信息已改为中文，请更新依赖错误信息解析的脚本
2. **新模块依赖**：使用新增标准库模块无需额外安装
3. **LLVM 编译**：LLVM 16.0+ 仍为推荐版本，新增 LTO 支持需要 LLVM 17.0+
4. **AI Copilot**：翻译功能需要安装额外的 AI 依赖（`pip install duan[ai]`）
