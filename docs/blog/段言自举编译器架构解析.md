# 段言编译器架构解析——自举编译器的实现之路

> **发布日期：** 2026-08-07
> **适用版本：** v6.0.0
> **作者：** 段言开发团队

---

## 引言

自举（Bootstrapping）是编译器领域最具挑战性的技术成就之一。当一个编译器能够编译自己的源代码时，它就实现了"自举"——编程语言成熟度的重要标志。

段言（Duan）从设计之初就将自举编译作为核心目标。在 v6.0 中，段言的自举编译器已包含 **120+ 个函数**，能够完整编译自身的词法分析器、语法分析器、代码生成器和类型系统。

本文将深入解析段言自举编译器的架构设计，带你了解自举循环的技术细节和实现路径。

## 什么是自举编译器？

自举编译器的核心思想是：**用语言 A 编写编译器，然后用这个编译器编译自己**。

```
┌─────────────────────────────────────────────┐
│               自举循环                       │
│                                             │
│   bootstrap_v1.duan  (初始版本，用Python实现)│
│         │                                   │
│         ▼                                   │
│   bootstrap_v2.duan  (用段言重写词法分析器)  │
│         │                                   │
│         ▼                                   │
│   bootstrap_v3.duan  (完整编译器，用段言编写)│
│         │                                   │
│         ▼                                   │
│   bootstrap_v4.duan  (自举编译，输出自身)    │
│         │                                   │
│         ▼                                   │
│   bootstrap_v5.duan  (自举循环验证)          │
└─────────────────────────────────────────────┘
```

段言的自举编译器位于 `bootstrap/` 目录，核心文件是 `bootstrap_v3.duan`（89KB，120+ 函数），以及 `bootstrap_level4.duan`、`bootstrap_level5.duan` 等后续版本。

## 第一阶段：词法分析器（Lexer）

**文件：** `bootstrap/lexer.duan`

词法分析是编译器的入口，负责将源代码文本切分为 Token 流。段言自举编译器的词法分析器需要处理中文关键字、缩进、中文运算符等特殊语法。

### 核心设计

```段言
# 简化版词法分析器核心逻辑
段落 词法分析 接收 源代码:
    设 令牌列表 为 []
    设 位置 为 0
    设 源代码长度 为 字符串长度(源代码)

    当 位置 小于 源代码长度:
        设 当前字符 为 源代码[位置]

        如果 当前字符 是空白字符:
            位置 为 位置 + 1
            跳过

        如果 当前字符 是中文或英文字母:
            设 标识符 为 读取标识符(源代码, 位置)
            位置 为 位置 + 字符串长度(标识符)
            如果 标识符 是关键字:
                列表追加(令牌列表, 创建关键字令牌(标识符))
            否则:
                列表追加(令牌列表, 创建标识符令牌(标识符))
            跳过

        如果 当前字符 是数字:
            设 数字 为 读取数字(源代码, 位置)
            位置 为 位置 + 字符串长度(数字)
            列表追加(令牌列表, 创建数字令牌(数字))
            跳过

        # 处理运算符和分隔符
        如果 当前字符 是运算符:
            设 运算符 为 读取运算符(源代码, 位置)
            位置 为 位置 + 字符串长度(运算符)
            列表追加(令牌列表, 创建运算符令牌(运算符))
            跳过

        # 处理字符串字面量
        如果 当前字符 等于 "\"" 或 当前字符 等于 "'":
            设 字符串 为 读取字符串(源代码, 位置)
            位置 为 位置 + 字符串长度(字符串) + 2  # 包含引号
            列表追加(令牌列表, 创建字符串令牌(字符串))

        位置 为 位置 + 1  # 默认前进

    返回 令牌列表
```

### 关键技术挑战

**1. 中文关键字识别**

段言的关键字全部是中文，如 `设`、`段落`、`如果`、`遍历`、`类` 等。词法分析器需要维护一个关键字表进行匹配：

```段言
设 关键字集合 为 {
    "设": 真, "段落": 真, "如果": 真, "否则": 真,
    "遍历": 真, "当": 真, "返回": 真, "类": 真,
    "构造": 真, "导入": 真, "从": 真, "尝试": 真,
    "捕获": 真, "最终": 真, "抛出": 真, "匹配": 真,
    "模式": 真, "异步": 真, "等待": 真, "使用": 真,
    "打印": 真, "设": 真, "为": 真, "接收": 真
}
```

**2. 缩进处理**

段言使用缩进表示代码块（类似 Python），词法分析器需要生成 `INDENT`/`DEDENT` 令牌：

```段言
# 缩进栈管理
设 缩进栈 为 [0]  # 初始缩进级别为 0

段落 处理缩进 接收 当前缩进:
    如果 当前缩进 大于 栈顶(缩进栈):
        列表追加(缩进栈, 当前缩进)
        返回 INDENT

    如果 当前缩进 小于 栈顶(缩进栈):
        当 当前缩进 小于 栈顶(缩进栈):
            弹出栈顶(缩进栈)
        返回 DEDENT

    返回 无  # 缩进不变，不需要令牌
```

**3. 中文运算符支持**

段言支持中文运算符和符号运算符的等价写法：

```段言
设 运算符映射 为 {
    "加": "+", "减": "-", "乘": "*", "除": "/",
    "等于": "==", "不等于": "!=", "大于": ">", "小于": "<",
    "大于等于": ">=", "小于等于": "<=", "且": "and", "或": "or", "非": "not"
}
```

## 第二阶段：语法分析器（Parser）

**文件：** `bootstrap/parser.duan`

语法分析器将 Token 流转换为抽象语法树（AST）。段言自举编译器使用**递归下降解析器**，这是一种手写的自顶向下解析方法。

### 核心设计

```段言
段落 解析程序 接收 令牌列表:
    设 位置 为 0
    设 语句列表 为 []

    当 位置 小于 列表长度(令牌列表):
        设 语句 为 解析语句(令牌列表, 位置)
        如果 语句 不等于 无:
            列表追加(语句列表, 语句)

    返回 创建程序节点(语句列表)

段落 解析语句 接收 令牌列表, 位置引用:
    设 当前令牌 为 查看当前令牌(令牌列表, 位置引用)

    如果 当前令牌.类型 等于 "关键字":
        如果 当前令牌.值 等于 "设":
            返回 解析变量声明(令牌列表, 位置引用)
        如果 当前令牌.值 等于 "段落":
            返回 解析段落定义(令牌列表, 位置引用)
        如果 当前令牌.值 等于 "如果":
            返回 解析条件语句(令牌列表, 位置引用)
        如果 当前令牌.值 等于 "遍历":
            返回 解析循环语句(令牌列表, 位置引用)
        如果 当前令牌.值 等于 "类":
            返回 解析类定义(令牌列表, 位置引用)
        如果 当前令牌.值 等于 "尝试":
            返回 解析异常处理(令牌列表, 位置引用)
        如果 当前令牌.值 等于 "匹配":
            返回 解析模式匹配(令牌列表, 位置引用)
        如果 当前令牌.值 等于 "返回":
            返回 解析返回语句(令牌列表, 位置引用)

    如果 当前令牌.类型 等于 "标识符" 或 "数字" 或 "字符串":
        返回 解析表达式语句(令牌列表, 位置引用)

    返回 无
```

### 递归下降解析

段言自举编译器使用递归下降解析器，每个语法结构对应一个解析函数：

```段言
段落 解析变量声明 接收 令牌列表, 位置引用:
    消耗令牌(令牌列表, 位置引用, "关键字", "设")
    设 变量名 为 消耗令牌(令牌列表, 位置引用, "标识符")
    消耗令牌(令牌列表, 位置引用, "关键字", "为")
    设 初始值 为 解析表达式(令牌列表, 位置引用)
    返回 创建变量声明节点(变量名.值, 初始值)

段落 解析条件语句 接收 令牌列表, 位置引用:
    消耗令牌(令牌列表, 位置引用, "关键字", "如果")
    设 条件 为 解析表达式(令牌列表, 位置引用)
    消耗令牌(令牌列表, 位置引用, "冒号")
    设 然后分支 为 解析语句块(令牌列表, 位置引用)
    设 否则分支 为 无

    如果 查看当前令牌(令牌列表, 位置引用).值 等于 "否则":
        消耗令牌(令牌列表, 位置引用, "关键字", "否则")
        如果 查看当前令牌(令牌列表, 位置引用).值 等于 "如果":
            设 否则分支 为 解析条件语句(令牌列表, 位置引用)
        否则:
            消耗令牌(令牌列表, 位置引用, "冒号")
            否则分支 为 解析语句块(令牌列表, 位置引用)

    返回 创建条件语句节点(条件, 然后分支, 否则分支)
```

### 表达式解析：普拉特解析法

段言自举编译器使用**普拉特解析法（Pratt Parsing）** 来处理表达式，这是一种结合了递归下降和运算符优先级的高效解析方法：

```段言
# 运算符优先级表
设 前缀解析函数 为 {}
设 中缀解析函数 为 {}

段落 注册前缀 接收 令牌类型, 解析函数:
    前缀解析函数[令牌类型] 为 解析函数

段落 注册中缀 接收 令牌类型, 优先级, 解析函数:
    中缀解析函数[令牌类型] 为 {"优先级": 优先级, "解析": 解析函数}

# 注册各种运算符
注册中缀("+", 50, 解析二元运算符)
注册中缀("-", 50, 解析二元运算符)
注册中缀("*", 60, 解析二元运算符)
注册中缀("/", 60, 解析二元运算符)
注册中缀("==", 40, 解析二元运算符)
注册中缀("!=", 40, 解析二元运算符)
注册中缀(">", 40, 解析二元运算符)
注册中缀("<", 40, 解析二元运算符)
注册中缀("且", 30, 解析二元运算符)
注册中缀("或", 20, 解析二元运算符)

段落 解析表达式 接收 令牌列表, 位置引用, 最小优先级:
    设 当前令牌 为 查看当前令牌(令牌列表, 位置引用)
    设 前缀函数 为 前缀解析函数[当前令牌.类型]

    如果 前缀函数 等于 无:
        抛出 解析错误("意外的令牌: " + 当前令牌.值)

    设 左值 为 前缀函数(令牌列表, 位置引用)

    当 查看当前令牌(令牌列表, 位置引用).类型 在中缀解析函数:
        设 中缀 为 中缀解析函数[查看当前令牌(令牌列表, 位置引用).类型]
        如果 中缀["优先级"] 小于 最小优先级:
            跳出
        左值 为 中缀["解析"](令牌列表, 位置引用, 左值)

    返回 左值
```

## 第三阶段：AST 定义

**文件：** `bootstrap/duan_ast.duan`

AST 节点定义了编译器中间的树形数据结构。段言自举编译器使用类来定义各种 AST 节点：

```段言
# AST 节点定义（简化版）
类 AST节点:
    构造 接收 节点类型:
        己.节点类型 为 节点类型

类 程序节点 继承 AST节点:
    构造 接收 语句列表:
        父类.构造("程序")
        己.语句列表 为 语句列表

类 变量声明节点 继承 AST节点:
    构造 接收 变量名, 初始值:
        父类.构造("变量声明")
        己.变量名 为 变量名
        己.初始值 为 初始值

类 段落定义节点 继承 AST节点:
    构造 接收 名称, 参数列表, 主体:
        父类.构造("段落定义")
        己.名称 为 名称
        己.参数列表 为 参数列表
        己.主体 为 主体

类 条件语句节点 继承 AST节点:
    构造 接收 条件, 然后分支, 否则分支:
        父类.构造("条件语句")
        己.条件 为 条件
        己.然后分支 为 然后分支
        己.否则分支 为 否则分支

类 二元运算节点 继承 AST节点:
    构造 接收 运算符, 左操作数, 右操作数:
        父类.构造("二元运算")
        己.运算符 为 运算符
        己.左操作数 为 左操作数
        己.右操作数 为 右操作数
```

## 第四阶段：代码生成器

**文件：** `bootstrap/codegen.duan`

代码生成器将 AST 转换为等效的 Python 代码。这是段言自举编译器的默认后端，因为 Python 运行时是最广泛可用的执行环境。

### 核心设计

```段言
段落 生成代码 接收 AST:
    如果 AST.节点类型 等于 "程序":
        返回 生成程序(AST)
    如果 AST.节点类型 等于 "变量声明":
        返回 生成变量声明(AST)
    如果 AST.节点类型 等于 "段落定义":
        返回 生成段落定义(AST)
    如果 AST.节点类型 等于 "条件语句":
        返回 生成条件语句(AST)
    如果 AST.节点类型 等于 "二元运算":
        返回 生成二元运算(AST)
    # ... 其他节点类型

段落 生成变量声明 接收 节点:
    返回 "    " * 当前缩进级别 + 节点.变量名 + " = " + 生成表达式(节点.初始值)

段落 生成段落定义 接收 节点:
    设 参数 为 连接字符串(节点.参数列表, ", ")
    设 结果 为 "def " + 节点.名称 + "(" + 参数 + "):\n"
    设 原缩进 为 当前缩进级别
    当前缩进级别 为 当前缩进级别 + 1
    遍历 语句 于 节点.主体:
        结果 为 结果 + 生成代码(语句) + "\n"
    当前缩进级别 为 原缩进
    返回 结果
```

## 自举循环：从 bootstrap_v3 到 bootstrap_v5

### bootstrap_v3（基础版本）

`bootstrap_v3.duan` 是段言自举编译器的第一个完整版本，包含 120+ 个函数，支持：

- 完整的词法分析（中文关键字、缩进、字符串、数字、注释）
- 完整的语法分析（变量声明、段落定义、条件语句、循环、类定义）
- 代码生成（Python 后端）
- 基本类型系统

### bootstrap_level4（自举验证）

`bootstrap_level4.duan` 是用 bootstrap_v3 编译自身生成的版本。验证流程：

```bash
# 第 1 步：用 Python 解释器运行 bootstrap_v3，编译 bootstrap_v3.duan
python bootstrap/run_compiler.py bootstrap/bootstrap_v3.duan

# 第 2 步：用生成的编译器再次编译 bootstrap_v3.duan
python bootstrap/bootstrap_level4.duan < bootstrap/bootstrap_v3.duan

# 第 3 步：验证两个输出是否一致
diff bootstrap_level3_output.py bootstrap_level4_output.py
```

如果第 3 步的输出完全一致，说明自举循环验证通过。

### bootstrap_level5（完整自举）

`bootstrap_level5.duan` 是更完善的自举版本，增加了对模块系统的支持：

```bash
# 编译 bootstrap_level5.duan，验证模块导入和依赖解析
python bootstrap/test_level5_module.py
```

## 模块系统与预处理器

**文件：** `bootstrap/module_preprocessor.py`

段言自举编译器支持模块系统，通过预处理器处理 `导入` 语句：

```python
# 预处理器逻辑（简化）
def preprocess_modules(source_code):
    """解析导入语句，合并依赖模块的源代码"""
    lines = source_code.split('\n')
    result = []
    for line in lines:
        if line.startswith('导入'):
            module_name = extract_module_name(line)
            module_source = load_module(module_name)
            result.append(module_source)
        else:
            result.append(line)
    return '\n'.join(result)
```

## 自举编译器的挑战与解决方案

### 挑战 1：鸡生蛋问题

**问题**：要编译段言编译器，需要先有一个段言编译器。

**解决方案**：采用**多阶段自举**策略：

1. **阶段 0**：用 Python 手写初始编译器（`run_compiler.py`）
2. **阶段 1**：用阶段 0 编译 bootstrap_v3.duan
3. **阶段 2**：用阶段 1 的输出编译 bootstrap_v4.duan
4. **阶段 3**：用阶段 2 的输出编译 bootstrap_v5.duan
5. **阶段 4**：验证阶段 2 和阶段 3 的输出一致

### 挑战 2：中文关键字的 Python 兼容性

**问题**：段言使用中文关键字，但 Python 不支持中文关键字作为语法。

**解决方案**：在代码生成阶段，将段言的关键字映射为 Python 等效代码。例如，`设 变量 为 值` 映射为 `变量 = 值`，`段落 名 接收 参数:` 映射为 `def 名(参数):`。

### 挑战 3：缩进处理

**问题**：段言和 Python 都使用缩进表示代码块，但缩进的管理方式不同。

**解决方案**：词法分析器使用缩进栈生成 `INDENT`/`DEDENT` 令牌，代码生成器跟踪当前缩进级别，在生成代码时添加正确的缩进空格。

### 挑战 4：自举循环验证

**问题**：如何确保自举编译器生成的代码与原始编译器一致？

**解决方案**：采用**双向验证**策略：

```
┌─────────────────────────────────────────────────┐
│              双向验证流程                         │
│                                                 │
│  原始编译器 A (Python)                          │
│     │                                           │
│     ├── 编译 bootstrap_v3.duan → 输出 X         │
│     │                                           │
│  自举编译器 B (由 A 编译 bootstrap_v3.duan 得到) │
│     │                                           │
│     ├── 编译 bootstrap_v3.duan → 输出 Y         │
│     │                                           │
│  比较 X 和 Y，如果完全一致则验证通过             │
└─────────────────────────────────────────────────┘
```

## 未来方向：LLVM 自举

当前段言的自举编译器主要针对 Python 后端。v6.0 之后，自举编译器的下一个重要目标是**支持 LLVM 后端**，实现真正的原生代码自举。

```
当前（v6.0）：
  段言源代码 → 自举编译器 → Python 代码 → Python 解释器执行

未来（v7.0+）：
  段言源代码 → 自举编译器 → LLVM IR → 原生机器码 → 独立 EXE
```

LLVM 自举的关键挑战：

1. **类型信息保留**：Python 是动态类型，而 LLVM 需要类型信息
2. **内存管理**：自举编译器需要处理自身的内存分配和释放
3. **运行时支持**：需要自举的运行时库（字符串操作、I/O 等）
4. **性能目标**：自举编译器的编译速度应不低于 Python 后端

## 总结

段言的自举编译器是中文编程语言领域的一项重要技术成就。通过多阶段自举策略、递归下降解析、普拉特表达式解析和关键字映射等关键技术，段言成功地实现了编译器的自我编译。

### 技术要点回顾

1. **词法分析**：处理中文关键字、缩进栈、中文运算符映射
2. **语法分析**：递归下降解析 + 普拉特表达式解析
3. **AST 定义**：使用段言类系统定义各种 AST 节点
4. **代码生成**：关键字映射 + 缩进跟踪 + 类型感知
5. **自举循环**：多阶段自举 + 双向验证
6. **模块系统**：预处理器处理导入语句和依赖解析

### 自举的意义

自举不仅是一项技术成就，更代表着编程语言的**自我一致性**和**独立性**：

- **自我一致性**：语言足够强大，能够实现自身的编译器
- **独立性**：不依赖其他语言来维持自身的发展
- **可验证性**：自举循环提供了编译器正确性的强验证
- **社区信任**：自举是社区对语言信心的标志

段言 v6.0 的自举编译器已经走过了从概念验证到生产可用的完整历程。未来，随着 LLVM 后端的自举完善，段言将实现真正的"用中文编译中文"的完整自举闭环。
