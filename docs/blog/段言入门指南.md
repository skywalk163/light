# 段言入门指南：用中文自然语言编程

> **发布日期：** 2026-08-07
> **适用版本：** v5.5.0

---

## 什么是段言（Duan）？

段言是一门**基于中文自然语言的编程语言**。它的关键字全部使用中文，让中文母语者可以像写文章一样写代码。

```段言
打印 "你好，世界！"
```

没错，这就是一个完整的段言程序——不需要记忆英文关键字，不需要区分大小写，不需要纠结于括号和分号。

段言的设计理念是：**编程应该是一种表达，而不是一种翻译**。中文母语者不应该在思考逻辑的同时还要把思路翻译成英文。

## 为什么选择中文自然语言编程？

### 降低学习门槛

对于中文母语者来说，学习编程的最大障碍往往不是逻辑思维，而是英文关键字。`def`、`while`、`elif`、`lambda` 这些对初学者来说毫无意义。而段言的 `段落`、`当`、`否则如果`、`接收` 一目了然。

### 减少思维转换

编程的本质是「用代码表达逻辑」。如果表达方式与你的母语一致，思维转换的成本就降到了最低。段言让你可以直接用中文思考，用中文表达。

### 适合教育场景

段言在编程教育领域有天然优势。中小学的信息技术课程中，学生不需要先学英文就能开始编程，这大大降低了教育门槛。

## 5 分钟快速开始

### 第 1 步：安装

确保已安装 Python 3.10 或更高版本，然后运行：

```bash
pip install duan
```

验证安装：

```bash
duan --version
```

### 第 2 步：创建第一个程序

创建文件 `hello.duan`：

```段言
打印 "你好，段言！"
```

### 第 3 步：运行

```bash
duan run hello.duan
# 输出：你好，段言！
```

恭喜！你已经完成了第一个段言程序。

## 基础语法示例

### 变量

```段言
设 姓名 为 "张三"
设 年龄 为 25
设 分数 为 95.5

打印 姓名
打印 年龄
```

### 条件判断

```段言
设 分数 为 85

如果 分数 >= 90：
    打印 "优秀"
否则如果 分数 >= 60：
    打印 "及格"
否则：
    打印 "不及格"
```

### 循环

```段言
# 遍历范围
遍历 i 在 1 到 5：
    打印 i

# 遍历列表
设 水果 为 ["苹果", "香蕉", "橘子"]
遍历 水果 为 果：
    打印 果

# 当循环
设 计数 为 0
当 计数 < 5：
    打印 计数
    设 计数 为 计数 + 1
```

### 段落（函数）

```段言
段落 加法(甲, 乙):
    返回 甲 + 乙

设 结果 为 加法(3, 5)
打印 结果  # 输出：8
```

### 类与对象

```段言
类 动物：
    属性 名字

    构造 接收 名字：
        己.名字 为 名字

    段落 介绍 接收:
        打印(f"我叫{己.名字}")

设 小狗 为 动物("旺财")
小狗.介绍()
```

### 列表与字典

```段言
# 列表
设 数字 为 [1, 2, 3, 4, 5]
数字.追加(6)
打印 数字

# 字典
设 学生 为 {"名字": "张三", "年龄": 25}
打印 学生["名字"]
```

### 异常处理

```段言
尝试：
    设 结果 为 10 / 0
捕获 Exception 为 错误：
    打印("出错了：" + 转字符串(错误))
最终：
    打印("操作结束")
```

## 常用命令

```bash
duan run hello.duan        # 运行程序
duan compile hello.duan    # 编译为 Python
duan ast hello.duan        # 查看语法树
duan tokens hello.duan     # 查看 Token 流
duan repl                  # 交互式编程
duan tutorial              # 交互式教程
duan pkg init myproject    # 初始化项目
duan ai generate "排序"    # AI 生成代码
```
