# 测试分级与远程跑测（本地窄测 → 0.88 排队全量）

> 伴随工具：`tools/remote_ci.py`（用法、排障详见 `tools/README_remote_ci.md`）。
> 本文定的是**纪律**：什么改动在本地跑、什么必须上 0.88、判红以什么为准。
> 背景：各 agent 机器不一样（Windows 老机 / 云沙箱 / FreeBSD），同一份改动在不同机器上
> 「红绿」不可比——0.88 上 light 仓全量 **28m57s / 18 failed**，本机 Windows 90s 且失败面
> 不同。**「不可比」比慢更贵**，所以可比的结论只能出自 0.88。

## 一、三级闸门

| 级别 | 什么时候跑 | 怎么跑 | 预期耗时 |
|---|---|---|---|
| L1 本地窄测 | 写码期，随时 | 本机 pytest，只跑跟改动相关的 `-k` 子集 | 秒级～分钟级 |
| L2 0.88 定向窄测 | 功能成型后，自查用 | `python tools/remote_ci.py --repo . --tag <卡号-线名> -- -k <子集>` | 几分钟（全仓 10,155 项，收集阶段本身约 72–89 s） |
| L3 0.88 全量 | 合流 / 收口（M 线）必跑 | `python tools/remote_ci.py --repo . --tag <卡号-线名>` | 全量约 29 分钟（`-n 6`）；两条线并行时按 1.3 倍估 |

- L1 的结论只用于快速迭代，**不得写进汇报当验收**。
- L2/L3 的汇报必须带输出末尾这一行（M 线复核的唯一凭据）：

  `[4/4] rc=… ｜ 现场：192.168.0.88:/tmp/lp-ci/run-<时间戳>-<tag> ｜ 槽位已释放`

- 并行收益全在 xdist：远端测试是延迟受限（大量 `subprocess.run` 起 python/bash），
  串行在 12 核上并不快。**永远带 `-n`（工具默认 `-n 6`），不要串行跑全量。**

## 二、判红口径（最重要的一条）

0.88 的环境与 Windows 本机 / 082 门不同（缺编译链、缺 cryptography、路径与本地化差异），
**「新增红 = 0」是相对 0.88 的 18 条已知红基线，不是相对「0 failed」**。

- 基线名单与耗时特征：`tools/baseline_0_88_light_merge.md`
  （2026-11-17 实测：18 failed / 9981 passed / 146 skipped / 10 xfailed，28m57s，rc=1）。
- 改动后跑出的失败列表应恰好等于基线 18 条 ∪ 自己的预期失败；**新增红必须为 0**。
  基线内的红不归本轮管，但谁顺手修了要在汇报里注明。

## 三、排队纪律（红线）

1. **只走 `tools/remote_ci.py`**。禁止自己 ssh 上去跑 pytest、禁止在远端仓库目录直接跑
   （会污染别人的 checkout）。
2. 槽位是共享资源（2 槽 × `-n 6` = 12 worker，正好吃满 12 vCPU）：不手工删 `slots/slot-*`、
   不 kill 别人的 pytest、不删别人 tag 的 `run-*` 目录。
3. `[queue] 槽位全满，排队等待` 是正常输出，**不要 Ctrl-C 改本地跑**。
4. `--queue-timeout`（默认 3600s）到点退出码 75 = **没占到位、没上跑**：如实汇报「未占用槽位、未跑」，
   等收口线统一安排，不许本地跑出结论顶上。
5. 远端锁超过 4 小时无更新会被自动回收（防死锁），这是脚本行为，不用人工介入。
6. 凭据（`.env` 的 `SSH_USER_WORKBUDDY` / `SSH_PASS_WORKBUDDY`）不进仓、不进日志、不进汇报。

## 四、跑不了 0.88 怎么办

本机没有 paramiko、连不上 0.88（云沙箱无内网）：**不要本地跑出结论**。
在 summary 里写一行 `REMOTE_CI: unavailable(<原因>)`，把改动留在分支上，由收口线代跑。
参数准备可以照常做：把拟跑的命令原样写进汇报（含 `--tag`、`-k` 子集）。

## 五、常见报错速查

- **`no tests ran` 且瞬间退出**：多半是多余的 `--` 落到了 pytest 手里（`pytest -- -k xxx`）。
  工具已剥掉分隔符；自己手敲命令时不要让 `--` 落到 pytest 手里。
- **`unrecognized arguments: --timeout=60`**：远端缺 `pytest-timeout`。
  要么 `python3 -m pip install --user pytest-timeout`，要么加 `--no-addopts` 清空仓库 addopts
  （注意：会连 `--ignore=tests/archive` 与 `--dist=loadscope` 一起丢掉，口径就变了，只在排障时用）。
- **`[error] 没占到槽位（rc=75）`**：等槽超时，本次没跑。稍后 `--list` 看占用再试。
