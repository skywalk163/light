# 快速开始

本指南将帮助你快速上手光明编程语言，从安装到运行第一个程序，再到掌握基本语法。

## 安装光明

### 通过 pip 安装（推荐）

```bash
pip install light
```

### 从 GitHub 源码安装

```bash
git clone https://github.com/light-lang/light.git
cd light
pip install -e .
```

### 验证安装

安装完成后，运行以下命令验证是否成功：

```bash
light --version
```

如果看到版本号信息，说明安装成功。

## 你的第一个光明程序

创建一个名为 `hello.light` 的文件，写入以下代码：

```python
打印("你好，光明！")
```

### 运行程序

```bash
light hello.light
```

输出：

```
你好，光明！
```

恭喜！你已经成功运行了第一个光明程序。

## 基本概念

### 变量

光明使用 `设` 关键字声明变量：

```python
设 姓名 为 "张三"
设 年龄 为 18
设 身高 为 1.75
设 爱好 为 ["编程", "阅读", "音乐"]
```

变量名可以中英文混用，推荐使用中文命名：

```python
设 用户名 为 "admin"
设 登录次数 为 42
```

### 条件判断

光明使用 `如果` / `否则` 进行条件判断：

```python
设 分数 为 85

如果 分数 >= 90：
  打印("优秀")
否则 如果 分数 >= 60：
  打印("及格")
否则：
  打印("不及格")
```

### 循环

#### 遍循环（for-in）

```python
# 遍历范围
遍 i 于 范围(5)：
  打印(i)

# 遍历列表
设 水果 为 ["苹果", "香蕉", "橘子"]
遍 果 于 水果：
  打印(果)
```

#### 当循环（while）

```python
设 计数 为 3
当 计数 > 0：
  打印(计数)
  计数 = 计数 - 1
```

### 函数

使用 `段` 关键字定义函数：

```python
段 打招呼(姓名)：
  打印("你好，" + 姓名 + "！")

段 加法(甲, 乙)：
  返回 甲 + 乙

# 调用函数
打招呼("张三")
设 结果 = 加法(3, 5)
打印(结果)  # 输出：8
```

### 列表与字典

```python
# 列表
设 列表 为 [1, 2, 3, 4, 5]
列表.追加(6)
打印(列表[0])     # 输出：1
打印(列表.长度)   # 输出：6

# 字典
设 字典 为 {"姓名": "张三", "年龄": 18}
打印(字典["姓名"])  # 输出：张三
字典["城市"] = "北京"
```

## 文体选择

光明支持两种文体风格：

### L1 白话体（推荐新手）

使用双字关键字和中文标点，语法接近自然语言：

```python
# 文体: 白话
如果 温度 > 30：
  打印("太热了")
否则：
  打印("还可以")
```

### L2 文言体（推荐商业项目）

使用单字关键字和英文标点，代码更简洁：

```python
# 文体: 文言
若 温度 > 30:
  印("太热了")
否:
  印("还可以")
```

## 运行光明程序

### 直接运行

```bash
light 程序.light
```

### 交互式模式（REPL）

```bash
light repl
```

在 REPL 中可以直接输入代码并立即看到结果：

```
光明 v6.0 REPL
>>> 打印("你好")
你好
>>> 1 + 2
3
```

### 编译为 Python 代码

```bash
light compile 程序.light -o 输出.py
```

### 编译为原生可执行文件

```bash
light compile --native 程序.light
```
