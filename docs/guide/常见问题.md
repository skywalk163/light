# 常见问题

## 安装问题

### Q: 安装时提示 "pip 不是内部或外部命令"

请确保 Python 已正确安装并添加到系统 PATH 环境变量中。可以在命令行中运行：

```bash
python --version
```

如果 Python 未安装，请先访问 [python.org](https://python.org) 下载安装 Python 3.10 或更高版本。

### Q: 安装光明后提示 "No module named light"

可能是安装环境不匹配，尝试使用以下方式之一：

```bash
# 使用 python -m 安装
python -m pip install light

# 或使用 pip3
pip3 install light
```

### Q: 安装后运行 `light --version` 提示找不到命令

确保 Python 的 Scripts 目录已添加到 PATH 环境变量中：

```bash
# 查看 light 的安装位置
python -m light --version

# 找到 Scripts 目录
python -c "import sys; print(sys.executable)"
```

### Q: 光明支持哪些平台？

光明支持 Windows、Linux 和 macOS 三大主流操作系统，已在 Python 3.10 至 3.13 版本上完成测试。

## 语法问题

### Q: 光明和 Python 语法有什么区别？

光明语法受 Python 启发，但做了大量中文适配：

| 特性 | 光明 | Python |
|------|------|--------|
| 关键字 | 中文单/双字 | 英文 |
| 缩进 | 必须（与 Python 相同） | 必须 |
| 变量声明 | 需要 `设` 关键字 | 直接赋值 |
| 函数定义 | `段 函数名():` | `def 函数名():` |
| 注释 | `# 注释` | `# 注释` |

### Q: 缩进有什么要求？

光明使用缩进表示代码块，与 Python 类似。推荐使用 2 个空格作为缩进单位（与官方示例保持一致）：

```python
如果 条件：
  打印("缩进 2 空格")
  如果 嵌套条件：
    打印("嵌套缩进 4 空格")
```

### Q: 变量名有什么限制？

- 支持中文、英文、数字和下划线
- 不能以数字开头
- 不能使用关键字作为变量名
- 区分大小写

```python
# 合法变量名
设 姓名 为 "张三"
设 userName 为 "admin"
设 _计数 为 0
设 变量1 为 "值"

# 不合法变量名
设 1变量 为 "值"  # 数字开头
设 设 为 "值"     # 关键字
```

### Q: 中英文标点用错了怎么办？

L1 白话体使用中文标点（，。：），L2 文言体使用英文标点（,.:）。如果混用，编译器会给出提示。建议在文件首行声明文体：

```python
# 文体: 白话  → 使用中文标点
# 文体: 文言  → 使用英文标点
```

## 常见错误

### Q: 遇到 "缩进错误" 怎么办？

确保使用了一致的缩进方式（不要混用空格和 Tab），推荐统一使用 2 个空格缩进。大多数编辑器可以设置"将 Tab 转换为空格"。

### Q: 遇到 "未定义变量" 错误

检查是否忘记了使用 `设` 声明变量：

```python
# 错误：直接赋值
姓名 = "张三"

# 正确：使用设声明
设 姓名 为 "张三"
```

### Q: 函数定义提示语法错误

检查函数定义格式：

```python
# 正确格式
段 函数名(参数1, 参数2)：
  函数体
  返回 结果

# 常见错误：缺少冒号
段 函数名(参数)
  函数体

# 常见错误：缩进不正确
段 函数名(参数)：
函数体  # 缺少缩进
```

### Q: 字符串拼接不生效

光明使用 `+` 进行字符串拼接。如果拼接数字和字符串，需要先转换：

```python
设 年龄 为 18
打印("年龄是：" + 串(年龄))  # 正确：使用串()转换
```

## 最佳实践

### Q: 新手应该用哪种文体？

推荐新手从 **L1 白话体** 开始，使用双字关键字（如 `如果`、`打印`、`遍历`）和中文标点，语法更接近自然语言，学习门槛更低。掌握基本概念后再过渡到 L2 文言体。

### Q: 如何组织代码文件？

- 小项目（< 200 行）：单个 `.light` 文件即可
- 中项目（200-1000 行）：按功能拆分为多个模块
- 大项目（> 1000 行）：使用模块系统 + `package.toml`

### Q: 如何给代码添加注释？

```python
# 这是单行注释

# 多行注释建议每行
# 前面加一个 #
```

### Q: 有哪些命名规范推荐？

- 变量名：使用名词，如 `用户名`、`年龄`
- 函数名：使用动词或动词短语，如 `获取用户`、`计算总和`
- 类名：使用名词，首字可大写，如 `用户管理`、`文件处理`
- 常量：全大写或使用 `常` 修饰

## 性能问题

### Q: 光明运行速度如何？

光明提供两种后端：
- **Python 解释执行**：适合开发和调试，启动快
- **LLVM 原生编译**：适合生产环境，性能接近 C 语言

### Q: 如何提高程序性能？

1. 使用 LLVM 后端编译为原生代码
2. 使用类型注解让编译器生成更优代码
3. 避免在循环中做重复计算
4. 对性能关键部分使用 L4 引用 C 或 Python 优化库

```bash
# 编译为原生可执行文件
light compile --native 程序.light -o 程序.exe
```

### Q: 光明的启动速度如何？

Python 后端启动约 50ms，适合脚本和工具类场景。LLVM 编译后的原生可执行文件启动时间 < 1ms。

## 与其他语言的关系

### Q: 光明能调用 Python 库吗？

可以。使用 L4 外语引用即可调用 Python 生态：

```python
引 Python:
    import requests
    def get_data(url):
        return requests.get(url).json()
出 get_data

设 数据 = get_data("https://api.example.com/data")
```

### Q: 光明能调用 C 语言库吗？

可以。光明支持 FFI（外部函数接口）调用 C 语言动态库，也支持通过 L4 层调用 C 代码。

### Q: 光明代码可以转为 Python 吗？

光明提供了迁移工具，可以将光明代码转换为 Python 代码。但推荐直接使用光明，享受中文编程的便利。

## 规范说明

### Q: `遍 典 之 k` 遍历字典时，k 是键还是值？

**遍历字典时迭代的是键**，与 Python 的 `for k in dict:` 一致。如需获取值，使用 `典[k]`。

```light
设配置={"端口":8080,"主机":"localhost"}
遍配置之为键:
    打印键 并 "=" 并 配置[键]  # 输出: 端口=8080  主机=localhost
```

### Q: `X的Y` 属性访问是怎么解析的？

由于词法分析器将 `的` 视为特殊字符，`成绩的长度` 会被整体识别，而非拆分为 `成绩.长度`。当前解析器通过白名单机制在代码生成阶段将已知属性名（如 `长度`、`首`、`尾`、`键`、`值`）拆分出来，生成 `对象.属性` 的 Python 代码。

```light
设成绩=[85,92,78]
打印成绩之长度    # → 成绩.长度
打印成绩之首      # → 成绩[0]
```

**注意**：方法调用建议使用英文句点（如 `列表.排序()`），避免使用 `X的 方法()` 形式。

### Q: `遍 X 为 Y` 和 `遍 X 之 Y` 有什么区别？

**语序不同，不等价。** 遍历循环的语序由连接词决定：

- `之` / `于` / `在` / `中的` —— **变量在前**：`遍历 项 之 列表：` → `for 项 in 列表:`
- `之为` / `为` —— **可迭代对象在前**：`遍 列表 为 项：` → `for 项 in 列表:`

所以 `遍 列表 为 i` 等价于 `遍 列表 之为 i`，而**不**等价于 `遍 列表 之 i`（后者会把 `列表` 当循环变量、把 `i` 当可迭代对象）。

裸 `之` 历史上曾被两种语序混用，v7 合并时统一裁定为「变量在前」；需要「可迭代对象在前」请写 `之为` 或 `为`。
