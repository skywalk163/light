## 概述

L2 文言体是光明的**工程级文体**,面向商用项目、库开发、团队协作、性能关键代码、大型工程场景。

**设计哲学**:
- **显式优于隐式**:类型、参数、返回值、可见性都明确
- **符号优于文字**:算术用 `+ - * /`,与国际通用符号一致
- **缩进强制**:块结构清晰,适合大文件阅读
- **静态检查**:支持类型检查器、IDE 友好
- **工程化**:模块、可见性、错误处理、接口、继承完善

**文件头声明**:
```light
# 文体: 文言
```

## 使用的 L0 核心字

L2 使用 L0 全部 **30 字**(L1 的 19 字 + L2 新增/强化 11 字):

| 类别 | L2 新增/强化的 11 字 |
|------|---------------------|
| 定义与类型 | `类` `承` `接` `配` |
| 自指与连接 | `自` |
| 组织 | `出` |
| 其他 | (L1 也用但 L2 用法更全的算) |

L1 的 19 字:L2 全部支持,且更严格要求(如类型注解)。共 30 字:
若 否 当 遍 跳 过 返 | 设 段 类 承 接 配 | 试 捕 抛 终 | 自 之 并 从 是 | 且 或 非 真 假 空 | 导 出

## 一、词法

### 1.1 标识符命名

**基本规则**:中文字、英文字母、数字、下划线`_`,不以数字开头。

**命名约定**(文言体工程规范):

| 类别 | 约定 | 示例 |
|------|------|------|
| 变量名 | 蛇形(下划线) | `学生列表`、`user_name` |
| 段/函数名 | 蛇形或动词开头 | `计算总分`、`process_data` |
| 类名 | 首字母大写(驼峰) | `学生`、`User`、`HTTPRequest` |
| 接口名(接) | `可` 开头 or 驼峰 | `可打印`、`Printable` |
| 常量名 | 全大写下划线 | `最大重试`、`MAX_RETRY` |
| 私有成员 | 下划线开头(约定) | `_缓存`、`_internal` |

### 1.2 标点符号

**主用英文标点**(与国际工程规范对齐),中文标点作为别名:

| 英文标点 | 中文别名 | 用途 |
|---------|---------|------|
| `,` | `，` | 分隔列表、参数 |
| `.` | `之`、`.`(主用) | 属性访问、方法调用 |
| `:` | `：` | 块开始、类型注解、三目 |
| `()` | `()` | 函数调用、参数列表、分组 |
| `[]` | `[]` | 列表、索引、切片 |
| `{}` | `{}` | 字典、命名空间 |
| `""`、`''` | `""`、`''` | 字符串字面量 |
| `->` | `→` | 返回值类型注解 |
| `//` | 无 | 单行注释(或用 `#`) |
| `/* */` | `""" """` | 块注释 |

## 二、类型系统

### 2.1 基础类型

| 类型名 | 含义 | 示例 |
|--------|------|------|
| `数` | 整数/浮点数统一(默认) | `10`、`3.14` |
| `整` | 整数(可选,优化用) | `42` |
| `符` | 浮点数(可选,优化用) | `2.718` |
| `串` | 字符串 | `"hello"`、`"你好"` |
| `布` | 布尔 | `真`、`假` |
| `列` | 列表/数组 | `[1, 2, 3]` |
| `典` | 字典/哈希表 | `{"a": 1}` |
| `空` | 空值单元类型 | `空` |
| `值` | 任意类型(动态) | 不推荐,但可用 |

### 2.2 泛型参数

> 说明：泛型下标标注（`列[数]`、`典[串, 数]`、`列[列[数]]`）属于 v4.0 设计目标，
> 当前 parser 尚未实现类型下标语法，照此书写会 ParseError。故本节代码块以 `text`
> 标注，仅作设计示意；实际编写时请用不带下标的 `列`/`典`（见 1.5、2.1）。

```text
# 列表泛型
设 数列表: 列[数] = [1, 2, 3]
设 串列表: 列[串] = ["a", "b"]

# 字典泛型: 典[键类型, 值类型]
设 学生成绩: 典[串, 数] = {"张三": 95, "李四": 82}

# 嵌套泛型
设 矩阵: 列[列[数]] = [[1,2],[3,4]]
```

## 三、表达式与运算符

### 3.1 算术运算符(符号为主,中文为别名)

| 运算符 | 中文别名 | 优先级 | 示例 |
|-------|---------|--------|------|
| `**` | 幂 | 最高 | `2**10` |
| `-x` | 取负 | | `-5` |
| `*` `/` `%` `//` | 乘 除 取余 整除 | 高 | `10/3` |
| `+` `-` | 加 减 | 低 | `甲+乙` |

### 3.2 比较运算符

| 运算符 | 中文别名 | 示例 |
|-------|---------|------|
| `==` | 等于、是 | `甲==10`、`甲是10` |
| `!=` | 不等于 | `甲!=5` |
| `<` `>` | 小于 大于 | `甲<10` |
| `<=` `>=` | 小于等于 大于等于 | `甲<=10` |

**多值比较**(Python 风格):
```light
段 评级 接收 分数：
    配 真:
        情况 90 <= 分数 <= 100: 返 "优"
        情况 60 <= 分数 < 90:  返 "及格"
        其他: 返 "不及格"
```
> 口径（v7 单 J 裁定）：以实现与语料为权威。`配` 的分支引导词是 **`情况`**，
> 默认分支是 **`其他`**（`否`/`否则` 亦可），主语后**不带 `之`**。
> 早期文档写的 `配 X 之: 若 …: 否: …` 从未被 parser 支持，照那样写会 ParseError。


### 3.3 逻辑运算符

| 运算符 | 核心字 | 示例 |
|-------|--------|------|
| `&&` | 且 | `甲>0 且 乙>0` |
| `\|\|` | 或 | `甲>10 或 乙>10` |
| `!` | 非 | `非 甲`、`!甲` |

### 3.4 成员与访问

```light
// 属性访问
设 列表 = [3, 1, 4]
打印(列表.长度)   # 3
打印(列表之长度)   # 3 (别名)

// 索引
打印(列表[0])     # 3
// 之 只接成员名,不接下标数字;取下标一律写 []

// 切片
打印(列表[1:3])   # [1, 4]

// 包含判断:用 包含(保留字 是 尚未实装为运算符)
打印(列表 包含 3)      # 真 (成员包含)
打印(非 (列表 包含 5))  # 真
```

### 3.5 类型判断与转换

```light
// 类型判断:用 类型() + 等于/不等于(保留字 是 尚未实装为类型运算符)
若 类型(变量) 等于 整数:
    打印("这是数字")
若 类型(变量) 不等于 学生:
    打印("不是学生")

// 类型转换
设 年龄: 数 = 整(输入("年龄:"))
设 文字: 串 = 串(123)
设 列表: 列 = 列(字典)
```

### 3.6 三目表达式

> 说明：三目（条件表达式）是 v4.0 设计目标，parser 目前没有任何条件表达式产生式
> （`若 … : … 否: …`、`若 … 则 … 否 …`、`若 … 那么 … 否则 …` 均 ParseError），
> 故本节代码块以 `text` 标注仅作设计示意。当前等价写法是条件语句：
> `设 等级: 串 = "不及格"` 再 `若 分数 >= 60:` / `设 等级 为 "及格"`。

```text
设 等级: 串 = 若 分数 >= 60: "及格" 否: "不及格"
```

### 4.5 模式匹配(配)

> 口径（v7 单 J 裁定，以实现与语料为权威）：分支引导词是 **`情况`**，
> 守卫词是 **`若`/`如果`**（写在 `情况 模式 若 条件:`），默认分支是
> **`其他`**（`否`/`否则` 亦可），主语后**不带 `之`**。生成 Python `match/case`。
> 早期文档的 `配 X 之: / 若 分支 / 当 守卫` 写法从未被 parser 支持，已在下方更正。

```light
// 基础模式匹配（配 + 情况 + 其他；情况后接布尔表达式即为守卫）
段 评级(分数: 数) -> 串:
    配 真:
        情况 分数 >= 90: 返 "优"
        情况 分数 >= 80: 返 "良"
        情况 分数 >= 60: 返 "及格"
        其他: 返 "不及格"

// 解构匹配（守卫用 若）
设 对: 列 = [3, 5]
配 对:
    情况 [0, 0]: 打印("原点")
    情况 [x, y] 若 x == y: 打印("对角线")
    情况 [x, y]: 打印("坐标:{x},{y}")

// 类型匹配：情况 <类型名> <绑定名>（parser 的 type_check 模式，发射 case 类型() as 绑定）
类 学生:
    段 构(自): 过

配 变量:
    情况 学生 甲: 打印("学生")
    情况 整数 甲: 打印("数字")
    情况 字符串 甲: 打印("字符串")
    其他: 打印("其他")
```

> 类型匹配只认 `情况 类型名 绑定名:` 两个标识符相邻的形状,**不写 `是`**——
> `情况 是 数:` 会 ParseError。内置类型请写全名 `整数`/`字符串`
> （短别名 `数`/`串` 未进 codegen 的类型映射表,会发射 `case 数()` 并在运行期 NameError）。
> 每个 `情况` 只带一个模式,不支持 `情况 2, 3` 逗号多值,也不支持 `情况 2 | 3`。



### 4.6 异常处理


## 十一、完整示例:学生成绩管理系统

```light
# 文体: 文言
# 文件: 学生管理.light

出 学生, 大学生, 成绩统计, 等级评定
// 不导出 内部辅助()

#
# 学生基类
#
类 学生:
    设 姓名: 串
    设 年龄: 数
    设 成绩: 列

    段 __init__(自, 姓名: 串, 年龄: 数):
        自.姓名 = 姓名
        自.年龄 = 年龄
        自.成绩 = []

    段 添加成绩(自, 分数: 数):
        若 分数 < 0 或 分数 > 100:
            抛 ValueError("分数必须在0-100之间,实际=" + 串(分数))
        自.成绩.追加(分数)

    段 平均分(自) -> 数:
        若 自.成绩.长度 == 0:
            返 0
        返 自.成绩.求和() / 自.成绩.长度

    段 评级(自) -> 串:
        返 等级评定(自.平均分())

    段 __str__(自) -> 串:
        返 "{自.姓名}({自.年龄}岁,平均{自.平均分()})"

#
# 大学生子类
#
类 大学生 承 学生:
    设 专业: 串

    段 __init__(自, 姓名: 串, 年龄: 数, 专业: 串):
        超.__init__(姓名, 年龄)
        自.专业 = 专业

    段 __str__(自) -> 串:
        返 超.__str__() + "," + 自.专业

#
# 等级评定函数(可独立使用)
#
段 等级评定(分数: 数) -> 串:
    配 真:
        情况 分数 >= 90: 返 "优"
        情况 分数 >= 80: 返 "良"
        情况 分数 >= 70: 返 "中"
        情况 分数 >= 60: 返 "及格"
        其他: 返 "差"

#
# 批量统计
#
段 成绩统计(学生列表: 列) -> 典:
    设 统计: 典 = {
        "总人数": 0,
        "等级分布": {"优": 0, "良": 0, "中": 0, "及格": 0, "差": 0},
        "平均分": 0.0
    }
    设 总分: 数 = 0
    遍 学生列表 之为 s:
        设 统计["总人数"] 为 统计["总人数"] + 1
        设 总分 为 总分 + s.平均分()
        设 等级 为 s.评级()
        设 统计["等级分布"][等级] 为 统计["等级分布"][等级] + 1
    若 统计["总人数"] > 0:
        设 统计["平均分"] 为 总分 / 统计["总人数"]
    返 统计

#
# 主函数(可选)
#
段 主() -> 空:
    // 创建学生
    设 名单: 列 = [学生("张三", 18), 学生("李四", 19), 大学生("王五", 21, "计算机科学")]
    // 加成绩
    名单[0].添加成绩(85)
    名单[0].添加成绩(92)
    名单[1].添加成绩(78)
    名单[2].添加成绩(95)
    名单[2].添加成绩(88)
    // 输出
    遍 名单 之为 s:
        打印(串(s) + ",等级:" + s.评级())
    打印("统计:" + 串(成绩统计(名单)))

// 脚本运行时入口
若 __名称__ == "__主__":
    主()
```
