# 桥接测试规范

> 版本：v1.0（2026-08-06）
> 依据：`三个月工作计划_2026Q3Q4.md` 第 3.1.2 节「duanpub 桥接测试真实性修复」
> 状态：已落地执行（10 个已桥接包 68 个测试全部真实通过）

## 1. 目的

保证 duanpub 桥接包的**测试真实性**：每个桥接包测试必须是「导入 → 调用 → 结果验证」的全链路真实执行，不允许 mock、不允许跳过失败、不允许修改期望值冒充修 bug。

## 2. 适用范围

- 已桥接的 10 个包：P0（文件系统、JSON、CSV、正则表达式、日期时间、数学运算、加密）+ P1（HTTP客户端、Socket、SQLite）
- 后续新增的所有 duanpub 桥接包

## 3. 硬性要求

### 3.1 真实性（禁止项）

| 禁止行为 | 说明 |
|---|---|
| Mock 桩函数 | 测试必须调用真实桥接模块代码，不得用 mock 替换被测函数 |
| SkipTest 跳过失败 | 环境缺失（如无网络）可用 `skipIf` 显式标记，失败测试不得跳过 |
| 修改期望值 | 期望值必须来自规范/标准库真实行为（如 `MD5哈希('abc') == 900150...`），不得为了通过而改断言 |
| 模块级脚本 | 测试必须能被 pytest 收集（`test_` 函数 / `Test` 类），禁止无测试函数的「虚假通过」脚本 |

### 3.2 覆盖度

- 每个桥接包 ≥ 3 个真实功能测试
- 每个测试至少覆盖一个公开函数，包含输入 → 输出断言

### 3.3 文件组织

- P1 包测试：`tests/test_duanpub_bridge.py`（HTTP客户端 / Socket / SQLite）
- P0 包测试：`tests/test_duanpub_bridge_p0.py`（文件系统 / JSON / CSV / 正则表达式 / 日期时间 / 数学运算 / 加密）
- 新包测试：新建 `tests/test_duanpub_bridge_<包名>.py` 或追加到上述文件对应类

## 4. 编写模板

```python
"""测试 <包名> 桥接模块"""
import sys
import os
import unittest

sys.path.insert(0, os.path.join(os.path.dirname(__file__), '..', 'stdlib'))


class Test<包名>Bridge(unittest.TestCase):
    """测试 <包名> 桥接模块"""

    @classmethod
    def setUpClass(cls):
        from duanpub import <包名>
        cls.mod = <包名>

    def test_导入(self):
        self.assertIsNotNone(self.mod)

    def test_<功能1>(self):
        result = self.mod.<功能1>(参数)
        self.assertEqual(result, 期望值)

    def test_<功能2>(self):
        ...
```

## 5. 网络依赖处理

依赖外部网络的测试（如 HTTP 请求）使用 `unittest.skipIf` 显式标记：

```python
@unittest.skipIf(not _has_network(), "无网络连接")
def test_HTTP获取(self):
    resp = self.mod.HTTP获取('https://httpbin.org/get')
    ...
```

`_has_network()` 须真实探测（连接超时），不得恒定返回 `True`/`False`。

## 6. 验收标准

1. `python -m pytest tests/test_duanpub_bridge.py tests/test_duanpub_bridge_p0.py -q` 全部通过，无跳过（除显式网络标记）
2. 新桥接包合入前必须附带本规范要求的测试
3. 全量回归：`python -m pytest tests -q` 无新增失败
