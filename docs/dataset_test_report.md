#### 示例 2：定义一个狗类，继承动物类并重写说话方法

**错误**：类定义后缺少冒号或括号语法问题

---

#### 示例 3：使用三元表达式判断一个数是奇数还是偶数

**问题**：三元表达式不被支持
**错误**：`数字 % 2 == 0 ? "偶数" : "奇数"`
**原因**：光明语言不支持 `? :` 三元表达式语法
**修复**：改用 `如果...否则如果...否则` 结构

**正确写法**：
```光明
设 数字 为 7
设 结果 为 空
如果 数字 % 2 == 0：
    设 结果 为 "偶数"
否则如果 数字 % 2 == 1：
    设 结果 为 "奇数"
打印(转字符串(数字) + " 是 " + 结果)
```

## 发现的问题汇总

### 1. 导入语句错误（2个案例）

**错误模式**：`从 模块 导导入 函数`

**正确写法**：`从 模块 导入 函数`

**影响范围**：所有使用 `从...导入...` 的示例

**修复方案**：全局替换 `导导入` 为空字符串

---

### 2. 三元表达式语法（1个案例）

**错误模式**：`条件 ? 真 : 假`

**正确写法**：使用 `如果...否则如果...否则` 结构

**影响范围**：所有使用三元表达式的示例

**修复方案**：将三元表达式转换为 if-else 结构

---

**正确写法**：确保类定义使用正确的冒号和缩进

**修复方案**：检查并修复类定义语法
