# 续行规则（括号外跨行表达式）— T-0198 / LH-22 / LH-18b

> 本文件是 T-0198 的落点段落。`docs/AI编程指南.md` 的续行章节归另一张卡，勿在此重复维护。

## 一、合法续行的三种形态

光明没有「行尾加分号」这类显式语句终止符，语句边界由换行 + 缩进决定。因此**一个表达式要跨行，必须给出明确的续行标记**，否则下一行会被当成新语句。目前有三种：

### 1. 括号内跨行（一直支持）

括号 `(` `[` `{`（字面量括号）内的换行是普通空白，不需要任何标记：

```light
设 表 为 ["甲": 1,
        "乙": 2]

设 串 为 ("a" 加上
         "b")
```

### 2. 行尾运算符续行（L-023，词法层软续行）

上一行**以二元运算符结尾**时自动续行，与 Python 的隐式续行同义——运算符在语法上强制要求右操作数，合并不会改变任何合法程序的语义：

```light
设 负载 为 "a" 加上
           "b" 加上
           "c"
```

支持的行尾运算符：`加 减 乘 除 取余 模 幂 乘以 除以 整除 加上 减去 模以 幂以 等于 大于 小于 不等于 大于等于 小于等于 不小于 不大于 且 或`，以及符号 `+ - * / % < > <= >= == !=`。

### 3. 行首运算符续行（T-0198 新增）

上一行**语法完整**、本行**以二元运算符开头**、且本行缩进**比上一行更深**时自动续行：

```light
打印 "前半段"
    加上 "后半段"      # → 打印 "前半段后半段"
```

三个条件缺一不可，都是为了让「合并」只发生在不可能改变合法程序语义的位置：

| 条件 | 作用 |
|---|---|
| 上一行末尾是字面量 / 标识符 / 闭括号 / `真 假 空 无` | 上一行已是完整表达式；块头以「：」结尾，天然不在白名单内 |
| 本行首个词是二元运算符关键字 | 该词是保留字，不可能作为语句开头 |
| 本行缩进严格深于语句行 | 同级行仍是独立语句边界（`设 甲 为 1` / `加上 2` 不会被误并） |

续行行的前导缩进**不参与**缩进栈计算——块结构从原理上不可能被打断。

### 4. 反斜杠续行（T-0198 新增，LH-18b）

行末写 `\`（其后到行尾只能是空白）表示下一行接上：

```light
设 甲 为 "a"
设 乙 为 甲 加上 \
  "b"                # → 乙 == "ab"
```

`\` 只在**字符串外**、且**其后到行尾全是空白**时才是续行符：

- 字符串里的 `\n` `\t` `\\` 是转义，不是续行（两者互不影响）；
- 注释里的 `\` 属于注释内容，整行被注释吞掉；
- 行中其他位置的 `\` 仍是「意外的标记」。

## 二、不支持的形态与报错口径

```light
打印 "a"
加上 "b"        # 同级缩进：不加缩进就看不出意图，按新语句处理（报错）
```

```light
设 甲 为
    加上 "b"    # 上一行没写完（末尾是「为」）→ 不能续行，报错
```

上面第二种形态下，报错文案**不再只提缩进**，而是追加：

```
（疑似续行：本行以运算符「加上」开头，光明不支持括号外跨行表达式。
请把整个表达式放进括号，或先落到临时变量。）
```

同时，聚合报错里「缩进不正确」这类**级联回声**会被排到最后（判据：该条错误的上一行另有一条非回声错误），保证「错误 1/N」恒指向真因——否则看的人会去改缩进，改三遍都不对。

## 三、异常链（LH-12）

运行期异常跨模块抛出时，报错在位置块之后追加**最短异常链**：

```
错误: 除零错误
  （位置: …\依赖.light:2，模块「依赖」）
  异常链（抛出点 → 调用点）: 依赖.light:2 → 主.light:2
```

只有链上 ≥2 跳可归因时才输出；单帧报错一字不加。跳数 >4 时只保留两端（中间 `…`）——这条链用来指明方向，不是调用栈转储。
