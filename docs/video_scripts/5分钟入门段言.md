# 《5 分钟入门段言》视频脚本

> **版本：** v6.0
> **时长：** 5 分钟
> **适用对象：** 编程零基础用户

---

## 片头（0:00 - 0:15）

**画面：** 段言 Logo 动画 + 标题「5 分钟入门段言」

**旁白：**
"段言，一门用中文编程的语言。5 分钟，让你写出第一个程序。"

---

## 第1幕：段言是什么（0:15 - 0:50）

**画面：** 对比展示 Python 代码和段言代码

```
# Python
name = "张三"
age = 25
print(name)

# 段言
设 姓名 为 "张三"
设 年龄 为 25
打印 姓名
```

**旁白：**
"段言是一门中文编程语言。所有关键字都是中文——设变量、打印输出、如果判断条件。你不需要懂英语，就能写代码。"

**画面：** 展示特性列表动画
- 中文关键字
- 标准库丰富
- 支持 LLVM 原生编译
- 内置 AI 辅助

**旁白：**
"它内置了 60 多个标准库模块，支持 LLVM 原生编译，还有 AI 辅助工具。但今天，我们只做一件事——安装并运行第一个程序。"

## 第4幕：基础语法（2:30 - 3:30）

**画面：** 展示变量、条件、循环代码

```段言
# 变量
设 名字 为 "小明"
设 年龄 为 18

# 条件
如果 年龄 >= 18：
    打印 "成年"
否则：
    打印 "未成年"

# 循环
遍历 i 在 1 到 5：
    打印 i
```

**旁白：**
"接下来看看基础语法。设 变量 为 值——声明变量。如果 条件：——做判断。遍历 项 在 范围：——循环。这些关键字都是中文，非常直观。"

**画面：** 代码逐行高亮，解释每个关键字

**旁白：**
"你不需要记住任何英文单词。段言的设计目标就是让中文使用者零门槛上手编程。"

## 技术说明

- **视频分辨率：** 1920×1080
- **帧率：** 30fps
- **配色方案：** 段言品牌色（蓝色 #2563EB、白色 #FFFFFF）
- **代码字体：** JetBrains Mono 或等宽字体
- **背景音乐：** 轻快、无版权音乐
- **字幕：** 中文简体 + 英文字幕（可选）
