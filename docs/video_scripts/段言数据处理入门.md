    设 副本 为 复制字典(记录)
    
    # 检查必要字段

    # 修复数据类型
    # 数量转整数
    尝试:
        副本["数量"] = 转整数(副本["数量"])
    捕获:
        返回 空  # 数量不是有效数字，丢弃
    
    # 单价转整数
    尝试:
        副本["单价"] = 转整数(副本["单价"])

段落 过滤金额大于 接收 数据, 最小金额:
    设 过滤结果 为 []
    
    遍历 数据 为 记录:
        如果 记录["金额"] > 最小金额:
            过滤结果.追加(记录)
    
    打印 "过滤结果：金额大于 " + 转字符串(最小金额) + " 的记录有 " + 转字符串(长度(过滤结果)) + " 条"
    返回 过滤结果

# 数据排序
段落 排序数据 接收 数据, 排序字段, 升序 = 真:
    设 排序后 为 复制列表(数据)
    设 长度 为 长度(排序后)
    
    # 简单冒泡排序
    设 i 为 0
    当 i < 长度:
        设 j 为 0
        当 j < 长度 - i - 1:
            设 甲 为 排序后[j][排序字段]
            设 乙 为 排序后[j + 1][排序字段]
            
            如果 升序:
                如果 甲 > 乙:
                    设 临时 为 排序后[j]
                    排序后[j] = 排序后[j + 1]
                    排序后[j + 1] = 临时
            否则:
                如果 甲 < 乙:
                    设 临时 为 排序后[j]
                    排序后[j] = 排序后[j + 1]
                    排序后[j + 1] = 临时
            
            j = j + 1
        i = i + 1
    
    打印 "排序完成，按 " + 排序字段 + " " + ("升序" 如果 升序 否则 "降序")
    返回 排序后

段落 复制列表 接收 源:
    设 新列表 为 []

            行.追加(值)
        CSV内容 = CSV内容 + 行.连接(",") + "\n"
