```段言
从 贡献.HTTP服务端 导入 路由, 响应, 请求
从 模型 导入 博客, 文章列表, 下一个ID

    # API 路由
```

### 2.3 POST 请求处理（10:00 - 12:00）

**画面：** 编写 API 处理函数

```段言
# 在 路由.duan 中继续

段落 API创建文章 接收 请求：
    尝试：
        设 数据 为 解析JSON(请求.主体)
        
        设 标题 为 数据["标题"]
        设 内容 为 数据["内容"]
        设 作者 为 数据["作者"]
        
        如果 标题 == "" 或 内容 == ""：
```

"POST 处理函数接收 JSON 格式的请求体。首先解析 JSON，提取标题、内容和作者字段。加入数据验证——如果标题或内容为空，返回 400 错误。验证通过后调用创建文章函数，返回 201 状态码和创建的文章数据。"

**代码高亮：** 数据验证逻辑

**旁白：**
"使用 `尝试/捕获` 包裹整个处理逻辑，确保 JSON 解析失败时返回友好的错误信息，而不是让服务器崩溃。"

**关键点强调：**
- 请求体 JSON 解析
- 输入验证

```段言
段落 文章详情 接收 请求：

    设 文章 为 获取文章(文章ID)
    
    如果 文章 为空：

    HTML = HTML + "<div class='内容'>" + 文章["内容"].替换("\n", "<br>") + "</div>"
    HTML = HTML + "<a href='/'>← 返回首页</a>"
    HTML = HTML + "</article></body></html>"
    
    返回 响应(200, {"内容类型": "text/html"}, HTML)

# API 文章详情
段落 API文章详情 接收 请求：
```

**关键点强调：**
- `请求.参数` 获取路径参数
- 404 处理
- 页面路由 vs API 路由的响应格式差异
