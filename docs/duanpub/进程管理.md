## 函数列表

共 16 个公开函数

> 进程管理 — duanpub 桥接模块
> 
> 基于 Python subprocess/os 库封装，函数名对齐 duanpub/packages/进程管理/源.duan。
> 
> duanpub 原始包通过 C FFI 直接调用操作系统进程 API，
> 本桥接模块用 Python subprocess/os 模块替代，提供等价的进程管理功能。
