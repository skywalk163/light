## 函数列表

共 47 个公开函数

> 数据导入导出 — duanpub 桥接模块
> 
> 基于 Python csv / json / xml / yaml / configparser 库封装，函数名对齐 duanpub/packages/数据导入导出/源.duan。
> 
> duanpub 原始包通过 C FFI 实现多种数据格式解析，
> 本桥接模块用 Python 标准库替代，提供等价的读写功能。
