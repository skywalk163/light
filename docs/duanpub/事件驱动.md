## 函数列表

共 6 个公开函数

> 事件驱动 — duanpub 桥接模块
> 
> 基于 Python asyncio 库封装，函数名对齐 duanpub/packages/事件驱动/源.duan。
> 
> duanpub 原始包通过 C FFI 实现事件驱动编程模型，
> 本桥接模块用 Python asyncio 模块替代，提供等价的 EventEmitter 功能。

### 创建事件循环

创建新的事件循环，返回事件循环对象

### 事件循环添加事件

**参数:** `loop, event_name, callback`

向事件循环添加事件监听器

### 事件循环运行

**参数:** `loop`

运行事件循环

### 事件循环停止

**参数:** `loop`

停止事件循环

### 创建事件

**参数:** `event_name, data`

创建事件对象

### 触发事件

**参数:** `loop, event_name, data`

触发事件，调用所有注册的监听器
