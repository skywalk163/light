## 函数列表

共 6 个公开函数

> 连接池 — duanpub 桥接模块
> 
> 基于 Python queue 库封装，函数名对齐 duanpub/packages/连接池/源.duan。
> 
> duanpub 原始包通过 C FFI 实现数据库连接池，
> 本桥接模块用 Python queue 模块替代，提供等价的连接池功能。

### 创建连接池

**参数:** `factory, min_size, max_size`

创建连接池

Args:
    factory: 创建连接的可调用对象
    min_size: 最小连接数
    max_size: 最大连接数
