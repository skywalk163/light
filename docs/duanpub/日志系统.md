## 函数列表

共 8 个公开函数

> 日志系统 — duanpub 桥接模块
> 
> 基于 Python logging 库封装，函数名对齐 duanpub/packages/日志系统/源.duan。
> 
> duanpub 原始包通过 C FFI 调用系统日志接口，
> 本桥接模块用 Python logging 模块替代，提供等价的日志功能。

### 创建日志器

**参数:** `名称, 级别, 格式, 输出文件`

创建或获取指定名称的日志器

### 日志器记录

**参数:** `logger, 级别, 消息`

日志器记录指定级别的日志

### 日志器调试

**参数:** `logger, 消息`

### 日志器信息

**参数:** `logger, 消息`

### 日志器警告

**参数:** `logger, 消息`

### 日志器错误

### 日志器设置级别

**参数:** `logger, 级别`
