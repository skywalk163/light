## 函数列表

共 20 个公开函数

> 路径处理 — duanpub 桥接模块
> 
> 基于 Python os.path / pathlib / glob 库封装，函数名对齐 duanpub/packages/路径处理/源.duan。
> 
> duanpub 原始包通过 C FFI 直接调用操作系统路径处理 API，
> 本桥接模块用 Python os.path/pathlib/glob 模块替代，提供等价的路径操作功能。

**参数:** `路径`

**参数:** `路径, 起始`
