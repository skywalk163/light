## 函数列表

共 56 个公开函数

> JSON — duanpub 桥接模块
> 
> 基于 Python json 库封装，函数名对齐 duanpub/packages/JSON/源.duan。
> 
> duanpub 原始包通过 C FFI 实现自研 JSON 解析器，
> 本桥接模块用 Python json 模块替代，提供等价的 JSON 解析与序列化功能。
> 函数签名与 duanpub 包保持一致。
