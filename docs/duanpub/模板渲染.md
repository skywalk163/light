**关键词:** 模板, 渲染, 布局, 继承, 过滤器

```duan
导入 模板渲染
```

或

```duan
导入 标准模板渲染
```

## 函数列表

共 45 个公开函数

> 模板渲染 — duanpub 桥接模块
> 
> 基于 Python string.Template / html / re 等库封装，
> 函数名对齐 duanpub/packages/模板渲染/源.duan。
> 
> duanpub 原始包通过 C FFI 实现模板引擎，
> 本桥接模块用 Python 标准库替代，提供等价的模板渲染功能。
