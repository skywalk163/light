## 函数列表

共 35 个公开函数

> 网络工具 — duanpub 桥接模块
> 
> 基于 Python ipaddress / socket 库封装，函数名对齐 duanpub/packages/网络工具/源.duan。
> 
> duanpub 原始包通过 C FFI 直接调用系统网络 API，
> 本桥接模块用 Python ipaddress/socket 模块替代，提供等价的网络工具功能。
