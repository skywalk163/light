## 函数列表

共 8 个公开函数

> 正则表达式 — duanpub 桥接模块
> 
> 基于 Python re 库封装，函数名对齐 duanpub/packages/正则表达式/源.duan。
> 
> duanpub 原始包通过 C FFI 调用 PCRE2 库，
> 本桥接模块用 Python re 模块替代，提供等价的正则匹配、替换、捕获组功能。

### MatchResultGroup

**参数:** `match, 组号`

获取匹配结果的捕获组

### RegexObjNew

**参数:** `模式, 标志`

创建正则对象

### RegexObjIsMatch

**参数:** `regex, 文本`

判断是否匹配

### RegexObjSearch

**参数:** `regex, 文本`

搜索第一个匹配，返回 MatchResult

### RegexObjSearchAll

**参数:** `regex, 文本`

搜索所有匹配，返回 MatchResult 列表

### RegexObjReplace

**参数:** `regex, 文本, 替换内容, 次数`

替换匹配内容

### RegexObjSplit

**参数:** `regex, 文本, 最大分割`

按正则分割字符串

### RegexObjFree

**参数:** `regex`

释放正则对象
