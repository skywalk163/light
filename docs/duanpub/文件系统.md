## 函数列表

共 25 个公开函数

> 文件系统 — duanpub 桥接模块
> 
> 基于 Python os / shutil / pathlib 库封装，函数名对齐 duanpub/packages/文件系统/源.duan。
> 
> duanpub 原始包通过 C FFI 直接调用操作系统文件 API，
> 本桥接模块用 Python os/shutil/pathlib 模块替代，提供等价的文件系统操作功能。

### 读取文件

**参数:** `文件路径, 编码`

读取文件全部内容，返回字符串

### 写入文件

**参数:** `文件路径, 内容, 编码`

写入文件（覆盖），返回 True/False

### 追加写入

**参数:** `文件路径, 内容, 编码`

追加写入文件，返回 True/False

### 按行读取

**参数:** `文件路径, 编码`

按行读取文件，返回字符串列表

### 按字节读取

**参数:** `文件路径, 最大长度`

按字节读取文件，返回 bytes

### 文件是否存在

**参数:** `路径`

### 文件大小

### 删除文件
