## 函数列表

共 36 个公开函数

> 证书 — duanpub 桥接模块
> 
> 基于 Python ssl / hashlib / datetime 库封装，函数名对齐 duanpub/packages/证书/源.duan。
> 
> duanpub 原始包通过 C FFI 调用 OpenSSL X.509 证书库，
> 本桥接模块用 Python ssl 和 crypto 相关标准库替代，
> 提供证书解析与操作功能。
