## 函数列表

共 32 个公开函数

> 哈希 — duanpub 桥接模块
> 
> 基于 Python hashlib / hmac 库封装，函数名对齐 duanpub/packages/哈希/源.duan。
> 
> duanpub 原始包通过 C FFI 调用 OpenSSL 库，
> 本桥接模块用 Python hashlib/hmac 模块替代，提供等价的哈希与 HMAC 功能。
