## 函数列表

共 7 个公开函数

> 随机数 — duanpub 桥接模块
> 
> 基于 Python random 库封装，函数名对齐 duanpub/packages/随机数/源.duan。
> 
> duanpub 原始包通过 C FFI 直接调用操作系统随机数 API，
> 本桥接模块用 Python random 模块替代，提供等价的随机数生成功能。

### 设置种子

**参数:** `种子`

设置随机数生成器的种子

### 随机整数

**参数:** `最小值, 最大值`

生成指定范围内的随机整数，包含两端

### 随机浮点数

**参数:** `最小值, 最大值`

生成指定范围内的随机浮点数

### 随机选择

**参数:** `序列`

从序列中随机选择一个元素

### 随机打乱

**参数:** `序列`

随机打乱序列（原地操作）

### 均匀采样

**参数:** `总体, 样本数`

从总体中均匀随机采样（无放回）

### 正态采样

**参数:** `均值, 标准差`

从正态分布中采样一个随机数
