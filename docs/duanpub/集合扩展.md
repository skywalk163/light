## 函数列表

共 15 个公开函数

> 集合扩展 — duanpub 桥接模块
> 
> 基于 Python itertools / collections 库封装，函数名对齐 duanpub/packages/集合扩展/源.duan。
> 
> duanpub 原始包通过 C FFI 实现集合操作，
> 本桥接模块用 Python 内置函数和标准库替代，提供等价的列表、字典、集合扩展操作功能。

### 列表_排序

**参数:** `列表, 反转, 键`

排序列表，返回新列表

### 列表_过滤

**参数:** `列表, 条件函数`

过滤列表，返回满足条件的元素新列表

### 列表_映射

**参数:** `列表, 转换函数`

对列表每个元素应用转换函数，返回新列表

### 列表_去重

**参数:** `列表, 键`

列表去重，保持顺序，返回新列表

### 列表_分组

**参数:** `列表, 键函数`

按指定键函数对列表分组，返回{键: [元素列表]}

### 列表_分块

**参数:** `列表, 块大小`

将列表分块为指定大小的子列表

### 列表_扁平化

**参数:** `嵌套列表`

将嵌套列表扁平化为一层

### 列表_复制

**参数:** `列表`

复制列表（浅拷贝）

### 字典_合并

合并多个字典，返回新字典（后面的覆盖前面的）

### 字典_获取键组

**参数:** `字典, 键列表`

从字典中获取指定键的键值对，返回新字典

### 字典_获取值组

**参数:** `字典, 键列表, 默认值`

从字典中获取指定键的值列表

### 字典_过滤

**参数:** `字典, 条件函数`

过滤字典中满足条件的键值对，返回新字典

### 集合_交集

**参数:** `集合1, 集合2`

返回两个集合的交集

### 集合_并集

**参数:** `集合1, 集合2`

返回两个集合的并集

### 集合_差集

**参数:** `集合1, 集合2`

返回两个集合的差集（在集合1中但不在集合2中）
