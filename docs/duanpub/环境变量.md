## 函数列表

共 15 个公开函数

> 环境变量 — duanpub 桥接模块
> 
> 基于 Python os.environ / os.path 库封装，函数名对齐 duanpub/packages/环境变量/源.duan。
> 
> duanpub 原始包通过 C FFI 直接调用操作系统环境变量 API，
> 本桥接模块用 Python os 模块替代，提供等价的系统环境变量操作功能。

### 获取环境变量

**参数:** `键, 默认值`

获取环境变量值，不存在返回默认值

### 设置环境变量

**参数:** `键, 值`

设置环境变量

### 删除环境变量

**参数:** `键`

删除环境变量

### 环境变量是否存在

**参数:** `键`

检查环境变量是否存在

### 列出全部环境变量

列出所有环境变量的键值对列表，返回[(键, 值), ...]

### 获取环境变量或抛出

**参数:** `键`

获取环境变量值，不存在则抛出异常

### 展开环境变量

**参数:** `文本`

展开文本中的环境变量引用，如 $VAR 或 %VAR%

### 解析env文本

**参数:** `文本`

解析环境变量文本，返回{键: 值}字典

### 解析env文件

**参数:** `文件路径`

从文件解析环境变量，返回{键: 值}字典

### 加载env文件

**参数:** `文件路径`

加载env文件到当前环境变量

### 获取环境变量整数

**参数:** `键, 默认值`

获取环境变量值并转为整数

### 获取环境变量布尔

**参数:** `键, 默认值`

获取环境变量值并转为布尔

### 获取环境变量列表

**参数:** `键, 分隔符, 默认值`

### 环境变量到字符串

将所有环境变量转为字符串

### 范围

**参数:** `开始, 结束`

返回指定范围的整数列表
