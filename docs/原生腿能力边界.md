## 0. 一句话

原生腿（LLVM）**只认它分派链里列出的节点**。链尾一律 `NotImplementedError`
带源码行号 + 转译后端指路；拼错名字的段落调用会列出本模块已定义候选。
**没有任何「编译成功、产物行为错误」的静默降级留在表达式层。**

网络层（B1-B4）同样遵循此原则：POSIX TLS 不支持时返回明确错误码，不静默失败。

## 1. 语句层

### 1.1 已支持（`_gen_statement`，`:2746` 起）

| 节点 | 说明 |
|---|---|
| `VariableDeclaration` | `设 X 为 值。` |
| `Assignment` | `X 为 值。`（含属性/成员赋值） |
| `SelfAssignment` / `CompoundAssignment` | `+=`、`己.x 为 …` 等 |
| `IfStatement` | `如果 …` |
| `ForeachStatement` | `遍历 … 于 …` |
| `WhileStatement` | `当 …` |
| `ReturnStatement` | `返回 …` |
| `BreakStatement` / `ContinueStatement` | 循环跳转 |
| `PrintStatement` | `打印 …` |
| `TryStatement` / `ThrowStatement` | 异常 |
| `ExpressionStatement` | 表达式语句（含适配层 `<unknown:XXX>` 揭穿，见 §4） |
| `ImportStatement` | 当 no-op（`:2785 pass`） |
| `AsyncScope` | `异步 作用域` |

模块层（`generate`，`:714`）额外支持：类定义（`_collect_class`，`:2501`）、
接口定义、段落定义、导出别名。

### 1.2 已支持运算符（`_gen_typed_binary_op`，`:959` 起）

算术：`+ - * / % **` 及 `加 减 乘 除 模 幂`、`整除`（`//`，C3-1 补）
比较：`== != < > <= >=` 及 `等于 不等于 小于 大于 小于等于 大于等于`
逻辑：`and or`
连接：`连接`
未知运算符：链尾报错（C3-1，不再静默变 `dv_add`）。

### 1.3 不支持（走链尾 else，`:2789` 报错；或适配层揭穿后报错）

| 节点 | 源码写法 | 处理 |
|---|---|---|
| `ScopeDeclStmt` | `全局 X` / `外层 X` | 报错 |
| `YieldStmt` | `生成 X` | 报错 |
| `TypeAlias` | `类型 X = Y` | 报错 |
| `DecoratedFunction` | `@装饰 段落 …` | 报错（转译后端支持） |
| `AssertStmt` | `断言 …` | 报错 |
| `RunAsyncStmt` | `异步 运行 …` | 报错（转译后端支持） |
| `EmbedBlock` | 嵌入块 | 报错 |
| `ClassDefinitionWithNested` | 嵌套类 | 报错 |
| `SetLiteral`（语句位） | `设 X 为 {1,2}` | 报错 |
| `PassStmt` | `pass` | **编成空操作**（C3-4，不走报错） |

## 3. 明确不做的特性与替代（C3-2 决策）

| 特性 | 原生腿 | 替代 |
|---|---|---|
| 切片 `表[1:2]` | 不做 | `截取`/`子串` 或转译后端 |
| Lambda / 推导式 / Pipeline / 解包 | 不做 | 转译后端（`python -m cli.light_unified run`） |
| 异步文件原语 `异步读取文件` 等 | 编译期报错（C3-7） | 同步 `读取文件`/`写入文件`/`追加文件`，或等 stdlib |

## 4. 适配层伪装揭穿

`AstAdapter`（`src/compiler.py`）对它不认识的 v3 节点包成
`Identifier("<unknown:XXX>")`。原生腿在**语句位**（`_gen_statement`
`ExpressionStatement` 分支）与**表达式位**（`_gen_expression` `Identifier` 分支）
都用 `_ADAPTER_UNKNOWN_PREFIX`（`:2680`）拆开，报出原 v3 类型名——`<unknown:DictLiteral>`
不会报成「未定义变量」。

## 7. B3 事件循环（runtime_typed.c:4858-5074）

### 7.1 能力面

`dv_scheduler_run_event_loop`（:5004）是原生腿的真事件循环，实现：

1. **IO 等待队列**（:4858-4920）：协程挂起等待 fd 读写时入队，poller 返回就绪后唤醒。
2. **定时器最小堆**（:4922-4970）：`dv_coro_sleep` 注册的定时器按到期时间排序。
3. **事件循环主体**（:4975-5074）：循环 `dv_poller_wait` → 检查定时器 → 唤醒就绪协程 → 检查退出条件。

### 7.2 协程模型

- **最大协程数**: 4096（`DV_MAX_COROUTINES`，:4047），不是 256。
- **实现方式**: 单线程 Duff's device，codegen 发 IR。
  - 入口 switch：`codegen_typed.py:3459-3475`
  - 挂起点：`codegen_typed.py:3634-3651`
  - **注意**: Duff's device 在 codegen 层，不在 runtime 层。
- **线程模型**: 单线程，无 pthread。
- **`await_io`**: 协程挂起等待 IO 就绪（`dv_coro_await_io`）。
- **`sleep`**: 协程挂起指定毫秒后恢复（`dv_coro_sleep`）。

### 7.3 内置函数入口

`运行事件循环`/`run_event_loop`（:1844）、`睡眠`/`sleep`（:1848）、`await_io`（:1852）。

### 7.4 真跑判据

`tests/test_llvm_async.py` 以真编译 + 真运行验证协程调度与事件循环。
`tests/test_llvm_net.py` 验证 socket + 事件循环联合工作。

## 8. B2-4 TLS（runtime_typed.c:5076-5779）

### 8.1 平台裁决（B7 首日裁决，2026-08-24）

**取「显式降级」方案**：

- **Windows**: Schannel 后端，真实现（:5111-5745）。
- **POSIX**: **不支持 TLS**。`dv_tls_*` 返回 `DV_TLS_ERROR` (-1) 并设置 `g_tls_error`
  错误文本为「本平台未实现原生 TLS：当前只有 Windows Schannel 后端（POSIX 待补 mbedTLS）」。
  `dv_tls_backend()` 返回 `"none"`。

**不静默失败**——调用方会拿到明确的错误码和可读错误文本。

改选引 OpenSSL/mbedTLS 必须先拿用户裁决（依赖红线）。

### 8.2 运行时符号

| 符号 | 声明行 (codegen) | 定义行 (runtime) | Windows | POSIX |
|---|---|---|---|---|
| `dv_tls_wrap` | :455 | :5081 | Schannel 上下文创建 | 返回 NULL |
| `dv_tls_handshake` | :456 | :5111 | Schannel 握手 | 返回 DV_TLS_ERROR |
| `dv_tls_send` | :457 | :5200 | Schannel 加密发送 | 返回 DV_TLS_ERROR |
| `dv_tls_recv` | :458 | :5280 | Schannel 解密接收 | 返回 DV_TLS_ERROR |
| `dv_tls_free` | :459 | :5350 | 释放上下文 | no-op |
| `dv_tls_last_error` | :460 | :5740 | 取错误文本 | 返回 g_tls_error |
| `dv_tls_backend` | :461 | :5745 | 返回 "schannel" | 返回 "none" |
| `dv_tls_set_verify` | :462 | :5370 | 设置证书校验模式 | 返回 DV_TLS_ERROR |
| `dv_tls_add_trusted_cert_file` | :463 | :5400 | 添加信任证书 | 返回 DV_TLS_ERROR |
| `dv_tls_is_ready` | :464 | :5420 | 检查握手是否完成 | 返回 0 |
| `dv_tls_want_event` | :465 | :5430 | 返回所需 IO 事件 | 返回 0 |

### 8.3 POSIX 降级桩（:5747-5778）

`dv_tls_unsupported()`（:5747）写入 `g_tls_error` 错误文本，所有 POSIX TLS 函数桩
调用它后返回错误码。这保证 POSIX 上的 TLS 调用方拿到可读错误而非段错误。

### 8.4 内置函数入口

`包装tls`/`tls_wrap`（:1902）、`握手tls`/`tls_handshake`（:1923）、
`发送tls`/`tls_send`（:1940）、`接收tls`/`tls_recv`（:1955）、
`释放tls`/`tls_free`（:1989）、`错误tls`/`tls_last_error`（:2000）等，共 26 个别名。

### 8.5 真跑判据

`tests/test_llvm_tls.py` 已有 `仅Windows`/`仅POSIX` mark：
- Windows 用例：真编译 + 真运行验证 Schannel TLS 回环。
- POSIX 用例：验证降级桩返回正确错误码（:286-310）。
