# 原生腿能力边界表（C3-3）

> **这张表是给 A3/B3 与后来者的地图。** 第二轮的能力边界靠读源码猜；这轮把它
> 变成**源码级守单点**：`tests/unit/test_native_leg_capability.py` 会读
> `src/llvm/codegen_typed.py` 的分派链，与下文「已支持」清单比对——**加了新节点
> 忘了更这张表，测试就打红**。
>
> 证据行号指向 `src/llvm/codegen_typed.py`（2026-08-22 快照，改后会漂移；
> 权威判据是 grep `isinstance(.*ast\.)` 所在的两条链）。

## 0. 一句话

原生腿（LLVM）**只认它分派链里列出的节点**。链尾一律 `NotImplementedError`
带源码行号 + 转译后端指路；拼错名字的段落调用会列出本模块已定义候选。
**没有任何「编译成功、产物行为错误」的静默降级留在表达式层。**

## 1. 语句层

### 1.1 已支持（`_gen_statement`，`:2746` 起）

| 节点 | 说明 |
|---|---|
| `VariableDeclaration` | `设 X 为 值。` |
| `Assignment` | `X 为 值。`（含属性/成员赋值） |
| `SelfAssignment` / `CompoundAssignment` | `+=`、`己.x 为 …` 等 |
| `IfStatement` | `如果 …` |
| `ForeachStatement` | `遍历 … 于 …` |
| `WhileStatement` | `当 …` |
| `ReturnStatement` | `返回 …` |
| `BreakStatement` / `ContinueStatement` | 循环跳转 |
| `PrintStatement` | `打印 …` |
| `TryStatement` / `ThrowStatement` | 异常 |
| `ExpressionStatement` | 表达式语句（含适配层 `<unknown:XXX>` 揭穿，见 §4） |
| `ImportStatement` | 当 no-op（`:2785 pass`） |
| `AsyncScope` | `异步 作用域` |

模块层（`generate`，`:714`）额外支持：类定义（`_collect_class`，`:2501`）、
接口定义、段落定义、导出别名。

### 1.2 已支持运算符（`_gen_typed_binary_op`，`:959` 起）

算术：`+ - * / % **` 及 `加 减 乘 除 模 幂`、`整除`（`//`，C3-1 补）
比较：`== != < > <= >=` 及 `等于 不等于 小于 大于 小于等于 大于等于`
逻辑：`and or`
连接：`连接`
未知运算符：链尾报错（C3-1，不再静默变 `dv_add`）。

### 1.3 不支持（走链尾 else，`:2789` 报错；或适配层揭穿后报错）

| 节点 | 源码写法 | 处理 |
|---|---|---|
| `ScopeDeclStmt` | `全局 X` / `外层 X` | 报错 |
| `YieldStmt` | `生成 X` | 报错 |
| `TypeAlias` | `类型 X = Y` | 报错 |
| `DecoratedFunction` | `@装饰 段落 …` | 报错（转译后端支持） |
| `AssertStmt` | `断言 …` | 报错 |
| `RunAsyncStmt` | `异步 运行 …` | 报错（转译后端支持） |
| `EmbedBlock` | 嵌入块 | 报错 |
| `ClassDefinitionWithNested` | 嵌套类 | 报错 |
| `SetLiteral`（语句位） | `设 X 为 {1,2}` | 报错 |
| `PassStmt` | `pass` | **编成空操作**（C3-4，不走报错） |

## 2. 表达式层

### 2.1 已支持（`_gen_expression`，`:820` 起）

| 节点 | 说明 |
|---|---|
| `NumberLiteral` / `StringLiteral` / `BooleanLiteral` / `NullLiteral` | 字面量 |
| `Identifier` | 变量引用（含适配层 `<unknown:XXX>` 揭穿） |
| `BinaryOp` / `UnaryOp` | 二元/一元运算 |
| `FunctionCall` / `ParagraphCall` | 内置与段落调用（未知名报错列候选） |
| `IndexAccess` | `X[k]`（列表/字典/字符串） |
| `ListLiteral` | `[1, 2]` |
| `DictLiteral` | `{键: 值}`（**C3-2 新增**） |
| `StringInterpolation` | `` f"…{x}…" ``（**C3-2 新增**，降级为分段拼接） |
| `ConditionalExpression` | 条件表达式 |
| `PropertyAccess` | 成员访问 |
| `ClassInstantiation` / `NewExpression` | 类实例化 |
| `AwaitExpression` | `等待 …` |

### 2.2 不支持（链尾 else，`:916` 报错）

| 节点 | 源码写法 | 处理 |
|---|---|---|
| `ListComprehension` | 列表推导 | 报错 → 转译后端 |
| `DictComprehension` | 字典推导 | 报错 → 转译后端 |
| `SetLiteral`（表达式位） | `{1, 2}` | 报错 → 转译后端 |
| `TupleLiteral` | `(1, 2)` | 报错 → 转译后端 |
| `LambdaExpression` | `接收 X：…` | 报错 → 转译后端 |
| `UnwrapExpression` | `X！`（解包） | 报错 → 转译后端 |
| `Pipeline` | `X -> 映射(函数)` | 报错 → 转译后端 |
| `SliceExpr` | `表[1:2]` | 专用报错 → `截取/子串` 或转译后端（C3-2 决策） |
| `DictExpand` | `{**展开}` | 报错 → 转译后端 |

## 3. 明确不做的特性与替代（C3-2 决策）

| 特性 | 原生腿 | 替代 |
|---|---|---|
| 切片 `表[1:2]` | 不做 | `截取`/`子串` 或转译后端 |
| Lambda / 推导式 / Pipeline / 解包 | 不做 | 转译后端（`python -m cli.light_unified run`） |
| 异步文件原语 `异步读取文件` 等 | 编译期报错（C3-7） | 同步 `读取文件`/`写入文件`/`追加文件`，或等 stdlib |

## 4. 适配层伪装揭穿

`AstAdapter`（`src/compiler.py`）对它不认识的 v3 节点包成
`Identifier("<unknown:XXX>")`。原生腿在**语句位**（`_gen_statement`
`ExpressionStatement` 分支）与**表达式位**（`_gen_expression` `Identifier` 分支）
都用 `_ADAPTER_UNKNOWN_PREFIX`（`:2680`）拆开，报出原 v3 类型名——`<unknown:DictLiteral>`
不会报成「未定义变量」。
