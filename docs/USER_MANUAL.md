## 快速开始

### 安装

#### 从 PyPI 安装（推荐）

```bash
pip install light
```

安装后即可使用 `light` 命令：
```bash
light --version
light --help
```

#### 从源码安装

```bash
git clone https://github.com/skywalk163/light.git
cd light
pip install -e .
```

### 第一个程序

创建 `hello.light` 文件：

```光明
打印 "你好，世界！"
```

运行：

```bash
light run hello.light
```

输出：
```
你好，世界！
```

### 编译为 Python 文件

```bash
light compile hello.light -o hello.py
```

### 编译为 Windows EXE

```bash
# 需要先安装 PyInstaller
pip install pyinstaller

# 编译为 exe
light compile hello.light -o hello.exe
```

**原理：** 先将光明代码编译为 Python 代码，再使用 PyInstaller 打包为独立的 .exe 可执行文件。

**注意：** 仅适用于 Windows 平台，生成的 exe 文件无需 Python 环境即可运行。

## 基础语法

### 注释

光明支持以下注释语法：

```光明
# 这是单行注释（推荐使用）
// 这也是单行注释
注 这也是注释（以"注"开头，不加冒号）
```

光明支持三种注释风格，可以灵活使用。

### 语句结束

每个语句以句号 `。` 结束（句号是可选的，不强制要求）。

```光明
令 甲 = 123
打印 甲
```

### 标点符号

| 中文符号 | 英文符号 | 用途 |
|---------|---------|-----|
| `。` | `.` | 语句结束 |
| `，` | `,` | 参数分隔、管道操作 |
| `：` | `:` | 块开始、类型注解 |
| `（` `）` | `(` `)` | 括号 |
| `【` `】` | `[` `]` | 列表 |
| `「` `」` | `"` `"` | 字符串 |

## 变量与数据类型

### 变量声明

**语法：** `令 变量名 = 值` 或 `设 变量名 为 值`

```光明
令 年龄 = 25
令 姓名 = "张三"
令 成绩 = 95.5
```

**数字类型：**
```光明
令 整数 = 123
令 浮点 = 3.14
令 中文数字 = 三 + 五  # 8
```

**字符串：**
```光明
令 消息 = "你好世界"
```

**布尔值：**
```光明
令 正确 = 真
令 错误 = 假
```

**列表：**
```光明
令 列表 = [1, 2, 3, 4, 5]
```


## 控制流程

### 条件语句

**基础语法：**
```光明
如果 条件:
    执行语句
```

**示例：**
```光明
令 分数 = 85

如果 分数 >= 90:
    打印 "优秀"
否则如果 分数 >= 80:
    打印 "良好"
否则如果 分数 >= 70:
    打印 "中等"
否则:
    打印 "及格"
```

### 循环语句

**遍历循环：**
```光明
令 列表 = [1, 2, 3, 4, 5]

遍历 元素 于 列表:
    打印 元素
```

**当循环（while）：**
```光明
令 计数 = 1

当 计数 <= 5:
    打印 计数
    令 计数 = 计数 + 1
```

**循环控制：**
```光明
遍历 元素 于 列表:
    如果 元素 == 3:
        跳出
    打印 元素
```

## 函数定义

### 基础函数

**语法：** `函数 函数名(参数):`

```光明
函数 加法(甲, 乙):
  返回 甲 + 乙

令 结果 = 加法(3, 5)
打印 结果  # 8
```

### 递归函数

**阶乘：**
```光明
函数 阶乘(数):
  如果 数 <= 1:
      返回 1
  返回 数 * 阶乘(数 - 1)

令 结果 = 阶乘(5)
打印 结果  # 120
```

**斐波那契：**
```光明
函数 斐波那契(数):
  如果 数 <= 2:
      返回 1
  返回 斐波那契(数 - 1) + 斐波那契(数 - 2)

令 结果 = 斐波那契(10)
打印 结果  # 55
```

## 类与对象

### 类与对象

### 类定义

**语法：**
```
类 类名：
    属性 属性名。
    段落 方法名：
        # 方法体
```

**示例：**
```光明
类 学生：
    属性 姓名
    属性 年龄

    构造 接收 姓名, 年龄：
        己.姓名 = 姓名
        己.年龄 = 年龄

    函数 介绍():
        打印 "我叫" + 己.姓名 + "，今年" + 己.年龄 + "岁"

令 学生1 = 学生("张三", 20)
学生1.介绍()
```

### 继承

```光明
类 大学生 继承 学生：
    属性 专业

    构造 接收 姓名, 年龄, 专业：
        父.构造(姓名, 年龄)
        己.专业 = 专业

    函数 介绍():
        打印 "我叫" + 己.姓名 + "，专业是" + 己.专业
```

### 访问修饰符

光明支持三种访问级别：

| 修饰符 | 说明 | 生成代码 |
|--------|------|----------|
| `公有` (默认) | 任何地方可访问 | 无前缀 |
| `私有` | 仅在类内部可访问 | 加 `_` 前缀 |
| `保护` | 类及子类可访问 | 加 `_` 前缀（Python约定）|

```光明
类 账户：
    公有 属性 用户名
    私有 属性 密码
    保护 属性 余额

    构造 接收 用户名, 密码：
        己.用户名 = 用户名
        己.密码 = 密码
        己.余额 = 0

    公有 函数 获取用户名():
        返回 己.用户名

    私有 函数 验证密码(输入密码):
        返回 己.密码 == 输入密码
```

### 静态属性和方法

使用 `静态` 修饰符定义类级别的属性和方法：

```光明
类 计数器：
    静态 属性 总数

    构造 接收 名称：
        设 己.名称 为 名称
        设 计数器.总数 为 计数器.总数 + 1

    静态 函数 获取总数()：
        返回 计数器.总数

# 静态属性的初始值在类外赋一次
设 计数器.总数 为 0
```

### 属性访问

- `己属性` - self.属性
- `对象.属性` - 对象.属性
- `类名.静态属性` - 类变量

## 异常处理

### 基本异常处理

```光明

  令 文件 = 打开("data.txt")
  令 内容 = 文件.读取
  打印 内容

  打印 "无法读取文件：" + 错误.信息
```

### 多异常捕获

```光明

  令 数值 = 转换整数("abc")

  打印 "不是有效的数字"
```

## 编译器使用

### CLI 工具

**基本用法：**
```bash
# 解释执行
light run file.light

# 编译为 Python 文件
light compile file.light

# 指定输出文件
light compile file.light -o output.py

# 编译为 Windows EXE（需安装 PyInstaller）
light compile file.light -o output.exe

# 显示 Token 流
light tokens file.light

# 显示 AST
light ast file.light

# 选择后端（antlr / src / llvm）
light run file.light --backend antlr
light compile file.light --backend src

# 详细输出
light run file.light -v

# 启动 REPL
light repl

# 查看版本
light --version

# 查看帮助
light --help
```

### 编译目标说明

| 命令 | 输出格式 | 说明 |
|------|---------|------|
| `light compile file.light` | `file.py` | 编译为 Python 源代码 |
| `light compile file.light -o file.exe` | `file.exe` | 编译为 Windows 可执行文件（需 PyInstaller） |
| `light compile file.light --backend llvm` | LLVM IR | 编译为 LLVM 中间表示 |

### Python API

```python
import sys
sys.path.insert(0, 'src')

from compiler import LightCompiler
from code_generator_unified import UnifiedCodeGenerator

# 编译流程
compiler = LightCompiler()
result = compiler.compile(source)

if result['success']:
    code_gen = UnifiedCodeGenerator()
    py_code = code_gen.generate(result['ast'])
    print(py_code)
else:
    print("编译错误:", result['errors'])
```

### 1. 计算器

```光明
函数 计算器(操作, 甲, 乙):
  如果 操作 == "加":
      返回 甲 + 乙
  如果 操作 == "减":
      返回 甲 - 乙
  如果 操作 == "乘":
      返回 甲 * 乙
  如果 操作 == "除":
      返回 甲 / 乙

令 结果 = 计算器("加", 10, 5)
打印 结果  # 15
```

### 2. 学生成绩管理

```光明
类 学生：
  属性 姓名
  属性 成绩列表

  构造(姓名):
    己.姓名 = 姓名
    己.成绩列表 = []

  函数 添加成绩(成绩):
    己.成绩列表.添加(成绩)

  函数 计算平均分():
    如果 长(己.成绩列表) == 0:
        返回 0
    令 总和 = 求和(己.成绩列表)
    返回 总和 / 长(己.成绩列表)

  函数 显示信息():
    打印 "学生：" + 己.姓名
    打印 "平均分：" + 转字符串(己.计算平均分())

令 学生 = 学生("张三")
学生.添加成绩(85)
学生.添加成绩(92)
学生.添加成绩(78)
学生.显示信息()
```

### 3. 银行账户

```光明
类 银行账户：
  属性 账户号
  属性 余额

  构造(账户号, 初始余额):
    己.账户号 = 账户号
    己.余额 = 初始余额

  函数 存款(金额):
    如果 金额 <= 0:
      抛出 ValueError("存款金额必须大于零")
    己.余额 = 己.余额 + 金额
    打印 "存款成功，当前余额：" + 转字符串(己.余额)

  函数 取款(金额):
    如果 金额 <= 0:
      抛出 ValueError("取款金额必须大于零")
    如果 金额 > 己.余额:
      抛出 ValueError("余额不足")
    己.余额 = 己.余额 - 金额
    打印 "取款成功，当前余额：" + 转字符串(己.余额)

  函数 查询余额():
    返回 己.余额

令 账户 = 银行账户("12345", 1000)
账户.存款(500)
账户.取款(200)
打印 账户.查询余额()  # 1300
```

## 常见问题

### 1. 为什么我的代码编译失败？

**常见原因：**
- 缺少句号 `。`
- 关键字拼写错误
- 括号不匹配
- 字符串引号不匹配

**解决方法：**
使用 `light tokens` 查看词法分析结果：
```bash
light tokens file.light
```

### 2. 如何调试代码？

**方法1：** 使用 `light ast` 查看语法树
```bash
light ast file.light
```

**方法2：** 使用 `-v` 详细输出
```bash
light run file.light -v
```

### 3. 光明支持哪些关键字？

**核心关键字：**
- 定义：`令`、`设`、`常量`、`类型`
- 条件：`如果`、`那么`、`否则`
- 循环：`遍历`、`当`、`跳出`、`跳过`
- 函数：`函数`、`段落`、`返回`
- 类：`类`、`继承`、`属性`、`构造`
- 模块：`导入`、`导出`、`从`
- 异常：`尝试`、`捕获`、`抛出`、`最终`

### 4. 如何参与开发？

**步骤：**
1. Fork 项目仓库
2. 创建功能分支
3. 编写代码和测试
4. 提交 Pull Request

**开发指南：**
- 代码风格：遵循 PEP 8
- 测试要求：新增功能必须有测试
- 文档要求：新增功能必须更新文档
