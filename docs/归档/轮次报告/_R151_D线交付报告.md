## 四、已知限制与边界

### 4.1 D1 线程原语
- 协同式停止：`dv_thread_stop` 只置标志，线程需自行配合轮询
- 回调异常局部 try 级兜底（与 `.py` 的 `except Exception: pass` 同口径），不向主线程传播
- 最大线程数 64（`DV_THREAD_MAX`）
- fnmatch 大小写敏感（与 Windows Python fnmatch 有差异，已登记）

### 4.2 D2 归档/解压
- zip 仅 store 模式（无压缩），tar 仅 ustar 未压缩
- gztar/bztar/xztar：C 层只做 tar 打包，压缩由 .py 层 `shutil` 处理
- 最大路径长度 1024 字节（`DV_WATCH_PATH_MAX`）
- 解压时 `..` 路径越界被过滤

### 4.3 D3 统计族
- 输入为列表，元素为 int/float
- 方差/标准差为样本方差（n-1 分母）
- 中位数使用 qsort 排序，O(n log n)

### 4.4 D3 XML
- 最小子集：只解析标签/文本，不处理 DTD/CDATA/注释/属性
- 输出为扁平 `{标签:文本}` 格式字符串

### 4.5 D3 Decimal
- 字符串级算术，精度固定 10 位小数
- 生产环境应实现纯字符串算术（当前用 `atof` 简化）
- 除零返回 `"inf"`
