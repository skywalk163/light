## 三、实施内容（方案 1，按缺陷账 §二十一）

**`src/llvm/codegen_typed.py`**（+40/-6）：
1. `dv_coro_create` 声明升级为 5 参 `(ptr, ptr, i32, i32, ptr)`。
2. 协程状态机签名加第 5 参 `ptr %env`。
3. 自由变量登记为协程帧槽（排在 collect(body)+params 之后，下标在末尾），快照到 `self._coro_free_vars`。
4. resume_0 块内（args→locals 拷贝之后、body 之前）复用 `_emit_closure_env_unpack` 解包——只首跑执行，不冲帧内更新。
5. 两个完成出口（显式 `返回` / 隐式结束）复用 `_emit_closure_env_writeback` 写回，与同步腿同口径（L-098）。
6. 段包装器 `dv_coro_create(..., ptr %env)` 透传本段收到的 env；num_locals 同步加上自由变量数；类异步方法包装器防御性同加（方法一般无捕获）。

**`src/llvm/runtime_typed.c`**（+38/-9）：
1. `LightCoroFunc` 升级 5 参；`LightCoroutine` 末尾加 `LightValue* env`。
2. `dv_coro_create` 加 env 参：`coro->env = dv_closure_env_clone(env)`（克隆数组随帧存活，不栈借）。
3. `dv_coro_resume` 两处调用点都传 `coro->env`。
4. `dv_coro_free` 释放 env 数组本身（不递归元素，与 `dv_closure_env_free` 同口径）。
5. `dv_coro_create_bound`（类异步方法）传 NULL。

**新增 `tests/unit/test_R163_L232_协程闭包env.py`**：3 行为探针 + 3 IR 佐证（计数/正则，非裸 `in`）；clang 探测走 `tests/_native_helpers.py:探测clang()`，缺 clang = skip。
