### 三腿对拍暴露并修复的真实缺陷（src 腿）

**缺陷：统计.light 众数/多众数/频率分布 把 `字典设置` 返回值重赋值给累加器，导致累加器变 None。**

根因：`字典设置(映射,键,值)`（`stdlib/内置核心字典.light:27`）是**原地修改、返回 None** 的内置（`设 映射[键] 为 值`）。原函数写成：
```
设 频次 为 字典设置(频次, v, 字典获取(频次, v, 0) + 1)   # 字典设置 返回 None → 频次 被赋为 None
# 下一轮 字典获取(频次, 键表[0]) → 'NoneType' object is not subscriptable
```
修复（行 177/200/292，replace_all）：去掉 `设 频次 为`，直接调用（原地改、不重赋值）：
```
字典设置(频次, v, 字典获取(频次, v, 0) + 1)
```
回归：`test_众数([1,2,2,3,3,3,4])` 此前抛 `TypeError: 'NoneType' object is not subscriptable`，修复后返回 `3`。

> 这是 src 腿真实缺陷（此前 `统计.light` 从未被三腿对拍覆盖，故长期潜伏）。已在 `test_R148_数学JSON_Tier2.py` 固化。

### R148-C 段 CRLF 损坏修复（关键坑）

初版字节追加时，`过滤字典` 段中 `如果 保留键[j] == k:` 这一行的 `\r\n` 被错写成了**字面 ASCII 文本** `/r/n`（0x2F 正斜杠，非反斜杠；字节 `3a 2f 72 2f 6e`）。解析器把下一行 `字典设置(...)` 拼到同行，报 `语法错误`。修复：用 Python 把字面量 `/r/n` 替换为真 CRLF（`0d 0a`），并重验 `bareLF=0`。修复脚本用后即删。
