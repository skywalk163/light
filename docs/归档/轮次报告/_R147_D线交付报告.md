## 二、D-2 · 假绿断言硬化 ✅

`tests/unit/test_R145_文件系统补齐.py:135` 原 `assert len(dup) >= 1`（恒真下界，
只要返回非空列表即过，哪怕分组是 `[[c]]` 这种漏掉真重复对的错结果也绿）已硬化为：

```python
assert len(dup) == 1
组 = dup[0]
assert a in 组 and b in 组
```

- **判据设计**：① 恰好 1 个重复组（a/b 同内容、c 异内容，真重复只有一对）；
  ② 真重复对 `a.txt`/`b.txt` 必须同组（两者都在组内即隐含该组 ≥2 元素，
  无需再写下界断言）。对「漏 / 错 / 空」三类错误实现均敏感。
- **变异验证**（`_r147d_scratch/mutation_check.py`）：空列表 / 漏真重复对 / 半对 /
  真对被拆散 **四种错误实现均被抓住（FAIL）**；现实现与 `.py` 参考实现均过（PASS）。
- **已知语义分歧（HEAD 起既有，非本轮回归，已登记交主 agent 编号）**：
  `c.txt` 与 a/b 同大小（4B）但内容不同——`.py` 参考实现（`stdlib/文件系统.py:1360`，
  同大小组内再比内容）返回 `[[a, b]]`；`.light` 实现（`stdlib/文件系统.light:471`）
  只按大小分组，返回 `[[a, b, c]]`。本条**不固化该分歧**（不断言 c 在不在组里），
  只钉「真重复对必须同组」。
- **证据**：`pytest tests/unit/test_R145_文件系统补齐.py` → **9 passed, RC=0**；
  `tools/ci/assert_quality.py --root .` → **无新增违规**（存量 492 冻结，RC=0）。
