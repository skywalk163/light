## 四、R144 修点核验（源码级）

`stdlib/分布式/节点网络.light::收全部`（L-194① 修复在位，未回退）：

```light
段落 收全部(套, 最大字节 等于 16777216):
  设 缓冲 为 ""
  设 活跃 为 真
  当 活跃:
    设 块 为 socket_recv(套, 4096)
    如果 长(块) == 0:
      设 活跃 为 假
    否则:
      设 缓冲 为 缓冲 加上 块
      如果 长(缓冲) > 最大字节:
        抛出 新建 节点错误("响应超过上限 " 加上 转字符串(最大字节) 加上 " 字节，疑似对端未关闭连接或数据洪泛")
  返回 缓冲
```

- **16 MiB 最大缓冲上限**：坏套接字 / 未就绪套接字 / keep-alive 不关连接 / 对端数据洪泛时，
  recv 持续返回非 0 长度块会无限拼接（旧实现 ~120 MB/s 线性 OOM，rc=-9）；超上限即抛
  `节点错误`，由 `请求` 包成结构化错误响应——**不再无限拼接**。
- 配套运行期硬化（R144，`src/llvm/runtime_typed.c`）：`dv_socket_recv` 硬化 +
  `dv_socket_set_recv_timeout`（SO_RCVTIMEO）——recv 不再无超时阻塞。
- 上游止损（同文件 L-194 收口注释）：「绝不再带着坏套接字继续 发送socket→收全部」
  （旧实现此处漏判，是无限拼接的入口）。
