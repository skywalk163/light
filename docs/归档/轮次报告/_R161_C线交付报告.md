四条均命中 `_native_或_已知阻塞` 的 `subprocess.TimeoutExpired` 分支 ⇒ `pytest.xfail(...)`，
理由串已按 R161 口径登记为「L-227/L-229/L-238：native 协程 runtime 挂死」。duration 全部
46–50s（即 45s 超时）⇒ 形态一致，是**挂死而非偶发慢**。L-229/L-238 修好后这四条会
**自动转正常断言**（签名门只吞挂死/已知崩溃码，不吞语义分歧）。
