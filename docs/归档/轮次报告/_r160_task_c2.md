## 任务 2 · `选择IO` native 真实 fd

**events 编码主 agent 已读码坐实（你不用再核）**：`DV_POLL_READ=1 / DV_POLL_WRITE=2`
（`runtime_typed.c:6426-6427`）；`dv_coro_await_io(coro, fd, events)`（`:6781`）语义 = 注册全局 poller
→ 协程 SUSPENDED → 事件循环 poll 到 ready 时唤醒；**`fd < 0` 静默 no-op**；poller 创建/注册失败
fail-closed 放回 run_queue（不静默丢 fd）。⇒ 规格 §3.7 的 `等待 await_io(fd, 1)` 编码正确，
把规格里「events 编码待段②核实」改为**已坐实 + 行号**（§9 delta）。

**真实 fd 来源线索（主 agent 已探，供起步）**：socket 系内置走裸 fd int——`连接socket(fd, 主机, 端口)`
首参即从 dv 抽出的 fd i32（`codegen_typed.py:4059`），`绑定socket`/`监听socket`/`接受socket` 同族
（`:4153/4172/4190`），fd 由 `创建socket` 族产生（`4059` 上方自查）。`打开文件` 返回
LV_TYPE_FILE 句柄（非裸 fd，不适用）。**方向**：监听 socket 即刻可读（accept 队列就绪即
POLLRDNORM）⇒ 确定性形态；或客户端连本地监听者、对端写数据制造可读。自选确定性者。

   命中 L-227/L-228 已知签名 ⇒ xfail（`_native_或_已知阻塞` 口径，理由写清）；**若竟跑通 ⇒
   真实 fd 就绪实证（重大进展，如实记录 + IR 佐证 `call void @dv_coro_await_io` 存在）**。
