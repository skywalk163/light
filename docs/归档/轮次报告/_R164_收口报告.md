## 三、未达硬判据项（诚实登记，转 R165）

### 3.1 new_reds=1（非 0）
第二轮全量门（`~/r164clean`，9398 例）唯一 new_red：
```
tests.unit.test_light_import_hook_stdlib::test_find_spec_does_not_intercept_stdlib_pure_shadow
AssertionError: assert ModuleSpec(name='inspect', loader=<LightLoader>) is None
```
- **定性**：测试隔离缺陷，非产品功能回归。单文件隔离跑 5 passed；全量门内因 conftest 全局 finder 的 `search_paths` 被前序用例污染而红。
- **根因**（T-2 §5.2 已取证）：`stdlib/_light_import_hook.py` 守卫用 `any(search_dirs)` 全局判定，加载却逐 base 判定，口径不对齐。
- **修法方向**：守卫改为逐 base 判定，或对 `_STDLIB_MODULES` 直接 import 一律 return None；同时用例 fixture 改 `uninstall()→install([STDLIB_DIR])` 拿干净 finder。
- **处置**：本轮不修（T-2 不碰产品代码纪律），转 R165 必修。
