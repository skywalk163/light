## 1. 各线交付物与判据

### A 线 · L-198（🔴 深水区 → 复验判定非缺陷）

- **任务书预期**：`codegen_typed.py` 深拷贝+写回模型只传播一层 → 需改「浅绑定 + 退出回写」。
- **实际复验结论（0.82 主 agent 亲自）**：原缺陷不成立。
  - 干净方法名（`存值`/`写值`）下，单级/多级嵌套、写已有字段/新字段、是否真挂起 —— **全部 `读=9`**，跨嵌套协程边界正确回写。
  - 登记示例用方法名 `写`，`等待 自.写(9)` 被原生腿编译成**文件写** `dv_file_write`（L-196/L-197 同族命名碰撞），实例属性从未被改 → 假 `读=0`。
- **交付**：`tests/unit/test_R143_L198_嵌套异步写实例.py`（5 例：P1-P4 干净名锁正确性 + 反跑 `写` 名碰撞证明非对称性）。
- **实证**：0.82 → **5 passed**；反跑用例 `test_反跑_写名碰撞_原生读0_python读9` 独立复跑 1 passed。
- **红线合规**：`src/llvm/codegen_typed.py` **零改动**，R140-A 的 UAF 修复点与 `dv_class_set_member` free+realloc 语义一字未动 → L-182/L-191 无回归风险。

### A 线 · L-194（节点内存爆，未闭环）

- **复测命令**：`ulimit -v 6000000; python3 tools/ci/native_run_readiness.py --sample 节点`
- **实测**：`桶：跑崩 / rc=0 但 stdout 无 SMOKE_OK 哨兵`（未闭环）。
- **定性**：L-198 关闭后真凶退回 R140-A 登记的未验证假设 —— `节点网络.light::请求` 的 `收全部` 在坏套接字上退出条件 `长(块)==0` 永不成立 → 无限拼接。属独立深水区（`runtime_typed.c` / `节点网络.light`），留 R144+ 立专项。

### B 线 · L-199（向量 `追加` arity 派发）

- **根因**：`src/code_generator.py` 把关键字 `追加` 映射到 `_light_builtin.追加`（`stdlib/builtins.py` 的 0 参文件标志 `def 追加(): return os.O_APPEND`），而 20+ 个 stdlib `.light` 用 2 参函数式 `追加(结果, x)` → `TypeError: 追加() takes 0 positionals`。
- **修法**：`ParagraphCall` 分支补 **arity 感知派发** —— ≥2 参 → `_light_builtin.列表追加`；0 参保留 `_light_builtin.追加`（文件标志常量）。原生腿 `codegen_typed.py:2606` 本就按 arity 派发，无需改动。
- **交付**：`tests/unit/test_R143_L199_向量追加.py`（7 例，含类内 0 参与模块 2 参共存）。
- **实证**：0.82 → **7 passed**；反跑（还原路由）→ `test_A1_2参追加不再TypeError` **FAILED**（有牙）。
- **降级登记**：`stdlib/向量.py` 影子**未删** —— 其 `__init__` 写 `self._数据` 而其余方法读 `self._data`，运行期 `AttributeError`，不能三腿对拍一致。登记 **L-201**，建议 R144。

### B 线 · L-200（模板嵌套键展开）

- **根因**：`stdlib/模板.light` 循环替换判型 `类型(项)=='dict'` 在两腿语义分歧 —— src 腿 `type()` 返回 `<class 'dict'>`、原生腿 `dv_get_type_name` 返回 `'dict'`，src 腿 dict 分支**恒不走**。
- **修法**：判型改 `是字典(项)`（两腿同义），严格对齐 `.py` oracle 语义（只做顶层键包替换，`{{item.信息.名}}` 不递归展开）。
- **交付**：`tests/unit/test_R143_L200_模板嵌套键.py`（6 例）。
- **实证**：0.82 → **6 passed**；反跑 → `test_A1_点号路径展开` **FAILED**（`{{item.名}}={{item.年}}` 原样输出，有牙）。
- **影子处置**：删 `stdlib/模板.py`（165 行），`tests/test_stdlib_comprehensive.py::TestStdlib模板` 改经 `_light_import_hook` 加载 `模板.light` + 内联期望值。影子数 **62 → 61**。
