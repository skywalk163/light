## 一、根因（三个 A 线改动的背景）

### ① R131 漏登：socket 服务端原语 + poller 注销
`runtime_typed.c` 早已实现 `dv_socket_bind` / `dv_socket_listen` / `dv_socket_accept` /
`dv_socket_shutdown` / `dv_socket_set_nonblocking` / `dv_socket_get_peer_addr` /
`dv_poller_unregister`，IR declare 也已就位（`codegen_typed.py` 顶部 `_declare_typed_runtime`）。

**但** `_gen_typed_builtin` **未注册**这些内建名；`stdlib/socket.light` / `stdlib/selectors.light`
门面也未导出 → 服务端 socket 原语在原生腿**完全不可用**（实测 `打印(绑定socket(...))`
报 `NotImplementedError: 未定义的段落：绑定socket`）。

### ② REF 解引用缺失（原生腿 dict 字段误读）
原生腿 `dv_dict_get` 返回 **REF（type 8）**——指向 dict 内部值的指针。标量读取/只读内置
（`整数` / `浮点数` / `取模` / `整除` / `四舍五入` / `格式化时间` / `时间格式化` / `码位` /
`字符自码位` 等）直接对 REF 读 `LightValue` 字段，会**误读结构体的垃圾字段**：
`整数(dict字段) = 0`、`格式化时间(dict字段) = 1970-01-01`（即 1970）。

### ③ 多参打印丢参
`_gen_typed_builtin` 的 `if name in ('输出','打印'):` 分支**只发 `args[0]`**，`args[1:]` 被
静默丢弃。`打印("x", 5)` 输出只有 `x`；`打印("标签", 值)` 的第二及以后参数全部空白。

### ① R131 漏登：codegen 新增 7 个分支（英 + 中别名成对）

| 内建名（英） | 中文别名 | C 函数 | 位置 |
|-------------|----------|--------|------|
| `socket_bind` | `绑定socket` | `dv_socket_bind(fd, host, port)` | codegen_typed.py:3767 |
| `socket_listen` | `监听socket` | `dv_socket_listen(fd, backlog)` | codegen_typed.py:3786 |
| `socket_accept` | `接受socket` | `dv_socket_accept(fd)` | codegen_typed.py:3804 |
| `socket_shutdown` | `socket关闭读写` | `dv_socket_shutdown(fd, how)` | codegen_typed.py:3818 |
| `socket_set_nonblocking` | `设置非阻塞socket` | `dv_socket_set_nonblocking(fd, enable)` | codegen_typed.py:3836 |
| `socket_get_peer_addr` | `socket对端地址` | `dv_socket_get_peer_addr(fd)` | codegen_typed.py:3854 |
| `poller_unregister` | `注销poller` | `dv_poller_unregister(poller, fd)` | codegen_typed.py:3908 |

stdlib 侧：
- `stdlib/socket.light`：新增段 `bind/listen/accept/set_nonblocking/shutdown/get_peer_addr`
  （ASCII 段名，与 Python socket 对齐），各自转发到对应 codegen 内建。
- `stdlib/selectors.light`：新增段 `注销`。**不取 `等待`**——光明里 `等待 X` 是 await 关键字，
  实测 `从 selectors 导入 等待` 后写 `等待(选择器, 50)` 会被解析成 await 语句，运行期静默取到空值。

### ② REF 解引用：`_deref_value(ssa)` helper
```python
def _deref_value(self, ssa: str) -> str:
    # 分配一个新 slot，用 dv_deref_value(result=slot, value=store(ssa))
    # 对非 REF 实参幂等（*result = *v；字符串额外 strdup）
```
对 REF 返回**指向内部值的副本**；对非 REF 直接复制。应用到：
`整数/浮点数/取模/整除/四舍五入/格式化时间/时间格式化/码位/字符自码位/截取` 等
**约 40 处**「标量读取 / 只读」内置（只读语义，写回路径不动）。

### ③ 多参打印
```python
if name in ('输出', '打印'):
    # 逐参 dv_print（无换行）+ 参间 dv_print(" ") + 末参 dv_println（带换行）
    if args:
        for i, a in enumerate(args):
            slot = self._store_dv(a)
            if i == len(args) - 1:
                self.emit(f'call void @dv_println(ptr {slot})')
            else:
                self.emit(f'call void @dv_print(ptr {slot})')
                sep_dv = self._create_str_dv(self.gen_string_constant(" "))
                sep_slot = self._store_dv(sep_dv)
                self.emit(f'call void @dv_print(ptr {sep_slot})')
    else:
        # 空参：dv_null + dv_println（与 src 腿 print() 空行对齐）
```
与 src 腿 `print(*args)`（空格连接 + 换行）语义一致。
