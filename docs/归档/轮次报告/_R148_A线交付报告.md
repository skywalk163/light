## 二、根因（JSON 内部级联解耦）

- `stdlib/builtins.py:452/462/468` 的 `解析JSON` / `序列化JSON` / `美化JSON` 走
  `import JSON` → `stdlib/JSON.light` → `JSON核心.light` 的 **Python import 级联**（惰性转发）。
- 原生腿 `_gen_typed_builtin` **无对应分支**，也不走 `_light_builtin` 回退 →
  光明代码直接调用报 **「未定义的段落：解析JSON」**（原生后端编译期失败）。
- 这是 Tier2 四项缺口中**最高优先**项（任务书 §A-2 明示「优先 JSON 级联」），也是 C 线
  JSON 高级工具的前置依赖。

## 六、两腿 repr 分歧裁定

| 表达式 | Native 腿 | Src 腿 |
|---|---|---|
| `转字符串(真)` / `转字符串(假)` | `真` / `假` | `真` / `假`（**一致**） |
| 列表内布尔 `[真,假,真]` | `[真, 假, 真]` | `[true, false, true]`（**分歧**） |

- **分歧精确边界**：仅**容器（列表/字典值）内布尔元素的 repr**；标量 `转字符串(布尔)` 两腿一致。
- **根因**：src 腿容器 repr 复用 Python 内置 repr（`true/false`）；标量 `转字符串` 是光明层自定义（中文）。
- **建议口径（推荐）**：**native 对齐 src**——容器内布尔也 `true/false`（src 是规范源；JSON 序列化
  已统一 `true/false`；改动面小）。
- **影响面**：本轮 JSON 对拍测试**不受影响**（走 `序列化JSON` 路径，两腿一致）；依赖容器内 `真/假`
  repr 的测试需更新期望；属**预存差异非本轮回归**，**本轮不实施**（登记建议留后续）。
