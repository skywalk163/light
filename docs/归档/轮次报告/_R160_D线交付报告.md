## 4. 短板清单（最小可复现 + 归类）

三类归因，**主因是判据口径、其次是数据集噪声，真正的语言短板最少**。

### 4.1 判据口径（占失败最大头，**非模型短板**）

- **现象**：R159 17 类池的语料参考译文**本身就是语句级片段**（无顶层声明），而 J1 要求「含顶层声明」⇒ 判据与语料粒度不匹配。
- **最小可复现**：
  - `d['name'] = 'test'`（字典类）：模型输出 `d['name'] = 'test'`，**gold 参考译文亦为 `d["name"] = "test"`** ⇒ 二者 J1 均 false、J2 均 true。
  - `i = 0 / while i < len(lst): ...`（循环类）：模型输出与 gold 参考**逐字相同**，J1 仍 false。
- **量化（gold 自检，`pool_a_valid` 1052 条）**：整池 **J1 36.0% / J2 100%**；分类 J1 通过率——段落 100%、协议 100%、类 94.1%、LLVM异步 86.7%、复合 83.3%；**列表/变量/循环/条件/字符串/字典 = 0%**；异常映射 1.7%、LLVM异常 4.3%、py2duan 14.7%、上下文 15.2%。
- **结论**：armA2 J1 40% ↔ J2 100% 的落差**几乎全部来自口径**，不是模型能力问题。

### 4.2 数据集噪声

| 噪声类型 | 量 | 最小可复现 | 影响 |
|---|---|---|---|
| **空 input（light-schema 行）** | `sft_dataset.jsonl` 541 行 light-schema（**无 input/output**），其中 **399 行** category 以「工程」开头；`pool_a_strict` 内空 input 120 行 | armA_strict idx7（异常映射）：input=`""`，模型回「请提供需要翻译的 Python 代码。」 | 被误当样本 ⇒ 空 user 消息；v1 armB 曾因此严重污染 |
| **`input=output` 直通** | armA_strict 2 条 | 模型把输入**原样回吐**（未翻译，如 idx 输入已是光明片段），J1 判 false | 计入失败但非翻译能力问题 |
| **空输入诱发的编造** | 回馈子实验中出现 | idx42（空 input）→ 模型编造 `段落 主` | **噪声，须标注**，不计入能力评估 |

### 4.3 语言短板（真·模型/语言侧）

| # | 最小可复现 | 归类 | 备注 |
|---|---|---|---|
| 1 | armB idx12（工程-JSONL）：模型把 `import json` / `json.loads(...)` / `.append(...)` **保留为 Python**，仅把 `def`→`段落`、`for`→`遍历` | Python 顶层/行内 API 未译 | 3 次尝试均失败；回馈子实验救回 |

| 3 | armA2 失败中 1 条 `python_leak` | Python 顶层泄漏 | — |

## 5. 新发现：J1 判据盲区（量化为本轮新增洞察）

**J1 会漏检「已通过、但最终输出仍含行内 Python API」的样本**——即语法骨架已光明化、但函数级 API 仍是 Python。

对 run2 最终通过样本，用行内 API 残留集 `{len( os.path open( json.loads json.dumps .append( isinstance( .keys( .items( .strip( .format( }` 扫描：

| 臂 | J1 通过样本 | 其中含行内 API 残留 | 残留 token（计数） |
|---|---|---|---|
| armB_144d | 78 | **43（55.1%）** | `.append(` 14、`len(` 11、`isinstance(` 10、`os.path` 7、`open(` 6、`json.dumps` 3、`.keys(` 3、`json.loads` 1、`.items(` 1 |
| armA_strict | 24 | 3（12.5%） | `.append(` 2、`len(` 1 |
| armA2_valid | 24 | 3（12.5%） | `.append(` 2、`len(` 1 |

- **含义**：armB「97.5%」是**结构骨架口径**的通过率；若把「行内 API 全译」也算进判据，**通过率会显著下降**。这不是模型失败，而是**判据覆盖不足**——语料 gold 参考译文本身也大量使用 `.追加(`/`字典获取(` 等光明等价物，说明**可译而未译**的存在。
- ⇒ 建议把「行内 Python API 残留检测」纳入下一版判据（见 §6 建议）。
