## 2. A 线 · L-232 协程闭包 env 实施

### 2.1 现状（R162-D 取证结论，勿重复探查）

- 探针：`段落 造(计): 异步 段落 内层(): 返回 计 加上 1 / 返回 内层`，外层销毁后 `等待 f()`（计=10）
  ⇒ 实得 **`异步闭包=计1`**，期望 `11`。同步同形态 = **11（正确）**；协程只吃实参的负对照 = **11（正确）**。
- IR 三证：
  1. `define void @_coro_f2(ptr %result, ptr %coro, ptr %args, i32 %num_args)` —— **无 `%env`**；
     同步段 `define void @_seg_f2(ptr %result, ptr %args, i32 %num_args, ptr %env)` —— **有 `%env`**。
  2. `call ptr @dv_coro_create(ptr @_coro_f2, ptr %args, i32 %num_args, i32 3)` —— 不收 env；
     协程体里**没有** `closure_env_unpack_*` / `closure_env_writeback_*` 块（同步侧两个都有）。
  3. 捕获变量被降级成标识符字符串常量：
     `@.str.30 = private unnamed_addr constant [4 x i8] c"\E8\AE\A1\00"`（`计`），
     随后 `dv_add` 走字符串拼接 ⇒ `计1`。

### 2.2 要做

1. **按缺陷账 §二十一 方案 1（推荐项）实施**：
   - `src/llvm/codegen_typed.py`：协程状态机函数签名加 `ptr %env`；`dv_coro_create` 调用点把 env 传进去。
   - `src/llvm/runtime_typed.c`：`dv_coro_create` 增加 env 参数；帧布局里给 env 一个**持久槽**
     （**必须随帧，不得放栈** —— 否则跨 await 后失效，等于回到 L-228 同款坑）。
   - 语义对齐同步侧：复用 `closure_env_unpack` / `closure_env_writeback` 的口径，
     含 **L-098「闭包不能重绑外层变量」** 的写回语义（内层改捕获值要不要回写，与同步腿必须一致，
     不一致就是新的两腿分歧）。
2. **新增回归门** `tests/unit/test_R163_L232_协程闭包env.py`：
   - 三条探针**行为断言**（stdout 逐行全等）：异步闭包 `异步闭包=11` / 同步闭包 `同步闭包=11` /
     异步无捕获（负对照）`异步无捕获=11`。
   - IR 佐证（有信号的计数/集合，不是字符串 `in`）：状态机 define 行**含 `%env`**、
     `dv_coro_create` 调用**带 env 实参**、协程体内**不含**「捕获变量名的字符串常量」（对照 `.str.30`）。
   - clang 探测走 `tests/_native_helpers.py` 的 `探测clang()`（缺 clang **skip 不许 error**）。
3. **反跑有牙（必须做，不许写没跑过的断言）**：把 env 形参去掉（或 `dv_coro_create` 不传 env）
   ⇒ 异步闭包用例必须**转红**（不是 skip、不是静默通过）；还原后转绿。
4. **预算与回退**：若实施中发现 ABI 面（协程调用点 / 帧槽编号 / `dv_coro_create` 的槽数参数）
   超出本轮预算 ⇒ **立即停手**，改走 §二十一 **方案 3**（编译期禁止异步段捕获外层变量并响亮报错）
   并如实登记；**不许半成品落地**（理由同 L-227/L-228 排 R161 的纪律）。
