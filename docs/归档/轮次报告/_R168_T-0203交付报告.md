## 5. 门禁：`tests/unit/test_文档内置名存在性.py`（13 例）

### 5.1 为什么是**双层**判据

单层都会漏，两条都有本轮实证：

| 只查… | 会被什么骗过 | 实证 |
|---|---|---|
| 运行时可达 | **Python 内置名泄漏** | `设 x 为 len([1])` / `str(1)` / `sorted([2,1])` 都能跑，但它们不是光明内置名 |
| 登记表（`builtin_names()`，约 2900 条） | **口径太宽**：约 2591 条是 lightpub **模块函数**，不是地板内置名 | `临时目录` 是真实函数（须 `从 系统接口 导入`），裸调用 `NameError`；`转布尔` 同理（须 `从 类型工具 导入`）。登记表为守「宁可漏报」红线有意放宽，于是这两个名字裸调用都不报 |

所以每个文档名必须**同时**满足：**(a) 登记**（在 `builtin_names()` 里，或在 `DOC_IMPORT_NAMES` 里声明了导入方式）；
**(b) 可达**（真编译 + 真跑 `设 __probe 为 <名字>(空)`，抛 `NameError` 即失败；其它异常算可达）。

### 5.2 用例清单

| 用例 | 作用 |
|---|---|
| `test_doc_table_parsed` | 解析得到 ≥25 个名字（防「零名字全绿」的空转门禁） |
| `test_every_doc_name_registered_and_reachable` | **主判据**：任一不可达 → 失败并逐个点名 |
| `test_module_names_are_really_importable` | `转布尔` 的文档导入路径必须真能导入且能调用 |
| `test_known_fake_names_not_back_in_doc`（×3） | `集合创建`/`repr`/`去除首尾空白` 不许写回文档 |
| `test_empty_set_hint_is_actionable` | 删了 `集合创建` 必须给出 `集合([])` 的可执行答案 |
| `test_known_unreachable_is_empty` | **豁免清单必须为空**（防「加豁免换绿」） |
| `test_gate_has_teeth_unregistered_name` | 反跑：`len`（能跑但没登记）必须被登记闸拦住 |
| `test_gate_has_teeth_module_function_name` | 反跑：`临时目录`（登记表有、裸调用不可达）必须被可达闸拦住 |
| `test_gate_has_teeth_nonexistent_name` | 反跑：不存在的名字两个闸都拦 |
| `test_no_cache_switch_reads_env` / `…_actually_bypasses_cache` | 守住本卡在 `compiler_cache.py` 落地的 `NO_CACHE` 开关 |

### 5.3 反跑实证（不是「断言了就算有牙」）

把伪名塞回文档副本、再把 `转布尔` 从 `DOC_IMPORT_NAMES` 摘掉，跑同一套判据：

反跑结论： PASS（两个闸都能红）

### 5.4 为什么要改 T-0199 的 `KNOWN_DOC_ERRORS`

`tests/unit/test_LH21_未定义名.py` 原断言「允许名单里的名字必须**还写在文档里**」，
即要求 `集合创建`/`repr` 永远留在文档 —— 与本卡「清掉伪名」直接冲突。
处置：把 `KNOWN_DOC_ERRORS` 清成空集，**保留全部三条断言**（`⊆ doc_names` / `∩ real = ∅` /
`doc_names - real = ∅`）——空集下前两条空过，第三条仍会在「有人把伪名写回文档」时转红。
即**判据不减弱，只是基线随修复下移**。该文件 `18 passed`。
