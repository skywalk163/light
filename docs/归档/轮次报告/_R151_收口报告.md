### F 线 · 收口修复（合并点，本报告 §四 之前完成）

1. **14 条 declare 对齐 C 真身**（`codegen_typed.py`）：`dv_stat_*` 7 条、`dv_xml_*` 2 条、
   `dv_decimal_add/sub/mul/div` 5 条原声明为「标量返回 (ptr)」，与 C 真身

   手写 call 传 struct 寄存器的问题。
3. **删 `stdlib/builtins.py` 4 个 D3 重复定义**（求和/方差/标准差/中位数——A 线已在 `数学.light` 落地，
   builtins.py 的旧副本会造成语义漂移）。
4. **`scripts/sync_builtins.py` 重生** `bootstrap/release/stdlib/builtins.py`（补 75 个：逐字 64 + 自包含 11）
   与 `lightharness/stdlib/builtins.py`（公共函数体逐字同步，`LH_ONLY=['整数']` 保留）。
5. **地板清单重建基线**：总数 163→**184**、`native_required` 67→**88**、
   分母仍 184−88=**96**、自举率仍 **68/96=70.83%**（与 R150 完全持平——豁免扩张未缩小分母、未涨点，合法）。
6. **凭证防泄露加固**（`lightharness/scripts/同步0.82.py`）：嵌套 `.env` 按文件名任意深度排除
   （原前缀规则只罩两仓根级，`nuitka_final/.env` 带真 `OPENAI_API_KEY` 会漏过整树上 0.82）；
   `nuitka_final`（366MB 构建产物）进 `EXCLUDE_DIRS`。单测 11/11 过（`.env.example`/源码不误排）。
7. **行尾归一化**：12 个文本文件转 CRLF（`裸LF=0`），`reports/082_*latest.json` 保持 LF 与基线家族一致。
