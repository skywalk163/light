### 执行内容

1. `runtime_typed.c` 新增 C 原语（严格对齐 `dv_json_*` 既有风格）：
   - `dv_fs_access(path, mode)` → `access()`（支撑 `是否可执行`）
   - `dv_fs_symlink(target, linkpath)` → `symlink()`
   - `dv_fs_readlink(path)` → `readlink()`
   - `dv_fs_chmod(path, mode)` → `chmod()`

3. `stdlib/文件系统.light` 补齐对应段（消费上述原语 + 已有 `_light_builtin`），并**双腿对拍**（native / src）。
