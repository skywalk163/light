## 二、落地修复明细

### 1. `src/llvm/codegen_typed.py`
- **内建别名补齐**（`_gen_typed_builtin`，全部为既有运行时函数接线）：
  - `类型` → 取类型分支（L1710 区域）
  - `str` → 转字符串分支
  - `替换字符串` → 替换分支
  - `转大写` / `转小写` → 大写/小写分支
  - `开头`/`以开头`/`startswith`/`starts_with`/`前缀是` → `dv_str_starts_with`（原 declare 未接线）
  - `字符串重复`/`重复`/`str_repeat`/`repeat` → `dv_str_repeat`
  - `字符串包含`/`str_contains`/`包含字符串` → `dv_str_contains`
  - `连接路径`/`join_path`/`path_join` → `dv_path_join`
  - `分割字符串` → split 分支别名
  - `列表排序` → sort 分支别名
  - `目录存在`/`dir_exists`/`is_dir` → `dv_is_dir`（原 declare 未接线）
- **异常类名直呼构造**（`_gen_typed_builtin` 开头）：stdlib 写 `抛出 运行时错误("…")` 是裸类名调用（非 `新建`），此前纯注册异常别名不够，补直呼构造分支（走 `dv_class_new_named`，与 `新建 异常` 同语义）。覆盖中文 6 别名 + 英文 8 名。
- **变量名与内置判型名重名歧义兜底**（`_gen_typed_function_call` reject 前）：v3 解析器把 `设 是浮点 为 假` 后 `如果 是浮点 == 真` 的变量引用解析成**无参 ParagraphCall**（因 `是浮点` 是内置判型名），适配层转成 `FunctionCall`，原生腿当作函数调用报「未定义段落」。兜底：**无参调用且名字已在 `_local_vars` 时降级为变量引用**，与转译腿语义一致。这是 `是浮点`（阻塞 JSON/JSON核心/列表工具 3 模块中的前身）、`映射`（内置核心字典）的公共根因。

### 2. `src/llvm/runtime_typed.c`
- **新增 `dv_path_join`**：POSIX 风格路径连接（对齐 `stdlib/内置核心路径.light` 的 `连接路径` 口径：b 绝对则丢弃前面全部、a 尾斜杠不重复补）。clang -fsyntax-only 无 error（仅既有 strcpy deprecated 警告）。

### 3. `docs/原生腿能力清单.json`
- 全量同步：builtin 243→290、runtime 215→216（新增 `dv_path_join`）；因 codegen/runtime 插入代码导致既有行号漂移，**全量重算** evidence 行号（能力单点测试通过）。

## 四、剩余 7 个「代码生成不支持」模块：根因 + 后续路线

| 模块 | 阻断 | 所需能力 | 规模 |
|---|---|---|---|
| JSON / JSON核心 / 内置核心列表 | KeywordArg | 关键字参数（`打开文件(路径,"w",encoding="utf-8")`、`表.sort(reverse=反向)`）+ **文件句柄对象 + 方法分派**（`f.write(文本)`/`f.close()`） | 大（新运行时类型） |
| 内置核心路径 | TupleLiteral | 元组字面量 + 解包/索引（`返回 (头, 尾)`） | 大（新运行时类型） |
| 数据结构轻量 | 列表弹出 | **变异函数属性写回**（`列表弹出(己.数据)` 原地改属性）+ runtime `dv_list_pop` | 中 |
| 文件流 | YieldStmt | 生成器（`生成`/`yield`） | 大 |
| 文件系统 | 目录名 | runtime `dv_path_dirname` + 文件句柄（同 KeywordArg 依赖） | 中（但依赖文件句柄） |

**建议下一批顺序**：① 变异函数写回 + `dv_list_pop`（解锁 数据结构轻量，中等、可先做）；② KeywordArg + 文件句柄（解锁 3 个模块，收益最大但需新类型）；③ 元组；④ 生成器。
