## 6. 本阶段新增判据 + 反跑方式

全部写在 `tests/test_内置与直调S2_BI2.py`，零信号断言已清（裸 `is not None`/`len>0` 一律升级成具值或 `isinstance` 断言，`assert_quality` 不再判低信号）。反向探针写法：

- 判据：20 名同时在 `builtin_map` 与 `builtins.py`，且映射以 `_light_builtin.` 结尾（非空壳）。
- 反跑：把 `code_generator.py` 里任一条注册删掉 / 改成 `X`（非函数）→ `test_全部20在builtin_map且非空壳` 红；把 `builtins.py` 某条顶层 `def` 删掉 → `test_全部20在builtins且可调用` 红。

**B. 路径与状态（第 88–124 行）**
- 判据 `真实路径 解 junction`：`mklink /J` 建 junction，断言 `真实路径(链接) == os.path.realpath(目标)`。
  反跑：把 `builtins.py:1144` 改回 `os.path.abspath`（词法拼接、不解链接）→ junction 点到沙箱外即红。
- 判据 `文件状态/句柄状态 往返`：`st_size==5`、`st_nlink>=1`、`isinstance(…, os.stat_result)`，且 `句柄.st_ino==状态.st_ino` + `句柄.st_dev==状态.st_dev`。
  反跑：`文件状态` 改为 `return None` → st_size 断言红；`句柄状态` 用 `文件状态(路径)` 顶替（再开一个 stat 窗口）→ 打开后换文件则 ino/dev 分叉红。

**C. 低级 IO 与标志（第 127–179 行）**
- 判据 `二进制写读往返`：写入 `bytes(range(256))+b"\x1aX\x0aY\x00Z"`，读回必须逐字节相等。
  反跑：`低级打开` 退回 `open()` 或 `二进制` 硬编码 0（Windows 文本模式）→ `0x1A` 处被截断/换行被改写，往返红。
- 判据 `8 常量与 os.O_* 等价`：逐条 `== os.O_*`，异平台走 `0`。
  反跑：任一条硬编码异平台数字 → 该断言红。
- 判据 `独占拒预置文件`：预置文件 `低级打开(…, 只写+新建+独占)` 抛 OSError。
  反跑：少或一个 `新建`/`独占` → 预置文件被静默打开，不抛错 → 断言红。

**D. 随机与原子替换（第 182–201 行）**
- 判据 `随机字节 len==8`：反跑改成 `random.getrandbits`（伪随机可预测、可能撞名）→ 本断言只钉长度与 type，把“必须是 CSPRNG”的强断言留给护栏临时文件撞名场景。
- 判据 `原子替换`：预置旧目标 → 替换后源消失、目标为新内容。
  反跑：改成 `shutil.move`（目标已存在即抛）→ 红。

**E. 环境与时钟（第 204–234 行）**
- 判据 `环境枚举` 形状（`[[名,值],…]`）+ 必有 `PATH` 键。
  反跑：返回 `dict`（少二元子表）→ 形状断言红；`return []` → PATH 断言红。
- 判据 `单调时钟` 严格递增：`sleep(0.02)` 后 `t2>t1`。
  反跑：改成 `time.time()`（墙钟可回跳）→ 语义锚被破坏（少数情况不红，已在 docstring 标注为启发式锚，核心锚靠 `test_光明绑定冒烟`）。
