## 0. 这一轮为什么这么排

第三轮把 harness 做成了「真能干活」：tools 声明真发出去了、六个工具真实现了、沙箱护栏真拦了、
两道质量门禁真接进 CI 并在真 runner 上判过绿。**但这一轮的复核挖出三件事，性质比上一轮更严重。**

**第一件：我们一直在说的「异步」，在业务链路上一个 await 点都没有。**

语言侧是真的——`异步 运行 主()。` 真发射成 `asyncio.run`（`src/code_generator.py:1167-1171`），
`并发等待` 真发射成 `asyncio.gather`（`:252`）。但传输层是**阻塞** socket：

- `stdlib/流式.light:250-256` 唯一的读原语是裸 `s.recv(大小)`
- `stdlib/流式.light:73-81` 只设了 `settimeout`，**从来没有 `setblocking(False)`**
- 全 stdlib 没有任何 selectors/epoll 的 socket 用法

后果：任何 asyncio 包装都会堵在 `recv` 上，整个 event loop 停摆。
`stdlib/代理循环.light:377-384` 的注释自己把结论写明白了：
「**要真异步必须先让 流式.light 走非阻塞 socket + selector**」，所以那里至今是 `time.sleep`。
**这是本轮的第一性阻塞点。**

**第二件：`test_async.py` 是全仓最大的一片假绿区。**

- `:659-660` 断 `'asyncio.gather' in py_code`、`:88` 断 `'async def 异步任务' in code`、`:573` 断 `'async for' in py_code`——全是断字符串
- `:531-548` 唯一真跑起来的 async 用例，跑的是**手写 Python**（`async def gen()` + `asyncio.run(main())`），不是光明产物
- `:295-317` 是空断言（`for stmt in ...: pass`）；`:319-343` 写成 `assert isinstance(...) or True`——**永真**

所以「异步能力」从来只被验证到「代码生成器吐出了这个字符串」。

**第三件：沙箱里有一条从未被记录过的真越界写。**

`stdlib/代理工具集.light:266-269`（write）与 `:330-333`（edit）的原子写临时文件路径
**从未经过 `护栏.核准`**，是裸 `os.open`：

```
设 临时路径 为 os.path.join(os.path.dirname(实路径), 临时名)。
设 fd 为 os.open(临时路径, 标志, 384)。
```

入参 `path="."` → `实路径 == 护栏.根目录` → `父目录 = os.path.dirname(根目录)` = **沙箱根的父目录**，
`os.path.isdir` 检查通过 → 临时文件被创建在**沙箱外**。后续 `os.replace` 会失败并 unlink，
但**沙箱外已经发生过一次真实写入**，且临时名可预测（`"_taskB3_tmp_" + 微秒时间戳`）。
`TestWriteFile`/`TestEditFile` 里**没有任何一条用例检查临时文件落点**。

一句话概括这三件：**上一轮我们学会了「判据要真」，这一轮要学的是「判据要覆盖到 I/O 边界」。**

## 4. 接口契约（开工前冻结，不许协商变更）

### 4.1 工具注册加第五参（A4 定义，B4 消费）

```
己.注册工具(名称, 描述, 参数模式, 实现, 副作用)
```

- `副作用`：字符串，取值**只许**三种：`"只读"` / `"写"` / `"执行"`

| 事件名 | 发出位置 | 载荷键 |

- 处理器签名仍是**两参** `处理器(事件名, 载荷)`，事件总线在 `订阅` 那一刻就校验（A3-7）。

**移入第五轮候选：把 `工具调用` 拆成 `工具开始`/`工具结束`/`工具失败`。**
这不是改名而是新增能力，不许当文字替换做：
- `工具结束` 要带执行结果 —— 但 `read_file` 可能返回 50KB，载荷要不要截断、截多长，是设计决策

- 并行批里执行发生在工作线程，而**事件发布必须留在主线程**（事件总线的 `监听者表` 是普通 dict，
  且监听器常往 stdout 写中文——多线程同时写捕获流是「3565 errors 幻影」的成因）。

会让反跑证明失去归因价值——出问题时分不清是并行调度坏了还是事件拆分坏了。

`核准(路径)` 仍是「越界抛 `路径护栏错误`，通过则返回归一化实路径」。
B4 加的 `O_NOFOLLOW`/`dir_fd`/`fstat` 复核是**内部加固**，不许改这个契约，
也不许把 `读取/写入/续写` 的返回类型改掉。

## 5. 本轮新增的三条硬约束

1. **不许用「代码生成器吐出了这个字符串」当能力验收。**
   凡涉及运行时行为（异步、并发、并行、超时、重试），判据必须是**跑产物看行为**：
   时序、副作用、返回值。`assert 'asyncio.gather' in py_code` 这类断言本轮起视为**零信号**，
   写新的一条即算违规（D4 的门禁会拦）。
2. **凡是 `os.open` / `open` / 子进程 cwd，路径必须先过护栏。**
   临时文件、锁文件、溢出文件、日志文件一律算。B4 那条临时文件缺陷就是「主路径过了、辅路径没过」。
   自查方式：grep 自己文件里所有 `os.open(`、`open(`、`os.replace(`，逐个回答「这个路径过核准了吗」。
3. **xfail 只许用来钉「本轮明确不修」的缺口，且必须在总纲里有对应条目。**
   本轮已裁决要修的（硬链接、TOCTOU）**不许再用 xfail 交付**——要么正向断言，要么写进未完成项并说明为什么改不动。

## 10. 环境约定（PowerShell 5.1，血泪版）

- **中文输出必须落盘再读**，直接读会乱码（乱码只在显示层，文件内容是好的）
- **不支持 `&&`**，用 `;` 或分多次；**不支持 heredoc**，commit message 用 `git commit -F <文件>`
- 输出被截断时重跑同一条命令重定向到临时文件，读完即删
- `curl` 是 `Invoke-WebRequest` 的别名，要用 `curl.exe`；curl 输出别直接管道给 python（UTF-8 会坏），先 `-o` 落盘
- git 把进度写 stderr，`$LASTEXITCODE` 可能在推送成功时读到 1 —— 用 `git ls-remote` 复核，别信退出码
