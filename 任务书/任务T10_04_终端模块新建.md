## 4. 验收标准（全部自动化 + 反跑判据）

1. **启动 + 读取**：spawn `python -c "print('hi')"` → 读取到 `hi`，退出码 0。
2. **写入 + 交互**：spawn 一个循环读 stdin 的命令（如 `python -c "import sys; print(input())"`）→ 写入 `hello` → 读取到 `hello`。
3. **信号**：spawn 长睡进程 → `发信号("SIGTERM")` → 状态变为已退出（Windows 上可用 `terminate` 等价，标「未实测 POSIX」）。
4. **超时**：spawn 不输出进程 → `读取(短超时)` 返回超时原因（`timeout`），会话仍可继续或关闭。
5. **状态机**：启动前/运行中/已退出三态 + 退出码；关闭后释放句柄。
6. **反跑判据**：把 `hi` 断言改成 `nope` → 立红。
7. **不回归**：`python 运行.py examples/test_子进程.light` 与 `examples/test_子进程后台.light` 仍绿（没动子进程）。

## 5. 光明缺陷避坑

- 命名规范：`终端会话` 的**成员名**避开危险词根（`读取`/`写入` 是安全前缀「读/写」，可放心用；但 `状态`/`输出`/`信号` 若与关键字冲突先查命名规范表再定；`等待`/`返回`/`类型` 开头一律禁）。
- 模块级函数/类名宽松，类成员名从严；新成员名先写最小类测试（参考 `examples/test_前缀.light`）。
- 注释不写「导入 某模块」字样（L-009）。
