## 2. S1 必做（三条）

### 2.1 `--backend llvm` 死腿处置

`src/llvm/compiler.py:486` 引用 `runtime.c`，而 `src/llvm/` 下只有 `runtime_typed.c`。实测：

```
python -m cli.light compile a.light --backend llvm
→ LLVM (string) 编译错误: 运行时库编译失败:
   clang: error: no such file or directory: 'G:\...\src\llvm\runtime.c'
```

`compile --backend llvm` 与 `run --backend llvm` 两条 CLI 路径 **100% 不可用且零测试**，在 `cli/light.py:1432/:1473` 的 `choices` 里却是合法取值 —— 这是「用户照文档敲一条命令必然失败」级别的问题。

**二选一，在交付报告里写明选哪个和为什么**：
- (a) **删**：`compile_light` 整个函数删掉，`choices` 里摘掉 `llvm`，文档同步。
- (b) **修**：让它复用 `runtime_typed.c`。选这条必须补测试（今天零测试）。

倾向 (a) —— 全仓无调用方、无测试、与 `llvm-typed` 功能重复。但你要自己核实一遍再决定。顺带处理：`compile_light_project`（`compiler.py:1078`）**全仓零调用方**，同一笔账。

### 2.2 `run --backend native` 成为一等取值

现状：`cli/light.py:1430-1441` 的 `run --backend` 只有 `antlr/src/llvm/llvm-typed`，实测 `--backend native` 直接 argparse 报错。而 `_run_native`（`:378-427`）其实已经把「编到临时目录 → `subprocess.run([exe])` → 退出码原样透传」做好了。

**要求**：
- `native` 成为 `run`/`compile` 的合法 backend（作为 `llvm-typed` 的别名，或直接改名并保留旧名兼容 —— 你定，写明理由）。
- `compile` 的 `--optimize` 补上 `Os`/`Oz`（`get_optimization_flags` 与 `OptimizationPipeline` 都已支持，只是 CLI 没暴露，`cli/light.py:1475`）。
- 顺手修 `cli/light.py:489`/`:513`：默认输出名硬编码 `.exe`，在 Linux/macOS 上也这样（虽然 `compile_light_typed:612` 会 `_strip_exe_ext` 剥掉，但 CLI 提示里给用户看的是错的）。
- 判据：`tests/test_native_cli.py` 扩测，含 `native` 别名、`Os/Oz` 两档真产物、非零退出码透传。

### 2.3 原生腿能 `导入` 纯光明 stdlib —— 本轮最硬的一条

**现状**：`src/llvm/codegen_typed.py:2799-2800` 的 `ImportStatement` 是 `pass`（no-op）。单文件原生编译**根本看不见 stdlib**；多模块的唯一 CLI 出口是 `light pkg native`（`cli/light.py:1099-1102` → `package_manager.build_project_native` → `compile_modules_typed`）。

这条不解，M23（`light run --backend native <harness 入口>`）永远做不成 —— harness 单模链要 `导入` 至少 `JSON核心 / 文件流 / 流式 / SSE / 大模型客户端 / 度量 / 并发 / 重试`。

**要求**：
- `导入` / `从 X 导入 Y` 在原生腿真解析：定位 `.light` 模块 → 递归编译 → 符号可见。名字修饰规则（避免跨模块同名段落撞车）要写进 `docs/原生腿能力边界.md`。
- **同名 `.py` 影子必须显式报错，不许静默降级**：原生腿没有 Python，遇到「`.light` 是 decl 0 空壳、实现在 `.py`」的模块（今天有 52 个）必须给一条可读错误，指出是哪个模块、缺什么。静默产出一个跑起来就崩的 exe 是最坏结果。
- 判据：新建 `tests/test_native_import.py`：① 单层导入真跑；② 两层传递导入；③ `从 X 导入 Y` 别名；④ **反跑**：导入一个空壳模块必须报明确错误而不是编译成功。
