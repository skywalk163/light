## 具体要点（实现提示，非限定）

1. **一等函数值**：确认 parser 是否把段落名当可求值表达式；若目前靠「按名展开」，需要引入真正的
   函数值。拿到之后 `组装增量` 式绕法可以被替换，但**不要为演示去改 stdlib**（A5/C5 的活），
   只在 `tests/test_feature_core_light.py` 里写等价形态。
2. **`推迟`**：语义 = 延迟到作用域退出、栈序 FILO、异常路径也执行；用 `try/finally` 兜底发射，
   把行为写进 `docs/语法.md`。`tests/test_async.py:133-155` 现有断言 `['开始','推迟执行','结束']`
   固化的是旧语义，按新语义必须改，并在交付报告里写明**为什么这条判据被改**。
3. **`异步 遍历` 泛化**：对可迭代对象回退走「收集后逐个 await」或包装 `aiter()`；对异步生成器走
   `async for`。注意 unified 那份**完全忽略 `is_async`**，若决定两套都改，这里也要修。
4. **位运算**：`tokens.py` 加 TokenType、`lexer.py` 符号表与关键字表登记、`parser_expr.py` 进二元
   运算符优先级、`code_generator.py` 发射对应 Python 位表达式；优先级按 Python 口径
   （`| < ^ < & < 移位 < 算术`），别自创。
