## 4. 任务分解

### D1 进程执行引擎 → `stdlib/进程树.light`（新建）

上游 harness 的对应实现是 `packages/shell|subprocess|terminal`，靠 `node:child_process` + `detached` 进程组。要复刻的语义：

**1）分离进程树**
- 启动子进程时建立**独立进程组**（POSIX `setsid`/`start_new_session`；Windows `CREATE_NEW_PROCESS_GROUP`），这样杀的时候能杀整棵树而不是只杀直接子进程
- 这是 agent 执行 tool 的刚需：`npm install` 之类会 fork 一堆孙子进程，超时只杀父进程会留下孤儿

**2）信号升级链**
- `SIGTERM` → 等宽限期（默认 5 秒，可配）→ 仍活着则 `SIGKILL`
- Windows 无 SIGTERM 语义：用 `taskkill /T /PID`（先不带 `/F` 尝试优雅），宽限期后 `taskkill /F /T /PID`
- **必须验证进程真的死了**（轮询存活），不许发完信号就宣称成功

**3）有界输出收集 + spill 文件**
- 内存里只保留**尾部** N 字节（默认 64KB 可配）——agent 只需要看结尾，但完整输出要留档
- 超出部分写 spill 文件，返回文件路径供上层按需读取
- **spill 文件创建必须用 `O_EXCL` 语义防 symlink 攻击**（上游 harness 明确这么做）。光明侧确认 `stdlib/文件系统.py:637-643` 有 msvcrt/fcntl 文件锁分支可参考
- 截断时要在中间插入明确标记（如 `…[已省略 N 字节，完整输出见 <路径>]…`），不许静默丢数据
- **UTF-8 多字节字符不许被截断成半个**

**4）超时**
- 总超时 + 空闲超时（多久没有新输出算卡死）分开
- 超时后走信号升级链杀树，返回明确的"超时"结果而不是抛通用异常

**5）安全**
- **命令构造必须走参数数组，绝不允许拼字符串交给 shell**。默认 `shell=否`
- 如果提供了 `使用外壳` 选项，文档里必须明确标注命令注入风险，且默认关闭
- 环境变量传递要可控（白名单/黑名单），不许无脑继承全部环境（agent 场景里环境里常有 API key）

**接口建议**
```
类 执行结果：
  属性 退出码 等于 0。
  属性 标准输出 等于 ""。      # 有界尾部
  属性 标准错误 等于 ""。
  属性 溢出文件 等于 空。      # spill 路径，无溢出则空
  属性 是否超时 等于 假。
  属性 耗时毫秒 等于 0。

类 进程树：
  段落 启动 接收 命令数组, 配置。
  段落 等待 接收 超时毫秒。
  段落 杀树 接收 宽限期毫秒。
  段落 是否存活。
```

**测试**：`tests/test_process_tree_light.py`（新建）。必须覆盖：正常退出取输出、非零退出码、超时杀树（**用一个真的 fork 孙子进程的场景验证孙子也死了**）、输出超界触发 spill、UTF-8 边界、命令不存在的错误、stderr 与 stdout 分离。**跨平台差异要写 `skipif` 而不是假装通过。**

### D2 事件总线 → `stdlib/事件总线.light`（新建）

上游对应 Cordis 插件总线的事件部分。**这是 agent loop 的地基**（三态相位机、inbox 队列、事件瀑布全靠它）。

**要实现的**
- `订阅(事件名, 回调)` / `取消订阅(句柄)` / `发布(事件名, 载荷)` —— 注意 `lightpub/事件驱动.py` **只有注册没有 emit**，你要把 emit 补上
- **事件瀑布语义**：一个事件多个监听者，按注册顺序执行；某个监听者可以**中止后续传播**（返回特定值或调用 `中止()`）。上游的 hooks/guard 机制依赖这个来做策略拦截
- **一次性监听** `订阅一次`
- **通配/命名空间**：至少支持 `工具:*` 这类前缀匹配（上游事件名形如 `tool/before-call`）
- **错误隔离**：一个监听者抛异常不许打断其它监听者。收集异常并统一上报，**不许静默吞掉**
- **取消令牌（`AbortSignal` 等价）**：`类 取消令牌` + `已取消` 查询 + `取消()` + `注册取消回调()`。agent loop 的中断全靠它。这个可以放在总线模块里，也可以单独一个 `stdlib/取消.light`——**你定，但要在移交里说明**
- 同步版先做。异步版（`异步 段落` 监听者 + `等待` 派发）等任务 A 的异步入口就绪后加

**测试**：`tests/test_event_bus_light.py`（新建）。覆盖：多监听者顺序、中止传播、一次性、通配、监听者抛异常不影响其它、取消令牌传播、重复取消订阅幂等。
