## 4. 环境与协作（照抄第九轮，不改）

- 每人一个 worktree：`git worktree add ../wt-X10 -b task-X10 main`，只在自己目录里作业。
- **只跑定向测试，不许跑全量**；定向测试超过 5 分钟先问主线。
- 端口一律 `bind(("127.0.0.1", 0))` + `getsockname()[1]` 取回，不写死端口。
- 临时文件加任务前缀 `_taskX10_*`，收尾删干净。
- 杀进程只许按自己 spawn 的 PID，**绝对禁止按进程名杀**。
- 中文输出必须落盘再读；落盘用 `cmd /c` 字节重定向。
- 临时验证脚本不写盘，用 `python -c` 或落到临时目录，收尾删。

## 5. 交付格式（每条认领项一份）

1. 改了哪些文件（逐个 + 一句意图）
2. 定向测试结果（跑了哪些，输出落盘）
3. 反跑判据：改哪一行立红 + 复位后绿
4. 已知未完成 / 未实测项（只在 Windows 实测过的 POSIX 分支必须标「未实测」）
5. 处置完同步回写 `docs/known_issues.md`（勾选 + 证据行 + commit 号）
