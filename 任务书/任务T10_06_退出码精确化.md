## 5. 验收标准（全部自动化 + 反跑判据）

1. **精确码**：`python -c "exit(3)"` → `码 == 3`；`exit(0)` → `码 == 0`；`exit(-2)`（POSIX 语义）→ `码 == -2`。
   - **反跑判据**：把 `码 == 3` 改成 `码 == 0` → 立红。
2. **运行并取输出** 契约不变：`test_子进程.light`/`test_子进程后台.light` 仍绿。
3. **沙箱**：沙箱内进程退出码同样精确化；路径护栏原有断言不回归（`test_沙箱.light` 仍绿）。
4. **不回归**：bash 工具（`test_总入口.light`）仍绿。
