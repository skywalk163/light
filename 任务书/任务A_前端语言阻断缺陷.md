## 1. 待修缺陷（按顺序做，A1 最重要）

### A1 🔴 异步代码没有启动入口

**现象（实测）**
- 顶层 `等待 主()。` → 生成模块级裸 `await 主()` → `SyntaxError: 'await' outside function`
- `运行异步(...)` 不存在 → ParseError
- `创建事件循环` / `事件循环运行` 只出现在 `src/lexer.py:238-239` 的标识符白名单里，**codegen 与 stdlib 零实现**
- 退路也堵死：`引 Python：asyncio.run(主())` 中 L4 块 `exec` 到独立 ModuleType 命名空间，**看不见光明侧定义的 `主`** → `NameError: name '主' is not defined`

**已有的（不用你做）**：`异步 段落`→`async def`（`parser_stmt.py:330-345`、`code_generator.py:1409`）、`等待 X`→`await`（`parser_expr.py:423-449`、`code_generator.py:1096-1099`）、`异步 遍历`→`async for`（`parser_stmt.py:339-342`、`code_generator.py:1306`）、`使用 异步`→`async with`（`parser_stmt.py:4851-4855`、`code_generator.py:1956`）、`异步 作用域`→`asyncio.gather`（`parser_stmt.py:3347`、`code_generator.py:1998-2019`）。

**要做的**
1. 提供一个**顶层异步启动语句/内置**，把 `async def` 跑起来。命名建议（择一，需与既有关键字风格一致）：
   - `运行 异步 主()。` → `asyncio.run(主())`
   - 或内置动词 `运行异步(主())`
   - 二选一，**不要两个都加**。选定后写进 `docs/` 对应语法文档。
2. 顶层 `等待 X` 与顶层 `异步 作用域` 目前静默生成非法 Python。**改为编译期报错并给出修正建议**（指向 A1 新增的启动入口）。禁止继续静默错编。
3. `src/lexer.py:238-239` 白名单里的 `创建事件循环`/`事件循环运行` 二者之一必须真落地，或从白名单删掉（**不许留"词法认得、后端没有"的悬空名字**）。
4. 原生后端侧：`src/llvm/codegen_typed.py:2781-2999` 已有 await 点预扫描 + resume label 骨架，`runtime_typed.c:4233-4243` 有 `dv_scheduler_run`。**你只需让新的启动语句在原生后端映射到 `dv_coro_run_to_completion` / `dv_scheduler_run`**，不需要动 C 代码（那是任务 B 的文件）。

**验收断言**
```
异步 段落 报数 接收 次数：
  设 索引 为 0。
  当 索引 小于 次数：
    打印(索引)。
    设 索引 为 索引 加上 1。

运行 异步 报数(3)。        # 或你选定的写法
```
- 转译后端：输出 `0\n1\n2`，退出码 0
- 原生后端（`--backend llvm-typed`，需本机 clang）：输出逐字节一致
- 新增测试文件必须**真跑产物**，不许只 `assert 'async def' in py_code`（现存 `tests/test_async.py` 全是断字符串，这就是这个洞没人发现的原因）

### A2 🔴 `yield from` 静默错编

**现象**：`生成 从 乙()。` → `yield 从` + `乙()`（**两条语句**）；`生成 全部 乙()。` → `yield all(乙)()`。编译期零提示，运行期才炸。

**位置**：`src/parser_stmt.py:2950-2965`（`_parse_yield_stmt`）；`code_generator.py:1100-1106`。

**要做的**：落地生成器委托。语法建议 `生成 全部 乙()。` → `yield from 乙()`（`全部` 已是既有词，语义贴合）。若选新写法，说明理由。**无论选哪个，另一种写法必须编译期报错，不许静默产出错代码。**

**为什么重要**：SSE 分帧、chunked 解码天然是嵌套生成器，任务 C 的流式解析器直接依赖这个。

**验收断言**
```
段落 内层：
  生成 1。
  生成 2。

段落 外层：
  生成 全部 内层()。
  生成 3。

遍历 项 之 外层()：
  打印(项)。
```
输出 `1\n2\n3`。

### A3 🔴 `映射`/`筛选` 参数顺序反了

**现象**：`映射([1,2], 接收 数：返回 数 乘 2)` → `map([1, 2], lambda 数: ...)` → 运行时 `TypeError: 'function' object is not iterable`。

**位置**：`src/keywords.py:355-356`（两者 arity=2），codegen 按源序直落。

**要做的**：定下参数序并落实。**推荐保持光明源码序为「数据在前、函数在后」**（读起来是"映射 这批数据 用 这个函数"，符合中文语序），codegen 时交换成 `map(func, iterable)`。**注意这是行为变更**：如果有现存 `.light` 代码/测试/积木库按 `映射(函数, 数据)` 写，改动会打红——必须逐条 set-diff 确认，并在提交说明里列出受影响用例。

**验收断言**：`打印(列表(映射([1,2,3], 接收 数：返回 数 乘 2)))` → `[2, 4, 6]`。`筛选` 同理。

### A4 🔴 调用侧关键字实参不支持

**现象**：`打印(甲 = 1)` → `意外的标记: 「=」`。定义侧 `接收 *其余, **关键：` 是支持的（`parser_stmt.py:3164-3180, 4308-4332`），调用侧展开 `打印(*列)` / `打印(**典)` 也支持——**只有 `名 = 值` 形式的关键字实参不行**。

**位置**：`src/parser_expr.py:2564-2592` 有一段 C 风格 kwarg 代码路径但未生效，先查清为什么没走到。

**要做的**：让 `函数(位置实参, 名 = 值, 名2 = 值2)` 正常编译成 Python kwargs。同时考虑是否提供中文连接词形式（如 `函数(超时 为 30)`）——**如果加，`=` 和 `为` 两种写法必须都能用且语义一致；如果不加，只做 `=`**。别留半套。

**为什么重要**：一个 agent 框架有几十个可选项（超时、重试次数、并发度、工具过滤器、深度预算），没有 kwargs 会让每个 API 退化成一长串位置参数。

**验收断言**
```
段落 连接 接收 主机, 端口 等于 443, 超时 等于 30：
  打印(f"{主机}:{端口}/{超时}")。

连接("example.com", 超时 = 5)。
```
输出 `example.com:443/5`。（注意这个用例同时覆盖 A5′ 见下）

### A5 🔴 无 `global` / `nonlocal` 等价物

**现象**：函数内 `设 计 为 计 加上 1` 编成 `计 = (计 + 1)` → `UnboundLocalError`。跨作用域可变状态目前只能靠对象属性或可变容器兜。

**要做的**：新增声明语句。命名建议 `全局 计。` → `global 计`；`外层 计。` → `nonlocal 计`。

**⚠️ 项目既定口径**：**新增单字关键字必须先过全仓 token A/B 扫描**（历史上 `约` 因 lexer 返回值失配被暂缓）。`全局`/`外层` 是双字词，风险低，但仍需扫描确认不与现存标识符冲突（尤其积木库 182 块与 tests/ 下的 `.light`）。

**验收断言**
```
设 计 为 0。
段落 加一：
  全局 计。
  设 计 为 计 加上 1。
加一()。
加一()。
打印(计)。
```
输出 `2`。

### A6 🟠 类属性默认值写法窄（低成本，一并做）

**现象**：类体内只认 `属性 计数 等于 0。`；`属性 计数 为 0。` / `= 0` / `属性 计数: 整数 = 0。` 全部硬报错「类体内不支持的成员声明」。而语言其它地方一律用 `为` 赋值——这是高频踩坑点。

**位置**：`src/parser_stmt.py:3866` `_parse_class_definition`。

**要做的**：至少让 `属性 X 为 值。` 与 `属性 X: 类型 为 值。` 可用，与 `设 X 为 值。` 的赋值连接词保持一致。（**嵌套类不在本任务范围**，登记到移交清单即可。）

---

### A7 🟠 推导式介词不统一（低成本，一并做）

**现象**：推导式只认 `之`/`在`，不认 `于`（`[数 遍历 数 于 列]` → "列表推导期望'之'或'在'"）；而 `遍历` 语句认 `于`。同一概念两套介词。

**要做的**：让推导式也接受 `于`。**不要反向去掉 `遍历` 语句的 `于`**——那是既有契约，动了会打红一片。
