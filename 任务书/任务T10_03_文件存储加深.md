## 4. 验收标准（全部自动化 + 反跑判据）

1. **写读闭环**：写入文本 → 读回一致；JSON 写读；二进制字节写读。
2. **目录操作**：递归建目录、列目录（含递归）、删除（文件/空目录/非空目录）、重命名、复制。
3. **stat**：文件大小/类型（文件 or 目录）/存在性。
4. **glob**：通配符匹配（`*.txt`、`子目录/**/*.json`）返回匹配路径。
5. **存储**：`设 存储 为 新建 存储(...)` → `set`/`get`/`delete`/`keys` → 关闭后重开能读回（持久化）。
6. **反跑判据**：每个能力的断言改反一行即红（如读回断言改成相反值）。
7. **不回归**：`python 运行.py examples/test_文件.light` 仍绿。

## 5. 光明缺陷避坑

- 命名规范：成员名避开危险词根（`取`/`生成`/`导出`/`类型`/`部分`/`原因`/`全部`/`模式`/`等待`/`返回`/`异步` 等）；`存储`/`文件` 这类与模块名冲突的词慎做**类成员名**。
- stdlib `.py` 里别写 `进程.沟通` 这类「光明词根但 Python 无此属性」的伪名（应写 Python 原生名，见缺陷账 L-011 教训：`外部命令.py` 的 `进程.沟通` 应为 `process.communicate()`）。
- 注释不写「导入 某模块」字样（L-009）。
