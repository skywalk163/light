## 开工首日必须先定的一件事：selector 就绪 → `await` 怎么桥

**这是本轮实现风险最高的一处，必须像 B5「`推迟` 落哪条生成器链路」那样先裁决、写进交付报告第 1 项，
再动手。** 约束是硬的、且互相咬：

- 语言层 codegen 只有 5 个 asyncio 映射（`code_generator.py:249-253`），**没有 `add_reader` /
  `get_running_loop` / `Future`**；而 A5 不许碰 `src/`。
- `选择器.light` 的 `等待`（`:61-69`）和 `等待就绪`（`:74-92`）都是**阻塞式 `sel.select(超时)`**。
  在事件循环里直接调 = 把 loop 卡死，违反总纲 §4.3 末尾的「不许在 loop 里跑阻塞调用」。

三条可选路线，**默认走 (a)**：

- **(a) 轮询让步（默认）**：`等待就绪(sel, 套接字, "读", 0)` 以 0 超时做一次非阻塞探测，未就绪就
  `等待 异步睡眠(0)`（或极小值）让出控制权，再探。零新增语言能力、纯 stdlib 内可完成，能过 §1.1 的
  结构 + 时序判据。**代价是粗**：忙等有 CPU 开销，睡眠粒度会给时序判据带来抖动——所以时序判据只断
  「并发 < 0.8s、串行 > 1.0s」的**关系**，不断绝对值（总纲 §1.1 已如此写）。选它就在文件头写明
  「这是过渡实现，等 (b) 可用后替换」。
- **(b) `loop.add_reader` 回调桥接**：`导入 asyncio` + `get_running_loop().add_reader(fd, 回调)`，
  回调里 `set_result`。语法上「导入 Python 模块」是允许的（不增加 `引 Python` 计数），但**回调要传
  函数值** → 依赖 B5 的一等函数值合入。按总纲 §8 的合并顺序 B5 先合，所以 **(b) 是 B5 合入后的替换目标**，
  不是首日路线。
- **(c) 移交 B5 加 codegen 映射**（`创建未来`/`注册读回调` 之类新名）：**默认不选**。理由是 M11 已删
  `创建事件循环` 那条，就是不想为了「显式 loop 语义」再造一批只有壳的名字；真要走这条，必须先给出
  (a)/(b) 都表达不出来的具体反例，写进移交清单由 B5 裁决。

**裁决记录要求**：首日在交付报告里写明「选了哪条 + 为什么 + 若 (a) 则何时换 (b)」。中途换路线要
重新贴时序实测，不许拿 (a) 的数字充 (b) 的账。

## 目标与验收（M11，结构 + 时序 + 反跑三连，缺一即红）

1. **结构判据（产物行为）**：`异步 段落 流式对话` 是 **async 生成器**（能被 `异步 遍历` 驱动），
   且真的 `等待` 网络读。不 grep 源码字符串。
2. **时序判据**：两个 mock server 各延迟 0.5s，**同一份用例**里异步并发 N 路
   总耗时 < 0.8s、串行 > 1.0s，断关系不断绝对。贴原始输出（串行 X.XXs / 并发 Y.YYs）。
   **可与 A4 的线程版实测对照**（并行 0.303s / 串行 0.904s，比值 2.98，`自测报告_任务A4.md:62-66`），
   说明这不是「把线程换了个名字」。⚠️ **两组数字不是同一档实验**：A4 那组的单次工作量是 `sleep 0.30s`，
   本轮判据用的是 **0.5s 延迟**的 mock server。引用时写清各自的延迟档位，**不许把 0.303/0.904 直接
   当本轮的期望值**，只能作「线程版能做到接近 3 倍」的量级参照。
3. **反跑判据**：把异步读那一步改回同步阻塞 recv，用例必须变红。交付报告贴前后实测。

### 具体新增能力（全部走新名字，绝不改同步语义）

- `流式.异步收(大小)`、`异步 段落 read_body`：async 走 selector + event loop，返回 awaitable。
- `大模型客户端` 的 `异步 段落 流式对话(消息列表)`：async 生成器，增量块字段与同步版一致
  （`角色/内容增量/工具调用增量/累积内容/完成原因/结束`）。`[DONE]` 早停、工具按 index 累积照搬同步版逻辑。
  **命名严格照总纲 §4.1 的带空格写法**，不许写成 `异步流式对话`（那是一个标识符，C5/D5 会调不上）。
  若语言层不允许同名重载，开工首日定出实际定名并回写总纲 §4.1。
- ~~`创建事件循环()`~~ **本轮不做（总纲 M11 已删该条）**：它是 A2-3 主动删掉的死名字
  （`src/lexer.py:239-243`，依据「全仓 0 处使用」），`异步 运行` 已发射 `asyncio.run` 够用。
  **A5 不许把这个名字加回来**；真需要显式 loop 语义就记移交清单给 B5，附上用例。
