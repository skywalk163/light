  全文件 grep 无 `异步/等待`。
- 传输层**已经是非阻塞 + selector**（`流式.light:17` 导入选择器、`:99 s.setblocking(假)`、
  `:257-289` 收走 selector 且 want-read/want-write 分开处理）——**这块别重做，A5 是往上接语言层 await**。
  注意：`自测报告_任务A4.md` 与 `代理循环.light:444` 里「流式只有阻塞 recv、全 stdlib 无 selectors」
  的说法是 **C4 合入前的旧话，已过时**，别照它下判断。
- 语言层 `异步 运行 主()` / `并发等待` / `限时` 已发射成真实 asyncio（`code_generator.py:249-253`），
  但业务链路上一个 await 点都没有——必须由 A5 补上。

  且它只被验证到「无 key 早退」，流式那段零覆盖（归 D5）。

## 目标与验收（M11，结构 + 时序 + 反跑三连，缺一即红）

1. **结构判据（产物行为）**：`异步 段落 流式对话` 是 **async 生成器**（能被 `异步 遍历` 驱动），
   且真的 `等待` 网络读。不 grep 源码字符串。
2. **时序判据**：两个 mock server 各延迟 0.5s，**同一份用例**里异步并发 N 路
   总耗时 < 0.8s、串行 > 1.0s，断关系不断绝对。贴原始输出（串行 X.XXs / 并发 Y.YYs）。
   **可与 A4 的线程版实测对照**（并行 0.303s / 串行 0.904s，比值 2.98，`自测报告_任务A4.md:62-66`），
   说明这不是「把线程换了个名字」。
3. **反跑判据**：把异步读那一步改回同步阻塞 recv，用例必须变红。交付报告贴前后实测。

  （`角色/内容增量/工具调用增量/累积内容/完成原因/结束`）。`[DONE]` 早停、工具按 index 累积照搬同步版逻辑。

  若语言层不允许同名重载，开工首日定出实际定名并回写总纲 §4.1。
- ~~`创建事件循环()`~~ **本轮不做（总纲 M11 已删该条）**：它是 A2-3 主动删掉的死名字
  （`src/lexer.py:239-243`，依据「全仓 0 处使用」），`异步 运行` 已发射 `asyncio.run` 够用。
  **A5 不许把这个名字加回来**；真需要显式 loop 语义就记移交清单给 B5，附上用例。
