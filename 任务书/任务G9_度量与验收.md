## 3. 已知会咬人的门禁坑（照抄，别重新踩）

1. **Windows 全量的「3565 errors 幻影」**：捕获流被 reconfigure 成 strict 会导致整场级联；`PYTHONUTF8` 自己也会造假红。**门禁基线的键带 `os.sep` 会让本机绿 / CI 红**，键带行号会造幻影红（第七轮 `--root` 默认值造过 424 条幻影）。
2. **门禁不许与测试并发跑**（既有规程）。
3. **`.gitignore` 会吃基线**：gitignore 的生成物**只有 `dir` 看得见**，`git status` 看不见。
4. **单行 docstring 会被 `assert_quality` 点名**；新增 `time.time()` 会打红 Python 直调门禁（第八轮实测：评测驱动 16→17，只许降不许升，修法是抽一个 `段落 已过秒`）。
5. **gitea CI 状态查询**：用 `/actions/tasks`（`/actions/runs` 是 404）；`status` 直接是 `success/failure/cancelled`，**没有 `completed` 这一步**，`conclusion` 恒 `None` —— 轮询脚本等 `status=='completed'` 会空转到超时（第八轮空转 90 次）。要看是哪一步失败就拉 web 路由 `/actions/runs/<run_number>/jobs/0/logs`（200，免 token）。
6. **e2e 的假转绿**：本机不收集 e2e 时 `check_regression` 会报十几条「已转绿」，**据此刷 `ci_baseline_failures.txt` 就是造假绿**（第七、八轮各踩一次）。
