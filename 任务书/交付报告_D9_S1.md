## 4. 已知未完成 / 未实测项

1. **`路径护栏` 直调 32 → ≤3 未达标，已达 16，判定为阻断。** 根因即 3.2：缺内置 + 新文件带直调必红。剩余 16 条已全部收进单一「系统边界段」，一段一个原语，等 3.2 到位后是机械替换，不需要再改判断顺序。
2. **护栏 fd 路径的 POSIX 分支：未实测。** `O_NOFOLLOW`、符号链接语义只在 Windows 上过了逻辑分支（Windows 无 `O_NOFOLLOW`，走的是另一支）。标注**未实测**，不冒充绿。
3. **`\\?\` 扩展长度路径：故意 fail-closed。** Python 3.14 上 `os.path.realpath("\\\\?\\C:\\x")` 会产出畸形的 `\\C:x`，无法安全比较，因此护栏对 `\\?\` 前缀直接判拒并新增用例固定该行为。这是**已知限制**，不是支持。
4. **`ntpath.isabs("/x")` 在 3.13+ 为 False**，而 `是绝对("/x", "win32")` 返回 True。此为**刻意分歧**（护栏要把 `/x` 当绝对路径才不会被绕过），已在测试里写成显式对照表并注明原因，不是 bug。
5. `native_product.py` 的结构性红（第 2 节）需主线在合并点重建基线。
