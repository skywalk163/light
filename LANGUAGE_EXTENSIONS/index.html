    光明（Light）编程语言 - 语法扩展设计¶

    概述¶

    本文档定义光明编程语言的语法扩展，包括： - 类与对象 - 模块系统 - 异常处理

    设计原则： 1. 保持中文语法风格 2. 简洁易读 3. 与现有语法一致

    1. 类与对象¶

    1.1 类定义¶

    语法： 

    类 类名：
  属性列表

  构造(参数)：
    初始化代码

  方法名(参数)：
    方法代码

    示例： 

    类 学生：
  属性 姓名
  属性 年龄

  构造(姓名, 年龄)：
    己.姓名 为 姓名。
    己.年龄 为 年龄。

  段 介绍()：
    打印("我叫" 加 己.姓名 加 "，今年" 加 己.年龄 加 "岁。")。

    生成 Python： 

    class 学生:
    def __init__(self, 姓名, 年龄):
        self.姓名 = 姓名
        self.年龄 = 年龄

    def 介绍(self):
        print(f"我叫{self.姓名}，今年{self.年龄}岁。")

    1.2 继承¶

    语法： 

    类 子类 继承 父类：
  方法重写

    示例： 

    类 大学生 继承 学生：
  属性 专业

  构造(姓名, 年龄, 专业)：
    父.构造(姓名, 年龄)。
    己.专业 为 专业。

  段 介绍()：
    打印("我叫" 加 己.姓名 加 "，今年" 加 己.年龄 加 "岁，专业是" 加 己.专业 加 "。")。

    1.3 属性访问¶

    语法： - 己属性 - self.属性 - 对象.属性 - 对象.属性

    示例： 

    设 学生 为 创建学生("张三", 20)。
学生.介绍()。
设 年龄 为 学生.年龄。

    2. 模块系统¶

    2.1 模块定义¶

    语法： 

    模块 模块名：
  导出内容

    示例：

    文件：math.light 

    模块 数学工具：
  导出加法
  导出乘法

  段 加法(甲, 乙)：
    返回甲加乙。

  段 乘法(甲, 乙)：
    返回甲乘乙。

    2.2 模块导入¶

    语法： 

    从 模块名 导入 函数名
从 模块名 导入 函数1, 函数2
导入 模块名

    示例： 

    从 数学工具 导入 加法, 乘法。

设 结果 为 加法(三, 五)。
打印(结果)。

    生成 Python： 

    from math_tool import add, multiply

result = add(3, 5)
print(result)

    导入绑定语义（重要）：

    从 X 导入 Y 编译后对应 Python 的 from X import Y——它在导入时刻把 X.Y 的值 拷贝到当前命名空间（导入时快照）。此后源端若对模块级变量 Y 重新绑定 （设 Y 为 新值），引用端的 Y 仍是导入时刻的旧值；只有对同一对象的原地修改 （改键 / 改元素）才会反映到引用端。这是 Python 原生语义，跨模块暴露会重绑的可变全局 时容易误用（参考语言缺陷账 L-065）。

    正确绕法（需要读取会变化的模块级可变全局时）：

    1. 读实时全局函数：在源模块定义
    段落 查Y：
    全局 Y
    返回 Y

    引用端 从 X 导入 查Y 后调用 查Y() 读取当前值，而非直接 从 X 导入 Y。

    1. 初始化空容器 + 原地改键：源端 设 Y 为 {} 后只做 Y["键"] = 值 （原地修改，绝不重绑变量名），引用端导入的是同一 dict 对象，可实时看到变化。

    示例： 

    从 标准库 导入 json。
从 标准库 导入 os。

    3. 异常处理¶

    3.1 基本异常处理¶

    语法： 

    尝试：
  可能出错的代码
捕获 错误类型 为 错误变量：
  错误处理代码

    示例： 

    尝试：
  设 文件 为 打开("data.txt")。
  设 内容 为 文件.读取()。
  打印(内容)。
捕获 文件错误 为 错误：
  打印("无法读取文件：" 加 错误.信息)。

    生成 Python： 

    try:
    file = open("data.txt")
    content = file.read()
    print(content)
except FileNotFoundError as error:
    print(f"无法读取文件：{error}")

    3.2 多异常捕获¶

    语法： 

    尝试：
  代码
捕获 错误类型1 为 错误1：
  处理1
捕获 错误类型2 为 错误2：
  处理2
最终：
  清理代码

    示例： 

    尝试：
  设 数值 为 转换整数("abc")。
捕获 值错误 为 错误：
  打印("不是有效的数字")。
捕获 其他错误 为 错误：
  打印("发生未知错误")。
最终：
  打印("处理完成")。

    3.3 抛出异常¶

    语法： 

    抛出 错误类型 参数 \"错误信息\"

    示例： 

    段 检查年龄(年龄)：
  如果 年龄 小于 零：
    抛出 值错误("年龄不能为负数")。
  返回 年龄。

    3.4 自定义异常¶

    语法： 

    异常 异常名 继承 基类异常：
  属性定义

    示例： 

    异常 年龄错误 继承 异常：
  构造(年龄)：
    定义己信息等于\"无效的年龄：\"加年龄。

    4. 其他扩展¶

    4.1 装饰器¶

    语法： 

    装饰器 装饰器名：
  装饰器代码

@装饰器名
段 函数名：
  函数代码

    示例： 

    装饰器 计时：
  段 包装(函数)：
    段 执行(参数)：
      定义开始等于时间.当前。
      定义结果等于函数参数参数。
      定义结束等于时间.当前。
      打印\"执行时间：\"加(结束减开始)。
      返回结果。
    返回执行。

@计时
段 计算斐波那契(数)：
  返回斐波那契参数数。

    4.2 上下文管理器¶

    语法： 

    使用 资源 为 变量名：
  使用资源的代码

    示例： 

    使用 打开("data.txt") 为 文件：
  设 内容 为 文件.读取()。
  打印(内容)。

    生成 Python： 

    with open("data.txt") as file:
    content = file.read()
    print(content)

    4.3 列表推导式¶

    语法： 

    [表达式 遍历 变量 在 列表 如果 条件]

    示例： 

    设 列表 为 [1, 2, 3, 4, 5]。
设 平方 为 [数字 乘 数字 遍历 数字 在 列表 如果 数字 大于 二]。
打印(平方)。  # 输出：[9, 16, 25]

    4.4 字典推导式¶

    语法： 

    {键表达式: 值表达式 遍历 变量 在 列表}

    示例： 

    设 列表 为 ["甲", "乙", "丙"]。
设 映射 为 {字符: 字符.长度 遍历 字符 在 列表}。
打印(映射)。  # 输出：{'甲': 1, '乙': 1, '丙': 1}

    4.5 Lambda 表达式¶

    语法： 

    匿名(参数): 表达式

    示例： 

    设 平方 为 接收 数：返回 数 乘 数。
打印(平方(5))。  # 输出：25

设 列表 为 [1, 2, 3, 4, 5]。
设 筛选 为 列表.筛选(接收 数：数 大于 二)。
打印(筛选)。  # 输出：[3, 4, 5]

    5. 语法关键字总结¶

    5.1 新增关键字¶

    类相关： - 类 - 类定义 - 继承 - 继承关系 - 属性 - 类属性 - 构造 - 构造函数 - 己 - self 引用

    模块相关： - 模块 - 模块定义 - 导入 - 导入模块 - 从 - 导入来源 - 导出 - 导出符号 - 标准库 - 标准库标识

    异常相关： - 尝试 - try - 捕获 - except - 抛出 - raise - 最终 - finally - 异常 - exception 定义

    其他： - 装饰器 - decorator - 使用 - with - 匿名 - lambda

    5.2 关键字优先级¶

    保持双字关键字优先原则： - 所有核心关键字统一为双字 - 单字保留给特殊用途（如 己 表示 self）

    6. 实现优先级¶

    阶段1（高优先级）¶

    1. 类定义和继承
    2. 属性访问
    3. 异常处理（try-except-finally）
    4. 模块导入导出

    阶段2（中优先级）¶

    1. 自定义异常
    2. 上下文管理器（with）
    3. 列表推导式

    阶段3（低优先级）¶

    1. 装饰器
    2. 字典推导式
    3. Lambda 表达式

    7.1 完整类定义¶

    类 银行账户：
  属性 账户号
  属性 余额

  构造(账户号, 初始余额)：
    己.账户号 为 账户号。
    己.余额 为 初始余额。

  段 存款(金额)：
    如果 金额 小于等于 零：
      抛出 值错误("存款金额必须大于零")。
    己.余额 为 己.余额 加 金额。
    打印("存款成功，当前余额：" 加 己.余额)。

  段 取款(金额)：
    如果 金额 小于等于 零：
      抛出 值错误("取款金额必须大于零")。
    如果 金额 大于 己.余额：
      抛出 值错误("余额不足")。
    己.余额 为 己.余额 减 金额。
    打印("取款成功，当前余额：" 加 己.余额)。

  段 查询余额()：
    返回 己.余额。

设 账户 为 创建银行账户("12345", 1000)。
账户.存款(500)。
账户.取款(200)。
打印(账户.查询余额())。
