# 光明 (Light) VSCode 扩展

光明编程语言的 VSCode 扩展，提供完整的语言支持。

## 功能

- **语法高亮**：L0-L4 全部语法，包括关键字、类型、运算符、注释、字符串、嵌入块等
- **代码片段**：v4.0/v4.3 代码片段，包括变量声明、条件判断、循环、函数定义、类定义、类型别名、泛型、模式匹配、调试输出等
- **运行命令**：运行当前 .light 文件
- **编译命令**：编译当前文件为 Python 代码
- **格式化命令**：格式化当前文件
- **解析命令**：查看 AST 解析树
- **构建项目**：构建整个项目
- **调试适配器**：支持断点、单步执行、变量查看、调用栈、表达式求值
- **LSP 语言服务**：代码补全、悬停提示、跳转定义、查找引用、文档符号、格式化、语义令牌、代码诊断
- **状态栏**：显示当前文体模式（L1/L2）
- **编辑器菜单**：标题栏运行按钮、右键菜单

## 安装

### 从 VSCode 扩展市场安装

1. 打开 VSCode
2. 按 `Ctrl+Shift+X` 打开扩展面板
3. 搜索 "光明" 或 "Light"
4. 点击安装

### 从 VSIX 安装

```bash
code --install-extension light-lang-5.0.0.vsix
```

## 使用

### 命令列表

| 命令 | 标题 | 快捷键 |
|------|------|--------|
| `light.runFile` | 光明: 运行当前文件 | `Ctrl+Shift+R` |
| `light.compileFile` | 光明: 编译当前文件 | `Ctrl+Shift+B` |
| `light.formatFile` | 光明: 格式化当前文件 | `Ctrl+Shift+F` |
| `light.parseFile` | 光明: 解析当前文件 (AST) | - |
| `light.compileNative` | 光明: 编译为原生可执行文件 (LLVM) | - |
| `light.buildProject` | 光明: 构建整个项目 | - |
| `light.showVersion` | 光明: 显示版本信息 | - |

### 调试

1. 打开 .light 文件
2. 按 `F5` 启动调试
3. 在行号左侧点击设置断点
4. 使用 `F10` 单步跳过，`F11` 单步进入，`Shift+F11` 单步跳出

### 文体模式

光明支持两种文体模式：
- **L1 白话**：使用 19 个白话关键字
- **L2 文言**：使用 30 个文言关键字

可在设置中修改 `light.style` 配置项切换。

## 配置

| 设置项 | 类型 | 默认值 | 描述 |
|--------|------|--------|------|
| `light.pythonPath` | string | `python` | Python 解释器路径 |
| `light.style` | string | `L2` | 默认文体模式 |
| `light.lsp.enabled` | boolean | `true` | 启用 LSP 语言服务器 |
| `light.debug.enabled` | boolean | `true` | 启用调试适配器 |

## 语言层级

光明编程语言分为五个层级：
- **L0 基础**：最简关键字集，共 19 个单字
- **L1 白话**：19 个白话关键字
- **L2 文言**：30 个文言关键字
- **L3 格律**：带格律约束的文体
- **L4 嵌入**：支持嵌入其他语言代码块
