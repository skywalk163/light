# 光明 K12 教育专属教学包

面向中小学（K12）学生的编程教育课程，使用光明 L1 白话体教学。

## 课程目录

| 课程 | 名称 | 内容 |
|------|------|------|
| 课程1 | 认识光明 | 编程是什么、安装环境、第一个程序 |
| 课程2 | 变量与计算 | 变量、数字、运算符、表达式 |
| 课程3 | 条件判断 | 如果/否则、比较运算符、逻辑判断 |
| 课程4 | 循环 | 当循环、遍循环、循环控制 |
| 课程5 | 函数 | 定义函数、参数、返回值 |
| 课程6 | 列表与字典 | 列表操作、字典操作、遍历 |
| 课程7 | 字符串 | 字符串操作、格式化、方法 |
| 课程8 | 文件操作 | 读写文件、CSV处理 |
| 课程9 | 小游戏 | 猜数字、石头剪刀布 |
| 课程10 | 综合项目 | 学生管理系统 |

## 使用方式

每课包含：
- `教案.md` - 教学计划（含知识点、示例、作业）
- `示例.light` - 可运行的光明代码
- `习题.md` - 课后练习题
