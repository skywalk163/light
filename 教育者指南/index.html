    版本： v6.2 更新日期： 2026-08-07 适用对象： 中小学信息技术教师、编程教育机构讲师、教育工作者

    1. 为什么光明适合 K12 教育？¶

    全中文关键字，零英文门槛¶

    光明的所有关键字均为中文（如 如果、循环、函数、输出），学生无需任何英语基础即可开始学习编程。这消除了语言障碍，让低龄学生和英语薄弱的学生也能专注于编程逻辑本身。

    自然语言式语法，降低认知负担¶

    光明的语法贴近自然语言表达，例如：

    循环 5 次：
    输出 "你好，世界！"

    相比传统编程语言中的 for i in range(5): print("Hello, World!")，光明的语法更直观，学生可以"所见即所得"地理解代码含义。

    内置 REPL 和调试器，交互式学习¶

    光明内置了交互式 REPL 环境，学生可以逐行输入代码并立即看到结果。调试器支持断点、单步执行和变量查看，帮助学生理解程序运行过程。

    丰富的趣味示例¶

    光明提供了针对不同年龄段设计的趣味示例，包括： - 图形绘制 — 用 ASCII 艺术画各种图形，学习循环和条件判断 - 猜数字游戏 — 带分数的交互式游戏，学习变量和用户输入 - 故事生成器 — 多模板故事生成器，学习字符串处理和函数

    这些示例让编程学习变得有趣且贴近生活。

    从光明到 Python 的自然过渡¶

    光明与 Python 在编程范式上高度一致，语法结构有清晰的映射关系。学会光明后，学生可以通过光明与 Python 对比案例快速过渡到 Python，继续进阶学习。

    2. 教学体系总览¶

    教学理念¶

    光明 K12 编程教育遵循"四阶递进"教学理念：

    启蒙 → 基础 → 进阶 → 应用
    • 启蒙阶段：激发兴趣，建立编程思维
    • 基础阶段：掌握核心语法，理解编程概念
    • 进阶阶段：学习数据结构与算法，培养计算思维
    • 应用阶段：项目实战，实现从光明到其他语言的迁移

    教学闭环¶

    每节课遵循"五步教学法"：

    导入（5 分钟）→ 讲解（15 分钟）→ 实践（20 分钟）→ 展示（10 分钟）→ 总结（10 分钟）
    1. 导入 — 通过生活场景或趣味问题引入课题
    2. 讲解 — 核心知识点讲解与演示
    3. 实践 — 学生动手编程，教师巡回指导
    4. 展示 — 学生展示作品，互相交流
    5. 总结 — 回顾知识点，布置课后练习

    资源配套¶

    每个教学阶段配套以下资源： - 教学课件（PPT/Keynote 模板） - 课堂活动手册 - 课后练习题库 - 项目评估标准 - 家长沟通指南

    3. 分龄教学方案¶

    方案总览¶

    年龄段 课程名称 课时 核心内容 推荐示例
    8-10 岁 编程启蒙 6 次课 × 1 小时 图形绘制、简单游戏 draw_shapes.light
    10-12 岁 编程基础 8 次课 × 1.5 小时 变量、条件、循环、函数 number_game.light
    12-14 岁 编程进阶 10 次课 × 1.5 小时 数据结构、算法、Web 开发 story_generator.light
    14-16 岁 编程应用 12 次课 × 2 小时 项目实战、Python 桥接 综合项目

    8-10 岁：编程启蒙¶

    教学目标： - 培养基本逻辑思维和顺序思维 - 理解"指令"和"程序"的概念 - 能够使用循环简化重复操作 - 体验编程的乐趣和创造力

    教学特点： - 以图形化输出为主，视觉反馈强烈 - 代码量少（每节课 10-20 行），循序渐进 - 强调"修改-观察-理解"的学习模式 - 每节课完成一个可展示的作品

    10-12 岁：编程基础¶

    教学目标： - 掌握变量、条件判断、循环三大核心概念 - 理解用户输入和程序交互 - 学会使用函数组织代码 - 能编写简单的交互式程序

    教学特点： - 引入交互式程序（输入/输出） - 代码量逐步增加（每节课 20-40 行） - 强调"变量"作为数据容器的概念 - 开始培养调试能力

    12-14 岁：编程进阶¶

    教学目标： - 掌握列表、字典等基本数据结构 - 理解模块化设计和函数抽象 - 学习基本的算法思维（搜索、排序） - 能够完成中等复杂度的编程项目

    教学特点： - 引入多种数据结构 - 代码量 40-80 行，涉及多个函数 - 强调模块化设计和代码复用 - 培养项目规划能力

    14-16 岁：编程应用¶

    教学目标： - 能够独立完成综合性编程项目 - 理解光明与 Python 的语法映射 - 掌握 Python 基础语法 - 具备自学新编程语言的能力

    教学特点： - 项目驱动，以完整项目为学习单元 - 引入 Python 对比学习 - 代码量 80-200 行，涉及多个文件 - 强调工程实践和代码规范

    4. 课程大纲¶

    4.1 编程启蒙（8-10 岁，6 次课）¶

    第 1 课：编程初体验¶

    项目 内容
    教学目标 理解程序的概念，能运行第一个光明程序
    核心知识点 输出语句、字符串、运行程序
    课堂活动 运行 draw_shapes.light，观察各种图形输出
    课后练习 修改输出内容，用自己的名字替换图形中的文字
    预期成果 能独立运行程序，理解"代码→运行→结果"的过程

    第 2 课：神奇的循环¶

    项目 内容
    教学目标 理解循环的概念，能用循环简化重复操作
    核心知识点 循环语句、缩进、循环次数
    课堂活动 用循环画不同大小的三角形，观察循环次数对图形的影响
    课后练习 用循环画出正方形、长方形等新图形
    预期成果 能独立编写包含循环的图形绘制程序

    第 3 课：条件判断¶

    项目 内容
    教学目标 理解条件判断的概念，能根据条件控制程序行为
    核心知识点 条件语句、比较运算符、奇偶判断
    课堂活动 修改棋盘程序，尝试不同的颜色组合
    课后练习 编写一个"星期几"程序，输入数字输出对应的星期名称
    预期成果 能使用条件判断控制程序输出

    第 4 课：函数小能手¶

    项目 内容
    教学目标 理解函数的概念，能定义和调用函数
    核心知识点 函数定义、函数调用、参数
    课堂活动 将画不同图形的代码封装成函数，组合成"图形画册"
    课后练习 编写一个"画花"函数，用循环和图形组合出花朵图案
    预期成果 能定义带参数的函数，实现代码复用

    第 5 课：综合创作¶

    项目 内容
    教学目标 综合运用所学知识创作完整程序
    核心知识点 循环 + 条件 + 函数综合运用
    课堂活动 设计并实现一个"艺术画板"程序，组合多种图形
    课后练习 为画板添加新图形（星形、菱形等）
    预期成果 完成一个包含多种图形和颜色的个人作品

    第 6 课：作品展示会¶

    项目 内容
    教学目标 展示作品，互相学习，培养表达能力
    核心知识点 回顾与总结
    课堂活动 学生展示作品，介绍自己的创意和实现方法
    课后练习 无
    预期成果 每个学生完成一个可展示的编程作品

    5. 课堂活动设计¶

    活动 1：代码侦探¶

    目标： 培养代码阅读和理解能力

    准备： - 打印 3-5 段包含不同错误或有趣现象的光明代码 - 每组学生准备纸笔

    步骤： 1. 将学生分成 4-5 人小组 2. 每组分发一段代码，要求在不运行的情况下预测输出 3. 学生讨论并写下预测结果 4. 教师运行代码，展示实际输出 5. 各小组对比预测与实际结果，讨论差异原因 6. 小组轮流分享发现

    讨论点： - 为什么预测和实际结果不同？ - 代码中的哪些部分最容易让人误解？ - 如何通过阅读代码理解程序行为？

    活动 2：拼图编程¶

    目标： 理解程序结构和逻辑顺序

    准备： - 将一个完整光明程序拆分为多行代码卡片 - 每行代码写在一张卡片上 - 准备 3-4 套不同程序的卡片

    步骤： 1. 将学生分成 3-4 人小组 2. 每组发放一套打乱的代码卡片 3. 学生需要讨论并拼出正确的程序顺序 4. 完成后运行验证 5. 小组间交换卡片，尝试拼出对方程序 6. 讨论不同的程序结构

    讨论点： - 哪些代码行有固定的顺序要求？ - 哪些代码行可以调换顺序而不影响结果？ - 程序的结构如何影响运行结果？

    活动 3：创意改造工坊¶

    目标： 培养创造性思维和代码修改能力

    准备： - 运行正常的光明示例程序 - 提出改造目标（如：把猜数字变成猜颜色、把画三角形变成画星星）

    步骤： 1. 教师展示一个正常运行的光明程序 2. 提出一个改造目标，要求学生分组讨论改造方案 3. 各小组在 15 分钟内完成改造 4. 运行改造后的程序，展示改造成果 5. 全班投票选出"最有创意改造奖" 6. 获奖小组分享改造思路

    讨论点： - 改造过程中遇到了哪些困难？ - 如何保持改造后程序的正确性？ - 改造给程序带来了哪些新的可能性？

    活动 4：结对编程挑战¶

    目标： 培养协作编程能力和沟通能力

    准备： - 每台计算机配备两名学生 - 准备 3 个递进难度的编程任务 - 计时器

    步骤： 1. 学生两人一组，一人为"驾驶员"（负责敲键盘），一人为"导航员"（负责观察和思考） 2. 教师发布第一个编程任务 3. 学生开始编程，每 5 分钟交换角色 4. 完成后进入下一个难度任务 5. 记录每组的完成时间和正确率 6. 讨论结对编程的体验

    讨论点： - 作为驾驶员和导航员，感受有什么不同？ - 如何有效沟通编程思路？ - 结对编程比独立编程有哪些优势？

    活动 5：Bug 大作战¶

    目标： 培养调试能力和错误分析能力

    准备： - 准备 5 个包含不同类型 Bug 的光明程序 - Bug 类型包括：语法错误、逻辑错误、运行时错误 - 为每个 Bug 准备提示卡（可选）

    步骤： 1. 将学生分成 3-4 人小组 2. 每组获得一个包含 Bug 的程序 3. 学生需要找出并修复所有 Bug 4. 记录每个 Bug 的类型、位置和修复方法 5. 完成的小组可以挑战其他组的 Bug 6. 总结常见 Bug 类型和调试技巧

    讨论点： - 哪些 Bug 最容易发现？哪些最难？ - 有什么有效的调试策略？ - 如何避免常见的编程错误？

    6. 评估与考核¶

    6.1 形成性评估方法¶

    形成性评估贯穿整个教学过程，主要采用以下方法：

    评估方法 实施方式 频次 评估内容
    课堂观察 教师记录学生课堂参与度和理解程度 每节课 学习态度、参与度
    代码走查 随机检查学生编写的代码 每节课 代码规范、逻辑正确性
    快速问答 课堂口头提问 每节课 2-3 次 知识点掌握程度
    同伴互评 学生互相评价作品 每单元 作品质量、创意
    学习日志 学生记录学习心得和遇到的问题 每节课 反思能力、问题记录

    6.2 项目制考核标准¶

    每个教学阶段结束时，学生需完成一个综合性项目。项目考核采用四维评分标准：

    维度 权重 优秀（90-100） 良好（75-89） 合格（60-74） 待改进（<60）
    功能完整性 35% 功能完整，运行无误 主要功能完整，有小缺陷 核心功能可用 无法正常运行
    代码质量 25% 结构清晰，命名规范，有注释 结构合理，偶有冗余 能工作但代码混乱 代码难以理解
    创意与设计 25% 设计新颖，有独特创意 有一定创意 基本完成功能 缺乏设计思考
    展示与表达 15% 表达清晰，能回答提问 表达基本清楚 能展示但说不清 无法展示

    7. 常见问题¶

    Q1：光明适合多大年龄的孩子？¶

    光明适合 8 岁及以上的学生。8-10 岁建议从图形绘制和简单游戏开始，10-14 岁可以学习完整的编程基础，14 岁以上可以进行项目实战和 Python 桥接。

    Q2：学生需要具备哪些基础？¶

    零基础即可。光明的全中文关键字和自然语言式语法设计，就是为了降低入门门槛。学生只需要具备基本的读写能力和逻辑思维能力。

    Q3：一个班需要多少课时？¶

    光明 K12 课程共 36 次课，分为四个阶段： - 启蒙阶段：6 次课 × 1 小时 - 基础阶段：8 次课 × 1.5 小时 - 进阶阶段：10 次课 × 1.5 小时 - 应用阶段：12 次课 × 2 小时

    建议每周 1 次课，学完全部课程约需 9 个月。

    Q4：教学需要什么硬件和软件？¶

    硬件要求： - 每名学生一台计算机（Windows / macOS / Linux 均可） - 投影仪或大屏显示器（教师演示用）

    软件要求： - Python 3.10 或更高版本 - 光明编译器 v6.0 或更高版本 - 文本编辑器（推荐 VS Code 或任何代码编辑器）

    Q5：光明和其他编程语言（如 Scratch、Python）相比有什么优势？¶

    对比项 光明 Scratch Python
    语言门槛 全中文，零门槛 图形化，零门槛 英文关键字
    键盘输入 需要 拖拽为主 需要
    语法复杂度 极低 无 中等
    真实编程体验 ✓ ✗（图形化） ✓
    向专业语言过渡 自然过渡到 Python 需重新学习 本身即是专业语言
    适合年龄 8 岁+ 6-12 岁 12 岁+

    Q6：如何评估学生是否适合进入下一阶段？¶

    通过以下方式综合评估： 1. 完成当前阶段的项目并通过考核（评分 ≥ 60 分） 2. 掌握当前阶段 80% 以上的核心知识点 3. 具备独立完成当前阶段难度任务的能力

    具体评估标准参见第 6 节"评估与考核"。

    Q7：学生学完光明后，如何过渡到 Python？¶

    光明设计时就考虑了与 Python 的桥接： 1. 光明与 Python 共享相同的编程范式（面向过程/函数式） 2. 光明的变量、循环、条件、函数等概念与 Python 完全对应 3. 参考 docs/光明与Python对比案例.md 中的语法对照表 4. 应用阶段（14-16 岁）的课程专门设计了 Python 桥接内容

    Q8：家长如何配合教学？¶

    1. 创造编程环境：为孩子准备一台可用的计算机
    2. 鼓励：关注孩子的学习进展，及时给予鼓励
    3. 参与：参加家长开放日，了解孩子的学习成果
    4. 延伸：鼓励孩子用光明解决生活中的小问题

    Q9：教学过程中遇到技术问题怎么办？¶

    • 参考 docs/30分钟入门光明.md 中的安装和使用教程
    • 查看光明编译器的错误信息，通常包含详细的提示
    • 利用 REPL 环境逐行测试代码，定位问题

    Q10：光明的教学资源是否免费？¶

    光明编译器本身是开源免费的。本指南配套的教学资源（课件模板、活动手册、练习题库等）将陆续在光明社区中开放，欢迎教育工作者贡献和分享自己的教学资源。

    开始教学： 从第一节课开始，让学生运行 light run examples/kids/draw_shapes.light，感受编程的乐趣！

    更多教学资源，请参考 少儿编程趣味示例 README。
