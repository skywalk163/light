    30 分钟入门光明¶

    版本： v6.0 光明是一门中文编程语言——关键字用中文书写，同时支持中文运算符和符号运算符，让零基础用户也能快速上手编程。

    本教程专为 从未写过代码 的中文用户设计，跟着读完即可独立编写简单程序。

    📋 教程地图¶

    ① 安装环境  ──→  ② 第一个程序  ──→  ③ REPL 练手  ──→  ④ 基础语法
                                                      │
                                                      ↓
⑧ 发布程序  ←──  ⑦ 调试排错  ←──  ⑥ 异常处理  ←──  ⑤ 高级语法
                                                      │
                                                      ↓
                                              ⑨ 从错误中学习

    预计时间： 30 分钟
    适合人群： 完全零基础的中文用户
    学完你将能： 独立编写、调试、编译光明程序

    🔰 第一部分：环境准备（5 分钟）¶

    1.1 安装 Python——为什么光明需要它？¶

    光明的语言本身是用 Python 编写的，所以它需要 Python 环境来运行。你可以把 Python 想象成「语言的土壤」——光明这棵「树」生长在 Python 的土壤上。

    为什么不用 C++ 或 Rust 写编译器？ 因为 Python 生态成熟、跨平台方便，而且光明的目标用户是中文初学者，降低安装门槛比追求极致性能更重要。

    操作步骤：

    1. 访问 python.org，下载最新版 Python（3.10 或更高）
    2. 运行安装程序，务必勾选「Add Python to PATH」

      为什么勾选这个？它让系统知道「python」这个命令在哪，否则你敲 python 时系统会说「找不到命令」

    3. 一路「下一步」完成安装

    验证安装： 打开终端（Windows 按 Win+R，输入 cmd 回车），输入：

    python --version

    看到类似 Python 3.12.x 就说明成功了。

    1.2 安装光明¶

    在终端中执行：

    pip install light

    为什么用 pip？ pip 是 Python 的包管理器——就像手机上的应用商店。你输入 pip install 包名，它就会从 PyPI（Python 包仓库）下载软件并自动安装。

    验证安装：

    light --version

    看到 光明编译器 v6.x.x 说明安装成功。

    1.3 你的第一个光明程序¶

    创建文件 hello.light，写入：

    打印 "你好，光明！"

    为什么文件后缀是 .light？ 后缀名告诉计算机「这是一个光明源文件」，就像 .docx 表示 Word 文档一样。

    运行它：

    light run hello.light

    看到 你好，光明！ 输出——恭喜，你已经跑通了第一个光明程序！

    为什么 打印 不需要括号？ 光明中 打印 是内置命令，加括号也可以（打印("你好")），两种写法等价。这是为了让零基础用户少记一个语法规则。

    🚀 第二部分：第一个完整程序（5 分钟）¶

    2.1 变量——为什么需要「盒子」？¶

    变量就像厨房里的储物盒——你把不同的东西放进不同的盒子，需要时打开盒子取出来。计算机用变量来「记住」数据。

    设 名字 为 "张三"
设 年龄 为 25
设 身高 为 1.75

打印 名字
打印 年龄
打印 身高

    语法拆解： - 设 → 告诉光明「我要创建一个变量」 - 名字 → 给盒子贴标签（变量名） - 为 → 把右边的值放进去 - "张三" → 带引号的是文本（字符串），不带引号的是数字

    为什么用 设 而不是 var 或 let？ 光明的目标是让中文母语者用母语思考。「设」在中文里就是「设定一个变量」的意思，不用先翻译成英文再理解。

    2.2 字符串插值——把变量嵌入文字¶

    如果想把变量嵌入到一段文字中，用 f 开头的字符串（f-string）：

    设 名字 为 "光明"
设 版本 为 1.11

打印(f"语言：{名字}，版本：{版本}")

    为什么叫 f-string？ 这里的 f 代表「format」（格式化）。{名字} 就像一个占位符，运行时会被变量的实际值替换。输出：

    语言：光明，版本：1.11

    2.3 注释——给未来的自己写纸条¶

    # 开头的是注释——程序会跳过它，完全不执行。注释是写给人看的：

    # 计算年龄
设 当前年份 为 2026
设 出生年份 为 2000
设 年龄 为 当前年份 - 出生年份  # 结果：26
打印 年龄

    为什么需要注释？ 你写代码时头脑清醒，但一个月后回来看，可能完全想不起当初为什么这么写。注释就是给「未来的自己」留的纸条。

    2.4 交互式输入——让程序和你对话¶

    使用 输入 函数让程序等待用户输入：

    设 名字 为 输入("请输入你的名字：")
打印(f"你好，{名字}！欢迎学习光明！")

    为什么需要 输入？ 没有它，程序只能输出固定的内容。有了它，程序可以根据用户的输入做出不同响应——这才是真正的「交互」。

    2.5 句号是可选的¶

    光明语句末尾的句号「。」是可选的——加了不影响运行，不加也完全没问题。本教程的示例一律不加句号，保持简洁。

    为什么设计成可选的？ 中文编程的初心是降低门槛。强制句号会让初学者多一个「忘记加句号」的报错，这和光明的设计理念不符。

    💻 第三部分：REPL——边敲边学（5 分钟）¶

    3.1 什么是 REPL？¶

    REPL 是 Read-Eval-Print Loop（读取-求值-打印-循环）的缩写。简单说，就是一个「敲一行，执行一行」的交互式环境。

    为什么需要 REPL？ 你想试试某个语法对不对，不用创建文件、不用保存、不用 light run——直接敲进去就能看到结果。这是学习新语言最快的方式。

    启动 REPL：

    light repl

    你会看到类似这样的提示符：

    光明 REPL v6.0
>>>

    3.2 REPL 基础操作¶

    试试在 >>> 后面敲这些：

    >>> 打印 "你好，REPL！"
你好，REPL！

>>> 设 甲 为 10
>>> 设 乙 为 20
>>> 甲 + 乙
30

>>> 10 * 3 + 5
35

    为什么最后一个没写 打印 也有输出？ 在 REPL 中，输入一个表达式，它会自动计算并显示结果。这让你可以快速验证想法。

    3.3 REPL 中的多行代码¶

    复杂语句需要多行时，REPL 会自动识别：

    >>> 如果 10 > 5：
...     打印 "10 大于 5"
... 否则：
...     打印 "这个不会被执行"
...
10 大于 5

    看到 ... 提示符表示 REPL 在等你继续输入。

    3.4 REPL 实用技巧¶

    >>> # 快速计算
>>> 1024 * 768
786432

>>> # 字符串操作
>>> "光明" + "真棒"
光明真棒

>>> # 查看帮助
>>> 帮助(打印)
打印(value) → 输出内容到屏幕

    退出 REPL 按 Ctrl+Z 回车（Windows）或 Ctrl+D（Mac/Linux），也可以输入 退出()。

    🔢 第四部分：基本运算与条件判断（5 分钟）¶

    4.1 算术运算——为什么有两种写法？¶

    光明同时支持符号运算符和中文运算符，两者完全等价：

    设 甲 为 10
设 乙 为 3

打印(甲 + 乙)       # 加法 → 13    等价于：甲 加 乙
打印(甲 - 乙)       # 减法 → 7     等价于：甲 减 乙
打印(甲 * 乙)       # 乘法 → 30    等价于：甲 乘 乙
打印(甲 / 乙)       # 除法 → 3.333  等价于：甲 除 乙
打印(甲 // 乙)      # 整除 → 3     等价于：甲 整除 乙
打印(甲 % 乙)       # 取余 → 1     等价于：甲 取余 乙
打印(甲 ** 乙)      # 幂 → 1000    等价于：甲 幂 乙

    为什么设计两种写法？ 新手可能记不住 // 表示整除、% 表示取余——但「整除」「取余」一看就懂。同时保留符号写法是为了让有编程经验的用户能快速上手。推荐使用符号写法，更简洁通用。

    💡 小提示： % 取余在实际编程中非常常用——判断奇偶（数 % 2 == 0）、循环取数等场景都会用到。

    4.2 比较运算¶

    比较的结果是 真（成立）或 假（不成立）：

    设 甲 为 10
设 乙 为 5

打印(甲 > 乙)        # 真    等价于：甲 大于 乙
打印(甲 < 乙)        # 假    等价于：甲 小于 乙
打印(甲 == 乙)       # 假    等价于：甲 等于 乙
打印(甲 != 乙)       # 真    等价于：甲 不等于 乙
打印(甲 >= 乙)       # 真    等价于：甲 大于等于 乙

    注意： == 是「判断相等」，= 是「赋值」。这是编程初学者最容易犯的错误之一——后面「从错误中学习」部分会详细讲。

    4.3 逻辑运算——组合多个条件¶

    用 且（两个都满足）、或（满足其一即可）、非（取反）连接多个条件：

    设 年龄 为 20
设 有身份证 为 真

如果 年龄 >= 18 且 有身份证：
    打印 "可以上网"

    4.4 条件判断——让程序做决策¶

    设 分数 为 85

如果 分数 >= 90：
    打印 "优秀"
否则如果 分数 >= 60：
    打印 "及格"
否则：
    打印 "不及格"

    为什么用冒号和缩进？ 冒号（：）告诉光明「接下来是条件成立时要执行的代码」，缩进（前面空两格或四格）标示哪些代码属于这个条件。这是 Python 和光明共同的风格——强制缩进让代码结构一目了然。

    4.5 三元表达式——一行写完二选一¶

    设 数 为 10
设 结果 为 "偶数" 如果 数 % 2 == 0 否则 "奇数"
打印 结果    # 输出: 偶数

    为什么叫「三元」？ 因为它有三个部分：条件（数 % 2 == 0）、条件成立时的值（"偶数"）、条件不成立时的值（"奇数"）。

    4.6 循环——让计算机做重复的事¶

    计算机最擅长的事情就是——不厌其烦地重复。

    当循环（while）——「只要条件成立，就一直做」：

    设 计数 为 1
当 计数 <= 5：
    打印(f"第{计数}次")
    计数 = 计数 + 1

    为什么叫「当」？ 你读出来就是「当计数小于等于5时，执行大括号里的代码」——和日常说话完全一致。

    遍历循环（for）——「对每个元素做一次」：

    遍历 项 在 1 到 5：
    打印 项

    遍历列表：

    设 水果 为 ["苹果", "香蕉", "橘子"]
遍历 水果 为 果：
    打印 果

    循环控制：

    • 跳出：立刻结束整个循环（相当于 break）
    • 跳过：跳过当前这一轮，直接进入下一轮（相当于 continue）
    遍历 项 在 1 到 10：
    如果 项 % 2 == 0：
        跳过           # 跳过偶数
    如果 项 > 7：
        跳出           # 超过 7 就停止
    打印 项            # 输出：1, 3, 5, 7

    ⚡ 第五部分：段落（函数）——把代码打包（3 分钟）¶

    5.1 定义和调用——为什么需要「段落」？¶

    想象你每天都在写：

    打印 "你好，张三！"
# ... 50行代码 ...
打印 "你好，张三！"

    太重复了！函数就是把这些代码「打包」成一个名字，需要时叫一下名字就行：

    段落 问好 接收 名字：
    打印(f"你好，{名字}！")

问好("张三")   # 输出：你好，张三！
问好("李四")   # 输出：你好，李四！

    为什么叫「段落」？ 文章由段落组成，程序也由一个个「段落」组成。每个段落做一件事，组合起来就是一个完整的程序。

    语法拆解： - 段落 → 关键字，告诉光明「我要定义一个函数」 - 问好 → 函数名，你自己起 - 接收 名字 → 参数列表，调用者传入的数据 - ： → 后面缩进的代码是这个「段落」的内容 - 返回 → 把结果「抛」回给调用者

    5.2 返回值¶

    段落 加法 接收 a, b：
    返回 a + b

设 结果 为 加法(3, 5)
打印 结果    # 输出: 8

    为什么需要 返回？ 没有 返回，函数虽然计算了 a + b，但结果只在函数内部「消化」了，外面拿不到。返回 就是把结果「传递」出来。

    5.3 默认参数——给参数一个「保底值」¶

    段落 问候 接收 名字 = "世界"：
    打印(f"你好，{名字}！")

问候("张三")    # 你好，张三！
问候()          # 你好，世界！

    为什么需要默认参数？ 有些参数大多数时候用同一个值，只有少数情况需要改。默认参数让你少写代码。

    5.4 递归——函数调用自己¶

    段落 阶乘 接收 n：
    如果 n <= 1：
        返回 1
    返回 n * 阶乘(n - 1)

打印 阶乘(5)    # 输出: 120

    递归是怎么工作的？ 阶乘(5) 会调用 阶乘(4)，阶乘(4) 会调用 阶乘(3)……直到 阶乘(1) 直接返回 1，然后结果一层层「传回来」：

    阶乘(5) = 5 * 阶乘(4)
        = 5 * 4 * 阶乘(3)
        = 5 * 4 * 3 * 阶乘(2)
        = 5 * 4 * 3 * 2 * 阶乘(1)
        = 5 * 4 * 3 * 2 * 1
        = 120

    ⚠️ 递归必须有「出口」：也就是 n <= 1 时直接返回，否则会无限循环下去。

    6.1 列表——多个东西放一起¶

    设 水果 为 ["苹果", "香蕉", "橘子"]
打印 水果[0]    # 输出：苹果（为什么从0开始？下文解释）
水果.追加("葡萄")
打印 长度(水果)  # 输出：4

    为什么索引从 0 开始？ 计算机内部，列表是一块连续的内存地址。[0] 表示「第一个元素的位置」，偏移 0 个单位。[1] 表示偏移 1 个单位。虽然初学者觉得从 1 开始更自然，但几乎所有编程语言都从 0 开始——这是编程的「通用约定」。

    6.2 列表推导——一行代码生成列表¶

打印 平方数    # 输出：[1, 4, 9, 16, 25]

    读法： 「x 乘 x，遍历 x 从 1 到 5 的范围」——和中文的表达顺序完全一致。

    带条件筛选：

    设 偶数 为 [x 遍历 x 之 范围(1, 11) 若 x % 2 == 0]
打印 偶数  # [2, 4, 6, 8, 10]

    6.4 字典——键值对映射¶

    设 学生 为 {"名字": "张三", "年龄": 25, "成绩": 95}
打印 学生["名字"]    # 输出：张三
打印(f"{学生['名字']}的年龄是{学生['年龄']}")

    为什么需要字典？ 列表用数字索引（0, 1, 2...），但数字不直观。字典让你用「名字」这样的文字来查找——就像查字典一样。

    🏗️ 第七部分：类与对象（3 分钟）¶

    7.1 面向对象——为什么需要类和对象？¶

    写程序时，我们经常需要表示「现实世界的事物」——比如一个学生有名字、年龄、成绩，还能计算平均分。用之前学的变量可以做到，但会很零散：

    设 张三的名字 为 "张三"
设 张三的年龄 为 20
设 张三的成绩 为 [85, 92, 78]
# ... 如果有10个学生，就有30个变量，太乱了！

    类 就是「蓝图」，对象 就是根据蓝图造出来的「实物」：

    类 学生：
    属性 名字
    属性 年龄
    属性 成绩

    构造 接收 名字, 年龄：
        己.名字 为 名字
        己.年龄 为 年龄
        己.成绩 为 []

    段落 添加成绩 接收 分数：
        己.成绩.追加(分数)

    段落 平均分 接收：
        如果 长度(己.成绩) == 0：
            返回 0
        设 总和 为 0
        遍历 己.成绩 为 分：
            设 总和 为 总和 + 分
        返回 总和 / 长度(己.成绩)

# 创建对象——根据「蓝图」造出「实物」
设 张三 为 学生("张三", 20)
张三.添加成绩(85)
张三.添加成绩(92)
打印(f"{张三.名字}的平均分是{张三.平均分()}")

    为什么要用 己？ 己 相当于其他语言的 this 或 self，表示「当前对象自己」。己.名字 的意思是「这个学生自己的名字」。

    7.2 继承——减少重复代码¶

    当两个类有很多共同点，可以让一个类「继承」另一个类的功能：

    类 动物：
    属性 名字

    构造 接收 名字：
        己.名字 为 名字

    段落 介绍 接收：
        打印(f"我叫{己.名字}")

类 狗 继承 动物：
    段落 叫 接收：
        打印 "汪汪！"

设 小狗 为 狗("旺财")
小狗.介绍()    # 我叫旺财（继承自动物）
小狗.叫()      # 汪汪！（自己的方法）

    为什么说「继承」？ 就像孩子继承父母的基因——狗 自动拥有 动物 的所有属性和方法，不需要重新写一遍。

    7.3 静态方法——不需要对象就能调用的方法¶

    类 数学工具：
    静态 段落 平方 接收 x：
        返回 x * x

打印 数学工具.平方(5)    # 输出: 25

    为什么需要静态方法？ 有些工具函数不需要创建对象就能用——数学工具.平方(5) 直接调用，不用先 设 工具 为 数学工具()。

    8.1 异常处理——程序出错了怎么办？¶

    程序运行中总会有意外——比如用户输入了不合法的数据、要读取的文件不存在。尝试/捕获 就是给程序穿上「防弹衣」：

    尝试：
    设 结果 为 10 / 0
    打印 结果
捕获 错误：
    打印("出错了：" + 转字符串(错误))
最终：
    打印("无论是否异常都会执行")

    为什么需要 最终？ 有些操作无论成功还是失败都必须执行——比如关闭文件、释放资源。最终 保证了这一点。

    8.2 主动抛出异常¶

    打印(f"年龄是{年龄}")

尝试：
    检查年龄(-5)
捕获 e：
    打印("捕获到异常：" + 转字符串(e))

    10.1 为什么需要调试器？¶

    写完代码第一次运行就完美通过——这种情况几乎不存在。调试器让你可以逐行执行代码，观察每一行执行后变量的变化，找到问题所在。

    10.2 使用 light debug¶

    光明内置了调试器，直接用 light debug 命令：

    light debug hello.light

    调试器常用命令：

    命令 作用 为什么用这个？
    b 5 在第 5 行设置断点 让程序在指定行停下来，方便观察
    d 5 删除第 5 行的断点 不再需要时清除
    c 继续执行到下一个断点 跳过不需要细看的代码
    n 单步跳过（不进入函数内部） 如果函数是可信的，直接跳过
    s 单步进入（进入函数内部） 想看函数内部发生了什么
    p 变量名 打印变量的当前值 检查变量是否如预期
    w 显示调用栈 看当前是哪个函数调了哪个函数
    l 显示当前源代码 确认当前执行到哪一行
    vars 显示所有变量 全局查看所有变量的状态
    q 退出调试 结束调试

    10.3 实战调试示例¶

    段落 阶乘 接收 n：

        返回 1
    返回 n * 阶乘(n - 1)

设 结果 为 阶乘(5)
打印(f"5! = {结果}")

    🚢 第十一部分：编译与发布——把程序变成 EXE（额外 3 分钟）¶

    11.1 为什么需要编译？¶

    你写的 .light 文件需要光明环境才能运行——别人得先安装光明才能跑你的程序。编译成 .exe 文件后，任何 Windows 用户（即使没有安装 Python 和光明）都能直接运行。

    11.2 编译为 Python 代码¶

    light compile hello.light -o hello.py

    为什么先编译成 Python？ 光明解释器本身是 Python 写的，编译成 Python 代码后，可以借助 Python 生态进一步打包成 EXE。

    11.3 编译为独立的 EXE 文件¶

    # 需要先安装 PyInstaller（只需一次）
pip install pyinstaller

# 编译为 exe
light compile hello.light -o hello.exe

    原理： light compile 先把光明代码翻译成 Python，然后 PyInstaller 把 Python 打包成一个独立的 .exe 文件。这个文件里包含了运行所需的一切，无需任何环境就能运行。

    11.4 LLVM 原生编译——更快、更小¶

    light build hello.light -o hello.exe

    为什么用 light build 而不是 light compile？ light build 走的是 LLVM 后端——直接把光明代码编译成机器码，生成的原生可执行文件启动更快、体积更小，不需要 Python 运行时。

    light build 和 light compile 的区别：

    命令 后端 输出 是否需要 Python 启动速度
    light compile SRC/ANTLR .py 或 .exe 打包后不需要 中等
    light build LLVM 原生 .exe 不需要 最快

    注意： 如果代码中使用了类（class）等高级特性，需要使用 LLVM 后端才能正确编译。可以用 light ai check 检测代码与后端的兼容性。

    🧠 第十二部分：从错误中学习——常见新手错误¶

    错误是学习编程的最佳老师。下面列出光明新手最常见的错误，遇到时对照检查。

    错误 1：忘了写 为¶

    # ❌ 错误
设 名字 "张三"

    # ✅ 正确
设 名字 为 "张三"

    为什么？ 设 X 为 Y 是固定语法结构，为 是必须的关键字，漏掉它会报语法错误。

    错误 2：混淆 = 和 ==¶

    # ❌ 错误：这是赋值，不是比较
如果 分数 = 100：
    打印 "满分"

    # ✅ 正确：== 才是比较
如果 分数 == 100：
    打印 "满分"

    为什么？ = 是「把右边的值放进左边」，== 是「判断左右两边是否相等」。这个错误几乎每个编程初学者都会犯——连有经验的程序员偶尔也会写错。

    错误 3：忘记冒号 ：¶

    # ❌ 错误
如果 年龄 >= 18
    打印 "成年"

    # ✅ 正确
如果 年龄 >= 18：
    打印 "成年"

    为什么？ 冒号告诉光明「条件写完了，后面是要执行的代码块」。光明中 如果、否则、遍历、当、段落、类 后面都需要冒号。

    错误 4：缩进不一致¶

    # ❌ 错误：缩进混乱
如果 真：
    打印 "第一行"
  打印 "第二行"  # 缩进不对

# ✅ 正确：统一缩进
如果 真：
    打印 "第一行"
    打印 "第二行"

    为什么？ 光明用缩进（空格或 Tab）来标示代码块的归属。缩进不统一，光明无法判断某行代码属于哪个块。建议统一使用 4 个空格。

    错误 5：变量名冲突¶

    # ❌ 错误：使用内置函数名作变量名
设 打印 为 123
打印(打印)  # 报错：打印不再是函数了

# ✅ 正确：避免使用关键字
设 打印值 为 123
打印(打印值)

    为什么？ 打印、输入、长度、转字符串 等是光明的内置函数，把它们当作变量名会覆盖内置函数。

    错误 6：索引越界¶

    # ❌ 错误
设 列表 为 [1, 2, 3]
打印 列表[5]  # 列表只有3个元素，索引5不存在

# ✅ 正确：先检查长度
设 列表 为 [1, 2, 3]
如果 长度(列表) > 5：
    打印 列表[5]
否则：
    打印(f"列表只有{长度(列表)}个元素，索引5不存在")

    为什么？ 列表索引从 0 开始，长度为 3 的列表，有效索引是 0、1、2。

    错误 7：字符串引号不匹配¶

    # ❌ 错误
设 消息 为 "你好'

    # ✅ 正确：引号成对
设 消息 为 "你好"
设 消息2 为 '你好'

    为什么？ 字符串必须用成对的引号包裹。" 开始就要用 " 结束，' 开始就要用 ' 结束。

    错误 8：修改列表时用 设¶

    # ❌ 错误：创建变量用「设」，修改列表元素用「=」
设 列表 为 [1, 2, 3]
设 列表[0] 为 10  # 在 SRC 后端不支持

# ✅ 正确：直接赋值
设 列表 为 [1, 2, 3]
列表[0] = 10

    🎯 第十三部分：综合实战——猜数字游戏¶

    把学到的知识串起来，写一个完整的猜数字游戏：

# 生成 1 到 100 的随机数
