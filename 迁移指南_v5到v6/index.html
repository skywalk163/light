    迁移指南：从 v5.x 迁移到 v6.0¶

    本文档帮助你将段言代码从 v5.x 版本迁移到 v6.0.0。

    版本变更概览¶

    版本 发布时间 主要变更
    v5.5.0 2026-08-07 AI 工具链 2.0，包管理器增强，LSP 完整实现
    v5.6.0 2026-08-07 核心语言特性（异常/模式匹配/异步/装饰器/上下文管理器）
    v6.0.0-rc1 2026-08-07 Web 框架，示例项目，包注册中心，英文文档
    v6.0.0 2026-08-07 正式发布，社区建设，文档完善，安全审计

    1. 语法变更¶

    1.1 新增语法（v5.6.0）¶

    异常处理¶

    # v5.x — 基础异常处理
尝试：
    设 结果 为 10 除以 0
捕获：
    打印 "出错了"

# v6.0 — 完整异常处理
尝试：
    设 结果 为 10 除以 0
捕获 值异常 为 e：
    打印 "值错误：" + 转字符串(e)
捕获 错误 为 e：
    打印 "其他错误：" + 转字符串(e)
最终：
    打印 "清理完成"

# 异常链
尝试：
    抛出 值异常("原始错误")
捕获 错误 为 e：
    打印 "原始错误：" + 转字符串(e)
    抛出 运行时异常("包装错误")

    模式匹配¶

    # v5.x — 传统条件判断
设 值 为 [1, 2, 3]
如果 值.长度 等于 3 且 值[0] 等于 1：
    打印 "匹配"

# v6.0 — 结构化模式匹配
匹配 值：
    情况 [1, 甲, 乙]：
        打印 "匹配到列表: " + 转字符串(甲) + ", " + 转字符串(乙)
    情况 整数 甲 且 甲 大于 0：
        打印 "正整数: " + 转字符串(甲)
    情况 字符串 甲：
        打印 "字符串: " + 甲
    情况 _：
        打印 "无匹配"

    异步/协程¶

    # v5.x — 同步代码
段落 获取数据 接收 网址：
    设 响应 为 请求(网址)
    返回 响应

# v6.0 — 异步代码
异步 段落 获取数据 接收 网址：
    设 响应 为 等待 请求(网址)
    返回 响应

异步 段落 主程序：
    设 数据 为 等待 获取数据("https://api.example.com")
    打印 数据

异步 运行 主程序()。

    装饰器¶

    # v5.x — 手动装饰
段落 计算 接收 甲, 乙：
    返回 甲 加 乙
计算 = 日志装饰器(计算)

# v6.0 — 装饰器语法
@日志
段落 计算 接收 甲, 乙：
    返回 甲 加 乙

# 参数化装饰器
@重试(最大次数=3, 延迟=1.0)
段落 不稳定函数 接收 参数：
    返回 可能失败的调用(参数)

    上下文管理器¶

    # v5.x — 手动管理资源
设 文件 为 打开("文件.txt", "读取")
设 内容 为 文件.读取()
文件.关闭()

# v6.0 — 使用上下文管理器
使用 打开("文件.txt", "读取") 为 文件：
    设 内容 为 文件.读取()
    打印 内容

# 异步上下文管理器
使用 异步 打开("文件.txt", "读取") 为 文件：
    设 内容 为 等待 文件.读取()
    打印 内容

    1.2 Web 框架（v6.0.0-rc1）¶

    # 从 duanpub 导入 Web 框架
从 Web框架 导入 创建应用, 路由, 启动, 静态文件, JSON响应

# 创建应用
设 应用 为 创建应用()

# 路由定义
@路由(应用, "/", "GET")
段落 首页 接收 请求：
    返回 "欢迎使用段言！"

@路由(应用, "/api/数据", "GET")
段落 获取数据 接收 请求：
    返回 JSON响应({"消息": "你好，世界！"})

# 路径参数
@路由(应用, "/用户/<id>", "GET")
段落 获取用户 接收 请求, id：
    返回 "用户 ID: " + id

# 中间件
段落 日志中间件 接收 请求，处理：
    打印 "请求: " + 请求.路径
    返回 处理(请求)

应用.使用(日志中间件)

# 启动服务器
启动(应用, 端口=8080)

    3. 迁移步骤¶

    步骤 1：更新段言版本¶

    pip install duan==6.0.0

    步骤 2：检查代码兼容性¶

    # 运行语法检查
duan check 你的文件.duan

# 运行类型检查
duan type-check 你的文件.duan --level 表达式

    步骤 3：利用新特性优化代码¶

    异常处理升级¶

    如果你有手动错误处理的代码，可以升级为完整的异常处理：

    # 旧代码
段落 除法 接收 a, b：
    如果 b 等于 0：
        打印 "错误：除数不能为零"
        返回 空
    返回 a 除以 b

# 新代码
段落 除法 接收 a, b：
    尝试：
        返回 a 除以 b
    捕获 值异常 为 e：
        打印 "参数错误：" + 转字符串(e)
        抛出

    资源管理升级¶

    如果你有手动打开/关闭资源的代码，可以升级为上下文管理器：

    # 旧代码
设 文件 为 打开("数据.txt", "读取")
设 内容 为 文件.读取()
文件.关闭()

# 新代码
使用 打开("数据.txt", "读取") 为 文件：
    设 内容 为 文件.读取()
    # 自动关闭

    步骤 4：更新包配置文件¶

    如果你的项目使用 package.toml，确保版本号更新：

    [package]
name = "你的项目"
version = "1.0.0"
duan-version = ">=6.0.0"

    步骤 5：更新 CI/CD 配置¶

    # .github/workflows/ci.yml
- name: 安装段言
  run: pip install duan==6.0.0

    4. 破坏性变更¶

    4.1 已废弃的语法¶

    废弃语法 替换语法 说明
    令 X = Y 设 X 为 Y 统一赋值语法
    函数 名(参数): 段落 名 接收 参数： 统一函数定义语法
    《》 段落引用 段落 名 接收 统一段落定义语法

    注意: 以上废弃语法在 v6.0 中仍可运行，但会在未来版本中移除。建议尽快迁移。

    4.2 行为变更¶

    变更 旧行为 新行为 影响范围
    异常处理 仅支持字符串异常 支持异常类型层级 所有异常处理代码
    模式匹配 不支持 结构化模式匹配 新代码
    异步 基础支持 完整事件循环 异步代码
    包管理器 本地索引 远程注册中心 包搜索和安装

    5. FAQ¶

    Q: 我的 v5.x 代码能在 v6.0 上运行吗？¶

    A: 是的，v6.0 完全向后兼容 v5.x 语法。你现有的代码无需修改即可运行。新增的语法特性（异常处理完善、模式匹配、异步、装饰器、上下文管理器）是增量添加的，不会破坏现有代码。

    Q: 如何验证我的项目迁移成功？¶

    A: 运行以下命令：

    # 1. 语法检查
duan check 你的项目/主.duan

# 2. 运行测试
python -m pytest tests/

# 3. 运行项目
duan run 你的项目/主.duan

    Q: 迁移需要多长时间？¶

    A: 对于大多数项目，迁移只需 30 分钟到 2 小时： - 语法检查：5 分钟 - 代码升级（可选）：30 分钟到 2 小时 - 测试验证：10 分钟

    Q: Web 框架需要额外安装吗？¶

    A: 不需要。Web 框架内置在 duanpub 中，安装段言后即可使用：

    从 Web框架 导入 创建应用

    Q: 异步代码需要额外依赖吗？¶

    A: 不需要。异步运行时内置在段言标准库中，无需额外安装。

    Q: 装饰器如何工作？¶

    A: 装饰器语法 @装饰器 是 名 = 装饰器(名) 的语法糖。可以链式使用：

    @日志
@缓存(超时=60)
段落 计算 接收 甲：
    返回 甲 乘 甲

    等价于：

    段落 计算 接收 甲：
    返回 甲 乘 甲
计算 = 日志(缓存(超时=60)(计算))

    Q: 模式匹配支持哪些模式？¶

    A: v6.0 支持： - 字面量模式：若 42、若 "hello" - 变量模式：若 甲（绑定到变量） - 类型检查模式：若 整数 甲、若 字符串 甲 - 列表模式：若 [甲, 乙, 丙] - 字典模式：若 {"key": 值} - 守卫条件：若 甲 且 甲 大于 0 - 通配符：若 _

    Q: 如何获取帮助？¶

    A: - 查看文档：https://github.com/skywalk163/duan/tree/main/docs - 提交 Issue：https://github.com/skywalk163/duan/issues - 查看迁移指南：https://github.com/skywalk163/duan/tree/main/docs/迁移指南_v5到v6.md
