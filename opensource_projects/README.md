# 光明开源项目示例库

本目录收录了基于光明（LightLang）开发的开源示例项目，展示了光明在实际应用开发中的能力。

## 项目列表

| 项目 | 描述 | 演示知识点 |
|------|------|-----------|
| [CLI记事本](CLI记事本/) | 命令行记事本应用 | 文件IO、列表操作、字典、用户交互、CRUD |
| [简易博客引擎](简易博客引擎/) | 博客文章管理系统 | 函数模块化、数据管理、分类筛选、评论系统 |
| [待办事项管理器](待办事项管理器/) | 待办事项管理工具 | 列表操作、筛选排序、状态管理、统计功能 |

## 扩展项目

以下项目位于 `src/templates/` 目录，也可作为项目模板使用：

| 项目 | 位置 | 描述 |
|------|------|------|
| 数据分析模板 | `src/templates/data_analysis/` | 数据分析管线模板 |
| 学生管理模板 | `src/templates/student_management/` | 学生成绩管理系统 |
| Web服务模板 | `src/templates/web_service/` | HTTP Web服务模板 |

## 如何运行

```bash
# 直接运行某个项目的主文件
light run opensource_projects/CLI记事本/主.light

# 或者进入项目目录
cd opensource_projects/简易博客引擎/
light run 主.light
```

## 贡献指南

欢迎提交你的光明开源项目！请确保：
1. 项目使用 L1 白话体或 L2 文言体编写
2. 包含 `package.toml` 项目配置文件
3. 包含完整的 README 说明文档
4. 代码注释清晰，适合作为学习参考
