    光明编程语言 - 统一语法规范 v3.1¶

    版本：v3.1
    日期：2026-06-24
    状态：纯缩进式语法 + 句号可选 + 范围表达式 + 列表解构
    依据：Light 递归下降解析器 + 端到端测试验证

    重要变更（v2.0 → v3.1）¶

    变更项 v2.0（旧） v3.1（新） 说明
    块结束标记 结束。（必需） 移除 采用纯缩进式语法，类似 Python
    句号 语句必须以句号结尾 句号可选 缩进和关键字自然分隔语句
    解构赋值 仅支持元组 (甲, 乙) 支持元组和列表 [首, 余] 增加列表解构语法
    范围表达式 无 1至10 / 1到10步2 生成 range(start, end+1, step)
    无括号调用 部分支持 完全支持 动词调用可省略括号

    核心设计原则¶

    1. 纯缩进式语法¶

    使用冒号 ： 开始块，使用缩进来表示块层级，不再需要「结束」关键字。

    段落 平方 接收 数值：
  返回 数值 乘以 数值

如果 甲 大于 10：
  打印 "大于10"
否则：
  打印 "不大于10"

类 动物：
  属性 名称
  段 说话：
    打印 "叫声"

    2. 句号可选¶

    语句结尾的句号 。 是可选的，用于增强可读性而非语法必需。

    # 两种写法都正确
设 甲 为 10
设 乙 为 20。

    3. 中文无空格¶

    中文关键字和标识符之间不需要空格，保持中文书写的自然流畅。

    如果甲大于十那么打印甲

    异常处理 尝试、捕获、抛出、最终
    模式匹配 匹配、情况
    类与对象 类、继承、实现、属性、私属性、构造、新建、接口、方法
    上下文 使用、标注

    单字保留字：

    字 含义 备注

    或 逻辑或

    于 遍历连接符 遍历 甲 于 列表（等效于之）
    的 定语标记 对象的属性（等效于之）
    己 self 引用 类方法中使用
    父 super() 调用 类方法中使用
    至 范围表达式 1至10
    到 范围表达式 1到10
    步 范围步长 1到10步2

    注意：与 和 且 均可用作逻辑与运算符。且 是推荐写法，与 是兼容别名。
