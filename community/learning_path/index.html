    光明学习路径指南¶

    最后更新： 2026-08-07 适用版本： v6.2.1

    本文档为不同背景的学习者提供个性化的光明学习路径。无论你是编程新手还是有经验的开发者，都能找到适合自己的学习路线。

    目录¶

    1. 零基础入门路径
    2. 有 Python 基础路径
    3. 有英文编程语言基础路径
    4. 进阶路径
    5. 学习资源索引

    1. 零基础入门路径¶

    适合：完全没有编程经验，想从光明开始学习编程的新手

    第一阶段：编程启蒙（预计 1-2 周）¶

    目标：理解编程的基本概念，能运行第一个光明程序

    学习内容：

    主题 说明 学习时间
    安装光明 安装 Python 和光明编译器 30 分钟
    运行第一个程序 运行 hello.light，理解"打印"输出 30 分钟
    变量与赋值 理解 设 变量 为 值 的概念 1 小时
    基本数据类型 数字、字符串、布尔值 1 小时
    输入输出 使用 打印() 和 input() 1 小时

    推荐资源： - 5 分钟入门光明 — 快速上手视频脚本 - 入门教程 — 详细图文教程 - 基础示例 — 基础语法示例

    实践任务： - 编写一个程序，输出自己的名字和年龄 - 编写一个简单的加减法计算器

    第二阶段：基础语法（预计 2-3 周）¶

    目标：掌握光明的核心语法，能编写简单的交互程序

    学习内容：

    主题 说明 学习时间
    条件判断 如果 / 否则若 / 否则 2 小时
    循环语句 遍历 和 当 循环 2 小时
    列表操作 创建、访问、修改列表 2 小时
    字典操作 键值对存储和访问 2 小时
    段落（函数） 定义和调用函数 2 小时

    推荐资源： - 语法规范 — 完整语法参考 - 猜数字游戏 — 适合初学者的交互游戏 - 30 分钟入门光明 — 快速入门指南

    实践任务： - 编写猜数字游戏 - 编写待办事项列表程序

    第三阶段：实用编程（预计 3-4 周）¶

    目标：能编写实用的命令行工具，理解模块化编程

    学习内容：

    主题 说明 学习时间
    字符串操作 拼接、分割、查找、替换 2 小时
    文件读写 读取和写入文件 2 小时
    模块导入 导入 和 从...导入 1 小时
    错误处理 使用 尝试 / 捕获 处理异常 2 小时
    命令行参数 使用 sys.argv 接收参数 1 小时

    推荐资源： - 标准库文档 — 内置模块参考 - 文件搜索工具 — 命令行工具示例 - 文本统计分析工具 — 文件处理示例

    实践任务： - 编写文件搜索工具 - 编写文本统计分析工具 - 编写文件整理器

    第四阶段：综合实践（预计 4-6 周）¶

    目标：能独立完成中型项目，理解面向对象编程

    学习内容：

    主题 说明 学习时间
    类与对象 类、属性、构造、方法 3 小时
    继承与接口 类的继承和接口实现 2 小时
    数据结构 栈、队列、链表、树 3 小时
    算法基础 排序、搜索、动态规划 4 小时
    综合项目 从零完成一个完整项目 1-2 周

    推荐资源： - 算法库 — 20+ 算法实现示例 - 数据清洗工具 — 完整项目示例 - 博客系统 — Web 应用示例

    实践任务： - 编写数据可视化工具 - 编写个人博客系统 - 参与社区示例贡献

    2. 有 Python 基础路径¶

    适合：熟悉 Python，想快速掌握光明语法的开发者

    快速迁移（预计 1-3 天）¶

    光明 vs Python 语法对照：

    概念 Python 光明
    变量赋值 x = 1 设 x 为 1
    函数定义 def add(a, b): 段落 加法 接收 甲, 乙:
    条件判断 if x > 0: 如果 x 大于 0:
    for 循环 for i in items: 遍历 i 于 items:
    while 循环 while x > 0: 当 x 大于 0:
    类定义 class MyClass: 类 我的类:
    构造方法 def __init__(self): 构造:
    打印输出 print(x) 打印(x)
    列表推导 [x*2 for x in list] 暂不支持
    异常处理 try/except 尝试/捕获
    导入模块 import os 导入 文件系统
    注释 # comment # 注释

    学习重点：

    1. 中文关键字：光明使用中文关键字，如 如果、遍历、当、段落、类
    2. 语句结尾：光明建议使用 。（中文句号）结束语句
    3. 代码块：使用 ：（中文冒号）+ 缩进表示代码块
    4. 内置函数：光明有独立的内置函数体系，如 打印()、列表长度()、转字符串()
    5. 标准库：光明有独立的标准库，如 文件系统、JSON、数学 等

    推荐资源： - 光明与 Python 对比案例 — 详细对比 - 从光明到 Python — 迁移指南 - 语法规范 — 快速查阅语法

    实践任务： - 将你熟悉的 Python 小工具用光明重写 - 对比两种语言的实现差异

    深入掌握（预计 1-2 周）¶

    学习内容：

    主题 说明
    光明类型系统 了解光明的动态类型和类型注解
    光明标准库 熟悉文件系统、JSON、数学、日期时间等模块
    光明模块系统 了解模块导入和包管理
    光明 CLI 工具 掌握 light run、light compile、light pkg 等命令
    LLVM 编译 了解光明的 LLVM 后端编译能力

    推荐资源： - API 参考 — 标准库 API 文档 - 包管理器使用指南 — duanpub 包管理 - 工具链文档 — CLI 工具参考

    3. 有英文编程语言基础路径¶

    适合：熟悉 Java、C++、JavaScript 等英文编程语言，但不熟悉中文编程的开发者

    光明特色功能速览（预计 1-2 天）¶

    光明的核心特色：

    1. 全中文关键字：如果、遍历、当、段落、类、返回 等
    2. 中文标识符：变量名、函数名、类名均可使用中文
    3. 中英文混编：支持中英文关键字混用，如 打印() 等价于 print()
    4. 自然语义语法：设 姓名 为 "张三" 读起来像自然语言
    5. LLVM 编译后端：支持编译为原生可执行文件，性能接近 C
    6. 自举编译器：光明的编译器本身可以用光明编写

    与主流语言的差异：

    方面 主流语言 光明
    关键字 英文 中文
    变量声明 var x = 1 / let x = 1 设 x 为 1
    函数定义 function f() {} / def f() 段落 函数名:
    代码块 {} 或缩进 缩进（类似 Python）
    语句结束 ; 或换行 。 或换行
    泛型/模板 <T> 暂不支持泛型
    静态类型 可选类型注解 可选类型注解

    推荐资源： - 语法规范 — 完整语法参考 - 设计哲学与定位 — 了解光明的设计理念 - 统一语法规范 — 语言规范文档

    4. 进阶路径¶

    适合：已经掌握光明基础，想深入了解语言内部实现和参与核心开发的开发者

    4.1 编译器开发¶

    前置知识：Python 基础、编译原理基础

    学习路径：

    阶段 内容 参考资源
    1. 词法分析 了解光明的词法分析器如何将源码拆分为 Token 源码: src/lexer.py
    2. 语法分析 了解语法分析器如何构建抽象语法树（AST） 源码: src/parser_core.py
    3. 语义分析 了解类型检查和语义分析过程 源码: src/type_checker.py
    4. 代码生成 了解代码生成器如何生成目标代码 源码: src/code_generator.py
    5. LLVM 后端 了解 LLVM IR 生成和优化 源码: src/llvm_backend/
    6. 自举编译器 学习用光明编写的光明编译器 源码: bootstrap/

    推荐资源： - 编译器架构解析 — 架构概述 - 自举编译器架构解析 — 自举实现 - 从光明到 LLVM — LLVM 后端文档 - 开发指南 — 开发环境搭建

    4.2 标准库贡献¶

    前置知识：Python 基础、光明基础

    学习路径：

    阶段 内容 参考资源
    1. 了解标准库结构 查看 stdlib/ 目录下的模块组织 stdlib/
    2. 选择一个模块 从较小的模块开始，如 字符串工具、数学 API 文档
    3. 阅读现有代码 理解光明标准库的 Python 实现模式 现有 stdlib 源码
    4. 添加新功能 在现有模块中添加新函数 参考现有函数的实现
    5. 编写测试 为标准库功能编写测试用例 tests/

    常用标准库模块：

    模块 说明 适用于
    文件系统 文件和目录操作 初学者贡献
    字符串工具 字符串处理函数 初学者贡献
    数学 数学计算函数 初学者贡献
    JSON JSON 解析和序列化 中级贡献
    日期时间 日期和时间处理 中级贡献
    正则表达式 正则匹配 中级贡献

    4.3 示例编写¶

    前置知识：光明基础

    学习路径：

    阶段 内容 参考资源
    1. 了解示例规范 阅读示例库的 README 和 INDEX examples/README.md
    2. 选择主题 选择实用工具或有趣的应用场景 社区示例库
    3. 编写代码 遵循光明代码规范，写清晰注释 参考现有示例
    4. 编写文档 编写 README.md，包含运行说明和学习要点 参考现有 README
    5. 提交 PR 按照贡献指南提交 PR 贡献指南

    适合编写的示例类型：

    类型 难度 示例
    命令行工具 ⭐ 简单 文件搜索、文本统计、计算器
    数据处理 ⭐⭐ 中等 数据清洗、数据可视化、格式转换
    游戏娱乐 ⭐⭐ 中等 贪吃蛇、井字棋、迷宫生成
    Web 应用 ⭐⭐⭐ 较难 博客系统、API 服务、聊天室
    算法实现 ⭐⭐⭐ 较难 排序算法、图算法、机器学习基础
