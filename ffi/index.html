    C 外部函数接口（FFI）绑定指南¶

    光明支持通过 C FFI 直接调用 C 动态库（.so/.dll），实现与 C 语言生态的无缝互操作。本文档全面介绍光明 C FFI 的语法、特性和最佳实践。

    概念概述¶

    光明 C FFI 基于 Python ctypes 实现，将光明语法映射为对应的 ctypes 操作。代码生成器将 FFI 声明编译为 Python 代码，运行时模块（stdlib/FFI.py）提供辅助函数。

    成熟度演进¶

    阶段 成熟度 核心功能
    第一阶段 35% 加载库、函数声明、结构体、回调、类型映射
    第二阶段 60% 指针操作、数组操作、内存管理、错误处理
    第三阶段 80% 枚举、联合体、变长参数、回调创建、跨平台路径
    第四阶段 90%+ typedef、位域、函数指针、回调生命周期、调试、宏

    回调生命周期管理¶

    设 键 为 注册回调("我的回调", 回调函数指针)
设 cb 为 获取回调(键)
打印 列出回调()  # 所有已注册回调
注销回调(键)       # 释放回调

    回调注册表防止 Python GC 回收 ctypes 回调对象，确保 C 代码持有的回调指针始终有效。

    函数 说明
    注册回调(名称, 对象) 注册回调，返回键
    注销回调(键) 注销回调
    获取回调(键) 获取已注册回调
    列出回调() 列出所有回调键
    清理回调() 清理所有回调

    完整示例¶

    调用 libm 数学库¶

    加载库 "libm.so" 为 math

外部 段落 平方根 接收 输入: 小数 返回 小数 在 math
外部 段落 幂运算 为 "pow" 接收 底数: 小数, 指数: 小数 返回 小数 在 math
外部 段落 正弦 为 "sin" 接收 角度: 小数 返回 小数 在 math

设 根 为 平方根(25.0)
打印 "sqrt(25) = " + 根  # 5.0

设 幂 为 幂运算(2.0, 10.0)
打印 "2^10 = " + 幂  # 1024.0

设 值 为 正弦(3.14159 / 2)
打印 "sin(pi/2) = " + 值  # ~1.0

    结构体传参¶

    外部 结构体 矩形 { 宽: 小数, 高: 小数 }

外部 段落 计算面积 接收 矩形 返回 小数 在 geom

设 矩形 为 创建结构体值(矩形, 宽=10.0, 高=5.0)
设 面积 为 计算面积(矩形)
打印 面积  # 50.0

    回调排序¶

    外部 回调 排序比较器 接收 甲: 整数, 乙: 整数 返回 整数

段落 升序比较 接收 甲, 乙：
    如果 甲 < 乙：
        返回-1
    如果 甲 > 乙：
        返回 1
    返回 0

设 比较器 为 创建回调(排序比较器, 升序比较)
设 键 为 注册回调("排序", 比较器)

    架构说明¶

    文件结构¶

    src/
├── ast_nodes_v3.py      # FFI AST 节点定义（v3.2 语法）
├── ast_nodes.py         # 旧 AST 兼容节点（LLVM 后端）
├── light_parser_v3.py    # 解析器导出
├── keywords.py          # FFI 关键词定义
├── lexer.py             # 词法分析器（复合词）
├── parser_stmt.py       # FFI 语句解析器
├── code_generator.py    # Python 代码生成器
└── llvm/codegen.py      # LLVM 后端（占位）

stdlib/
└── FFI.py               # FFI 运行时模块（~700 行）

tests/
├── test_ffi.py          # 第一阶段测试（16 个）
├── test_ffi_phase2.py   # 第二阶段测试（17 个）
├── test_ffi_phase3.py   # 第三阶段测试（23 个）
└── test_ffi_phase4.py   # 第四阶段测试（28 个）

    编译流程¶

    1. 词法分析：lexer.py 识别 FFI 关键词和复合词
    2. 语法解析：parser_stmt.py 的 _parse_ffi_decl 分发到各子解析方法
    3. AST 构建：ast_nodes_v3.py 中的 FFI 节点实例化
    4. 代码生成：code_generator.py 生成 Python ctypes 代码
    5. 运行时：stdlib/FFI.py 提供辅助函数和回调注册表
