    光明 L1 白话体详细语法规范 v4.0¶

    版本：v4.0 日期：2026-08-03 状态：设计草案 基于：分层语法设计 v4.0

    概述¶

    L1 白话体是光明的入门级文体,面向青少年、教学、个人脚本、快速原型场景。

    设计哲学: - 单行优先:能用一行写的不用多行 - 无类型负担:不要求类型注解,动态类型 - 容错性强:句号、空格、冒号都可选 - 像说话一样写:主谓宾语序、因果链语法

    文件头声明: 

    # 文体: 白话
    无声明时默认 L1。

    使用的 L0 核心字¶

    L1 使用 L0 30 字中的 19 字(其余为 L2 专用):

    类别 L1 使用的字
    控制流 若 否 当 遍 跳 过 返
    定义与类型 设 段
    异常 试 捕 抛 终
    自指与连接 之 并 从 是
    逻辑与值 且 或 非 真 假 空
    组织 导(仅内置模块)

    不使用的 11 字(L2 专用):类 承 接 配 自 出 (注:类/自/承/接/配 为 OOP 工程化能力;出 为自定义模块导出,L1 不导出模块。)

    九、附注：规范未明确说明的实现细节¶

    本附件记录规范正文中未明确说明、但在当前解析器实现中已确定的行为，供用户和第三方（如门户网站、在线 Playground、教学平台）参考。

    9.1 遍历循环的语序与字典迭代语义¶

    语序口径（v7 合并裁决，2026-08）：遍历循环的语序由连接词决定，不做任何语义推断：

    连接词 语序 示例 等价 Python
    之 / 于 / 在 / 中的 变量在前 遍历 项 之 列表： for 项 in 列表:
    之为 / 为 可迭代对象在前 遍 列表 之为 项： for 项 in 列表:

    裸 之 在历史上曾被两种语序同时使用，无法靠语法消歧（遍 甲 之 乙 的 token 序列完全一致）。因此裁定：裸 之 一律为「变量在前」；需要「可迭代对象在前」时，必须写 之为 或 为。词法上 之为 是 之 + 为 两个 token，可与裸 之 做纯语法区分。

    字典迭代语义：遍历字典时迭代的是键。如需获取值，使用 典[键]。

    示例： 

    设配置={"端口":8080,"主机":"localhost"}
遍配置之为键:                   # 键 = "端口", "主机"
    打印 键 + "=" + 文本(配置[键])   # 通过键取值

    注意：此行为与 Python 的 for key in dict 一致，而非 .items() 或 .values()。取键值对需显式调用 .项()（见 docs/L2_文言体语法规范_v4.0.md 3.4 节）。

    9.2 X的 属性 与 X的 方法() 的解析规则¶

    背景：由于词法分析器将 的 视为 compound_safe 关键字，的 前后的字符会被合并为单个标识符，而非解析为 MemberAccess 节点。例如 成绩的长度 在词法阶段被识别为一个整体标识符，而非 成绩 . 长度。

    实际实现：当前在代码生成阶段通过白名单机制处理——将已知的常用属性名（如 长度、首、尾、键、值）从复合标识符中拆分出来，生成 Python 属性访问代码 对象.属性。对于其他 X的Y 形式，同样按 X.Y 的 Python 属性访问处理。

    示例： 

    设成绩=[85,92,78]
打印成绩之长度    # → 成绩.长度 → len(成绩)
打印成绩之首      # → 成绩.首 → 成绩[0]

    注意： - 在浏览器/Pyodide 环境下，X的Y 被翻译为 X.Y 的 Python 属性访问。 - 方法调用 X的 方法(实参) 在 L1 中应使用 X.方法(实参) 形式（英文句点），当前解析器对 的 + 方法调用的支持有限，建议方法调用统一使用英文句点 .。 - 此行为属于当前实现的选择，未来版本可能随解析器升级而改进为更精确的 AST 节点拆分。

    9.3 为 作为连接词的解析¶

    规范原文：为 在 L0 中是赋值标记（设 甲 为 10），在 L1 中 为 被列为 设 的别名。

    实际实现：当前解析器在 遍 X 为 Y 语法中，将 为 识别为「可迭代对象在前」的连接词，即 遍 列表 为 i 等价于 遍 列表 之为 i，生成 for i in 列表:。

    注意：为 不等价于裸 之 —— 裸 之 是「变量在前」（遍历 项 之 列表 → for 项 in 列表）。语序口径见 9.1。
