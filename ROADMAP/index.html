    光明（Light）项目路线图¶

    最后更新： 2026-08-07 当前版本： v5.5.0

    一、v5.x 系列里程碑（已完成）¶

    v5.0.0 — 基础重构与语法统一¶

    里程碑 状态 说明
    统一语法规范 v3.2 ✅ 已完成 全中文关键字风格，设/段落/如果/遍历/当 统一语法
    HM 类型推断系统 ✅ 已完成 Hindley-Milner 全局类型推断，支持泛型函数和泛型类
    三级类型检查 ✅ 已完成 签名级、变量级、表达式级类型检查
    空安全系统 ✅ 已完成 可空 类型注解与 unwrap 安全展开
    SRC 后端稳定 ✅ 已完成 手写递归下降解析器，无需 ANTLR 依赖
    基础包管理 ✅ 已完成 package.toml 项目配置，light pkg init/build/run

    v5.1.0 — 标准库扩展¶

    里程碑 状态 说明
    标准库阶段 1-7 ✅ 已完成 基础核心模块、数据结构、系统网络、编码安全、高级特性、数据科学、文本处理
    标准库阶段 8-9 ✅ 已完成 Web 与通信协议、测试与调试框架
    标准库阶段 10-11 ✅ 已完成 元编程与代码生成、安全与权限
    标准库阶段 12-14 ✅ 已完成 并发与分布式、系统工具、C FFI 外部函数接口
    60+ 标准库模块 ✅ 已完成 覆盖数学、文件、JSON、CSV、HTTP、加密、正则、FFI 等
    标准库文档 ✅ 已完成 API 参考文档和 duanpub 文档

    v5.2.0 — LLVM 后端与原生编译¶

    里程碑 状态 说明
    LLVM IR 生成 ✅ 已完成 从 AST 生成 LLVM 中间表示
    LLVM typed 后端 ✅ 已完成 类型化 LLVM 代码生成，支持整数、浮点、字符串、数组
    原生 EXE 编译 ✅ 已完成 通过 LLVM/Clang 编译为独立可执行文件
    自举编译 ✅ 已完成 自举编译器通过 LLVM 编译为原生 EXE（525KB）

    v5.3.0 — AI 工具链¶

    里程碑 状态 说明
    AI Copilot 基础命令 ✅ 已完成 light ai generate/fix/card/snippets/check
    LoRA 微调训练 ✅ 已完成 Qwen3-8B/3.5-2B LoRA/QLoRA 一键微调
    ERNIE 微调方案 ✅ 已完成 ERNIE-4.5-0.3B 轻量级翻译器
    训练数据集 ✅ 已完成 881 条 Python↔光明 v3.2 对照数据
    Ollama 模型发布 ✅ 已完成 airoot/light-translator 已上线 Ollama 官网

    v5.4.0 — 开发工具链¶

    里程碑 状态 说明
    LSP 语言服务器 ✅ 已完成 悬停提示、代码补全、跳转定义、诊断、符号搜索
    DAP 调试适配器 ✅ 已完成 VS Code 断点调试支持
    VS Code 扩展 ✅ 已完成 语法高亮、代码补全、调试支持
    交互式 REPL ✅ 已完成 命令历史、语法高亮、自动补全
    交互式教程 ✅ 已完成 10 节完整教程，支持 --repl 和 --step 模式

    v5.5.0 — 包管理器与生态增强¶

    里程碑 状态 说明
    duanpub 包管理器 ✅ 已完成 包索引、安装、依赖管理、发布流程
    light.json 配置 ✅ 已完成 项目配置文件标准
    包依赖解析 ✅ 已完成 语义化版本依赖解析
    文档系统完善 ✅ 已完成 API 文档、duanpub 文档、语法规范
    性能优化 ✅ 已完成 常量折叠、死代码消除、循环不变式外提
    增量编译 ✅ 已完成 文件变更检测、增量构建
