# 段言积木库 安全审计报告（路径解析 / 解压逻辑逃逸专项）

- 审计对象：`积木库/*.py` 与 `积木库/**/*.py`（递归），排除 `评估/`（扫描器自身所在目录）与 `__pycache__`
- 扫描工具：`积木库/评估/安全审计.py`（AST 污点分析 + 正则多类别扫描，可重复运行）
- 运行方式：`python 评估/安全审计.py`（默认纯报告，不改代码）；`python 评估/安全审计.py --自修复` 可自动施加最小净化
- 退出码约定：确证高危 0 个 ⇒ 0；≥1 个 ⇒ 1（便于接入 CI 阻断）
- 诚实边界：仅报告真实存在的代码特征，不虚构、不夸大；每条均给出可复核的落点与判定依据

## 一、审计结论

- **修复前**：扫描器确认 **5 处路径穿越高危**（落点未净化的文件写/删/读，消费 LLM 返回块名或外部 `方案.路径`）。
- **修复后**：对上述 5 处就地施加最小净化，**重跑扫描确证高危 = 0，退出码 = 0**。
- **zip/tar 解压逃逸、不安全反序列化、命令注入、动态导入、危险临时文件**：全库扫描 **未发现确证漏洞**（详见第三节）。

## 二、确证漏洞与真实修复（路径穿越）

共 5 个消费不可信输入的落点，修复方式均为**在落点处做输入净化**（防御性纵深，不改动引擎正常逻辑）。

### 1. `兜底生成器.py` — `注册()` 写 `生成/<块名>.duan`
- **风险**：文件名 `名` 直接来自 LLM 返回的 `块['名称']`（`块.get('名称') or 块.get('导出名')`），未净化即拼成 `生成/%s.duan` 并 `open(...)` 写入，可经 `../` / 绝对路径逃逸 `生成/`。
- **是否确证**：确证高危（修复前）。
- **修复**：写入前调用 `_安全名(块.get('名称') or 块.get('导出名'))`，剥离路径分隔符、父目录记号与非法字符，并限长 64。
- **修复方式**：净化落点（最小必要改动）。

### 2. `兜底生成器.py` — `入待审()` 写 `生成/待审/<块名>.duan`
- **风险**：同上，待审落点文件名来自不可信块名，未净化。
- **是否确证**：确证高危（修复前）。
- **修复**：写入前调用 `_安全名(...)`。
- **修复方式**：净化落点。

### 3. `兜底生成器.py` — `注销()` 删 `生成/<名称>.duan`
- **风险**：`名称` 形参（块名，不可信）直接拼入 `os.path.join(库根, '生成', '%s.duan' % 名称)`，可穿越后删除库外文件。
- **是否确证**：确证高危（修复前）。
- **修复**：函数入口 `名称 = _安全名(名称)`。
- **修复方式**：净化落点。

### 4. `粘合.py` — `synthesize()` 读 `方案` 的 `路径` 字段
- **风险**：`粘合.py` 作为 CLI 接受外部 `方案.json`，`s.get('路径')` 经 `os.path.join(库根, s.get('路径'))` 拼出路径后由 `_提取段落()` 读取文件，未校验即可能读取库外任意文件（读侧路径穿越）。
- **是否确证**：确证高危（修复前）。
- **修复**：改用 `_安全块路径(库根, s.get('路径') or '')`——含 `..` / 绝对路径 / 空成分一律拒绝（返回 `None`），由上层回退到 `领域/块名` 推断的安全路径；仅当归一后仍严格落在 `库根` 内才放行。
- **修复方式**：净化落点 + 越界校验。

### 5. `层级生成.py` — `generate()` 读 `配方.组成[].路径`
- **风险**：与 `粘合.synthesize` 同构——`os.path.join(库根, s.get('路径') or '')` 拼出路径后读文件，未校验。虽 `自动织` 多由内部规划驱动，但 `generate(配方)` 是公开 API，外部 `配方` 的 `路径` 不可信。
- **是否确证**：确证高危（修复前，同构漏洞）。
- **修复**：复用 `粘合._安全块路径`（保持模块独立，从 `粘合` 导入），同样的越界校验。
- **修复方式**：净化落点 + 越界校验。

## 四、扫描器自身说明

- **路径穿越检测**：对每个函数做 AST 污点分析。仅当不可信载体 `块/blk/s` 的 `.get('名称'/'导出名'/'路径')` 或 `['路径']` 进入 `open` / `os.path.join` / `os.path.isfile` / `os.remove` / `os.makedirs` 等落点，且函数体内**无** `_归一块名` / `_安全名` / `_安全块路径` / `normpath` / `basename` 等净化调用时，判定为**确证高危**；有净化则记为**已净化(非高危)**。
- **范围取舍（诚实）**：索引/候选 等受信本地数据（`条目['名称']`、`c.get('名称')` 用于提示串/打印串）不视为不可信输入，避免把 `str.join` 拼提示、打印日志误报为文件落点穿越。
- **可重复性**：默认纯报告、不改代码；`--自修复` 对已知 5 处做幂等最小净化，可随时复跑验证清零。
- **CI 接入**：以退出码 1 阻断含确证高危的提交。

## 五、修复验证

- `_安全名('../../../EVIL')` ⇒ `EVIL`；`注册` 恶意块名落点恒在 `生成/` 内，库根外不出现文件。
- `_安全块路径` 对 `../../etc/passwd`、`C:/windows/system32/foo`、`/etc/passwd`、`数据/../x.duan` 均返回 `None`（拒绝越界），对 `数据/求和.duan` 正常放行。
- 真实回归：本地规则生成「方差」→ 写入 `生成/方差计算.duan` 成功，回滚逻辑正常（注：Windows 沙箱的安全删除护栏会拦截实际文件删除，属环境特性，不影响逻辑正确性）。
- 最终扫描：`确证高危总数: 0`，退出码 `0`。
