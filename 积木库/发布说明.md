# 段言积木组合平台 v1.0 发布说明

> 发布时间：2026-08-11 ｜ 协议版本：1.0.0（`协议.md`）｜ 包：`duan-blocks 1.0.1`（演示海报/视频重发）｜ 积木库版本：v0.26（真实语料 200 条）

## 一句话

把「用户自然语言需求」映射为「预置积木的组合装配 + 契约级接线 + 内联生成 + 自动运行」，
**常态零 AI token、全离线**；能力缺失时由本地规则或 LLM 兜底生成新积木并**永久沉淀**，
下次零 token 复用。

## 快速上手

> ✅ **已发布到 PyPI**（2026-08-10）：`duan-blocks 1.0.1` — https://pypi.org/project/duan-blocks/

```bash
# 1) 安装（运行时 + 积木平台）
pip install duan            # 段言语言
pip install duan-blocks     # 积木组合平台
pip install duan-blocks[zh] # + 拼音/繁简等中文能力（可选）

# 2) 命令行：一行需求出结果（零 token）
duan-combo "对一批数字求和再算平均" --输入 "[1,2,3,4,5]"
duan-combo "把这段中文转成拼音" --输入 '"你好"' --json

# 3) Web 服务：交互式演示页 + JSON API
uvicorn duan_blocks.api:app --port 8123
#   GET  /       演示页
#   POST /combo  {"requirement":"半径5的圆有多大","input":"5"}
```

`duan-combo` 定位积木库顺序：`DUAN_BLOCKS_LIB` 环境变量 → 包内数据（wheel 自带）→ 仓库内。

## 五段式数据流

```
用户需求 → [选块] 概念图+TF-IDF 混合（零 token）
        → [校验] 本地概念交集（第二道闸）
        → [接线] 契约级类型闸门（列表[数] vs 列表[文本]）
        → [粘合] 内联为单一 .duan（成语式宏展开）
        → [运行] cli/duan.py run（rc==0 且非空输出才算成功，失败自动换候选/兜底）
```

## 兜底沉淀闭环（v1.0 演示）

```
"把5转成二进制"（库外）
  → 无候选 → 本地规则生成「二进制」积木 → 注册入库
  → 运行输出 [1, 0, 1] ✓
  → 概念补齐后同需求第二次直接命中（零 token 复用）
```

## 已知边界（诚实声明）

- 拼音/繁简/历法依赖可选第三方包（pypinyin/opencc/lunardate），缺失时对应块运行期报错；
- 真实 LLM 兜底需配置 `llm_config.json` 的 api_key（未配时本地规则覆盖 7 类常见库外意图）；
- 真·句向量仅 `DUAN_EMBED_REAL=1` 实验启用（Windows 批量不稳定）。
