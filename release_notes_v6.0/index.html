    光明 v6.0 发布说明¶

    版本: 6.0.0
    发布日期: 2026-10-29
    版本名称: 全面自举与生态建设版
    发布阶段: stable

    一、概述¶

    光明 v6.0 是自 v5.1 以来的重大版本，历时 12 周开发，涵盖编译器完备（M1）、生态建设（M2）、性能与发布（M3） 三大阶段。

    本次发布标志着光明从"可用"迈向"好用"的关键里程碑：

    • 完全自举：编译器全部功能用光明自身编写，4 轮编译收敛
    • 类型系统完善：泛型、联合类型、模式匹配
    • 生态工具链：VSCode 扩展、文档站点、在线 Playground、包注册表
    • 性能优化：LLVM 优化 Pass、增量编译、编译速度提升 50%+
    • 跨平台支持：Windows/Linux/macOS 全平台 CI

    二、新特性详解¶

    2.1 编译器完备（第1-4周）¶

    Level 8 完全自举¶

    编译器全部功能用光明自身编写，实现了真正的自举编译：

    • 4 轮编译输出完全一致（收敛验证）
    • 支持类型注解、泛型、联合类型等全部新特性
    • 自举生成代码可加载运行，完成二次编译
    • 验证了 Level 8 编译器能成功自举编译 35KB+ 的光明源码

    类型系统完善¶

    • 泛型支持：列表[T]、字典[K,V] 运行时泛型，20+ 测试用例通过
    • 联合类型：整数|文本|空 语法，支持类型守卫与类型缩小
    • 模式匹配：配 值: 若 模式1: ... 语法，支持多种模式
    • 类型别名：类型 别名 = 原始类型
    • 类型守卫：在条件分支中自动缩小类型范围

    调试体验增强¶

    • 统一错误格式：中文错误提示 + 源代码标注 + 修复建议
    • 编译错误精准定位：行号/列号精准定位，错误上下文高亮显示
    • REPL 完善：代码补全、历史记录、多行输入、语法高亮

    模块系统与包管理器¶

    • 模块依赖循环检测：编译时自动检测并报告循环导入
    • 包版本管理：语义化版本支持，版本范围约束
    • 包发布/安装流程：完整的发布、安装、卸载流程
    • 本地包注册表缓存：加速重复安装操作
    • 标准库自动加载：常用模块无需手动导入

    三、升级指南¶

    3.1 从 v5.1.0 升级¶

    # 更新到最新版本
pip install --upgrade light

# 验证版本
light --version

    3.2 代码兼容性¶

    • v5.1.0 代码无需任何修改即可在 v6.0 上运行
    • 所有新特性都是可选的，不会破坏现有代码
    • 类型注解在 v5.1 基础上完全兼容

    3.3 推荐升级步骤¶

    1. 更新编译器到 v6.0
    2. 运行现有测试套件确认无回归
    3. 逐步采用新特性（泛型、模式匹配等）
    4. 利用新的调试体验优化开发流程

    四、向后兼容性说明¶

    4.1 兼容的 API¶

    • 所有 v5.1.0 的 CLI 接口完全兼容
    • 所有编译器 API 保持向后兼容
    • 标准库 API 未做破坏性变更
    • 包管理器 CLI 命令兼容

    4.2 废弃的功能¶

    本次版本无废弃功能。

    4.3 已知不兼容¶

    • 最低 Python 版本要求提升至 3.10（推荐 3.12）
    • 部分旧版调试接口已迁移到新的调试器架构

    • 类型系统测试：20+ 用例
    • 跨平台测试：Windows/Linux/macOS 全平台
