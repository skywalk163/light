# 反跑证明：非阻塞项-3（预防性形态 + 防造假检查的可用性）

**日期**：2026-08-23
**动作**：新增 `tests/unit/test_ci_gates.py`（12 条），把三处「零命中」判据从
「未验证」变成「已验证可用」。
**结论**：四发变异各自判红，复位后全绿。判据有分辨力，不是存在性检查。

## 为什么需要这条

三处判据当前全仓 0 命中：

- `assert_quality.py::RE_TRIVIAL_GE`（`trivial-ge0`）
- `assert_quality.py::RE_RETURNCODE_IN`（`returncode-in`）
- `bootstrap_rate.py::查自导入`（自举率防造假）

0 命中本身是对的——有命中才说明有人新写了假绿。问题是 **0 命中 = 0 证据**：
这三条哪天被改坏（正则写错、判据被顺手注掉），退化过程不会有任何红灯，
因为它们本来就不亮。所以要用「造一条该被拦的东西」来证明它们还活着。

## 判据设计：每条都配一个「几乎一样但不该命中」的反例

只证「该拦的拦住了」不够——一个 `re.compile(r"assert")` 也能通过那种检查。
必须同时钉住它 key 在哪个形状上：

- `assert len(xs) >= 0` 命中 `trivial-ge0`；`>= 1` 与 `> 0` **不命中**，
  而是落到 `lower-bound`（后者是真下界，不是恒真）。
- `assert returncode in [0, 1]` 命中 `returncode-in`；`returncode == 0`
  **两条正则都不命中**（确定值断言有真信号）。
- `甲.light` 里 `导入 甲。` 判为造假；`导入 乙。` 与 `导入 Python: 甲`
  **不判**（后者是引外语库，不是段言自导入）。
- `scan_stdlib` 整条打通：造假文件即便有 `段落` 声明也不计入 `has_impl`
  （2 个文件 → `has_impl=1`，`fake_hits` 精确指向 `stdlib/甲.light`）。
- `查自导入` 读不到文件时 **抬 OSError**，而不是返回 `[]`（这是 D4 的回补点：
  原实现 `except OSError: pass`，读失败静默当「没造假」，方向偏向放行）。

## 变异反跑（每发都是：改坏 → 判红 → 复位 → 判绿）

基线（未变异）：`rc=0  12 passed`

- `RE_TRIVIAL_GE` 的 `>= 0` 改成 `>= 987`（一个不会出现的形态）
  → `rc=1  1 failed, 1 passed`
- `RE_RETURNCODE_IN` 的 `in\s*\[` 改成 `in\s*\(`（只收圆括号）
  → `rc=1  2 failed, 10 passed`
- `查自导入` 的判据摘除（`if False and 模块名 in 取模块名位置(s)`）
  → `rc=1  1 failed, 9 passed`
- `查自导入` 的 OSError 吞回去（`except OSError: return []`）
  → `rc=1  1 failed, 10 passed`

复位后：`rc=0  12 passed`

第二发第一次跑时被探针自己跳过了，原因是锚点
`assert\s+returncode\s+in\s*\[` 在文件里出现 **2 次**（`RE_RETURNCODE_IN`
与合并正则 `RE_MASTER` 各一处）。这不是失败而是探针的保护生效了：锚点不唯一
就不许改。换成整行锚点后命中 1 次，变异成立。这一点值得记住——
**同一个形态在这份脚本里有两处表达（细分正则 + RE_MASTER），改一处不够。**

## 一个当场撞上的坑：反面样例不能写在单行 docstring 里

新文件最初把类 docstring 写成单行：

```python
class TestTrivialGe0(unittest.TestCase):
    """恒真断言式：`assert len(x) >= 0`。"""
```

结果全仓门禁立刻点名 `tests/unit/test_ci_gates.py:71` 与 `:87` 判红——
`_prose_lines()` 用 tokenize 只豁免注释与**多行**字符串（`tok.end[0] >
tok.start[0]`），单行字符串照扫。也就是说：**引用假绿写法当反面教材是正当的，
但必须放进多行块**。两处 docstring 改成多行后门禁回到 474 条、无新增。

这条已写进 `test_ci_gates.py` 的模块 docstring，避免下一个人重踩。
