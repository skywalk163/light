    光明语言 AI 编程指南¶

    本文档专为 AI 设计：看了就能直接写光明（Light）代码。 版本：v7.0+（2026-09-07）· 109 个标准库模块 · 711 项原生腿能力 文件后缀：.light · CLI：light 运行 文件.light 或 lightc 编译 文件.light

    一、30 秒上手¶

    # hello.light
从 时间 导入 当前时间

段落 问候 接收 名字 = "世界"：
    返回 "你好，" + 名字 + "！现在是 " + 当前时间()

段落 主：
    打印(问候("光明"))
    打印(问候())

    运行：light 运行 hello.light

    AI 必须记住的 5 件事： 1. 全中文关键字：如果/遍历/段落/设/返回/类/从...导入 2. 缩进 4 空格，冒号后换行缩进（： 或 : 均可） 3. 函数叫 段落，不是 def/函数 4. 字符串用双引号 "..."，注释用 # 5. 模块名和函数名都是中文：从 数学 导入 平方根

    2.3 控制流¶

    # 条件

    打印("优秀")

    打印("及格")
否则：
    打印("不及格")

# 三元表达式（光明不支持 `? :`，写成「真值 如果 条件 否则 假值」）

# while 循环
当 计数 < 10：
    打印(计数)
    设 计数 为 计数 + 1

# for 循环（介词用 于/在/之/中的，推荐 于）
遍历 项 于 列表：
    打印(项)

遍历 i 在 1 到 10：
    打印(i)

遍历 i 在 0 到 长(列表)：
    打印(列表[i])

# 带步长
遍历 i 在 1 到 10 步 2：
    打印(i)    # 1, 3, 5, 7, 9

# 循环控制
遍历 i 在 1 到 10：
    如果 i % 2 == 0：
        跳过        # continue
    如果 i > 5：
        跳出        # break
    打印(i)

    5.4 带重试的网络请求¶

    从 网络请求 导入 获取, 响应文本, 响应状态码
从 时间 导入 睡眠

段落 安全获取 接收 url, 最大重试 = 3：
    设 尝试 为 0
    当 尝试 < 最大重试：
        试：
            设 响应 为 获取(url)
            如果 响应状态码(响应) == 200：
                返回 响应文本(响应)
            打印("状态码 " + 转字符串(响应状态码(响应)) + "，重试")
        捕 错误：
            打印("请求失败：" + 转字符串(错误))
        设 尝试 为 尝试 + 1
        睡眠(1 * 尝试)    # 指数退避
    返回 空

段落 主：
    设 内容 为 安全获取("https://example.com/api/data")

    九、AI 写代码检查清单（提交前自查）¶

    • 所有关键字都是中文（如果/遍历/段落/设/返回/类/从...导入）
    • 函数用 段落 名 接收 参数：，不是 def/function
    • 布尔值用 真/假，空值用 空
    • 逻辑运算用 且/或/非，不是 &&/||/!
    • 字符串用双引号 "..."
    • 列表追加用 列表.追加(项)（方法调用）
    • 创建空容器用 列表创建()/字典创建()，不是 新建列表()
    • 遍历语句介词用 于，推导式介词用 之/在
    • 类的构造函数叫 初始化，实例属性用 己.属性名
    • 模块名和函数名都是中文（从 数学 导入 平方根）
    • 输出用 打印(...)，不是 print
    • 缩进 4 空格，冒号后换行缩进
    • 异常处理用 试/捕/最终，抛出用 抛 新建 异常类型("消息")
