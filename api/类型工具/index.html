    类型工具 API¶

    模块路径：stdlib/类型工具.py 导入方式：从 类型工具 导入 函数名 或 导入 类型工具

    函数 说明
    获取数字字符映射() 获取数字字符到数值的映射字典

    型别检查(值) 获取值的类型名称
