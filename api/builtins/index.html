    显示宽度(text: str) -> int¶

    获取字符串的终端显示宽度。中文、日文等全角（CJK）及宽字符计为 2，其余字符（ASCII、半角符号等）计为 1。用于终端表格/边框对齐，避免 字符串长度 把全角字符按 1 个字符计算导致右侧错位。

    参数：

    参数名 类型 说明
    text str 待测量显示宽度的字符串

    返回： int（显示宽度）

    示例：

    显示宽度("中文abc")   # => 7  （中、文 各 2，a、b、c 各 1）
显示宽度("hello")     # => 5
显示宽度("A中")       # => 3  （A 为 1，中 为 2）

    说明：与 字符串长度 不同，后者返回字符个数（如 "中文abc" 长度为 5），而 显示宽度 返回实际占据的列数（7）。
