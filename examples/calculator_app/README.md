# 终端计算器

## 功能

支持加减乘除四则运算的终端计算器，带历史记录功能。

## 运行方式

```bash
duan run examples/calculator_app/主.duan + 5
```

## 功能说明

- **四则运算**：支持 +、-、*、/ 四种基本运算
- **历史记录**：记录每次运算操作
- **命令行参数**：通过命令行参数传入运算符和操作数

## 使用示例

```bash
# 从 0 开始加 5
duan run examples/calculator_app/主.duan + 5
# 输出: 结果: 5

# 从 0 开始乘以 3
duan run examples/calculator_app/主.duan \* 3
# 输出: 结果: 0

# 从 0 开始加 10
duan run examples/calculator_app/主.duan + 10
# 输出: 结果: 10
```
