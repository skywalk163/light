# 文件搜索工具

## 功能

按文件名关键词搜索文件，支持扩展名筛选，并显示文件大小信息。

## 运行方式

```bash
# 搜索所有 .duan 文件
duan run examples/file_search/主.duan .duan

# 搜索包含 "src" 的 .py 文件
duan run examples/file_search/主.duan .py src

# 搜索所有文件（不筛选）
duan run examples/file_search/主.duan ""
```

## 功能说明

- **关键词搜索**：按文件名关键词匹配
- **扩展名筛选**：按文件扩展名过滤结果
- **文件信息显示**：显示文件名和文件大小
- **结果统计**：显示搜索到的文件总数
