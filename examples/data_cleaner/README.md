# 段言数据清洗工具

一个用段言（DuanLang）编写的实用数据清洗与处理工具，支持 CSV/JSON 数据的清洗、分析和格式转换。

## 功能特点

### 数据清洗
- **去除空值行**：自动删除包含空值的记录行
- **去除重复行**：基于行内容去重
- **日期标准化**：统一日期格式为 `YYYY-MM-DD`（支持 `YYYY/MM/DD`、`YYYY.MM.DD`、`YYYY年MM月DD日` 等格式）
- **数字标准化**：去除货币符号（¥、$、￥）和千分位分隔符
- **异常值检测**：基于 3 倍标准差检测异常值并标记
- **文本清洗**：去除首尾空白、多余引号

### 数据分析
- **基本统计**：每列的非空值数、类型判定、均值、中位数、最大值、最小值、标准差
- **频次统计**：分类列的频次和百分比统计
- **数值分布**：自动分区间统计并生成 ASCII 柱状图
- **相关性分析**：皮尔逊相关系数计算

### 格式转换
- CSV → JSON
- JSON → CSV
- CSV → Markdown 表格

### 数据处理
- 数据过滤（支持等于、大于、小于、包含等操作符）
- 数据排序（升序/降序）
- 列选择（只保留指定列）

## 安装要求

- 段言语言环境（DuanLang）
- 无需额外依赖

## 使用方法

### 基本用法

```bash
# 使用默认参数运行（读取 sample_data.csv，输出 JSON）
duan run 主程序.duan

# 指定输入和输出文件
duan run 主程序.duan --input sample_data.csv --output result.json

# 输出为 Markdown 表格
duan run 主程序.duan -i sample_data.csv -o report.md -f markdown

# 输出为 CSV
duan run 主程序.duan -i sample_data.csv -o cleaned.csv -f csv
```

### 高级用法

```bash
# 指定清洗操作
duan run 主程序.duan -i sample_data.csv -op 去除空值,去除重复,标准化数字,检测异常

# 数据排序
duan run 主程序.duan -i sample_data.csv --sort 薪资:降序

# 数据过滤
duan run 主程序.duan -i sample_data.csv --filter 城市 等于 北京

# 列选择
duan run 主程序.duan -i sample_data.csv --select 姓名,年龄,城市,薪资

# 组合使用
duan run 主程序.duan -i sample_data.csv -o result.md -f markdown --sort 薪资:降序 --filter 城市 等于 北京
```

### 命令行参数

| 参数 | 简写 | 说明 |
|------|------|------|
| `--input` | `-i` | 输入文件路径（支持 .csv） |
| `--output` | `-o` | 输出文件路径 |
| `--format` | `-f` | 输出格式：json、csv、markdown |
| `--operations` | `-op` | 清洗操作列表，逗号分隔 |
| `--sort` | `-s` | 排序：`列名:升序` 或 `列名:降序` |
| `--filter` | | 过滤：`列名 操作符 值` |
| `--select` | `-c` | 列选择：`列1,列2,列3` |
| `--help` | `-h` | 显示帮助信息 |

### 清洗操作列表

通过 `--operations` 参数指定要执行的清洗操作，多个操作用逗号分隔：

- `去除空值` - 删除空值行
- `去除重复` - 删除重复行
- `标准化日期` - 统一日期格式
- `标准化数字` - 统一数字格式
- `检测异常` - 异常值检测
- `清洗文本` - 文本清洗

如果不指定操作列表，将执行所有清洗步骤。
