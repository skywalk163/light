# 数据处理管道示例

演示如何使用段言标准库实现一个完整的数据处理管道（ETL），涵盖数据读取、清洗、聚合、存储和导出的全流程。

## 功能

- **读取 CSV** — 解析 CSV 文件为结构化数据
- **数据清洗** — 去除重复记录、过滤无效数据、标准化字段名、清洗数值格式
- **聚合分析** — 按字段分组统计：总和、平均值、最大值、最小值、计数
- **SQLite 存储** — 自动建表并将清洗后的数据存入数据库
- **JSON 导出** — 导出清洗后的数据为 JSON 格式
- **综合报告** — 生成包含数据摘要、聚合统计的完整报告

## 用法

```bash
# 使用默认样本数据
duan run examples/data_pipeline/pipeline.duan

# 指定自定义 CSV 文件
duan run examples/data_pipeline/pipeline.duan 我的数据.csv
```

## 管道流程

| 步骤 | 模块 | 说明 |
|------|------|------|
| 1/6 | CSV 读取 | 解析 CSV 文件，支持自定义分隔符 |
| 2/6 | 数据清洗 | 去重、过滤、标准化字段名、清洗数值格式（去除货币符号等） |
| 3/6 | 聚合分析 | 按分组字段计算汇总统计量 |
| 4/6 | SQLite 存储 | 自动推断字段类型，创建表并插入数据 |
| 5/6 | 数据库查询 | 从 SQLite 查询并展示数据验证结果 |
| 6/6 | JSON 导出 | 导出数据文件 + 综合报告 |

## 输出文件

| 文件 | 说明 |
|------|------|
| `output.json` | 清洗后的数据（JSON 格式） |
| `pipeline_report.json` | 完整的数据处理报告（含摘要和聚合统计） |
| `pipeline.db` | SQLite 数据库文件 |

## 涉及的语言特性

- `段落` 函数定义与多返回值
- `设` 变量声明
- `如果`/`否则若`/`否则` 条件判断
- `遍历` 列表和字典遍历循环
- `当` 条件循环（`跳过`/`跳出`）
- `尝试`/`捕获` 异常处理
- `导入` 标准库模块（文件系统、JSON、数据库）
- 字典和列表的增删改查
- 字符串处理（分割、替换、去除空格、大小写转换）
- 文件读写操作
- 数据库操作（建表、插入、查询）
- `转字符串`/`转整数`/`转浮点数` 类型转换
- `真`/`假` 布尔值
- `空` 空值处理
