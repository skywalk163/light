# 文本统计分析工具

## 功能

统计文本文件的字符数、行数、单词数，生成格式化统计报告。

## 运行方式

```bash
# 统计自身文件
duan run examples/text_stats/主.duan examples/text_stats/主.duan

# 统计其他文件
duan run examples/text_stats/主.duan 你的文件.txt
```

## 功能说明

- **字符统计**：统计文件的总字符数
- **行数统计**：统计文件的总行数
- **单词统计**：统计文件的总词数（按空白字符分隔）
- **格式化输出**：生成整齐的统计报告

## 代码统计

- `主.duan`：约 50 行

## 学习要点

- 文件读取（读取文件）
- 字符串操作（字符串长度、字符串获取）
- 字符遍历和条件判断
- 多重返回值
- 错误处理（文件不存在检查）
