# 贪吃蛇游戏

用段言语言编写的终端贪吃蛇游戏，支持 WASD 方向控制、分数显示、碰撞检测和最高分记录。

## 功能

- 方向控制（WASD / 方向键）
- 墙壁碰撞检测
- 自身碰撞检测
- 实时分数显示
- 最高分持久化存储（highscore.txt）
- 分数进度条
- 游戏结束评价
- 多局游戏支持

## 运行

```bash
cd examples/snake_game
duan run 主.duan
```

## 操作说明

| 按键 | 操作 |
|------|------|
| W / ↑ | 向上移动 |
| S / ↓ | 向下移动 |
| A / ← | 向左移动 |
| D / → | 向右移动 |
| Q | 退出游戏 |

## 项目结构

- `主.duan` — 主程序入口，包含所有游戏逻辑
- `highscore.txt` — 自动生成的最高分记录文件
- `README.md` — 项目说明文档
