# 猜数字游戏

用段言编程语言实现的经典猜数字游戏。电脑随机生成一个 1-100 之间的数字，玩家通过输入猜测数字，根据提示（太大/太小）逐步逼近正确答案。

## 功能

- 电脑随机生成目标数字（1-100 范围）
- 玩家输入猜测数字，获取"太大"或"太小"的提示
- 限制最大尝试次数（10 次）
- 猜中后根据尝试次数给出评价
- 支持多局游戏，统计总局数、总尝试次数和最佳成绩
- 友好的终端交互界面

## 用法

```bash
# 运行游戏
duan run examples/games/guess_number/主.duan
```

## 游戏流程

1. 程序显示游戏标题和规则说明
2. 电脑随机生成一个 1-100 之间的数字
3. 玩家在提示下输入猜测数字
4. 程序给出"太大"或"太小"的提示
5. 重复步骤 3-4，直到猜中或用完次数
6. 显示本局成绩和评价
7. 询问是否再来一局
8. 结束时显示统计汇总

## 涉及的语言特性

- `段落` 函数定义与参数传递
- `设` 变量声明
- `如果`/`否则若`/`否则` 条件判断
- `当` 条件循环
- `随机整数` 随机数生成
- `input()` 终端输入
- `打印` 终端输出
- 字符串拼接与格式化
- 算术运算（除法、比较）
