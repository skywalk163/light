# 终端数据可视化工具

## 功能

使用 ASCII 字符在终端中绘制柱状图和折线图，无需任何外部依赖库。

## 运行方式

```bash
duan run examples/data_visualization/主.duan
```

## 功能说明

- **柱状图**：绘制柱状图展示数据大小对比，数值显示在柱状条右侧
- **折线图**：使用 `*` 字符绘制折线图，展示数据变化趋势
