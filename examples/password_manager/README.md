# 段言密码管理器

一个使用段言编写的密码生成和存储管理工具。

## 功能

- **生成随机密码**：可指定长度的强随机密码
- **生成易记密码**：生成易于记忆的形容词+名词+数字组合密码
- **保存密码**：将服务、用户名、密码保存到本地文件
- **查看密码**：搜索和查看已保存的密码
- **密码强度检测**：评估密码强度并给出改进建议

## 运行

```bash
python -m cli.duan run examples/password_manager/主.duan
```

## 安全提示

- 密码以明文形式存储在本地 `passwords.txt` 文件中
- 此示例仅用于演示目的，生产环境请使用加密存储
- 建议使用专用密码管理器管理重要密码
