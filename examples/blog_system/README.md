# 简易博客系统

用段言语言编写的简易博客系统，基于 Web 框架构建，支持文章列表、查看文章、发布文章功能。使用 JSON 文件作为持久化存储。

## 功能

- 首页文章列表（按时间倒序排列，含摘要）
- 文章详情页（显示完整内容）
- 发布新文章（支持标题、标签、内容）
- 标签分类
- 空状态占位
- 404 错误页面
- JSON 文件持久化存储

## 运行

```bash
cd examples/blog_system
duan run 主.duan
```

启动后访问 http://127.0.0.1:8080

## 项目结构

- `主.duan` — 主程序入口，包含所有功能实现
- `posts.json` — 自动生成的文章数据存储文件
- `README.md` — 项目说明文档
