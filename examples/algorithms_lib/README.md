# 算法库（20+ 算法实现）

用段言语言编写的算法库，包含 20+ 种经典算法和数据结构的实现。

## 功能

### 排序算法（6种）
- 冒泡排序
- 选择排序
- 插入排序
- 归并排序
- 快速排序
- 堆排序

### 搜索算法（3种）
- 二分查找
- 广度优先搜索（BFS）
- 深度优先搜索（DFS）

### 图算法（3种）
- Dijkstra 最短路径
- Floyd-Warshall 算法
- 拓扑排序

### 动态规划（3种）
- 斐波那契数列（DP）
- 0/1 背包问题
- 最长公共子序列（LCS）

### 数据结构（5种）
- 栈（Stack）
- 队列（Queue）
- 链表（Linked List）
- 二叉搜索树（Binary Search Tree）
- 最小堆（Min Heap）

## 运行

```bash
cd examples/algorithms_lib
duan run 主.duan
```

## 项目结构

- `主.duan` — 主程序入口，包含所有算法实现和测试
- `README.md` — 项目说明文档
