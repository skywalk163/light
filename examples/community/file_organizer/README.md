# CLI 文件整理器

按文件类型自动分类整理文件的命令行工具，支持预览模式、自定义规则和进度显示。

## 运行方式

```bash
# 整理当前目录
duan run examples/cli_tool/file_organizer.duan

# 预览模式 - 查看整理结果但不实际移动文件
duan run examples/cli_tool/file_organizer.duan ./下载 --dry-run

# 使用自定义规则
duan run examples/cli_tool/file_organizer.duan ./桌面 -c 我的规则.json

# 指定输出目录
duan run examples/cli_tool/file_organizer.duan ./文档 -o ./整理后

# 查看帮助
duan run examples/cli_tool/file_organizer.duan --help
```

## 功能说明

- **目录扫描**：递归扫描指定目录，列出所有文件
- **智能分类**：按扩展名自动归类到 Images、Documents、Archives、Audio、Video、Code、Executables 等类别
- **预览模式**（`--dry-run`）：模拟执行，不实际移动文件，安全可靠
- **自定义规则**（`--config`）：支持 JSON 配置文件自定义分类规则
- **进度显示**：实时显示处理进度条和百分比
- **汇总报告**：完成后显示详细的统计信息（总文件数、已移动、已跳过、错误数）
- **自动跳过**：忽略隐藏文件和系统文件，避免误操作
- **错误处理**：完善的异常捕获和友好错误提示

## 学习要点

- **命令行参数解析**：支持 `--dry-run`、`--config`、`--output`、`--help` 等选项
- **文件系统操作**：`列出文件()`、`是文件()`、`文件大小()`、`创建目录()`、`移动文件系统()` 等
- **字典与列表操作**：复杂嵌套字典和列表的增删改查
- **JSON 序列化**：`解析JSON()`、`序列化JSON()` 配置管理
- **进度条实现**：终端字符动画进度显示
- **字符串处理**：`分割字符串()`、`转小写()`、`最后索引()`、`字符串获取()` 等
- **错误处理**：`尝试` / `捕获` 异常处理机制
- **模块化设计**：配置管理、文件操作、显示逻辑分离
