# 天气应用

天气查询与历史记录程序，演示段言中的 API 调用模拟、数据格式化和文件读写操作。

## 运行方式

```bash
cd examples/weather_app
duan run main.duan
```

## 功能说明

- 查询指定城市的天气信息（温度、天气状况）
- 格式化输出查询结果
- 保存查询历史记录到本地文件
- 查看历史查询记录
- 演示多模块项目结构

## 学习要点

- **多模块项目**：使用 `从 ... 导入` 组织多文件项目
- **标准库导入**：`导入 文件系统`、`导入 JSON` 使用标准库
- **字典操作**：字典的创建、读取和序列化
- **文件操作**：`文件存在()`、`读取文件()`、`追加文件()` 等文件 API
- **异常处理**：`尝试` / `捕获` / `最终` 异常处理机制
- **字符串操作**：字符串拼接、格式化输出
- **模块导出**：使用 `导出` 关键字暴露模块接口
