# 社区开源项目示例库

欢迎来到光明社区示例库！这里汇集了光明开发者社区贡献的开源项目示例，展示光明在真实场景中的应用。

## 如何贡献

我们热烈欢迎社区成员提交自己的光明项目示例。提交方式如下：

### 1. 准备你的项目

请确保你的项目：
- 使用光明 4.0dev 或更新版本语法
- 包含必要的说明文档（README.md）
- 代码注释清晰，适合他人学习和参考
- 附有运行说明和依赖说明

### 2. 提交方式

**方式一：Pull Request（推荐）**

1. Fork 本仓库
2. 在 `examples/community/` 目录下创建你的项目文件夹
3. 提交 Pull Request 到 `4.0dev` 分支

**方式二：提交 Issue**

在 GitHub 仓库提交 Issue，附上你的项目链接和简介，我们会审核后收录。

### 3. 项目结构规范

```
examples/community/你的项目名/
├── README.md          # 项目说明（必填）
├── 主.light            # 主程序文件（必填）
├── package.toml       # 包配置（可选）
└── 其他文件.light      # 辅助模块（可选）
```

### 4. README 模板

```markdown
# 项目名称

## 简介
用一两句话描述你的项目。

## 功能
- 功能1
- 功能2

## 运行方式
python -m cli.light 主.light

## 依赖
（如有外部依赖，请列出）

## 作者
你的名字 / GitHub ID
```

## 收录标准

- 代码能够正常运行
- 使用光明 4.0dev 语法
- 具有学习或参考价值
- 不包含恶意代码或敏感内容
