# 贪吃蛇游戏

经典贪吃蛇游戏的终端实现，支持 WASD 方向控制、实时分数显示、碰撞检测和最高分记录。

## 运行方式

```bash
duan run examples/community/snake_game/主.duan
```

或者直接运行源文件：

```bash
duan run examples/snake_game/主.duan
```

## 功能说明

- **方向控制**：WASD 或方向键控制蛇的移动
- **墙壁碰撞检测**：撞墙即游戏结束
- **自身碰撞检测**：撞到自己即游戏结束
- **实时分数显示**：每吃到一个食物加 10 分
- **最高分持久化**：最高分自动保存到 `highscore.txt`
- **分数进度条**：可视化显示分数进度
- **游戏结束评价**：根据分数给出不同等级评价
- **多局游戏支持**：结束后可选择再来一局
- **退出功能**：按 Q 随时退出游戏

## 操作说明

| 按键 | 操作 |
|------|------|
| W / ↑ | 向上移动 |
| S / ↓ | 向下移动 |
| A / ← | 向左移动 |
| D / → | 向右移动 |
| Q | 退出游戏 |

## 学习要点

- **游戏循环**：使用 `当` 循环实现游戏主循环
- **列表操作**：`列表追加()`、`列表插入()`、`列表弹出()` 实现蛇身增删
- **字典结构**：用字典表示蛇身段、食物等坐标对象
- **随机数生成**：`随机整数()` 生成食物位置
- **文件持久化**：`读取文件()`、`写入文件()` 保存最高分
- **终端绘图**：使用 Unicode 字符绘制游戏画面
- **碰撞检测算法**：墙壁碰撞和自身碰撞的逻辑实现
- **输入处理**：`input()` 获取用户输入并进行方向控制
- **状态管理**：游戏初始化、运行、结束、重玩的状态流转
