## 如何提交新示例

我们欢迎社区成员提交自己的段言作品！请按照以下步骤操作：

### 提交流程

1. **Fork** 本仓库到你的 GitHub 账号
2. 在 `examples/community/` 目录下创建你的项目文件夹
3. 项目文件夹内包含：
   - 主程序文件（`主.duan` 或 `main.duan`）
   - `README.md` 项目说明文档
   - 其他辅助文件（如有）
4. 提交 **Pull Request** 到本仓库的 `main` 分支
5. 等待社区评审

### 项目命名规范

- 文件夹命名：小写英文，单词间用下划线连接，如 `my_tool`
- 主文件命名：`主.duan` 或 `main.duan`
- 说明文档：`README.md`

### README 模板

每个示例的 README 应包含以下内容：

- **运行方式** — 如何运行此示例
- **功能说明** — 应用的主要功能和使用方法
- **代码行数统计** — 各文件的行数信息
- **学习要点** — 通过此示例可以学到哪些段言特性
- **扩展建议** — 如何进一步改进和扩展

## 评选标准

提交的示例将按照以下标准进行评审：

| 维度 | 权重 | 说明 |
|------|------|------|
| 实用性 | 40% | 是否能解决实际问题，具有实际使用价值 |
| 代码质量 | 30% | 代码结构清晰、逻辑严谨、命名规范、注释完整 |
| 创意性 | 20% | 构思新颖，或用段言以独特方式实现了有趣的功能 |
| 文档完整性 | 10% | README 说明清晰，包含运行方式、功能说明和使用示例 |
