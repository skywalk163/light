# 数据管道

完整的 ETL（Extract-Transform-Load）数据处理管道，演示 CSV 读取、数据清洗、聚合分析、SQLite 存储和 JSON 导出的全流程。

## 运行方式

```bash
# 使用默认样本数据
duan run examples/data_pipeline/pipeline.duan

# 指定自定义 CSV 文件
duan run examples/data_pipeline/pipeline.duan 我的数据.csv
```

## 功能说明

### 管道流程（6 步）

| 步骤 | 模块 | 说明 |
|------|------|------|
| 1/6 | **CSV 读取** | 解析 CSV 文件为结构化数据，支持自定义分隔符 |
| 2/6 | **数据清洗** | 去重、过滤无效记录、标准化字段名（中英文映射）、清洗数值格式（去除货币符号） |
| 3/6 | **聚合分析** | 按字段分组统计：总和、平均值、最大值、最小值、计数 |
| 4/6 | **SQLite 存储** | 自动推断字段类型，创建表并插入数据 |
| 5/6 | **数据库查询** | 从 SQLite 查询并展示数据验证结果 |
| 6/6 | **JSON 导出** | 导出清洗后的数据文件 + 综合报告 |

### 输出文件

| 文件 | 说明 |
|------|------|
| `output.json` | 清洗后的数据（JSON 格式） |
| `pipeline_report.json` | 完整的数据处理报告（含摘要和聚合统计） |
| `pipeline.db` | SQLite 数据库文件 |

## 学习要点

- **段言标准库**：`导入 文件系统`、`导入 JSON`、`导入 数据库` 三大标准库
- **多返回值函数**：段落函数返回多个值
- **字典与列表操作**：复杂数据结构的增删改查
- **字符串处理**：`分割字符串()`、`替换字符串()`、`去除空格()`、`转小写()`、`连接字符串()` 等
- **数据库操作**：`打开数据库()`、`创建表()`、`插入()`、`查询()`、`获取字段名()` 等
- **JSON 序列化**：`解析JSON()`、`序列化JSON()` 数据导出
- **文件操作**：`读取文件()`、`写入文件()`、`文件存在()` 等
- **异常处理**：`尝试` / `捕获` 完善的错误处理
- **循环控制**：`遍历`、`当`、`跳过`、`跳出` 多种循环模式
