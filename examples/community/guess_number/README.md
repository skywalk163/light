# 猜数字游戏

带分数的猜数字交互游戏，适合初学者入门段言编程。

## 运行方式

```bash
duan run examples/community/guess_number/主.duan
```

或者直接运行源文件：

```bash
duan run examples/games/guess_number.duan
```

## 功能说明

- 电脑随机生成一个 1-100 之间的数字
- 用户通过命令行输入猜测数字
- 每次猜测后提示"太大"或"太小"
- 猜中后显示尝试次数
- 根据尝试次数给出评价（天才、不错、继续加油等）
- 支持多局游戏，可反复挑战

## 学习要点

- **段落定义**：使用 `段落` 关键字定义函数
- **变量声明**：使用 `设` 声明变量
- **条件判断**：`如果` / `否则若` / `否则` 分支结构
- **循环控制**：`当` 循环的使用
- **用户输入**：`input()` 获取用户输入
- **随机数生成**：`随机整数()` 生成指定范围随机数
- **类型转换**：`转整数()`、`转字符串()` 类型转换
- **字符串拼接**：使用 `+` 拼接字符串
- **递归调用**：函数内部调用自身实现重玩
