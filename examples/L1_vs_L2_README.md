# 光明 v4.0 — L1 白话体 vs L2 文言体 对照与入门指南

光明 v4.0 最大的变化之一：**同一套 30 个 L0 核心字，写出两种文体**，
就像中文可以写白话文也可以写文言文，它们共享底层汉字，只是风格和使用场景不同。

## 快速选择（10 秒版）

| 你现在的场景 | 选哪种文体？ |
|-------------|-------------|
| 第一次学编程，15 岁以下，或者在教青少年 | ✅ **L1 白话体** |
| 写一次性脚本、Demo、验证想法、50 行以内小程序 | ✅ **L1 白话体** |
| 写长期维护的项目、和同学/同事协作 | ✅ **L2 文言体** |
| 写标准库、SDK、第三方包，给别人用 | ✅ **L2 文言体** |
| 写大项目（> 1000 行），需要类型检查、模块拆分、重构 | ✅ **L2 文言体** |

## 同一套核心字（L0 30字）共享

L1 和 L2 **共享所有 30 个 L0 核心字**：

| 分类 | 30 核心字（全部通用） |
|------|---------------------|
| 控制流 | 若、否、当、遍、跳、过、返 |
| 定义与类型 | 设、段、类、承、接、配 |
| 异常 | 试、捕、抛、终 |
| 自指与连接 | 自、之、并、从、是 |
| 逻辑与值 | 且、或、非、真、假、空 |
| 组织 | 导、出 |

→ 学会 L1，再学 L2 **不用重新学关键字**，只是学"更正式的写法"，就像从日常说话过渡到写论文。

## 对照：同一个功能的 L1 vs L2 写法

### 1. 条件判断（若 / 否）

```light
# 文体: 白话 (L1)
设 分数 = 86
若 分数 >= 90:
    打印 "A 优秀"
否:
    若 分数 >= 60:
        打印 "及格"
    否:
        打印 "加油"

# 因果链语法（只有 L1 推荐写这种口语化、单行）
温度大于30, 打印 "开空调"
```

```light
# 文体: 文言 (L2)
# 相同的若/否字，但可以结合 配 模式匹配
设 分数: 数 = 86
配 真:
    情况 分数 >= 90: 打印 "A 优秀"
    情况 分数 >= 80: 打印 "B 良好"
    情况 分数 >= 60: 打印 "C 及格"
    其他:           打印 "D 加油"
```

### 2. 循环（当 / 遍 / 跳 / 过）

```light
# 文体: 白话 (L1)
设 果 = ["苹果","香蕉","橘子"]
遍 果 为 x:
    打印 "我爱", x
```

```light
# 文体: 文言 (L2)
# 一样的遍、当。差别在：变量可以加类型，和 for 配套的列表推导
设 水果: 列 = ["苹果","香蕉","橘子"]
设 爱水果: 列 = ["我爱"+f 遍 水果 为 f]
遍 爱水果 为 句:
    打印 句
```

### 3. 函数定义（段）

```light
# 文体: 白话 (L1)
段 圆面积(半径):
    返 3.14159 * 半径 * 半径

打印 圆面积(3)
```

```light
# 文体: 文言 (L2)
# 加：参数类型 + 返回类型注解。重构时 IDE 能给提示、类型检查能发现 bug
段 圆面积(半径: 数) -> 数:
    设 圆周率: 精 = 3.14159_26535_89793
    返 圆周率 * 半径 * 半径

打印 圆面积(3)
```

### 4. 类 / 继承 / 接口（类 / 承 / 接 / 自）

```light
# 文体: 白话 (L1)
# L1 不强调"类"概念，新手直接用 列 和 典 就能完成所有任务。
# （类 关键字依然可用，但 L1 教学中通常等到第 15 课之后才介绍）
设 小明 = {"姓名":"小明","年龄":12}
打印 小明["姓名"]
```

```light
# 文体: 文言 (L2)
# 类/承/接/自 全部上场，适合大项目的模块化、复用、多态
接 可打印:
    段 字符串化() -> 串

类 人:
    设 姓名: 串
    段 构造(姓名: 串): 自之姓名 = 姓名

类 学生 承 人 接 可打印:
    设 学号: 串
    段 构造(姓名: 串, 学号: 串): 人之构造(自, 姓名); 自之学号 = 学号
    段 字符串化() -> 串: 返 "学生["+自之学号+"] "+自之姓名
```

### 5. 异常（试 / 捕 / 抛 / 终）

```light
# 文体: 白话 (L1)
# L1 教学里简单介绍 "出错了不要崩"，不强调自定义抛
试:
    设 n = 转成整数(用户输入)
捕 错:
    打印 "请输入数字哦"
```

```light
# 文体: 文言 (L2)
# 自定义异常信息 + 严格的终收尾
段 录入成绩(科目: 串, 分数: 数) -> 空:
    若 分数 < 0 或 分数 > 100:
        抛 "分数越界: " + 转成字符串(分数)
    自之成绩[科目] = 分数

试:
    s1之录入成绩("艺术", 105)
捕 e:
    日志_错误(e)
终:
    文件_关闭(f)
```

### 6. 模块系统（导 / 出）

```light
# 文体: 白话 (L1)
# L1 默认不推荐拆多文件；全部写在一个文件里，降低心智负担。
# （导/出 可用，但教学不强调）
```

```light
# 文体: 文言 (L2)
# 导 import，出 export，模块是大型项目必备：
# 学生模块.light:
出 学生, 人, 可打印

# 主程序.light:
导 学生模块 出 学生, 人, 可打印
```

## 快速切换指南

### 怎么声明文体？

在文件**第一行**或**前几行**加：
```light
# 文体: 白话    → 解析器走 L1 宽容模式，接受中文句号/中文冒号
# 文体: 文言    → 解析器走 L2 严格模式，类型注解必须合法
```
（不声明时，默认按照"出现了类型注解就是 L2，否则 L1"自动推断。）

### 怎么从 L1 升级到 L2？

三步走，**不用一次性改完**，可以逐函数升级：

1. **第 1 步：加类型注解**
   把 `段 圆面积(半径):` → `段 圆面积(半径: 数) -> 数:`
   把 `设 分数 = 86:` → `设 分数: 数 = 86:`

2. **第 2 步：把列/典 升级成 类**
   当字典里固定有 3+ 个键（比如 姓名/年龄/学号/成绩），考虑封装成类，配合 `自之` 访问。
   当多个类共享字段（人→学生/老师），考虑 `承` 继承。
   当要对一组对象统一调用某方法，考虑 `接` 接口（可打印、可排序、可序列化）。

3. **第 3 步：拆分模块 + 导/出**
   大文件按功能拆（学生模块/统计模块/报表模块），互相 `导` 进来使用。

### 怎么从 L2 降级回 L1？（一般不推荐，但可以）
- 去掉类型注解（`: 数` / `-> 数`）
- 把 类 → 典，把 承/接 → 字典组合
- 多文件合并成一个文件

## 写在最后：为什么要分 L1/L2？

> 中文只有 3000 常用字，却能支撑所有学科。光明只有 30 个核心字（L0），
> 却能支撑「青少年快速入门」和「高手写商用大项目」——关键就是文体分层。

给新手看 L1 的代码，不会被 `承` `接` `配` `类型注解` 吓跑；
给高手用 L2 的代码，不会因为缺类型、缺模块系统而难维护。
两者共享 30 个核心字——学过 L1，再学 L2，几乎是零额外心智负担。
