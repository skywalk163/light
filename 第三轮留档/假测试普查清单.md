## 2. 上界断言式 / 恒真断言式（集合为空时恒真，最隐蔽）

**定性**：`assert len(x) <= N` 在 `x` 为空集合时恒真——等于没测。第三轮活案例
`tests/test_agent_loop_light.py:231-247` 的 `TestMaxRounds`：`events` 被 `:152` 的
`捕获 错误` 吞掉而恒空，`assert len(events) <= 3` 空转通过。

**当前命中（3 条，全为上界）**：

| file:line | 文本 | 定性 | 处置 |
|---|---|---|---|
| `tests/test_agent_loop_light.py:247` | `assert len(events) <= 3` | **最危险**：依赖事件总线修复后才真有信号 | 等 A3 修事件总线后改为 `== 实际订阅数` 或 `>= 1` |
| `tests/_test_hm_inference.py:525` | `assert len(inf.errors) <= 3, …` | 错误数上界，空则恒真 | 改为 `== 0` 或具体预期 |
| `tests/unit/test_error_formatter.py:251` | `assert len(result) <= 2` | 同上 | 改为具体预期数量 |

恒真断言式（`assert len(x) >= 0`）当前 **0 条**。门禁仍扫，新增即红。
