    《段言数据处理入门》视频脚本¶

    版本： v6.0 时长： 35 分钟 适用对象： 有基础编程概念的段言学习者 前置知识： 基础语法（变量、列表、字典、函数）

    片头（0:00 - 0:30）¶

    画面： 段言 Logo 动画 + 标题「段言数据处理入门」

    背景音乐： 节奏明快、科技感的电子音乐

    旁白： "数据是编程的核心。今天我们用 35 分钟，学习如何使用段言读取、清洗、分析和可视化数据，构建一个完整的数据处理管道。"

    第一部分：从 CSV/JSON 读取数据（0:30 - 5:30）¶

    1.1 数据格式简介（0:30 - 1:30）¶

    画面： 展示 CSV 和 JSON 格式对比

    CSV 格式（表格数据）：
姓名,年龄,城市,得分
张三,25,北京,92
李四,30,上海,85
王五,22,广州,78

JSON 格式（结构化数据）：
[
  {"姓名": "张三", "年龄": 25, "城市": "北京", "得分": 92},
  {"姓名": "李四", "年龄": 30, "城市": "上海", "得分": 85},
  {"姓名": "王五", "年龄": 22, "城市": "广州", "得分": 78}
]

    旁白： "数据处理的第一步是读取数据。CSV 和 JSON 是最常见的两种数据格式。CSV 以表格形式存储，每行一条记录，逗号分隔字段。JSON 以键值对形式存储，结构更灵活。"

    关键点强调： - CSV 适合表格数据 - JSON 适合嵌套结构 - 两种格式的互转关系

从 文件系统 导入 读取, 写入, 文件存在

段落 读取CSV 接收 文件路径:
    如果 非 文件存在(文件路径):
        打印 "错误：文件不存在 - " + 文件路径
        返回 []

    设 内容 为 读取(文件路径)
    设 行们 为 内容.分割("\n")

    如果 长度(行们) < 2:
        打印 "错误：文件为空或只有标题行"
        返回 []

    # 解析标题行
    设 标题行 为 行们[0].去除空格()
    设 字段们 为 标题行.分割(",")

    # 去除字段名中的空格
    设 索引 为 0
    遍历 字段们 为 字段:
        字段们[索引] = 字段.去除空格()
        索引 = 索引 + 1

    # 解析数据行
    设 数据 为 []
    设 行索引 为 1
    当 行索引 < 长度(行们):
        设 行 为 行们[行索引].去除空格()
        如果 行 != "":
            设 值们 为 行.分割(",")
            设 记录 为 {}

            设 列索引 为 0
            当 列索引 < 长度(字段们) 且 列索引 < 长度(值们):
                记录[字段们[列索引]] = 值们[列索引].去除空格()
                列索引 = 列索引 + 1

            数据.追加(记录)
        行索引 = 行索引 + 1

    打印 "成功读取 " + 转字符串(长度(数据)) + " 条记录"
    返回 数据

# 读取数据
设 销售数据 为 读取CSV("sales_data.csv")
打印 "前3条记录："

    打印 销售数据[索引]

    2.2 缺失值处理（6:30 - 8:30）¶

    画面： 编写缺失值处理函数

    # 数据清洗模块

段落 清洗数据 接收 数据:

    设 丢弃数 为 0

段落 修复记录 接收 记录:

    # 检查必要字段
