    光明 L2 文言体详细语法规范 v4.0¶

    版本：v4.0 日期：2026-08-03 状态：设计草案 基于：分层语法设计 v4.0

    概述¶

    L2 文言体是光明的工程级文体,面向商用项目、库开发、团队协作、性能关键代码、大型工程场景。

    设计哲学: - 显式优于隐式:类型、参数、返回值、可见性都明确 - 符号优于文字:算术用 + - * /,与国际通用符号一致 - 缩进强制:块结构清晰,适合大文件阅读 - 静态检查:支持类型检查器、IDE 友好 - 工程化:模块、可见性、错误处理、接口、继承完善

    文件头声明: 

    # 文体: 文言

    使用的 L0 核心字¶

    L2 使用 L0 全部 30 字(L1 的 19 字 + L2 新增/强化 11 字):

    类别 L2 新增/强化的 11 字
    定义与类型 类 承 接 配
    自指与连接 自
    组织 出
    其他 (L1 也用但 L2 用法更全的算)

    L1 的 19 字:L2 全部支持,且更严格要求(如类型注解)。共 30 字: 若 否 当 遍 跳 过 返 | 设 段 类 承 接 配 | 试 捕 抛 终 | 自 之 并 从 是 | 且 或 非 真 假 空 | 导 出

    一、词法¶

    1.1 标识符命名¶

    基本规则:中文字、英文字母、数字、下划线_,不以数字开头。

    命名约定(文言体工程规范):

    类别 约定 示例
    变量名 蛇形(下划线) 学生列表、user_name
    段/函数名 蛇形或动词开头 计算总分、process_data
    类名 首字母大写(驼峰) 学生、User、HTTPRequest
    接口名(接) 可 开头 or 驼峰 可打印、Printable
    常量名 全大写下划线 最大重试、MAX_RETRY
    私有成员 下划线开头(约定) _缓存、_internal

    1.2 标点符号¶

    主用英文标点(与国际工程规范对齐),中文标点作为别名:

    . 之、.(主用) 属性访问、方法调用

    [] [] 列表、索引、切片
    {} {} 字典、命名空间
    ""、'' ""、'' 字符串字面量

    // 无 单行注释(或用 #)
    /* */ """ """ 块注释

    二、类型系统¶

    2.1 基础类型¶

    类型名 含义 示例
    数 整数/浮点数统一(默认) 10、3.14
    整 整数(可选,优化用) 42
    符 浮点数(可选,优化用) 2.718
    串 字符串 "hello"、"你好"
    布 布尔 真、假
    列 列表/数组 [1, 2, 3]
    典 字典/哈希表 {"a": 1}
    空 空值单元类型 空
    值 任意类型(动态) 不推荐,但可用

    2.2 泛型参数¶

    说明：泛型下标标注（列[数]、典[串, 数]、列[列[数]]）属于 v4.0 设计目标， 当前 parser 尚未实现类型下标语法，照此书写会 ParseError。故本节代码块以 text 标注，仅作设计示意；实际编写时请用不带下标的 列/典（见 1.5、2.1）。

    # 列表泛型
设 数列表: 列[数] = [1, 2, 3]
设 串列表: 列[串] = ["a", "b"]

# 字典泛型: 典[键类型, 值类型]
设 学生成绩: 典[串, 数] = {"张三": 95, "李四": 82}

# 嵌套泛型
设 矩阵: 列[列[数]] = [[1,2],[3,4]]

    3.1 算术运算符(符号为主,中文为别名)¶

    运算符 中文别名 优先级 示例
    ** 幂 最高 2**10
    -x 取负 -5
    * / % // 乘 除 取余 整除 高 10/3
    + - 加 减 低 甲+乙

    3.2 比较运算符¶

    运算符 中文别名 示例
    == 等于、是 甲==10、甲是10
    != 不等于 甲!=5
    < > 小于 大于 甲<10
    <= >= 小于等于 大于等于 甲<=10

    多值比较(Python 风格): 

    段 评级 接收 分数：
    配 真:
        情况 90 <= 分数 <= 100: 返 "优"
        情况 60 <= 分数 < 90:  返 "及格"
        其他: 返 "不及格"

    口径（v7 单 J 裁定）：以实现与语料为权威。配 的分支引导词是 情况， 默认分支是 其他（否/否则 亦可），主语后不带 之。 早期文档写的 配 X 之: 若 …: 否: … 从未被 parser 支持，照那样写会 ParseError。

    3.3 逻辑运算符¶

    3.6 三目表达式¶

    说明：三目（条件表达式）是 v4.0 设计目标，parser 目前没有任何条件表达式产生式 （若 … : … 否: …、若 … 则 … 否 …、若 … 那么 … 否则 … 均 ParseError）， 故本节代码块以 text 标注仅作设计示意。当前等价写法是条件语句： 设 等级: 串 = "不及格" 再 若 分数 >= 60: / 设 等级 为 "及格"。

    设 等级: 串 = 若 分数 >= 60: "及格" 否: "不及格"

    4.3 条件语句¶

    // if / elif / else(elif 的实装写法是 否则若 / 否则如果;单字 否若 未被 parser 支持)
若 分数 >= 90:

    4.4 循环语句¶

    // 当循环(while)
设 i: 数 = 0
当 i < 10:
    打印(i)
    设 i 为 i + 1

// 当循环兼任 for(类似 Go)
设 列表 = [3, 1, 4]
设 和: 数 = 0
设 i: 数 = 0
当 i < 列表.长度:
    设 和 为 和 + 列表[i]
    设 i 为 i + 1

// 遍历(foreach)
遍 列表 之为 元素:
    打印(元素)

// 遍历字典
设 配置: 典 = {"端口": 8080, "主机": "localhost"}
遍 配置.项() 之为 键, 值:
    打印(键 + "=" + 串(值))

// 循环控制
设 i: 数 = 0
当 i < 10:
    设 i 为 i + 1
    若 i % 2 == 0: 过    # 跳过偶数
    若 i > 7: 跳         # 提前跳出
    打印(i)

    4.5 模式匹配(配)¶

    口径（v7 单 J 裁定，以实现与语料为权威）：分支引导词是 情况， 守卫词是 若/如果（写在 情况 模式 若 条件:），默认分支是 其他（否/否则 亦可），主语后不带 之。生成 Python match/case。 早期文档的 配 X 之: / 若 分支 / 当 守卫 写法从未被 parser 支持，已在下方更正。

    // 基础模式匹配（配 + 情况 + 其他；情况后接布尔表达式即为守卫）
段 评级(分数: 数) -> 串:
    配 真:
        情况 分数 >= 90: 返 "优"
        情况 分数 >= 80: 返 "良"
        情况 分数 >= 60: 返 "及格"
        其他: 返 "不及格"

// 解构匹配（守卫用 若）
设 对: 列 = [3, 5]
配 对:
    情况 [0, 0]: 打印("原点")
    情况 [x, y] 若 x == y: 打印("对角线")
    情况 [x, y]: 打印("坐标:{x},{y}")

// 类型匹配：情况 <类型名> <绑定名>（parser 的 type_check 模式，发射 case 类型() as 绑定）
类 学生:
    段 构(自): 过

配 变量:
    情况 学生 甲: 打印("学生")
    情况 整数 甲: 打印("数字")
    情况 字符串 甲: 打印("字符串")
    其他: 打印("其他")

    类型匹配只认 情况 类型名 绑定名: 两个标识符相邻的形状,不写 是—— 情况 是 数: 会 ParseError。内置类型请写全名 整数/字符串 （短别名 数/串 未进 codegen 的类型映射表,会发射 case 数() 并在运行期 NameError）。 每个 情况 只带一个模式,不支持 情况 2, 3 逗号多值,也不支持 情况 2 | 3。

    4.6 异常处理¶

    // try-catch-finally 完整形式(捕获变量用 为 绑定,不是 是)
段 除法(甲: 数, 乙: 数) -> 数:
    若 乙 == 0:
        抛 ValueError("除数不能为零")
    返 甲 / 乙

试:
    设 结果 = 除法(10, 0)
捕 ValueError 为 e:
    打印("错误:" + e.消息)
捕 IndexError 为 e:
    打印("越界:" + e.消息)
捕 异常 为 e:
    打印("其他异常:" + e.消息)
终:
    打印("清理完成")

// 自定义异常
类 业务异常 承 异常:
    段 __init__(自, 代码: 数, 消息: 串):
        超.__init__(消息)
        自.错误代码 = 代码

试:
    抛 业务异常(404, "未找到")
捕 业务异常 为 e:
    打印("错误[{e.错误代码}]: {e.消息}")

    5.3 装饰器(段修饰)¶

    // 装饰器是高阶函数:接收一个 段,返回一个 段
